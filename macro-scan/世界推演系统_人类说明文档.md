## 一、这是什么

**世界推演系统**是一个跑在家里 NAS 上的世界理解引擎——持续监测全球宏观、地缘、社会、气候等多维度状态，并对任意假设情景进行传导路径推演。

每天定时从 FRED、akshare、GPR地缘风险指数、GDELT 等渠道拉取数据，结合知识库让 AI 写出当日世界形势报告，通过 ntfy 推送到手机。支持随时输入任意情景触发假设推演，并给出有历史依据的推演报告。

**V3.7.0 当前能力：**
- 🌍 **5域推演**：经济金融 / 地缘政治 / 社会政治 / 气候自然灾害 / 文化摩擦，48个快捷别名
- 📚 **知识库**：558 个 .md 文件，4156 个 RAG 向量块（BAAI/bge-m3），传导路径 20 条（含2条跨域复合路径）
- 🔍 **情境自动涌现**：每日 06:30 自动从 news.db 发现新话题，推送待确认（阈值 1.5x，v3.5.61）
- 📊 **历史案例库**：32 条（含1条反例），覆盖气候/社会/政治/文化/地缘域
- 🔗 **文档同步保障**：pre-commit 联动检查 + 每日 watchdog 巡检，防止代码和文档漂移
- 🌏 **GRV 11维向量**：台海/中美/俄欧/中东能源/全球合成 + 气候/灾害/制裁/地震/能源电网/日元货币，每日 06:10 稳定写出
- 🤖 **macro-sim 联动**：GRV 告警时自动触发 12-Agent Monte Carlo 仿真（v3.5.34+）
- 📡 **弱信号共振（R01~R10）**：10条规则，R09/R10（社会压力/文化摩擦）v3.5.62 修复启用，Staging 模式运行中
- 🧪 **天玑校验闭环**（v3.7.0 新增）：预测自动存档 → 月度 Brier/BSS 评分 → 玉衡权重矩阵反哺
- 📰 **叙事预处理**（v3.7.0 新增）：11维叙事桶，staleness衰减，防务RSS（Al Jazeera/Defense One），注入天璇推演
- 📐 **慢变量**（v3.7.0 新增）：IRP通胀体制概率 / UCRI中美博弈强度 / GCI地缘格局指数，月频更新

## 八、故障排查

| 现象 | 可能原因 | 处理方法 |
|:-----|:---------|:---------|
| Web UI 打不开 | 容器未暴露端口/未安装fastapi | 确认 `docker ps` 中 `0.0.0.0:8899->8899/tcp`；`pip install fastapi uvicorn` |
| 手机收不到报告 | 容器异常/ntfy网络 | `docker ps`；`docker logs macro-scan-macro-scan-1` |
| 报告只有数据没叙事 | MiniMax-M3/MiMo/SiliconFlow 故障 | 查 `us_daily.log`；检查 key；确认 `USE_EXTERNAL_LLM=1` |
| ask/narrative 无响应 | ntfy_listener 异常 | 查 `listener.log` |
| 定时任务未执行 | scheduler 进程异常 | `tail -10 /var/log/macro-scan/scheduler.log`；重启容器 |
| 假设推演置信度低 | GRV/GPR 数据未入库 | 检查 `data/grv_latest.json`；手动跑 `fetch_gpr.py` |
| 知识库检索结果空 | 向量索引不存在 | `build_rag_index.py` 重建 |

### macro-sim 联动（GRV 告警时自动触发）

GRV 单日涨幅 ≥6 或台海 ≥68 时，macro-scan 在推演结束后自动写 `sim_trigger.json`，macro-sim daemon 检测到后：

1. 读取当前 GRV / FRED / 新闻数据
2. 前50个月历史校准（LLM 自动调参）
3. Monte Carlo × 100，预测未来 24 个月演化路径
4. 生成 Markdown 报告写入 `docs/仿真报告/`
