## 一、背景与目标

### 1.1 现状盲区

系统目前的信号体系全部覆盖金融/地缘数字信号：

| 信号类别 | 当前状态 |
|:---------|:--------|
| 金融市场（VIX/信用利差/日元套利）| ✅ 已覆盖 |
| 台海/中美/俄欧地缘（GRV）| ✅ 已覆盖 |
| 能源价格（EIA/FIRMS）| ✅ 已覆盖 |
| 宗教冲突/族群暴力 | ❌ 完全盲区 |
| 社会动荡/大规模抗议 | ⚠️ GDELT 有采集但未利用 |
| 政权更迭/政治危机 | ❌ 完全盲区 |
| 文化/价值观摩擦 | ❌ 完全盲区 |

**根因**：`_compute_gdelt_scores()` 完全未读取 col 15/25（Actor 类型字段），导致宗教组织（REL）、族群组织（ETH）、叛乱武装（REB）发起的事件和普通政府行为无法区分。`protest` 维度已计算但仅取美德法3国，其余9国数据全部丢弃。

### 1.2 目标

1. **探测**：GDELT 新增宗教冲突/政权不稳两个维度；ALERT_KEYWORDS 新增3个新闻类别
2. **传导**：propagation_paths.yaml 新增4条社会类路径，带历史量化锚点
3. **推演**：signal_synthesizer 新增 R06/R07 规则，双重门槛（新闻+GDELT）才触发
4. **注记**：晨报自动加"社会压力监测"段落（无需 LLM，纯数据展示）

### 1.3 置信度天花板

社会/宗教/政治类推演**最高🟡，永不升🟢**。

原因：传导路径5-8步（金融类仅2-3步），step3以后大量 `llm_inference`，历史校准样本稀少，结局高度情境依赖。推送 title 固定前缀 `[社会推演🟡]`，body 首行固定免责声明。

```python
def _get_social_pressure_note() -> str:
    """读 gdelt_scores.json，生成3-5行社会压力注记。失败静默返回空字符串。"""
    try:
        import json, os
        from optim_config import DATA_DIR
        path = os.path.join(DATA_DIR, "gdelt_scores.json")
        if not os.path.exists(path):
            return ""
        with open(path, encoding="utf-8") as f:
            data = json.load(f)
        scores = data.get("scores", {})
        lines = []
        for dim, label in [("religious_conflict","宗教族群"), ("regime_change","政权不稳"), ("protest","社会抗议")]:
            top = sorted(scores.get(dim, {}).items(), key=lambda x: -x[1])[:2]
            if top and top[0][1] >= 20:
                lines.append(f"- {label}：" + "、".join(f"{c}={v:.0f}" for c, v in top))
        if not lines:
            return ""
        return "\n\n---\n**区域社会压力监测**（GDELT，仅供参考）\n" + "\n".join(lines)
    except Exception:
        return ""
```

## 五、关键风险与注意事项

### 5.1 GDELT 新维度 scale 是估算值

`religious_conflict` scale=8000 / `regime_change` scale=5000 均为保守估算，无实测峰值数据。

**后续校准方法**（运行3个月后）：

```bash
docker exec macro-scan-macro-scan-1 python3 -c "
import json
lines = open('/app/data/gdelt_history.jsonl').readlines()
vals = [json.loads(l)['scores'].get('religious_conflict',{}) for l in lines]
all_v = [v for d in vals for v in d.values()]
print('max:', max(all_v) if all_v else 'no data')
"
```

若 max < 50，scale 需要下调（否则信号永远很低，规则永不触发）。

### 5.2 hypothesis_engine.py 的路由枚举

实施前必须确认：

```bash
grep -n "scenario_type\|SOCIAL\|POLITICAL\|RELIGIOUS\|allowlist\|UnknownScenario" \
    /app/hypothesis_engine.py | head -20
```

若有 `raise` 或 `allowlist` 硬性枚举，需同步修改，否则新路径触发时报错。

### 5.3 _WATCH_COUNTRIES 扩展的性能影响

扩展5个国家后，每次 GDELT 扫描的匹配行数约增加 30-40%。首次运行观察 scan 耗时，若超过预期可暂时注释掉高流量国家（IND 是最大来源）。

### 5.4 R07 初期关闭原因

`religious_conflict` 维度的 scale 参数是估算值，gdelt_threshold=40 实际对应的真实事件强度未知。过早开启可能导致永不触发（scale 过高）或频繁误触发（scale 过低）。等2周数据积累后，用 gdelt_history.jsonl 确认分值范围再决定是否开启。
