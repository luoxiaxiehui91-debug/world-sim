## 1. M-1 news_geo.json 事件图层 — 修复后验收标准（EARS）

> 通用前置：修复实施后 news_geo.json 已由新逻辑生成、nginx 无缓存（`no-cache` 已配）、前端已刷新。每条 AC 的判定按 §6 门禁汇总。

### 1.1 数据非空与总体结构

- **[AC-M1-01]** When 新 feed 完成一次成功生成，系统 **必须** 产出非空 `news_geo.json`，且顶层结构为 `{schema_version, updated, events[]}`（§2.7），`events` 数组事件数 `N` **必须**满足 `100 ≤ N ≤ 2000`。
  验证：
  ```bash
  ssh nas 'python3 -c "import json; d=json.load(open(\"/vol2/1000/software/macro-scan/data/news_geo.json\")); N=len(d.get(\"events\",[])); print(\"events=\",N,\"schema=\",d.get(\"schema_version\"),\"updated=\",d.get(\"updated\")); assert 100<=N<=2000"'
  ```
  > 下限 100 的判定依据：jsonl 24h 原始 14,534 条（B4），即便强过滤（国家白名单 + 高提及 + 按坐标聚合），24h 窗聚合后点数仍应显著 >100；**若 N<100 视为实现过弱（过滤/聚合过头），>2000 视为实现未约束（将触发前端截断）**。

- **[AC-M1-02]** When 生成 `news_geo.json`，系统 **必须** 为每条事件输出契约字段且**不允许静默丢弃关键字段**：`id`（GDELT GLOBALEVENTID，建议前缀 `gdelt-`）、`lat`/`lng`（4 位小数）、`event_type`、`intensity`（0-100）、`country` 必填；`mention_count`/`theme`/`location_name`/`event_date` 有值即填、无值可省略。
  验证：
  ```bash
  ssh nas 'python3 -c "
  import json; d=json.load(open(\"/vol2/1000/software/macro-scan/data/news_geo.json\"))
  req={\"id\",\"lat\",\"lng\",\"event_type\",\"intensity\",\"country\"}
  bad=[e[\"id\"] for e in d[\"events\"] if not req.issubset(e)]
  print(\"缺字段事件数=\",len(bad)); assert not bad
  sample=d[\"events\"][0]; print(sorted(sample.keys()))"'
  ```

### 1.2 字段值域与契约合规

- **[AC-M1-03]** When 任一条事件被写出，系统 **必须** 保证 `lat ∈ [-90,90]` 且 `lng ∈ [-180,180]` 且均为有限数，坐标 **应该** 统一 4 位小数（≈11m，§2.7）；越界/非有限的事件 **必须** 整条丢弃（不画到 (0,0)）。
  验证：
  ```bash
  ssh nas 'python3 -c "
  import json, math
  ev=json.load(open(\"/vol2/1000/software/macro-scan/data/news_geo.json\"))[\"events\"]
  bad=[e[\"id\"] for e in ev if not (-90<=e[\"lat\"]<=90 and -180<=e[\"lng\"]<=180 and math.isfinite(e[\"lat\"]) and math.isfinite(e[\"lng\"]))]
  nd=[e[\"id\"] for e in ev if not (abs(e[\"lat\"]*1e4-round(e[\"lat\"]*1e4))<1e-6 and abs(e[\"lng\"]*1e4-round(e[\"lng\"]*1e4))<1e-6)]
  print(\"越界=\",len(bad),\"非4位小数=\",len(nd)); assert not bad and len(nd)==0"'
  ```

- **[AC-M1-04]** When 事件强度被写出，系统 **必须** 输出 `intensity` 为 **0-100 归一化数值**（契约 §2.7：归一口径由天枢给定，前端不二次折算），不得直接透传 Goldstein 原始值（-10~10）。判定：`intensity` 无负值、max≤100，且分布有区分度（**max ≥ 60 且 P90 ≥ 40**，证明高强度档位未被压缩丢失；若 >90% 的点集中在 0-20 视为归一公式失效，见 RSK-2）。
  验证：
  ```bash
  ssh nas 'python3 -c "
  import json, statistics
  ev=json.load(open(\"/vol2/1000/software/macro-scan/data/news_geo.json\"))[\"events\"]
  v=sorted(e[\"intensity\"] for e in ev)
  assert v[0]>=0 and v[-1]<=100
  print(\"min/max/P50/P90/P99=\",v[0],v[-1],v[len(v)//2],v[int(len(v)*0.9)],v[int(len(v)*0.99)])
  assert v[-1]>=60 and v[int(len(v)*0.9)]>=40"'
  ```

- **[AC-M1-05]** When `event_type` 被写出，系统 **必须** 输出域 ⊆ **五枚举** {`conflict` / `protest` / `disaster` / `political` / `unknown`}，未知 CAMEO 映射输出 `unknown`（**不输出原始码**）；修复方案应附 CAMEO → 四枚举映射表（arch/data 定稿），QA 抽验映射一致性。**unknown 过渡期规则（lead 裁决 2026-08-11）**：部署后 **48h 过渡期**内允许 `unknown` 占位（jsonl 只累积 10 天，补 EventCode 字段后窗口自然换新，旧记录无码即 unknown）；**部署满 48h 后** `unknown` 占比 **必须 < 5%**（硬判定，见下方脚本 `--enforce-unknown` 模式）。
  验证（脚本含两种模式：默认域校验 + `--enforce-unknown` 满 48h 后强制 unknown<5%）：
  ```bash
  ssh nas 'python3 -c "
  import json, collections
  ev=json.load(open(\"/vol2/1000/software/macro-scan/data/news_geo.json\"))[\"events\"]
  c=collections.Counter(e[\"event_type\"] for e in ev)
  DOMAIN={\"conflict\",\"protest\",\"disaster\",\"political\",\"unknown\"}
  assert set(c)<=DOMAIN, f\"越枚举: {set(c)-DOMAIN}\"
  uk=c.get(\"unknown\",0)/len(ev) if ev else 1.0
  print(\"event_type 分布=\",dict(c),\" unknown占比=\",round(uk*100,2),\"%\")
  # 部署满48h后运行：python3 verify_data.py --enforce-unknown 时断言 uk<0.05"'
  ```

- **[AC-M1-06]** When `country` 被写出，系统 **必须** 非空率 ≥ **99%**（jsonl `country_iso` 当前 100% 非空，B8），且值应能映射到 ISO 国家码（`iso_for_fips` 兜底后仍缺失的按 `full_name` 推导或置"未知"，但不得造成大比例缺失）。
  验证：
  ```bash
  ssh nas 'python3 -c "
  import json
  ev=json.load(open(\"/vol2/1000/software/macro-scan/data/news_geo.json\"))[\"events\"]
  miss=[e[\"id\"] for e in ev if not (e.get(\"country\") or \"\").strip()]
  print(\"country 缺失率=\", round(len(miss)/len(ev)*100,2), \"%\"); assert len(miss)/len(ev)<0.01"'
  ```

- **[AC-M1-07]** When 事件 id 被写出，系统 **必须** 保证 `events[]` 内 id 全局唯一（jsonl 实测 100% 唯一，B2），否则前端 `newsgeo:<id>` 点位 id 撞车会丢点。
  验证：
