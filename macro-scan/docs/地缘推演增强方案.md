## 一、背景与根因

### 1.1 现状

系统定位是"世界推演引擎"，但当前地缘数据极度薄弱：

- 历史类比层：13条危机 CSV 全是金融/经济危机，台海推演类比到"1973石油危机"（关键词误命中）
- 实时信号层：GDELT 分数已采集（`gdelt_scores.json`），但**假设推演从未读这个文件**
- 知识库层：大国博弈框架是静态文档，无传导路径量化结构
- 传导路径层：完全依赖 LLM 凭感觉，无数据锚点

### 1.2 代码核查结论（精确）

| 模块 | 现状 | 问题 |
|:-----|:-----|:-----|
| GDELT 采集 | `scan_weak_signals.py` 694-900行，每6h运行，军事/制裁/抗议/合作4维度分 | 存入 `data/gdelt_scores.json`，假设推演从未读取 |
| GDELT→MC调制 | `get_gdelt_geo_modifier()` 已把 GDELT 转为 MC 参数，日常报告在用 | `build_hypothesis_prompt()` 没有注入 GDELT 信号 |
| 历史类比 | `calibrate_mc.py` 返回13条案例 | 全是金融危机；无 `crisis_category`/`taiwan_strait_relevance` 字段 |
| 类比路由 | `hypothesis_engine.py` 用关键词评分 | GEO 情景 CSV 里无地缘案例，必然命中错误类比 |
| GPR 指数 | 未接入 | FRED 上有 `GPRC_TWN`/`GPRC_CHN` 等，SERIES 列表未加 |
| ACLED | 未接入 | — |
| 传导路径库 | 未建立 | — |

### 1.3 质量崩溃点定位

台海推演的误差在两个节点积累：

**Step 2（历史类比）—— 第一个严重失真**
类比到"1973石油危机"，传导机制完全不同：
- 1973：产油国禁运 → 物理供应缺口 → 能源涨价 → 通胀 → 衰退
- 台海L2：军事对峙 → 保险费跳升 → 航运绕道 → 半导体断供 → 制造业停产

**Step 4（LLM推理）—— 决定性崩溃**
LLM 接收到错误类比 + 概念性知识库 + 无结构化地缘信号，输出数字是"受过良好教育的猜测"。连续推演3次，结果漂移可达 ±30%。

## 二、台海情景的特殊性

台海与所有历史先例存在根本差异，**不能用"局部战争"模板建模**：

- 台积电生产全球 ~90% 先进芯片（≤7nm），无法在3-5年内建立替代产能
- 冲击形状是"全球工业供应链心脏病发作"，而非局部能源中断
- 必须区分三个子情景，传导路径完全不同：

| 子情景 | 触发标志 | T+0冲击 | 持续时间 | 历史类比 |
|:-------|:---------|:--------|:---------|:---------|
| 外交危机 | 言辞升级/演习/ADR折价>10% | VIX+10，台股-10% | 1-4周 | 2022年佩洛西访台 |
| 封锁 | 商业航运停滞/保险费翻倍 | 半导体期货历史性波动 | 3-12个月（有库存缓冲） | 无直接先例 |
| 武装冲突 | — | 全球工业供应链断裂 | 数年 | 无直接先例 |

**2022年8月2-10日（佩洛西访台）是系统回测锚点**：所有接入的信号应有可观测异动，可用来验证信号灵敏度。

### M2：推演质量深化（3-4周，M1完成后）

#### M2-1：置信度4维框架

在 `hypothesis_engine.py` 新增 `compute_confidence()` 函数：

```
综合置信度 = 调和平均(
    历史锚定强度   × 40%  # 有多少相关地缘历史案例支持
    传导路径完整性 × 25%  # 传导链中有数据支持的步骤占比
    信号时效性     × 20%  # 当前GRV是否与情景方向一致
    内部一致性     × 15%  # wiki历次推演的变异系数
)
```

报告输出格式替代现有简单 🟢🟡🔴：

```
综合置信度：0.42 / 1.00
  历史锚定  ████░░░░░░ 0.35  [1996案例样本极小]
  传导路径  ████░░░░░░ 0.40  [半导体→GDP缺数据]
  信号时效  ██████░░░░ 0.62  [台海GRV处于中位]
  内部一致  ███████░░░ 0.72  [历次推演σ=4.2%]
```

升格条件（🔴→🟡）：≥3条相关历史案例，类比质量>0.6；因果链>70%有数据；
≥5次推演，变异系数<20%。

永远不能升格到🟢：核威慑升级、政权崩溃、推演跨度>12个月。

#### M2-3：LLM Prompt 深度重构

`build_hypothesis_prompt()` 重构为6节明确结构：

```
[HYPOTHESIS]  假设前提 + 烈度 + GRV当前信号
[WIKI]        scenario_wiki 历史推演记录
[PATHS]       传导路径库命中结果（结构化）    ← M1-3新增
[CRISIS]      历史危机类比（含tw_rel排序）
[KB]          知识库RAG检索
[DATA]        实时经济指标 + GDELT分数快照

输出指令：要求LLM在推理中显式引用[PATHS]步骤编号；
         禁止将 source:llm_inference 的步骤作为定量依据
```

#### M2-4：校准闭环（M2完成后3-6个月等待真实事件）

当真实地缘事件发生后，人工或半自动：
1. 在 scenario_wiki 对应条目填写 `actual_outcome`
2. 将 `verified: false` 改为 `verified: true`
3. 计算预测误差，分解到哪条传导路径偏差最大
4. 生成参数调整建议（人工审核后才写入传导路径库）

传导路径库的 `source` 字段经 ≥3 次真实事件校验后可升级为
`empirically_calibrated`，对应置信度信号灯从 🔴 升为 🟡。

## 七、关于 LLM 的正确定位

来自行业实践研究的核心结论：

- LLM **不应该**直接输出"台海冲突概率是X%"，这个数字没有校准意义
- LLM 在**框架生成**和**情景叙事**（Step 4/7）最有价值
- **信号层**（GRV向量）和**传导层**（路径库）才是硬约束，LLM 消费这些约束后生成叙事
- Qwen3.5-27B 相比 GPT 系列，对中文政策文件和官媒论述理解更准确，当前选择正确
- 连续推演3次结果漂移 ±30% 不是 bug，是 LLM 随机性特性——解法是增加数据锚点，不是改模型

**GDELT 归一化机制（v3.5.35 新增）：**

GDELT 原始分（量纲 0–12）在进入 blend 前，先通过 `_normalize_gdelt_score()` 归一化到 0–100：

```
score_norm = min(raw / p95_ref × 100, 100)
```

基准 `_GDELT_P95`（gdelt_history.jsonl 实测 p95，211条，2026-05-21~07-08）：

| 热点 | countries | p95_ref |
|:-----|:----------|:--------|
| russia_europe | RUS+DEU+UKR | 1.42 |
| taiwan_strait | TWN+CHN | 0.65 |
| us_china | USA+CHN | 9.85 |
| mideast | IRN+SAU+ISR | 2.50 |

0 基点保留"无事件=0"的物理含义；无基准时返回 None（让 blend 走 GPR-only 路径，避免量纲混入）。

**持续冲突 floor（v3.5.35 新增）：**

`_apply_conflict_floor()` 在 blend 后执行，防止 GPR 因媒体疲劳（战争常态化）导致维度虚低：

- 检查 news.db 近30天 geopolitics 类别中含俄乌关键词的文章数
- ≥5篇时：`russia_europe = max(russia_europe, 35.0)`
- 数据库不可用时非阻断跳过
