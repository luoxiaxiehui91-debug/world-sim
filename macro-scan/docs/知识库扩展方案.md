## 一、问题诊断（方案背景）

以 `1900 hypothesis 厄尔尼诺导致东南亚粮食危机` 为例，当前调用链问题：

```
ScenarioParser → 无 CLIMATE 类别 → 误分类为 MACRO
        ↓
get_historical_analogies() → 匹配 1973油价/2020新冠（跑偏）
        ↓
RAG 检索 → 无气候文档 → 返回 LEI/央行框架（无关）
        ↓
build_hypothesis_prompt() → 无气候路径 → 凑合用能源路径
        ↓
LLM 推演 → 错误类比 + 无关背景 → 质量极差 🔴
```

另一个缺口：6个静态情况 + news.db 积累的数千篇文章完全脱节，新兴情况无法自动涌现。

## 七、层4 — 情境自动涌现（✅ 已实施）

**文件：** `核心代码/situation_detector.py`

**职责边界**：
- `signal_synthesizer`：已知13类关键词共振 → 自动推演
- `situation_detector`：ALERT_KEYWORDS 覆盖之外的新话题 → 推送待确认条目

**9项设计补丁**：中文jieba分词、EWMA基线（替代简单30日均值）、话题持续性过滤（≥3天）、跳过已有关键词、三级推送优先级（频率比≥3.0即时推送/≥2.0打包/其余静默归档）、JSON多层容错解析、needs_review标记、dismissed自动恢复机制（频率比>3.0时恢复）、daily_narrative区分已确认/待确认

**调度**：每日06:30（弱信号扫描后）

**ntfy 指令**：`1900 confirm_situation <id>` / `1900 dismiss_situation <id>`
