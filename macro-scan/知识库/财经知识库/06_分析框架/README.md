# 06_分析框架：叙事层文档

> 本文档是财经知识库的叙事层，回答"这些数据告诉我的故事是什么"。

---

## 一、框架总览：三层信号体系

宏观数据本质上是经济系统的**三层信号**：

```
信号层1：领先指标（预示未来）
信号层2：同步指标（反映当下）
信号层3：滞后指标（确认结果）
```

| 层次 | 核心指标 | 经济含义 |
|:---:|:---|:---|
| 领先 | M2、社融、PMI新订单、出口订单 | 未来3-6个月的经济走向 |
| 同步 | GDP实际增速、工业增加值、消费 | 经济正在发生什么 |
| 滞后 | 失业率、PPI、财政收入 | 经济的真实结果 |

**实战口诀**：领先指标向下 → 同步指标终将跟随；滞后指标已在底部 → 领先指标即将反弹。

## 二、四条核心逻辑链

### 逻辑链A：货币-信用-实体

```
货币政策（M2↑）→ 社融增量↑ → 企业融资成本↓ → 制造业投资↑ → GDP↑
                                 ↓
                          居民消费↑（收入预期改善）
```

**数据观测点**：
- M2同比 > 10%：货币政策宽松
- 社融增量单月 > 2万亿：信用开始扩张
- 人民币贷款同比 > 15%：银行放贷积极
- 社融结构中企业债占比提升：实体融资质量改善

---

### 逻辑链B：财政-基建-就业

```
财政发力（专项债发行↑）→ 基建投资↑ → 建筑业就业↑ → 居民收入↑ → 消费↑
                                ↓
                         原材料需求↑ → PPI降幅收窄
```

**数据观测点**：
- 一般公共预算支出同比 > 15%：财政积极
- 基建投资（不含电力）累计同比 > 8%：基建托底有力
- 财政收入累计同比 < 5%：财政压力显现（收不抵支）

---

### 逻辑链C：外需-制造业-就业

```
出口同比↑（美元计价）→ 制造业产能利用率↑ → 工业增加值↑ → 城镇就业↑
                                   ↓
                            居民消费↑
```

**数据观测点**：
- 出口金额（以美元计）当月同比 > 10%：外需强劲
- 制造业PMI新订单 > 55：出口前景好
- 工业增加值同比 > 8%：制造业景气温和

---

### 逻辑链D：地产-金融-消费

```
房地产投资↑ → 产业链上下游复苏 → 财政收入↑ → 消费改善
     ↓
金融系统（社融、贷款利率）受影响
```

**数据观测点**：
- 房地产开发投资累计同比 > -5%：地产企稳
- 社融中房贷占比：地产政策松紧的温度计

## 三、解读方法论

### 3.1 看数据不看单点，看趋势不看单月

❌ 错误：`2月CPI同比2.3%，通胀要起来了`
✅ 正确：`CPI环比连续3个月为负，需求通缩趋势未变`

单月数据波动大，**至少看3个月趋势**再下结论。

### 3.2 不同指标有不同频率，别混用

| 指标类型 | 发布频率 | 看趋势用 |
|:---|:---|:---|
| CPI、PPI | 月度 | 同比+环比双看 |
| GDP | 季度 | 实际增速 |
| 社融 | 月度 | 增量（亿元）不看占比 |
| M2 | 月度 | 同比，8-12%为中性区间 |

### 3.3 数据的叙事顺序

1. **先领先**：PMI、M2、社融（预判方向）
2. **再同步**：工业、消费、投资（确认当下）
3. **后验证**：就业、物价、财政（确认结果）

## 四、实战场景

### 场景1：经济下行期，如何读数据？
**背景**：GDP增速降至4.5%，市场担心衰退

读数顺序：
1. M2是否在扩张？（货币政策响应）
2. 社融增量是否企稳？（实体融资意愿）
3. 基建投资是否加速？（财政对冲力度）
4. 消费是否仍在负增长？（内生动能）

**结论逻辑**：
- M2↑+社融↓ → 货币政策传导不畅，政策不够
- M2↑+社融↑+基建↑ → 财政主导托底，非内生修复
- M2↑+社融↑+消费↑ → 修复通道，衰退风险低

### 场景2：出口回暖，能持续吗？
**背景**：3月出口同比大超预期

验证链条：
1. PMI新订单是否同步上行？（订单领先出口）
2. 海关出口金额（美元计）当月同比是否持续 > 5%？（确认）
3. 工业增加值是否跟上？（传导到生产）
4. 城镇就业是否改善？（传到就业）

## 五、数据源说明

### 核心数据源
- **中国人民银行**：M2、社融、人民币贷款、利率
- **国家统计局**：GDP、CPI、PPI、PMI、工业增加值、消费、固投、就业
- **海关总署**：进出口金额（以美元/人民币计）
- **国家外汇管理局**：外汇储备
- **财政部**：一般公共预算收入/支出

### 数据时效性
- 月度数据：次月中旬发布（如3月数据4月中旬出）
- 季度数据：次季度首月中旬（如Q1数据4月中旬出）
- 详细日历见 `05_经济日历/经济日历.md`

## 六、常见误区

1. **把M2当流动性直接映射**：M2高不代表钱流入实体，要看社融
2. **把CPI当通胀唯一指标**：PPI才反映工业品通胀，PPI-CPI传导有2-3个月时滞
3. **把出口当外需唯一指标**：还要看进口（反映内需）和贸易差额（综合）
4. **把社融当纯信贷数据**：社融包含企业债、政府债券、非标融资，结构比总量更重要
5. **单月数据下结论**：2月春节效应干扰大，1-2月合并看才准
