# 中国信用脉冲与房地产周期

> 中国的宏观经济周期本质上是信用周期，而信用周期的核心驱动是房地产。理解中国信用脉冲（Credit Impulse）是预判中国经济增速、全球大宗商品需求和新兴市场联动的关键。

---

## 一、信用脉冲（Credit Impulse）定义

### 1.1 概念来源

信用脉冲 = **信贷新增量的变化速度**，而非信贷总量或增速本身。

```
信用脉冲 = Δ(新增信贷) / GDP

即：当期新增社会融资 − 上期新增社会融资，除以 GDP

直觉：不是"借了多少钱"，而是"借钱速度是否在加速"
```

由 Michael Biggs（Deutsche Bank，2008）提出，用于解释为何信贷扩张结束时增长往往随之放缓，即使信贷总量仍在增长。

### 1.2 为何领先于 GDP

```
借钱 → 花钱（消费/投资）→ 生产 → GDP 增长

脉冲收缩：借钱速度放慢 → 花钱减少（需求端） → GDP 增长放缓
```

中国研究表明，信用脉冲领先 GDP 约 **2–3 个季度**，是预测中国增速的最有效单一指标。

## 二、中国信用体系结构

### 2.1 社会融资规模（TSF）

中国官方核心信用度量：

| 组成部分 | 2024年占比（约） | 特点 |
|:---|:---:|:---|
| 人民币贷款 | ~60% | 银行信贷主体 |
| 政府债券 | ~22% | 财政刺激主渠道，近年占比快速上升 |
| 企业债券 | ~8% | 公司融资 |
| 委托贷款+信托 | ~5% | 影子银行（已大幅收缩） |
| 股票融资 | ~3% | 权益融资 |
| 其他 | ~2% | ABS等 |

> **重要变化**：2018年强监管后，影子银行（委托+信托）规模大幅收缩，政府债券占比上升填补，TSF 结构已发生结构性转变，脉冲信号解读需调整。

### 2.2 M1-M2 剪刀差作为补充信号

```
M1（流通货币+活期存款）> M2（广义货币）增速 → 企业愿意持有活期而非定期
  → 投资意愿强，经济活跃

M1 < M2 → 企业倾向定期存款，观望情绪重
  → 经济下行风险上升
```

M1-M2 差值收窄/转负是信用脉冲收缩的先行验证信号。

## 三、房地产作为信用传导中枢

### 3.1 房地产-信用传导链

```
开发商拿地 → 抵押贷款 / 土地出让收入（地方政府财政）
↓
建设投资（钢铁/水泥/家电需求）
↓
土地价格上涨 → 居民财富效应 → 消费
↓
更多开发商拿地（正反馈）
```

中国房地产直接+间接贡献 GDP 约 25–30%。

### 3.2 土地出让收入对地方财政的依赖

| 年份 | 全国土地出让收入 | 占地方一般预算收入比例 |
|:---:|:---:|:---:|
| 2020 | 8.41万亿 | ~84% |
| 2021 | 8.71万亿（峰值） | ~87% |
| 2022 | 6.69万亿 | ~62% |
| 2023 | 5.78万亿 | ~52% |
| 2024E | ~4.5–5万亿 | ~45% |

土地出让持续下滑 → 地方政府财政收入缺口扩大 → 城投债展期/违约风险上升。

### 3.3 房地产周期阶段

**中国房地产周期历史（简化）**：

```
1998–2008  上升期：福利分房改革，商品房市场化，持续扩张
2008–2009  调整：全球金融危机，政府"4万亿"刺激，快速反弹
2010–2014  温和调整：限购限贷，去库存
2015–2016  深度调整：一二线城市去库存，三四线棚改货币化
2017–2021  第二轮峰值：房价屡创新高，开发商加杠杆
2021–至今  系统性去杠杆：
  - 2021-09: 恒大首次违约
  - 2022: 大规模断供潮、"保交楼"政策
  - 2023: 碧桂园、融创等相继违约
  - 2024-2025: 限购放开、降首付降利率，效果有限
  - 2026: 销售面积仍低于峰值约40%
```

## 四、恒大危机与系统性传导（2021–）

### 4.1 恒大危机时间线

| 日期 | 事件 |
|:---:|:---|
| 2021-06 | 恒大被标普下调评级至 BB- |
| 2021-09-23 | 恒大未能按时支付离岸债券利息，进入宽限期 |
| 2021-12-09 | 恒大正式被评级机构认定违约 |
| 2022 | 断供潮：烂尾楼业主集体停止还贷（约6450亿贷款风险暴露） |
| 2022-08 | 政府推出"保交楼"专项贷款（2000亿） |
| 2023-08 | 碧桂园无法偿还境外债务，进入违约程序 |
| 2024-01-29 | 香港法院裁定恒大清盘，负债超过3300亿美元 |
| 2024 全年 | 多家中型开发商持续违约，烂尾楼清单扩大 |

### 4.2 信用传导机制

```
开发商违约
↓
银行房地产相关贷款坏账率上升（建设贷+按揭贷）
↓
银行收紧信贷（供给端冲击）
↓
土地出让减少 → 地方财政收入下降
↓
城投债展期 → 隐性债务风险（约50–60万亿城投债）
↓
地方政府减少基建支出 → 进一步拖累 GDP
（螺旋型去杠杆，类似日本1990s）
```

### 4.3 与日本1990年的对比

| 维度 | 日本1990后 | 中国2021后 |
|:---|:---|:---|
| 触发 | 股市崩盘+房价崩溃，BOJ 快速加息 | 政策主动去杠杆（三道红线） |
| 居民杠杆 | 极高，资产负债表衰退 | 较高，但首付比例较高，系统性断供风险低 |
| 银行体系 | 大量坏账，信贷收缩10年 | 银行资本充足率较好，但隐性贷款规模大 |
| 政策空间 | 有限（通胀低，汇率升） | 较大（降息降准空间仍在，财政有余地） |
| 去杠杆速度 | 被动、缓慢 | 主动管控，快于日本但仍有序 |

## 五、2026 年现状分析

### 5.1 当前信用脉冲状态

- 社会融资规模同比增速：约 8–9%（低于疫情前 12–13% 水平）
- 结构：政府债主导（占比超过 20%），企业信贷增速偏弱
- **脉冲方向**：政府信用扩张对冲企业/居民去杠杆，净脉冲接近中性
- 含义：2026 年中国 GDP 增速维持 4.5–5%，但非"V型"复苏

### 5.2 主要风险

1. **城投债再融资风险**：2024–2026 年城投债到期规模高峰，地方政府现金流紧张
2. **居民资产负债表**：房价下跌 → 负财富效应 → 消费意愿低（居民储蓄率反升）
3. **开发商尾部处置**：仍有约100–200家中小开发商处于重组状态
4. **信用从地产转向制造业的再分配**：新能源、半导体贷款增加，但乘数效应低于房地产

## 七、对全球市场的传导

中国信用脉冲是全球商品价格的领先指标（领先3–6个月）：

```
中国信用脉冲扩张 → 基建/地产投资增加
  → 铁矿石/铜/钢铁需求上升
  → 铁矿石（澳大利亚）、铜（智利/秘鲁）、油价（沙特）
  → 全球商品出口国 GDP 上升
  → 新兴市场资本流入增加

反向：中国信用脉冲收缩 → 铜价下跌 → 商品出口国 GDP 下降
  → 新兴市场汇率承压
```

**典型案例**：2015–2016 年中国去杠杆 → 铁矿石从 $80→$37 → 澳元/巴西雷亚尔暴跌 → EM 危机。

## 八、核心结论

1. **中国信用脉冲 > 任何单一指标**：PMI、GDP、M2 都是其下游产物，脉冲本身才是驱动力
2. **房地产是信用乘数的扩大器**：地产复苏 = 信用乘数恢复；地产萎缩 = 乘数收缩
3. **2021年以后是结构转换**：政府信用替代私人信用，乘数效率下降，但可避免系统性危机
4. **"弹药耗尽"风险**：若地方政府财政持续恶化，中央财政转移支付空间变小，政策应对能力下降
5. **全球传导窗口**：铜价是最实时、噪声最低的中国信用脉冲代理指标
