# 中国_房地产债务传导链 — 结构化知识文档

> 核心主题：中国房地产债务危机的多条传导路径：开发商→银行→地方政府→居民→消费
> 更新时间：2026-05-11

---

## 核心传导链

```
三条红线政策（2020年8月）
        ↓
开发商融资渠道收紧
        ↓
┌──────────────────────────────────────────────┐

└──────────────────────────────────────────────┘
        ↓
┌──────────────────────────────────────────────┐

│  开发商美元债违约 → 外资抛售中资地产债        │
│  ↓ 离岸融资成本飙升 → 人民币汇率承压         │
│  ↓ 信托/理财产品暴雷 → 居民财富缩水          │
└──────────────────────────────────────────────┘
        ↓
┌──────────────────────────────────────────────┐
│  路径C：地方政府传导                          │

        ↓
```

## 一、三条红线政策：设计逻辑与连锁反应

### 1.1 三条红线的具体内容（2020年8月）

人民银行和住建部对重点房企设定三项财务指标"红线"：

| 红线 | 指标 | 上限 |
|------|------|------|
| 红线一 | 剔除预收款后的资产负债率 | ≤70% |
| 红线二 | 净负债率（净有息负债/权益） | ≤100% |
| 红线三 | 现金短债比（现金/短期债务） | ≥1 |

**档位划分：**
- 三线全达标（绿档）：有息债务年增速≤15%
- 踩一条（黄档）：有息债务年增速≤10%
- 踩两条（橙档）：有息债务年增速≤5%
- 踩三条（红档）：有息债务不得增加

**政策初衷：**降低开发商杠杆，防范系统性金融风险。但实施时机恰在新冠疫情冲击销售、叠加土地款延期政策收紧之时，形成"踩雷+去杠杆"双重压力。

### 1.2 三条红线对主要房企的冲击

| 企业 | 触线情况（2020年） | 结果 |
|------|-------------------|------|
| 中国恒大 | 三线全踩（红档） | 2021年12月违约，负债约2.4万亿 |
| 碧桂园 | 两条（橙档）→后降至绿档 | 2023年8月流动性危机，最终违约 |
| 融创中国 | 三线全踩 | 2022年5月违约 |
| 世茂集团 | 两条 | 2022年违约 |
| 富力地产 | 踩线 | 资产出售自救 |
| 万科 | 接近绿档 | 2024年出现流动性压力 |
| 保利/华润/中海 | 绿档（国企） | 相对稳健 |

## 二、预售制度：中国房地产杠杆的独特机制

### 2.1 期房预售制度的运作逻辑

```
开发商获地 → 申请预售许可证（施工至特定层数）
    ↓
购房者全款或按揭购买"未建好的房子"
    ↓
购房款进入预售资金监管账户
    ↓
（政策收紧前）开发商可提取资金用于其他项目或偿债
    ↓
形成"以新盘回款养旧盘债务"的滚雪球模式
```

**杠杆放大机制：**
- 开发商用购房者的预付款（不是自有资本）投资下一个项目
- 行业整体预收款/总资产比率一度超过40%
- 相当于购房者为开发商提供了免费"融资"
- 监管账户资金一旦被提取，烂尾风险全由购房者承担

### 2.2 "断供潮"的传导逻辑（2022年）

```
开发商挪用预售资金 + 销售下滑 → 工程款无力支付
    ↓
施工方停工 → 多地出现烂尾楼
    ↓
购房者已付全款但无法收房 → 集体发布"强制停贷告知书"
    ↓
断供潮：已签合同的购房者停止还款（合法权益抗争）
    ↓
银行按揭贷款资产质量恶化
    ↓
若规模扩大 → 银行不良资产↑ → 信贷收紧 → 经济进一步受损
```

**断供潮规模评估（2022年7月高峰）：**
- 涉及楼盘估计超过300个
- 问题楼盘面积约2-3亿平方米
- 潜在断供规模估计2000-3000亿元（后续大部分保交楼后解决）

## 三、开发商违约路径详解

### 3.1 中国恒大：史上最大房企危机

**恒大危机时间线：**

| 时间 | 事件 |
|------|------|
| 2020年8月 | 三条红线出台，恒大三线全踩 |
| 2021年9月 | 恒大首次出现美元债利息延付 |
| 2021年12月9日 | 恒大正式宣布无力偿还美元债，国际评级机构判定违约 |
| 2022年全年 | 恒大资产处置，引发供应商大规模讨债 |
| 2023年8月 | 恒大在美国申请破产保护（Chapter 15） |
| 2024年1月 | 香港法院颁发清盘令（历史性里程碑） |
| 2024年 | 清算程序启动，估计实际回收率极低（<30%） |

**负债规模：** 约2.4万亿人民币（330亿美元+数万亿境内债）

### 3.2 碧桂园：最大民营房企的滑落

| 时间 | 事件 |
|------|------|
| 2023年7月 | 碧桂园季报显示利润急剧恶化 |
| 2023年8月6日 | 碧桂园宣布两笔美元债息票延付 |
| 2023年10月 | 碧桂园正式违约 |
| 2024年 | 流动性持续紧张，依靠出售资产维持运营 |

**碧桂园的特殊性：**
- 比恒大更广泛的全国项目覆盖（3000+个项目，遍布三四五线城市）
- 其危机意味着问题已从高负债激进型开发商蔓延至"相对谨慎"的龙头
- 2023年销售额仍约1400亿，但仅为2022年高峰的一半

## 四、银行体系对地产的敞口

### 4.1 银行风险敞口估算

| 敞口类型 | 规模估算 | 银行资产占比 |
|----------|----------|-------------|
| 开发商贷款（直接） | 约5-6万亿 | ~5-6% |
| 居民按揭贷款 | 约38万亿 | ~25% |
| 城投相关（间接） | 约30-40万亿（隐性） | ~20-25% |
| 理财/信托穿透敞口 | 约5-10万亿 | ~3-5% |
| **合计（直接+部分隐性）** | **~50-70万亿** | **~35-45%** |

**注：** 以上含大量隐性和估算数据，官方口径银行直接地产敞口约占贷款总额23%。

### 4.2 银行风险的缓释因素

- 居民按揭贷款首付比例相对高（一线城市30-40%+），贷款质量好于美国次贷
- 即使房价下跌30-40%，多数按揭贷款仍有抵押品覆盖
- 银行不良贷款率官方口径约1.6-2%，含一定"人为压低"嫌疑
- 国有大行资本充足率>12%，具备一定缓冲

## 五、预警指标

| 指标 | 阈值/信号 | 含义 |
|------|-----------|------|
| 70城新房价格指数月环比 | 连续6个月负值 | 房价下行趋势固化 |

| 银行涉房不良贷款率 | >3%警惕（当前约2%） | 银行资产质量 |

## 六、历史案例对比

### 6.1 中国 vs 日本1990年代房地产泡沫

| 维度 | 日本（1990s） | 中国（2021-至今） |
|------|---------------|-------------------|
| 触发机制 | 央行加息刺破泡沫 | 政策主动去杠杆（三条红线） |
| 房价下跌幅度 | 东京商业地产-70% | 当前全国-15-25%，部分城市-30%+ |
| 银行不良率峰值 | 约8-10%（1990年代末） | 待观察（官方~2%） |
| 政府应对速度 | 极慢（"失去十年"主因） | 较积极但效果有限 |
| 影响范围 | 主要在日本国内 | 全球大宗商品市场受波及 |
| 资产负债表衰退风险 | 已发生 | 部分迹象（居民/企业去杠杆） |

## 七、政策应对

### 7.1 保交楼机制

- **2022年11月**："金融十六条"出台，要求银行对房企贷款展期6个月
- **保交楼专项借款**：由国家开发银行等提供约2000亿政策性资金
- **城市房地产融资协调机制（白名单）**：2024年起各地上报项目名单，银行提供"应贷尽贷"

### 7.2 收储政策

- 2024年5月：央行3000亿PSL（抵押补充贷款）支持国有企业收购已建成商品房转为保障性住房
- 目标：直接消化开发商库存，稳定房价
- 挑战：收购价格如何定？国企资产负债表如何处理？

### 7.3 住房政策松绑

| 措施 | 时间 | 内容 |
|------|------|------|
| 首付比例下调 | 2024年5月 | 首套降至15%，二套20% |
| 房贷利率下限取消 | 2024年5月 | 各地自主确定 |
| 限购放开 | 2024年各城市逐步 | 多城取消限购限售 |
| 以旧换新 | 2024-2025 | 补贴政策鼓励换房 |

## 八、当前状态（2026）

| 指标 | 高峰 | 2025年底估计 |
|------|------|--------------|
| 商品房年销售额 | 2021年：18万亿 | ~9-10万亿（腰斩） |
| 土地出让金 | 2021年：8.7万亿 | ~3-4万亿 |
| 开发商新开工面积 | 2019年：22亿㎡ | ~7-8亿㎡ |
| 房价（全国平均） | — | 较峰值跌15-25% |
| 保交楼竣工率 | — | ~70-80% |

**核心研判（2026）：** 中国房地产已从"量价齐升的高速扩张"进入"量缩价稳求活的长期收缩"新阶段。本轮调整周期可能持续8-10年，类日本路径但体量更大、国家干预更强。关键变量是：政府是否有足够财力和意愿持续"兜底"，以及内需是否能真正替代房地产成为增长引擎。
