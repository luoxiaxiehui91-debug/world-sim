# 大宗商品超级周期

---

## 1. 核心传导链

```
╔══════════════════════════════════════════════════════════════╗
║         长期供给约束                  需求结构性增长           ║
║  资本开支持续下降 / 资源品位下降   工业化大国崛起 / 能源转型    ║
╚══════════════╤═══════════════════════════╤══════════════════╝
               │                           │
               ▼                           ▼
      ┌────────────────────────────────────────────┐
      │     大宗商品价格趋势性上涨（持续 20-30 年）   │
      │   能源 / 金属 / 农产品全面进入上行超级周期     │
      └────────────────────┬───────────────────────┘
                           │
          ┌────────────────┼────────────────┐
          ▼                ▼                ▼
   出口国经常账户       通胀压力上升        资源企业利润
   盈余扩大           （成本推动型）        大幅膨胀
          │                │                │
          ▼                ▼                ▼
   出口国本币升值     央行收紧货币政策     扩产投资启动
   进口国贸易条件      实际利率上升        （滞后 5-10 年）
   恶化、外汇失衡      需求端压制              │
          │                │                ▼
          └────────────────┼──── 新增供给大量入市 ────┐
                           ▼                         │
                    需求增速下滑                      │
                    （下游行业利润收窄）               │
                           │                         │
                           ▼                         ▼
                    供需重新平衡 ←── 供给弹性恢复 ────┘
                           │
                           ▼
                    价格趋势性回落
                    超级周期进入尾声
```

**核心矛盾**：供给弹性低（资本开支→产出的滞后期长达 5-10 年）+ 需求弹性低（基础工业/基础设施刚需），两者叠加造成价格长期脱离均衡，形成区别于普通 3-5 年库存周期的 20-30 年超长趋势。

---

## 2. 关键阶段

| 阶段 | 名称 | 典型特征 | 历史时长 |
|------|------|----------|----------|
| **阶段1** | 供需缺口萌芽 | 需求加速增长，但库存尚充裕，价格温和上涨；资本开支低位，市场低估长期需求 | 2-5 年 |
| **阶段2** | 价格起飞 | 库存快速消耗，现货升水扩大；大宗商品相对股票跑赢；出口国货币大幅升值 | 5-8 年 |
| **阶段3** | 全面牛市顶峰 | 价格大幅超过边际成本，资本开支急剧扩张；通胀全面化，货币政策大幅收紧；投机资金涌入商品期货 | 3-5 年 |
| **阶段4** | 供给洪水 & 需求降速 | 新产能集中入市压低价格；需求端因高价抑制和经济下行而收缩；库存快速累积 | 3-5 年 |
| **阶段5** | 深度调整 & 资本撤离 | 价格跌至或低于边际成本；资本开支崩溃；产能出清；为下一轮周期埋下供给约束 | 5-10 年 |

**识别标准（非普通周期）**：
- 持续时长超过 15 年（非 3-5 年库存周期）
- 实际价格（剔除通胀）相较上一波低点涨幅超过 100%
- 至少两种主要商品类别同步走强
- 存在清晰的结构性需求驱动（工业化大国、能源转型等），而非单纯投机

## 3. 关键变量

### 3.1 历次超级周期概览

| 周期 | 大致起止 | 核心驱动 | 代表商品涨幅 |
|------|----------|----------|--------------|
| 第1次 | 1890s—1910s | 美国铁路/工业化 | 铜 +150%，煤炭 +120% |
| 第2次 | 1930s末—1950s | 二战军备 + 战后重建 | 铝 +200%，钢铁 +180% |
| 第3次 | 1971—1980 | 越战赤字 + 布雷顿森林解体 + 石油危机 | 原油 +1,200%（$3→$39），铜 +190%（$0.50→$1.45/磅），黄金 +2,300%（$35→$850） |
| 第4次 | 1999—2011 | 中国工业化 | 铁矿石 +800%（$20→$180），铜 +500%（$1,500→$10,000/吨） |
| 第5次？ | 2020s— | 能源转型 + 去全球化供给碎片化 | 铜 2020-2024 +90%，锂 2020-2022 +1,000% |

### 3.2 关键阈值与参考数值

- **供给响应滞后期**：金属矿山从勘探到投产平均 **10-16 年**（铜矿 14 年，锂矿 10 年）
- **中国工业化时期需求占比**（2000-2011）：
  - 铁矿石：中国消费量占全球比例从 **22% 升至 60%**
  - 铜：从 **13% 升至 40%**
  - 水泥：2011 年中国产量占全球 **57%**
- **能源转型需求（2030 目标情景，IEA）**：
  - 铜：2022-2030 年净需求增加 **约 540 万吨/年**（约 +25%）
  - 锂：2022-2030 年需求增长 **7-10 倍**
  - 钴：2022-2030 年需求增长 **2-3 倍**
- **美元指数与大宗商品**：美元 DXY 每上涨 **10%**，CRB 商品指数历史上平均下跌 **7-12%**（负相关）

## 4. 传导机制详解

### 4.1 供需失衡 → 价格螺旋 → 供给恢复完整闭环

```
需求结构性增长（工业化/能源转型）
         │
         ▼
库存/消费比（Stocks-to-Use Ratio）持续下降
         │
         ▼ （跌破临界值，约 20-25 天消费量）
现货升水（Backwardation）扩大
         │
         ▼
价格突破长期均衡（边际成本+正常利润）
         │
         ▼
超额利润刺激投资 ──► 但矿山/油田开发滞后 5-16 年
         │                                │
         ▼                                │（5-16年后）
供给弹性短期接近0 → 价格继续上涨          │
         │                                ▼
         │                     大量新矿山/产能投产
         │                                │
         ▼                                ▼
  高价抑制终端需求 ◄──────── 供给弹性恢复
（需求替代/节能投资）                      │
         │                                ▼
         │                     库存/消费比回升
         ▼                                │
  需求增速放缓 ──────────────────────────►│
                                           ▼
                               价格趋势性回落（熊市启动）
                               超级周期进入尾声/调整阶段
```

### 4.2 美元-大宗商品负相关机制

```
美元走强
    │
    ├─► 大宗商品以美元计价 → 非美买家购买力下降 → 需求压制
    │
    ├─► 全球风险偏好下降 → 资金流出商品市场 → 期货端抛压
    │
    └─► 美联储加息预期往往同步 → 实际利率上升 → 持有实物商品机会成本上升

反向（美元走弱时）：
    非美经济体购买力增强 + 通胀预期上升
    → 商品作为实物资产吸引力增强 → 价格上涨
```

**历史验证**：1971-1980 布雷顿森林解体，美元贬值 30%+，大宗商品全面飙升；2001-2011 美元弱势周期，CRB 指数翻倍；2014-2016 美元走强，大宗商品指数腰斩。

### 4.3 库存周期（基钦，3-5年）与超级周期的叠加效应

```
价格趋势（超级周期层，20-30年）：
  ▲
  │   ╭──────────────────╮
  │  ╭╯  第4次超级周期    ╰──╮
  │ ╭╯   1999-2011           ╰─────
  │─╯
  │
  └─────────────────────────────────► 时间

库存周期波动（基钦层，3-5年）叠加：
  ▲
  │  ╭─╮   ╭─╮   ╭─╮   ╭─╮
  │ ╭╯ ╰─╮╭╯ ╰─╮╭╯ ╰─╮╭╯ ╰─╮
  │╭╯    ╰╯    ╰╯    ╰╯    ╰──
  └──────────────────────────────── 时间
    补库  去库  补库  去库

叠加效果：
┌─────────────────────────────────────────────────────┐
│ 超级周期方向  │ 库存周期方向 │     实际价格表现        │
├─────────────────────────────────────────────────────┤
│    上行       │    补库      │ 价格大幅放大（最强信号）  │
│              │              │ 典型：2009-2011, 2020-2022│
├─────────────────────────────────────────────────────┤
│    上行       │    去库      │ 短暂回调，趋势不改        │
│              │              │ 典型：2012-2013 调整      │
├─────────────────────────────────────────────────────┤
│    下行       │    补库      │ 短暂反弹，难以持续        │
│              │              │ 典型：2016 年底小反弹     │
├─────────────────────────────────────────────────────┤
│    下行       │    去库      │ 价格崩溃（最弱信号）      │
│              │              │ 典型：2015-2016 大熊市    │
└─────────────────────────────────────────────────────┘
```

**投资含义**：在超级周期上行段 + 库存去库阶段的价格调整中逢低买入，是历史上超额收益最高的窗口（如 2013-2014 年布局铜）。

### 4.4 出口国汇率传导

```
大宗商品价格上涨
         │
         ▼
资源出口国（澳元、智利比索、巴西雷亚尔）
经常账户盈余 → 外汇流入 → 本币升值
         │
         ▼
制造业竞争力下降（荷兰病）
进口国贸易条件恶化 → 输入型通胀
         │
         ▼
进口国通胀预期 → 工资-通胀螺旋风险
         │
         ▼
货币政策收紧 → 实体经济需求降温
         │
         ▼
大宗商品需求端压制（周期反转信号之一）
```

## 6. 历史案例

### 案例一：1970s 超级周期——布雷顿森林崩溃 + 石油危机

**时间线**：1971—1980（核心上涨段约 9 年）

**触发机制（三重叠加）**：
1. **越战财政赤字**：1965-1973 年美国财政赤字累计超 1,000 亿美元，美元信用透支，黄金储备从 1960 年的 180 亿美元降至 1971 年的 100 亿美元
2. **布雷顿森林体系崩溃**（1971 年尼克松冲击）：美元与黄金脱钩，名义汇率浮动，1971-1979 年美元贬值约 30%；大宗商品定价体系重构，实物资产价值凸显
3. **两次石油危机**：1973 年 OPEC 禁运（油价从 $3→$12/桶，+300%）；1979 年伊朗革命（油价从 $15→$35/桶，+133%）

**具体数据**：
- 原油：$3/桶（1973 年初）→ $39/桶（1980 年峰值），**涨幅约 +1,200%**
- 铜：$0.50/磅（1971 年）→ $1.45/磅（1980 年峰值），**涨幅约 +190%**（实际价格，剔除通胀后约 +80%）
- 黄金：$35/盎司（1971 年）→ $850/盎司（1980 年峰值），**涨幅约 +2,300%**
- 美国 CPI 峰值：1980 年 3 月同比 **+14.8%**

**机制分析**：货币锚消失 → 美元贬值 → 实物商品保值需求 + 能源供给外生冲击叠加 → 典型的供给侧驱动超级周期；周期结束由沃尔克大幅加息（联邦基金利率升至 20%）强制压制需求实现。

---

### 案例二：2000s 中国工业化超级周期

**时间线**：1999—2011（核心上涨段约 12 年）

**触发机制**：
- 1999 年全球商品熊市尾声（供给过剩被清出，矿业资本开支降至历史低位）
- 2001 年中国加入 WTO，外商直接投资激增，城镇化率从 36%（2000 年）快速提升至 51%（2011 年）
- 年均固定资产投资增速超过 **20%**（2001-2010）；钢铁产量从 1.5 亿吨（2000 年）升至 **7 亿吨（2011 年）**，增长约 367%

**具体数据**：
- **铁矿石**：$20/吨（2003 年）→ $187/吨（2011 年峰值），**涨幅约 +835%**
- **铜**：$1,500/吨（2001 年初）→ $10,190/吨（2011 年峰值），**涨幅约 +579%**
- **原油（WTI）**：$15/桶（1999 年）→ $145/桶（2008 年峰值），**涨幅约 +867%**
- **煤炭（澳大利亚动力煤）**：$25/吨（2000 年）→ $180/吨（2008 年峰值），**涨幅约 +620%**
- 中国铜消费占全球比例：2000 年 **13%** → 2011 年 **40%**
- 中国铁矿石消费占全球比例：2000 年 **22%** → 2011 年 **60%**

**周期结束信号**：2011-2012 年中国固定资产投资增速开始边际下滑；矿山扩产产能（2005-2010 年批复）集中于 2012-2015 年入市；叠加美联储退出 QE 预期，美元走强，大宗商品进入长达 5 年的"超级熊市"（2011-2016）。

---

### 案例三（早期）：1890s-1910s 美国工业化周期

**时间线**：1895—1917（约 22 年）

**核心驱动**：美国铁路网从 15 万英里（1890）扩展至 25 万英里（1916），钢铁产量翻 4 倍；电气化革命带动铜需求暴增。

**数据**：铜实际价格较 1895 年低点上涨约 150%；煤炭上涨约 120%。

**意义**：最早被学术界确认的现代大宗商品超级周期，建立了"大国工业化驱动"的范式。

## 7. 政策应对

### 7.1 供给侧政策工具

| 工具 | 主要使用方 | 效果评估 |
|------|-----------|----------|
| 战略储备释放（SPR石油、金属国储）| 美国、中国、IEA成员国 | 短期（1-3个月）价格压制有效，但无法改变长期供需结构；2022年IEA协调释放 1.8亿桶储备，原油价格仅短暂回落 |
| 矿山勘探/开发补贴 | 资源国政府 | 长期有效但滞后 5-15 年；适合在超级周期早期阶段实施 |
| 出口禁令/关税（资源国）| 印尼（镍）、中国（稀土/镓）| 短期加剧进口国价格压力；长期促使进口国寻求替代供应，削弱垄断 |
| 碳排放成本内化 | 欧盟CBAM | 长期通过碳边境税压制高碳原材料需求；短期增加生产成本 |

### 7.2 需求侧政策工具

| 工具 | 主要使用方 | 效果评估 |
|------|-----------|----------|
| 货币政策收紧（加息）| 美联储、欧央行 | 1980年沃尔克冲击终结1970s超级周期——但代价是深度衰退；2022年加息周期有效压制需求但同时抑制绿色转型投资 |
| 价格补贴/价格管制 | 发展中国家政府 | 短期保护消费者，但扭曲价格信号，加重财政负担；长期阻碍节能技术发展（东南亚燃油补贴案例） |
| 需求侧替代技术推广 | 各国政府 | 长期最有效；如LED照明降低电力需求增速、电动车渗透压制原油需求长期曲线 |

### 7.3 政策时机悖论

超级周期下，政策应对面临典型的**"两难时机"**：
- 过早收紧货币政策 → 抑制绿色投资（恰恰是驱动下一轮供给扩张的基础）
- 过晚收紧 → 通胀预期脱锚，重蹈 1970s 覆辙
- 最优路径：财政政策定向支持供给侧扩张（补贴矿山/可再生能源），货币政策保持适度紧缩锚定通胀预期。

## 8. 当前状态（2026）

### 8.1 能源：结构性重塑期

- **石油**：俄乌冲突引发的供给地缘化已部分缓解，OPEC+ 通过减产维持 Brent 原油在 **$70-85/桶**区间（2025-2026年）；长期需求见顶时间线前移至 2027-2030 年（IEA 2023 预测），新兴市场抵消发达国家降幅
- **天然气**：欧洲 LNG 进口基础设施建设完成后，供需趋于平衡；全球 LNG 新产能（美国/卡塔尔）2025-2027 年集中投产，价格下行压力增加
- **煤炭**：亚洲需求（印度/东南亚）仍支撑价格，但发达国家退煤加速；2025 年澳大利亚动力煤约 **$100-120/吨**，低于 2022 年 $400 峰值

### 8.2 金属：能源转型的核心矛盾

**铜（最关键的能源转型金属）**：
- 2025 年铜价约 **$9,000-9,500/吨**（LME）；2024 年 5 月短暂触及 $11,000/吨历史高位
- 全球精铜消费量约 **2,700 万吨/年**（2025 估计）
- 铜矿供给端：智利（全球30%）品位持续下降（从2000年1.3%降至2024年约0.8%），巴拿马科布雷矿山（年产40万吨）2023年底被迫关停，全球铜矿产量增速下滑
- **供需缺口判断**：Wood Mackenzie 预测 2030 年铜累计缺口约 **600 万吨**，属于确定性供给短缺（基于已建设矿山产量曲线）；这是当前超级周期铜价长牛逻辑的核心基础面支撑

**锂（能源储存核心）**：
- 2022 年锂价（碳酸锂）爆涨至 **¥600,000/吨**（+1,000% vs 2020）
- 2023-2025 年产能过剩快速显现（澳大利亚/阿根廷/中国大量矿山投产），价格回落至 **¥70,000-100,000/吨**（2025 年）
- 短期过剩但长期缺口仍存：2030 年后需求增速将再度超越供给增速（IEA/BNEF一致预测）；当前低价正在压制新矿投资，为下一轮价格反弹积累条件

**钴**：
- 刚果金（DRC）产量约占全球 **70%**，地缘政治和童工问题驱动脱钴技术（磷酸铁锂电池替代）快速发展
- 2025 年钴价约 **$25,000-30,000/吨**，较 2022 年 $82,000 高位大幅回落
- 长期需求增长被技术替代部分对冲，不确定性高于铜/锂

### 8.3 农产品：气候变量主导

- 2022 年俄乌冲突引发粮价冲击（小麦 +70%，化肥 +150%）已基本消退
- 长期担忧：气候变化对主粮产区（北美/南美/南亚）单产影响逐步显现；气候风险溢价将成为农产品超级周期形成的新因素
- 2025-2026 年：La Niña 结束后降雨型态趋于正常，短期粮价压力有限

### 8.4 是否正在形成第5次超级周期？

**支持第5次超级周期的论据**：
1. **能源转型驱动需求结构性增长**：IEA可持续发展情景（SDS）下，2030年与2022年相比：铜需求约增长 **+70%**、锂约增长 **8-10倍**、钴约增长 **2.5倍**、镍约增长 **4倍**
2. **供给约束不可忽视**：矿山开发滞后期 10-16 年 + 近年资本开支不足（2015-2020 年矿业资本开支处于历史低位）
3. **去全球化供给碎片化**：中美技术脱钩 + 资源国民族主义（印尼镍出口禁令、智利锂国有化讨论）提高供给集中风险溢价
4. **美元长期走弱预期**：美国财政赤字扩张，去美元化趋势（部分对冲，但方向确立）

**反对或制约因素**：
1. **中国需求高峰已过**：中国城镇化率超 65%（2025），基础设施投资增速大幅放缓，钢铁/水泥需求或已见顶
2. **技术替代加速**：替代技术（固态电池/无钴电池/铝替代铜）可能削减部分金属需求
3. **短期过剩风险**：锂/钴已出现供给过剩，显示部分子类别不满足超级周期条件

**综合判断（基于现有分析，非最终结论）**：铜最符合超级周期条件（供需缺口确定、替代技术有限）；锂和钴属于波动性更高的小类别，难以单独形成超级周期但会在铜带动下放大；整体而言，能源转型大宗商品（铜主导）正处于超级周期**第2阶段（价格起飞阶段）早期**，但地缘政治、利率环境和中国增速放缓形成显著的下行尾部风险。
