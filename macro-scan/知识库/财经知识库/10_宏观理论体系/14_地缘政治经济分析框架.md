## 2. 关键阶段

| 阶段 | 时期 | 核心特征 | 地缘格局 | 标志性事件 |
|------|------|---------|---------|-----------|
| **布雷顿森林-冷战期** | 1945–1973年 | 西方主导多边主义，美元体系确立 | 美苏两极对抗 | 马歇尔计划（$130亿，相当于GDP约1.2%），布雷顿森林体系 |
| **石油危机-滞胀期** | 1973–1989年 | 资源武器化首次系统性登场 | 中东政治化，美苏竞争 | OPEC禁运（1973年），油价$3→$12（+300%）；1979年第二次油危机$12→$34 |
| **单极超全球化期** | 1990–2007年 | 冷战终结，WTO多边主义全盛 | 美国单极 | 中国2001年加入WTO；贸易占GDP比重从20%→55%（全球，2001–2008年） |
| **金融危机后地缘回归** | 2008–2016年 | 保护主义抬头，多边规则弱化 | 多极化萌芽 | WTO争端解决机构开始受阻；2010年南海/东海领土争议升级 |
| **大国竞争全面化** | 2017–至今 | 美中战略竞争明确化，制裁武器化 | G2对抗 | 2018年中美贸易战（$2500亿中国商品加税）；2022年俄乌战争+全面制裁；2024年中东冲突升级 |

## 3. 关键变量

| 变量 | 含义 | 关键阈值 / 历史数据 |
|------|------|-------------------|
| **GPR指数（地缘政治风险）** | Caldara & Iacoviello月度地缘政治风险指数，基于新闻关键词频率构建 | 基准约100（2000–2010年均值）；2001年9/11约400；2022年2月俄乌开战约约200+ |
| **石油价格（布伦特）** | 能源冲击的核心代理变量 | 1973年危机前$3/桶→峰值$12；2022年俄乌$85→$128（3月峰值），+50% |
| **贸易开放度（出口+进口/GDP）** | 全球化程度，地缘碎片化的反向指标 | 全球峰值约61%（2008年）；2023年约57%（下降反映去全球化） |
| **WTO争端解决案件数** | 多边规则有效性 | 1995–2018年年均约25件；2019年上诉机构瘫痪后实质冻结 |
| **稀土出口依赖度** | 关键矿产的对华依赖风险 | 中国占全球稀土精炼约85%（2024年，USGS数据） |
| **外汇储备货币构成** | 去美元化程度 | 美元占全球官方外储：2000年约71%→2023年约58%（IMF COFER数据） |
| **双边FDI流量** | 地缘政治摩擦的直接反映 | 2022年美国对华FDI承诺：$80亿（2016年$460亿，降幅约83%） |
| **制裁中国家数量** | 金融武器化程度 | 美国制裁名单（OFAC SDN List）：2000年约1000个→2022年超12000个实体 |

## 4. 传导机制详解

### 4.1 资源武器化机制

```
资源出口国主动控制供应
         │
    ┌────┴────────────────┐
    ▼                     ▼
OPEC减产/禁运          俄气断供欧洲
（油价冲击）           （天然气冲击）
    │                     │
能源进口国：             工业电价↑3–5倍
通胀↑（成本推动）        工业竞争力↓
GDP↓（需求破坏）         去工业化压力
实际工资↓               新能源加速
    │                     │
    └──────────┬──────────┘
               ▼
       滞胀风险（增长↓ + 通胀↑）
```

**关键数字**：
- 1973年美国：通胀从3.4%（1972年）→11.4%（1974年）；GDP -0.6%（1974年）
- 2022年欧洲：德国工业电价2021年€60/MWh→2022年€500+/MWh峰值（+700%以上）；德国2022年GDP仅+1.8%，2023年-0.3%

### 4.2 金融制裁机制

```
制裁发起国（美国/欧盟）
         │
    ┌────┴──────────────────────────────┐
    ▼                                   ▼
一级制裁                           二级制裁（次级制裁）
（直接针对目标国/实体）              （针对与目标国交易的第三方）
    │                                   │
目标国：                          第三方（中性国）：
SWIFT断网→国际支付瘫痪             被迫选择：配合制裁 or 失去美元金融系统访问权
外汇储备冻结→无法使用               欧洲/亚洲金融机构自我审查
进出口融资中断→贸易收缩             全球金融碎片化
    │
俄罗斯案例（2022年2月）：
7家俄罗斯银行被断开SWIFT
约$3000亿俄央行外储被冻结（欧洲托管的）
卢布2022年3月一度贬值50%（随后反弹）
2022年GDP:-2.1%（预期-10%，实际韧性更强）
```

**去美元化反应**：SWIFT制裁加速了BRICS国家推动非美元结算的动力。2022年后，中俄双边贸易中人民币结算比例从约20%升至约60%（2023年数据）。

### 4.3 贸易碎片化机制

```
多边主义规则弱化（WTO上诉机构瘫痪）
              │
    ┌─────────┴──────────┐
    ▼                    ▼
双边/区域协议替代        出口管制+关税壁垒
（RCEP/CPTPP/USMCA）    （美国301条款对华关税）
    │                    │
贸易转移（Trade         贸易创造减少
Diversion）：          （全球化收益↓）
中国→越南/墨西哥        供应链冗余成本↑15–25%
    │
全球供应链碎片化：
IMF测算完全碎片化下全球GDP损失约-2.5%至-7%（取决于程度）
```

### 4.4 不确定性溢价机制（预期渠道）

地缘政治不确定性直接影响企业投资决策：

```
GPR指数↑
    │
    ▼
实物期权价值↑（等待比投资更有价值）
    │
企业推迟资本支出（CAPEX延迟）
    │
供给侧产能扩张停滞
    │
长期供给约束 + 短期需求不确定
    │
经济增长下行 + 通胀结构性压力
```

研究显示：GPR指数上升1个标准差，企业投资在随后12个月内减少约1.5–2.0个百分点（Caldara & Iacoviello，2022年研究）。

## 6. 历史案例

### 案例一：1973年石油危机——资源武器化的原型

**背景**：1973年10月6日第四次中东战争爆发，10月17日OPEC阿拉伯成员国宣布禁运支持以色列的西方国家（美国、荷兰等）。

**价格传导**：
- 1973年10月前：国际油价约$3.0/桶
- 1974年1月：跳升至$12.0/桶（+300%）
- 后果：美国通胀从1972年3.4%→1974年11.4%；1974年GDP -0.6%；1975年失业率约9%

**机制分析**：
```
OPEC减产+禁运
    │
原油价格+300%
    │
    ├──► 进口国PPI大幅上升（能源/化工/运输）
    │         │
    │         ▼
    │   工业成本推动型通胀（无法靠货币政策单独解决）
    │
    └──► 实际购买力下降
              │
              ▼
         GDP衰退+通胀并存（滞胀）
```

**历史意义**：开创了"资源武器"的系统性使用先例；推动西方建立IEA（国际能源署，1974年）和战略石油储备（SPR）。

---

### 案例二：2022年俄乌战争——全谱制裁与能源武器化

**背景**：2022年2月24日俄罗斯入侵乌克兰，西方随即启动史上最大规模对单一国家制裁。

**制裁规模**：
- SWIFT断开7家俄罗斯银行（占俄银行资产约50%）
- 冻结俄央行约$3000亿外汇储备（约50%总储备，托管在欧洲）
- G7、EU、澳大利亚合计约60国参与制裁
- 美国301条款升级：俄罗斯能源进口禁止

**能源渠道**：
- 2022年欧洲天然气价格峰值：约€340/MWh（2022年8月，正常约€20–30/MWh，涨幅约10倍）
- 德国俄罗斯天然气依赖度从55%（2021年）→约45%（2022年）→约5%（2023年）
- 代价：德国工业电价从€60/MWh→高峰€500+/MWh，制造业竞争力受损，化工/钢铁等能源密集产业外迁

**俄罗斯韧性（出人意料）**：
- 2022年GDP实际下降仅-2.1%（西方预测-10%至-15%）
- 原因：①亚洲（中国/印度/土耳其）成为新出口方向（折价出口）；②资本管制稳定卢布；③战时财政扩张对冲制裁
- 制裁有效性争议：制裁削弱了长期经济潜力（技术获取受限、外资撤出），但短期影响被高估

---

### 案例三：2018–2026年中美科技脱钩

**时间线**：
- 2018年3月：美国301条款，对$340亿中国商品加征25%关税（随后扩大至$5000亿）
- 2018年8月：中兴通讯禁令事件（7年出口禁令，后和解）
- 2019年5月：华为被列入实体清单（Entity List）
- 2020年：TSMC被禁止向华为供货（利用美国技术）
- 2022年10月：全面芯片出口管制（14nm以下逻辑芯片、18nm以下内存、A100/H100级GPU）
- 2023年：扩大至先进芯片设计软件（EDA）、封装设备
- 2024年：进一步收紧，包括Gaudi AI芯片管制

**经济影响量化**：
- 美中双边贸易：2018年$6370亿→2023年约$5750亿（降幅约10%，但绝对量仍大）
- 贸易转移：越南对美出口份额从2017年1.2%→2023年约3.2%（主要承接中国商品）；墨西哥2023年首次超越中国成美国最大货物贸易伙伴
- 半导体：中国先进制程芯片国内产能仍无法替代TSMC；中芯国际7nm小批量生产，但良率和成本仍差距明显

## 7. 政策应对

### 7.1 工具清单与效果评估

| 政策工具 | 具体操作 | 适用场景 | 效果评估 | 局限性 |
|----------|---------|---------|---------|--------|
| **战略资源储备** | 建立石油储备（SPR）/关键矿产库存 | 能源/资源冲击预防 | 短期缓冲有效（2022年美国释放SPR 1.8亿桶平抑油价） | 储备有限，仅能延缓而非阻止供应中断 |
| **友岸外包（Friendshoring）** | 将供应链迁至盟友国家（印太经济框架/USMCA） | 战略脱钩 | 越南/印度/墨西哥FDI增长显著；但完全迁移耗时10–20年 | 替代方成本更高；过渡期风险 |
| **金融制裁+SWIFT** | 切断目标国跨境支付通道 | 对抗军事侵略/违反国际法 | 短期冲击有效，但去美元化和制裁规避逐渐显现 | 制裁武器滥用削弱其有效性；中国/俄罗斯推进CIPS/数字货币替代 |
| **出口管制** | 技术转让和产品出口限制（BIS实体清单） | 防止战略技术扩散 | 延缓对手技术发展（中国先进芯片滞后2–3个节点）；但无法完全封锁 | 盟友协调难度大（荷兰/日本/韩国有商业利益）；刺激对手自研 |
| **外储多元化** | 增加黄金/非美货币储备比例 | 规避制裁冻结风险 | 中国/沙特/印度大幅增持黄金（2022–2024年）；降低冻结风险 | 美元替代品流动性不足；再平衡成本高 |
| **能源替代** | 加速可再生能源部署（欧洲REPowerEU） | 降低化石能源地缘依赖 | 欧洲2022–2024年LNG接收能力扩大约80%；俄罗斯天然气依赖从55%→5% | 短期能源成本仍高于战前；电网改造需时 |

### 7.2 政策原则

- **多元化先于危机**：能源/关键矿产供应来源在平时多元化，危机时无法快速切换
- **制裁的双刃剑**：过度使用美元/SWIFT武器加速去美元化，侵蚀长期金融霸权
- **盟友协调是制裁有效性关键**：单边制裁容易被规避；多边协调（G7）效果更持久

## 8. 当前状态（2026）

### 8.1 俄乌战争——欧洲能源格局重构完成

- 2026年俄乌冲突进入僵持阶段，西方援助持续但规模调整
- 欧洲能源格局：俄管道气从2021年占欧洲天然气40%→2025年接近0%（完成替代）
- 欧洲LNG进口：2022–2025年新建约40个FSRU（浮式再气化装置）
- 代价持续：德国2024年GDP -0.2%，2025年勉强转正；工业电价仍高于2021年约50–80%

### 8.2 中美科技脱钩深化

- **芯片管制升级**：2022→2023→2024年，管制范围逐步扩至封装设备、先进存储（HBM）
- **中国突破**：华为Mate60系列（2023年）展示了7nm国内能力，但先进制程（3nm/2nm）仍有5–7年差距
- **供应链重组**：越南（消费电子）/印度（iPhone）/墨西哥（汽车电子）承接部分转移
- **贸易格局**：美中双边贸易下降但中国仍是美国最大单一商品来源，"脱钩"更准确描述为"去风险化（De-risking）"

### 8.3 台海——硅盾与地缘溢价

- 台积电（TSMC）在先进制程（3nm/2nm）的垄断地位使台湾具有独特"硅盾"战略价值
- 地缘折价：台湾股票相对历史均值存在约10–15%的"地缘政治折价"（分析师估算）
- 台积电海外分散：亚利桑那工厂（4nm，2025年量产）、日本熊本（28nm，2024年量产）部分分散风险，但2nm以下产能2026年前仍在台湾
- **关键指标**：台海紧张程度→台湾科技股溢价→全球半导体供应链风险定价

### 8.4 中东——红海危机与油价

- 2023年底–2026年：胡塞武装持续攻击红海商业航运
- 红海航线（苏伊士运河）转移：亚欧贸易大量绕行好望角，额外10–15天航程
- 石油价格：中东冲突保持约$5–10/桶的"地缘溢价"（相对纯供需定价）
- 以色列经济：2024年GDP约-1%（冲突影响），2025年逐步恢复；科技出口保持韧性

### 8.5 BRICS扩容与去美元化

- 2024年BRICS正式扩容：沙特、阿联酋、伊朗、埃塞俄比亚、埃及加入（G9→BRICS+）
- 去美元化进展：美元占全球外储从2016年约64%→2023年约58%（IMF COFER，缓慢但持续）
- 制约因素：人民币流动性不足，资本账户未完全开放；黄金流动性有限；BRICS货币分歧大
