## 3. 关键变量

| 变量 | 含义 | 关键阈值 / 历史数据 |
|------|------|-------------------|
| **VaR（99%，10天）** | 正常市场条件下10天内损失超过阈值的概率为1% | Basel要求：交易账户VaR×3的资本覆盖；2008年实际损失远超VaR预测 |
| **ES/CVaR（97.5%）** | 损失超过97.5%分位点时的条件期望损失 | Basel III FRTB要求：97.5% ES（约等效于99% VaR但更保守） |
| **峰度（Kurtosis）** | 分布尾部厚度，>3为超正态肥尾 | 标准普尔500日收益率峰度约7–10；正态分布为3 |
| **EVT形状参数ξ（xi）** | GPD/GEV的尾部厚度参数 | ξ>0：肥尾（帕累托型）；ξ=0：指数尾；ξ<0：有界（如Uniform分布） |
| **压力测试损失率** | 严重不利情景下银行资本损失比例 | 美联储DFAST 2023：18家大银行严重不利情景下总损失$5410亿，资本比率降约2.7pp |
| **VIX（隐含波动率）** | 市场对未来30天S&P500波动率的预期 | 正常约15–20；危机峰值：2008年10月89.53；2020年3月85.47 |
| **VVIX（VIX的波动率）** | 市场对VIX本身波动率的预期，尾部风险二阶指标 | 正常约80–100；极端事件前通常先于VIX上升 |
| **相关性稳定性** | 危机时期跨资产相关性向1趋同的程度 | 2008年9月后30天：全球股票与信用资产相关系数从~0.3升至~0.8 |

## 4. 传导机制详解

### 4.1 VaR的三大局限性

**局限性一：正态分布假设失效（肥尾问题）**

```
正态分布假设的隐含含义：
  极端损失概率 = P(X < -3σ) ≈ 0.13%（约每500个交易日一次）
  实际金融市场：
  - 1987年10月19日黑色星期一：道琼斯单日-22.6%（约22个标准差事件，正态分布下几乎不可能）
  - 标普500日收益率峰度约7–10（正态为3）
  
肥尾体现：
  ┌─────────────────────────────────────────────────┐
  │  理论分布（正态）              实际分布            │
  │       ████                     ████               │
  │      ██████                   ██████              │
  │     ████████                 ████████             │
  │  ████ ↑ ████                ████  ████            │
  │ ███ 尾部很薄 ███         ████ 尾部更厚 ████       │
  └─────────────────────────────────────────────────┘
VaR用正态分布 → 严重低估极端事件损失
```

**局限性二：次加性违反（Artzner等，1999）**

一致风险测度（Coherent Risk Measure）的四个公理中，次加性（Sub-additivity）要求：分散投资的风险 ≤ 各组成部分风险之和。VaR在非正态分布下可能违反此公理——即两个资产合并后VaR反而高于单独VaR之和，这在经济上说不通（分散化反而增加风险？）。

ES（Expected Shortfall）满足次加性，是VaR的一致性优化。

**局限性三：条件尾部盲区**

VaR回答的是："损失超过X的概率为1%"。但不回答："当损失真的超过X时，平均损失是多少？"

- 例：A组合：99% VaR = $100万，损失超过$100万时通常约$110万
- B组合：99% VaR = $100万，损失超过$100万时偶尔高达$10亿（肥尾）
- VaR认为A和B等价，ES能区分

### 4.2 期望损失（ES/CVaR）

```
                       VaR                 ES
                       (99分位)             (99%分位以上的条件期望)
                       ↓                   ↓
收益率分布            ─┼──────────────────── ←平均值
                       │                    │
    99%的概率          │                    │
    损失在这里以左      │                    │
                       │◄─── 1%概率 ──────►│
                       │         这部分     │
                       │         的平均损失 │
                       │       = ES         │
                  VaR分位点              最坏情景
```

Basel III从99% VaR转向97.5% ES的逻辑：97.5% ES在数值上更接近真实极端风险（ES隐含更厚尾部信息）。

### 4.3 极值理论（EVT）

**两种主要方法**：

**方法一：块最大值法（Block Maxima / GEV分布）**
- 将数据分为等长区块（如月度/季度），取每块最大值
- 极值定理：这些最大值收敛于广义极值分布（GEV），有三种子类型：Gumbel/Fréchet/Weibull
- 适合分析"年度最坏情景"

**方法二：超阈值法（POT / 广义帕累托分布 GPD）**
- 选择高阈值u，只分析超过u的观测值
- 这些超额值渐近收敛于广义帕累托分布（GPD）
- 形状参数ξ：
  - ξ > 0（帕累托型）：重尾，如金融资产收益
  - ξ = 0（指数型）：中等尾部
  - ξ < 0（有界型）：轻尾
- **LTCM案例应用**：若使用GPD对俄罗斯违约前数据拟合，ξ明显>0，意味着极端损失的发生概率远高于正态分布假设

```
GPD尾部密度（ξ>0情形）：
损失概率
  │
  │\
  │ \   → 尾部比正态分布厚得多
  │  \
  │   \___
  │       \___
  │           ─────────────
  └──────────────────────────► 损失规模
       正常区域        极端损失区域
                   ↑ EVT在此区域更准确
```

### 4.4 宏观压力测试（DFAST/CCAR）

```
美联储DFAST框架（年度，2009年起）：

设计三种情景：
  基准情景（GDP正常，失业率正常）
  不利情景（温和衰退：GDP -1–2%）
  严重不利情景（深度衰退：GDP -6–8%，失业率10%+）
         │
         ▼
银行提交资本计划（CCAR部分）：
各银行按情景测算9个季度损失
         │
         ▼
    ┌────┴──────────────────────┐
    ▼                           ▼
资本充足率 > 最低要求？      最坏情景下仍有正股权？
（普通股权益/风险加权资产）   （Going Concern能力）
    │                           │
    是：通过                    是：通过
    否：不得分红/回购          否：需要补充资本
```

**2023年DFAST结果**：23家大银行在严重不利情景下总预计损失$5410亿，普通股权益比率从平均12.4%降至10.1%（仍高于4.5%最低要求）。

### 4.5 相关性崩溃机制

```
正常时期（独立市场）：
资产A和B：相关性约0.2
        合并VaR < 单独VaR之和（分散化有效）

危机时期（Correlation Breakdown）：
                 系统性冲击
                      │
                      ▼
        所有市场参与者同时去杠杆
                      │
         ┌────────────┴──────────────┐
         ▼                           ▼
   抛售全部流动资产            追加保证金
   （不论基本面）              （强制平仓）
         │                           │
         └────────────┬──────────────┘
                      ▼
            资产A和B相关性趋向1
            合并VaR ≈ 单独VaR之和（分散化消失）
```

**Copula函数的选择**：
- Gaussian Copula（高斯Copula）：假设尾部独立性→危机时严重低估联合极端损失
- Clayton Copula：尾部下方（同时暴跌）的相依性比尾部上方（同时暴涨）更强
- Gumbel Copula：尾部上方相依性更强
- 2008年CDO定价使用Gaussian Copula，低估了相关性在压力下的上升

## 6. 历史案例

### 案例一：LTCM 1998——量化模型的"历史校准陷阱"

**背景**：长期资本管理公司（LTCM），由Robert Merton（1997年诺贝尔经济学奖得主）、Myron Scholes和John Meriwether创办，采用收益率利差套利策略（Long低流动性/Off-the-run国债，Short高流动性/On-the-run国债）。

**规模与杠杆**：
- 1998年初：自有资本约$47亿，总资产约$1250亿（杠杆约**25:1**）
- 衍生品名义价值：约**$1.25万亿**
- 策略假设：全球利差终将收敛（基于1994–1997年历史数据）

**危机触发链**：
```
1998年8月17日俄罗斯宣布卢布危机+GKO国债违约
                      │
                      ▼
    全球风险厌恶急剧上升（Flight to Quality）
                      │
                      ▼
        收益率利差扩大（而非收敛）
        （LTCM预期方向完全相反）
                      │
                      ▼
    账面损失→追加保证金→被迫平仓
                      │
                      ▼
    平仓压力推动利差进一步扩大（正反馈）
                      │
                      ▼
    1998年8月–9月：损失约$46亿（几乎损失全部资本）
```

**救助**：1998年9月23日，美联储纽约分行协调14家主要金融机构（高盛、美林、摩根大通等）注资**$36亿**（非公共资金），以90%股权换取，避免强制清算引发市场崩溃。

**建模失败教训**：
- LTCM使用的模型基于1994–1997年数据（未含类似俄罗斯危机场景）
- 模型认为10标准差事件"不可能"；实际出现了俗称"25标准差"的损失
- 正态分布假设+低相关性假设在危机时期双双失效

### 案例二：2008年CDO与Gaussian Copula的"毁灭公式"

**背景**：2000年代美国住房抵押贷款证券化（MBS）和担保债务凭证（CDO）快速扩张，核心定价工具是David Li 2000年提出的Gaussian Copula公式。

**Gaussian Copula的致命缺陷**：
- 假设抵押贷款违约之间的相关性服从高斯（正态）联合分布
- 意味着：即使存在相关性，极端情景下同时违约的概率仍很低
- 实际：房价普遍下跌时，抵押贷款违约的相关性趋向1（地区分散化无效）

**结果**：
- 评级机构基于Gaussian Copula给CDO评AAA
- 2007–2008年，美国各地房价同步下跌，CDO违约相关性飙升
- AAA级CDO市值在2008年跌去60–80%（评级本应仅有0.01%违约率）
- 全球金融机构合计写减损失约$2万亿（IMF估算）

### 案例三：2020年3月VIX飙升——流动性冲击下的相关性崩溃

**时间线**：
- 2020年2月19日：S&P500历史高点（3386点）
- 2020年2月20日–3月23日：S&P500从高点下跌约**34%**（约5周，历史最快下跌之一）
- 2020年3月16日：**VIX达82.69**（最终峰值3月18日约85.47，历史次高）
- 2020年3月12–18日：异常现象——国债、黄金、股票同时下跌（全资产抛售，追求现金）
- 2020年3月23日：美联储宣布无限QE → VIX快速回落

**关键数据**：
- VIX峰值85.47（2020年3月18日），仅次于2008年10月（89.53）
- 美国国债：10年期收益率短暂跳升（价格下跌），尽管是"避险资产"
- 黄金：2020年3月期间一度下跌约12%（随后反弹创历史新高）
- 流动性驱动原因：机构被迫大规模追加保证金，出售一切流动资产换现金

**建模启示**：尾部风险建模需要考虑"流动性冲击"这一特殊情景：在极端流动性危机下，所有资产相关性趋向1，分散化失效，仅持有现金（最短期国库券）才是真正的避险。

## 7. 政策应对

### 7.1 监管压力测试体系

| 工具 | 实施机构 | 机制 | 效果评估 | 局限性 |
|------|---------|------|---------|--------|
| **DFAST/CCAR（美国）** | 美联储（年度） | 银行提交资本计划，历经多情景测试 | 2009年后大型银行资本充足率显著改善（核心资本比率从~8%→~13%） | 模型风险：银行自行建模可能乐观估计；无法预测未知风险类型 |
| **EBA压力测试（欧盟）** | 欧洲银行管理局（两年一次） | 覆盖约50家欧洲大银行 | 提高市场透明度；发现意大利/西班牙银行薄弱 | 不通过不自动触发资本要求；执行依赖各国监管 |
| **反向压力测试** | 各银行内部 | 从破产结果倒推：什么情景会导致失败 | 识别隐藏集中风险 | 主观性强；难以校准 |
| **气候压力测试** | ECB（2022年首次）；美联储（2023年情景分析） | 测试气候物理/转型风险对银行资本的影响 | 提高意识；数据基础仍不成熟 | 数据可得性差；时间跨度（30–50年）超出常规建模范围 |

### 7.2 尾部对冲工具

- **VIX多头期权/期货**：在恐慌事件中暴涨，但持有成本高（负Carry），长期亏损
- **黄金**：通缩危机时与国债共同充当避险，但通胀危机时优于国债
- **尾部对冲基金策略（Universa等）**：专门购买深度虚值Put期权，平时亏损，危机时爆发性盈利（2020年3月Universa单月据报+4000%）
- **国债多头（在通缩型危机）**：最传统尾部对冲，但2022年通胀型危机失效
- **CDS保护**：可定向对冲信用风险，但对手方风险不可忽视（AIG在2008年即是对手方风险的受害者）

## 8. 当前状态（2026）

### 8.1 Basel III终局（Endgame）在美国的实施

- 2023年7月，美联储、OCC、FDIC联合发布Basel III终局提案（总资产>$1000亿的银行）
- 核心变化：扩大标准化方法适用，减少内部模型使用（降低RORWA操控空间）；引入市场风险FRTB框架
- **2024年修订**：因行业强烈反对（部分银行预计资本要求提高19%），修订版大幅削减影响
- **2026年状态**：最终版规则预计2026–2028年分阶段实施

### 8.2 气候风险建模进展

- **ECB气候压力测试（2022年）**：覆盖欧元区4大银行，发现气候物理风险影响有限但转型风险不可忽视
- **美联储气候情景分析（2023年）**：6家大型银行参与（非合规测试，为探索性），结果显示现有模型对气候风险捕捉不足
- **数据缺口**：企业气候信息披露标准（SEC规则2024年）争议持续

### 8.3 AI在量化风险模型中的应用

- 机器学习方法（随机森林、神经网络）在压力测试情景生成和尾部估计中开始被采用
- **模型可解释性（XAI）风险**：深度学习的"黑箱"属性与监管"可解释性"要求冲突
- **泡沫识别**：AI模型在历史数据上表现优秀，但对"新型"极端事件（首次出现的风险类型）的外推能力仍存疑
- 主要银行2025年报告：约30–40%的压力测试辅助模型采用机器学习增强

### 8.4 2026年主要尾部风险监测

- **商业地产（CRE）**：美国办公楼空置率约20%（2025年），中型银行CRE贷款敞口高，潜在信用损失$5000亿–$1万亿（估算）
- **利率风险传导**：BTFP到期后银行HTM证券损失重新暴露，利率长期维持高位的压力
- **私人信贷（Private Credit）**：2022–2026年私人信贷规模从$1.2万亿→$2万亿+（Preqin估算），流动性变现能力未经危机检验
- **AI算法羊群效应**：大量机构采用相似量化模型，可能放大市场波动（2010年闪崩的升级版风险）
