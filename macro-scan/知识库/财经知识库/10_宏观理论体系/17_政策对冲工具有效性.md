## 2. 关键阶段

| 阶段 | 时期 | 主流框架 | 核心政策 | 历史背景 |
|------|------|---------|---------|---------|
| **凯恩斯主义黄金期** | 1945–1970年代初 | 总需求管理，政府大规模介入 | 积极财政+货币从属 | 战后重建，充分就业优先；菲利普斯曲线被视为可利用的权衡 |
| **滞胀危机与货币主义转型** | 1973–1980年代 | 货币主义（Monetarism），M增速锚定 | Volcker加息至21.5%；打破通胀预期 | 石油危机+工资-价格螺旋；菲利普斯曲线失效论 |
| **通胀目标制（IT）** | 1990年代–2008年 | 独立央行+通胀目标（2%）+泰勒规则 | 新西兰1990年率先采用；1999年ECB成立 | 大缓和时代（Great Moderation），通胀受控，周期温和 |
| **QE与非常规政策** | 2008–2021年 | ZLB约束下资产负债表扩张+前瞻指引 | QE/TLTRO/前瞻指引/负利率（欧日） | 金融危机后传统货币工具耗尽；财政受政治约束 |
| **宏观审慎兴起** | 2010–至今 | 双支柱：货币政策+宏观审慎 | CCyB/LTV/DTI/G-SIB附加资本 | Basel III框架；系统性风险纳入央行职责 |
| **通胀回归+工具重评** | 2021–至今 | 传统加息工具重新主导；非常规退出 | 快速加息（美国+425bp/年）；QT | 供应链通胀+财政赤字叠加，非常规工具局限性暴露 |

## 3. 关键变量

| 变量 | 含义 | 关键阈值 / 历史数据 |
|------|------|-------------------|
| **政策利率** | 央行基准利率，货币工具核心变量 | 中性利率（r*）约2–3%（美国）；高于中性=紧缩；低于=宽松 |
| **财政乘数** | 财政支出增加1元对GDP的拉动 | 正常时期约0.5–1.0；流动性陷阱时约1.5–2.0（IMF 2012年承认低估希腊） |
| **债务/GDP** | 财政政策空间指标 | >90%（发达国家）财政扩张空间受限（Reinhart-Rogoff）；但r<g时边界更高 |
| **信贷/GDP缺口** | 宏观审慎核心触发指标（BIS Basel Gap） | >10pp（正缺口）触发CCyB累积；<-10pp触发释放 |
| **LTV（贷款价值比）** | 住房贷款审慎指标 | 韩国危机前>90%，2010年后政策约束在60–70% |
| **r-g差（利率-增长率）** | 债务可持续性核心指标 | r<g时债务自发稳定；r>g时需基本财政盈余 |
| **M2/GDP** | 货币深化程度与过剩流动性信号 | 中国约220%（2024年），美国约90%；快速上升为流动性过剩信号 |
| **QT速度** | 央行缩表节奏 | 美联储2022–2024年：国债$600亿/月+MBS$350亿/月为"最大节奏" |

## 4. 传导机制详解

### 4.1 流动性工具

**常备回购便利（SRF）——无stigma的流动性底线**

```
银行面临短期美元流动性压力
          │
    选择①：贴现窗口（stigma）
    银行不愿意→市场认为"示弱"
          │
    选择②：SRF（2021年后）
    以国债/MBS抵押隔夜借款，利率=EFFR上限
    没有stigma（常设工具，非紧急）
          │
          ▼
EFFR = 走廊内，不会因流动性压力脱轨
```

**贴现窗口stigma的历史证据**：2020年3月美联储将贴现率降至0.25%（与政策利率平级），但贴现窗口借款仍极低（机构宁可出售资产也不借款），说明stigma具有强黏性。

**货币互换额度（Swap Lines）**：
- 5家常设：美联储↔ECB/BOJ/BOE/BOC/SNB（2013年起，无上限，3个月期）
- 2020年COVID期间：临时扩展至9个央行（含澳大利亚/新西兰/韩国/新加坡/巴西/墨西哥等）
- 机制：外国央行从Fed借美元→向本国银行提供美元流动性→防止海外美元市场冻结
- 2020年峰值余额：约$4490亿（2020年5月）

### 4.2 信贷工具（QE）的三条传导渠道

```
美联储购买长期国债/MBS
          │
    ┌─────┴────────────────────────┐
    ▼              ▼                ▼
投资组合再平衡     信号渠道         流动性溢价
（Portfolio        （Signaling）     压缩
Rebalancing）
    │              │                │
投资者被迫持有     承诺未来低利率   改善市场流动性
风险更高资产       预期              减少illiquidity
（股票/公司债）    （前瞻指引强化）  premium
    │              │                │
    └──────────────┴────────────────┘
                   ▼
            长端收益率↓→借贷成本↓
            风险资产价格↑→财富效应→消费↑

【局限性】
- ZLB附近有效；通胀/高利率期间效果弱
- 分配不均（资产持有者受益更多）
- 退出困难（缩表可能引发利率波动）
```

**TLTRO III（欧洲定向长期再融资操作）**：
- 2019年9月–2024年：利率与银行贷款增速挂钩（贷款增速超基准→贷款利率可降至负值）
- 机制：引导银行将廉价资金传导至实体信贷，而非用于购买政府债券
- 效果：欧元区中小企业贷款利差收窄约50–80bp（ECB研究，2021年）
- 退出：2023–2024年大量TLTRO到期，欧洲央行缩表加速

### 4.3 财政工具

**自动稳定器 vs 相机抉择：时滞比较**

```
衰退发生
    │
    ├──► 自动稳定器（无时滞）
    │    失业保险立即支付
    │    税收随收入自动下降
    │    → 收入支撑，防止乘数收缩
    │
    └──► 相机抉择（三个时滞）
         1. 认知时滞（Recognition Lag）：
            判断"是否需要财政刺激"：约3–6个月
         2. 决策时滞（Decision Lag）：
            立法通过：约6–18个月（美国国会程序）
         3. 执行时滞（Implementation Lag）：
            资金真正支出：约6–24个月
         合计：衰退结束时刺激才到来（顺周期风险）
```

**凯恩斯乘数的实证范围**：
- 正常时期（货币政策正常运作）：约0.5–0.8（货币政策部分抵消财政扩张）
- ZLB（零利率）+货币政策无法扩张：约1.0–1.8（无抵消）
- 2012年IMF承认：对希腊财政乘数假设约0.5，实际约1.5，低估了紧缩的GDP损失

**r-g框架与财政空间**：

```
债务稳定条件：pb ≥ (r-g) × d
（pb=基本财政差额，r=名义利率，g=名义增长率，d=债务/GDP）

2010年代（r<g时代）：
r约2%，g约4%（名义）→ r-g = -2%
即使运行基本财政赤字，债务/GDP仍可稳定
→ Blanchard 2019年"安全的高债务"论文的背景

2022年后（r>g时代）：
r约5%，g约4–5%→ r-g接近0或正值
财政空间重新收窄→债务可持续性再度成为约束
```

### 4.4 宏观审慎工具

**逆周期资本缓冲（CCyB）**：

```
信贷/GDP缺口（Basel Gap）
          │
    ┌─────┴──────────────┐
    ▼                    ▼
缺口>10pp（过热）      缺口<-10pp（危机）
要求积累CCyB           释放CCyB
（最高2.5%）           （回零或更低）
          │                    │
银行资本要求↑           银行资本要求↓
→ 信贷供给放缓          → 银行可继续放贷
→ 金融周期降温          → 信贷收缩防止
```

**2020年COVID期间释放**：欧洲多国CCyB释放约700–900亿欧元银行资本，维护信贷供给。英格兰银行从0.5%→0%；瑞典从2.5%→0%。

**LTV上限的有效性证据**：
- 香港：1991年引入LTV上限（现约60–70%），房地产周期波动明显较低于没有管制的市场
- 韩国：2003–2012年多次调整LTV/DTI，房价波动与未管制估算相比降低约30–40%（IMF研究）
- 局限：仅约束新增贷款；借款人可通过其他渠道（第二抵押贷款、信用卡）规避

### 4.5 央行-财政协调框架

```
货币政策独立性
          │
    ┌─────┴──────────────────────────────┐
    ▼                                    ▼
理想情形（功能分离）               财政主导（Fiscal Dominance）
央行：价格稳定                    政府要求央行：
财政：资源分配+周期稳定           ① 维持低利率（财政融资成本）
两者协调但不从属                  ② 购买政府债券（货币化赤字）
          │                              │
          ▼                              ▼
通胀锚定有效                      通胀预期脱锚
信用资质良好                      长端利率↑/外资撤退
财政可持续                        货币贬值/通胀上升
```

**现代货币理论（MMT）的主张**：发行本币主权国家可无限发行货币（无违约风险），唯一约束是通胀；中央银行应配合财政支出。**主流批评**：通胀约束是真实的，MMT低估了通胀预期脱锚的速度和成本（阿根廷/津巴布韦等案例）。

## 6. 历史案例

### 案例一：2001年日本零利率+QE1.0——最早的非常规政策

**背景**：日本1990年代泡沫破裂后陷入资产负债表衰退（Balance Sheet Recession），传统降息无效——银行和企业在修复资产负债表，不借款也不贷款（流动性陷阱）。

**政策工具顺序**：
1. 1999年2月：引入零利率政策（ZIRP）
2. 2001年3月：首次量化宽松（QE1.0）——将日本银行活期存款目标从约1万亿日元提高至5万亿→6万亿日元
3. 2001–2006年：QE规模逐步扩大，购买国债和部分商业票据

**效果评估**：
- 直接效果：银行流动性充裕，短端利率维持低位
- 传导受阻：信贷增速仍持续萎缩，私人部门去杠杆优先于借贷
- GDP：2001–2004年平均约0.7%，远低于潜在增长
- **关键教训**：QE在需求端萎靡（无信贷需求）时无法有效刺激经济；资产负债表衰退需要财政政策配合——而日本财政因债务顾虑相对保守

### 案例二：2012年ECB"不惜一切代价"——信号效应的完美案例

**背景**：欧元区主权债务危机中，西班牙/意大利10年国债收益率飙升至7–8%（理论上无法维持偿债），欧元区解体风险被市场定价。

**2012年7月26日**：Mario Draghi在伦敦讲话：
*"在我们授权范围内，欧洲央行将不惜一切代价保护欧元。相信我，这已经足够了。"*

**随后公布OMT（直接货币交易）计划**：
- 无上限购买不超过3年期主权债券
- 附条件：相关国家需已接受ESM（欧洲稳定机制）援助协议
- **从未真正动用**

**效果**：
- 意大利10年收益率：讲话后2个月从约6.5%→约4.0%（-250bp）
- 西班牙10年收益率：从约7.5%→约4.5%（-300bp）
- **威慑力等于实际购买**：市场相信ECB会行动，投机性做空欧元区主权债的动机消失

**为何成功**：承诺的可信度来自：①无上限设计；②附条件（避免道德风险）；③德拉吉公信力；④市场理解ECB有无限发行欧元的能力

### 案例三：2020年美国财政+货币双重刺激——史上最大宏观对冲

**规模**：
- 财政：2020年CARES法案$2.2万亿 + 2020年12月$0.9万亿 + 2021年ARP法案$1.9万亿 = 合计约$5万亿（占GDP约25%）
- 货币：美联储QE累计增加资产$4.8万亿（2020年3月–2022年3月）；利率降至0–0.25%

**协调机制**：
- PPP（工资保障计划）：财政提供资金，银行发放贷款，Fed提供流动性（PPPLF）
- 主街贷款（MSLP）：Fed提供信贷，财政承担损失
- 政府直接补贴（Economic Impact Payments）：快速发放，通过银行账户

**效果**：
- GDP：2020年 -3.4%（相对疫情预期的 -10%以上，损失大幅控制）
- 2021年GDP：+5.7%（V型复苏）
- 失业率：2020年4月峰值14.7%→2021年底降至4.2%

**代价**：
- 通胀：2021–2022年CPI高达9.1%（2022年6月峰值），为1980年代以来最高
- 根本原因争议：供应链通胀 vs 过度财政刺激（"货币化"效果）
- 美联储2022年被迫快速加息纠偏

## 7. 政策工具矩阵

### 7.1 情景×工具优先选择

| 宏观情景 | 首选工具 | 次选工具 | 禁忌 |
|---------|---------|---------|------|
| **衰退+通缩风险** | 降息+QE | 财政刺激（ZLB时加码） | 过早加息（2011年ECB错误） |
| **通胀过热** | 加息+QT | 财政紧缩（降赤字） | 过晚加息（2021–2022年美联储滞后） |
| **金融不稳定（流动性危机）** | SRF/贴现窗口/互换 | 短暂QE（稳定市场） | 加息（2008年9月ECB错误） |
| **房地产泡沫（信贷过度）** | LTV/DTI收紧+CCyB积累 | 加息（副作用大） | 单纯加息（牺牲全局） |
| **结构性低增长** | 财政结构性改革 | 生产率提升政策（R&D/教育） | 无限量QE（副作用>效益） |

### 7.2 政策组合原则

- **搭配原则**：货币+财政+宏观审慎三者配合，单一工具难以应对复合风险
- **时序原则**：宏观审慎（预防）→货币（短期稳定）→财政（中期支撑）
- **退出纪律**：过晚退出QE/低利率会埋下通胀/金融稳定隐患（2021–2022年案例）

## 8. 当前状态（2026）

### 8.1 货币政策工具箱状态

- **联邦基金利率**：约3.50–4.00%（2026年初），仍高于中性利率，处于轻度紧缩区
- **美联储资产负债表**：约$7.0–7.3万亿，QT仍在进行（节奏已放缓至国债约$250亿/月）
- **ON RRP余额**：约$3000–5000亿，接近正常水平，QT可能在2026年内暂停
- **工具储备**：若衰退，降息空间约350bp；重启QE技术上可行但政治阻力更大

### 8.2 财政政策空间
