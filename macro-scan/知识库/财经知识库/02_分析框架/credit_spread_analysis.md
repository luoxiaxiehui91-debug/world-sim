# 信用利差（BAA10Y）解读框架

## 核心定义

BAA10Y = 穆迪 Baa 级企业债收益率 - 10年期美国国债收益率。
衡量投资级企业债相对于无风险利率的额外溢价，反映信贷市场对企业违约风险的定价。
利差扩大 = 信用收紧，企业融资成本上升，经济压力加大；利差收窄 = 信用宽松，风险偏好回升。

## Workflow

### Step 1：判断当前利差绝对水平

| BAA10Y 数值 | 信用状态 | 含义 |
|:------------|:---------|:-----|
| < 1.5% | 极度宽松 | 信贷市场过热，投资者追逐收益，低利差往往是周期顶部特征 |
| 1.5% ～ 1.8% | 正常宽松（risk-on 区间上限）| 扩张期典型水平，企业融资畅通；**低于 1.8% 满足核心框架 risk-on 得分阈值** |
| 1.8% ～ 2.0% | 正常宽松（neutral 区间起点）| 信用条件仍较宽松，但已进入核心框架 neutral 区间 |
| 2.0% ～ 2.5% | 轻度收紧 | 市场开始谨慎，但尚在正常范围 |
| 2.5% ～ 3.5% | 明显收紧 | 信用风险溢价上升，企业再融资压力加大 |
| 3.5% ～ 5.0% | 信用压力 | 对应经济减速或市场动荡期，违约预期上升 |
| > 5.0% | 信用危机 | 历史对应：2008年金融危机（峰值约 6.1%）、2020年疫情冲击（峰值 4.6%） |

### Step 2：判断趋势方向

- **利差快速走阔**（1个月内扩大 > 0.5%）：信用市场恶化加速，通常领先股市下跌，须提升风险级别
- **利差持续高位**（> 3.0% 维持 > 4 周）：信用市场尚未修复，即使股市反弹也需谨慎
- **利差从高位快速收窄**：流动性恢复，通常是危机渡过的早期信号
- **利差低位长期盘整**（< 1.8%）：市场自满，是后续利差大幅扩张的前提条件

### Step 3：与其他指标交叉验证

- BAA10Y 扩大 + VIX 上升 → 双市场（权益+信用）同步收紧，系统性压力确认
- BAA10Y 扩大 + T10Y2Y 倒挂 → 信用收紧叠加衰退预期，stress 级别
- BAA10Y 扩大 但 VIX 平稳 → 信用市场先行预警，权益市场尚未反应，需高度关注
- BAA10Y 收窄 + VIX 下降 + PMI > 50 → 典型 risk-on 修复组合

### Step 4：生成信用利差叙事描述

基于以上判断，输出格式：
> "当前 BAA10Y 信用利差为 [数值]，处于 [状态描述]。[趋势描述]。企业债融资成本 [上升/下降/平稳]，信贷市场整体呈现 [宽松/中性/收紧] 状态，[一句话对经济活动的影响判断]。"

## Important Notes

- BAA10Y 是**滞后于**股市但**领先于**实体经济的中间指标，信用市场的拐点通常比GDP更早反映压力
- 高收益债利差（HY spread）比 BAA10Y 更敏感，但 FRED 数据中 BAA10Y 序列更长、更稳定
- 历史参考锚点：2008年10月峰值约 6.1%；2020年3月峰值 4.64%；2016年初 油价危机 3.36%；正常扩张期均值约 1.8%–2.2%
- 利差扩大时，中小企业受影响远大于大企业（大企业有债券市场直接融资），分析时注意传导路径
