# 经济周期定位框架

## 周期阶段划分

```
            通胀
              ↑
    过热      │      滞胀
   (高增长    │   (低增长
    高通胀)   │    高通胀)
              │
──────────────┼──────────────→ 增长
              │
    复苏      │      衰退
   (高增长    │   (低增长
    低通胀)   │    低通胀)
              ↓
```

## 四阶段特征矩阵

| 阶段 | 增长 | 通胀 | 就业 | 利率 | 资产表现 |
|------|------|------|------|------|----------|
| 复苏 | ↑ | ↓或稳 | ↑ | ↓或稳 | 股↑债↑ |
| 过热 | ↑或稳 | ↑ | 高 | ↑ | 股↓债↓商品↑ |
| 滞胀 | ↓ | ↑ | ↓ | ↑ | 股↓债↓商品↑ |
| 衰退 | ↓ | ↓ | ↓ | ↓ | 股↓债↑ |

## 关键定位指标

### 1. 增长指标
- **GDP增速**：环比年化 vs 潜在增速
- **PMI**：>50扩张，<50收缩
- **工业产出**：同比增速
- **零售销售**：消费动能

### 2. 通胀指标
- **CPI/PCE**：同比、环比、核心
- **PPI**：上游价格压力
- **工资增速**：成本推动压力
- **通胀预期**：调查、市场隐含

### 3. 就业指标
- **失业率**：U3、U6
- **非农就业**：月度变化
- **初请失业金**：高频指标
- **职位空缺率**：劳动力需求

### 4. 金融条件
- **利率水平**：政策利率、长端利率
- **信用利差**：风险偏好
- **收益率曲线**：期限结构
- **金融条件指数**：综合指标

## 周期判断流程

### Step 1：增长定位
```
GDP增速 > 潜在增速 + 1%  → 过热区
GDP增速 ≈ 潜在增速      → 稳健区
GDP增速 < 潜在增速 - 1%  → 衰退区
```

### Step 2：通胀定位
```
核心CPI > 目标 + 1%  → 高通胀
核心CPI ≈ 目标      → 通胀适中
核心CPI < 目标 - 1%  → 低通胀/通缩压力
```

### Step 3：交叉判断
- 高增长 + 高通胀 → 过热
- 高增长 + 低通胀 → 复苏
- 低增长 + 高通胀 → 滞胀
- 低增长 + 低通胀 → 衰退

### Step 4：动态确认
- 观察指标变化趋势
- 确认是阶段转换还是暂时波动
- 多指标交叉验证

## 辅助判断工具

### 收益率曲线
- **倒挂**：衰退信号（领先6-18个月）
- **陡峭**：复苏信号
- **平坦**：周期中段

### 信用利差
- **收窄**：风险偏好强，经济向好
- **走阔**：风险规避，经济承压

### 库存周期
- **补库存**：需求回升，复苏信号
- **去库存**：需求回落，衰退信号

### 产能利用率
- **>85%**：产能紧张，通胀压力
- **<75%**：产能过剩，通缩压力

## 各阶段政策含义

### 复苏期
- 货币：维持宽松或缓慢退出
- 财政：可适度收紧
- 投资：股票、高收益债

### 过热期
- 货币：加息收紧
- 财政：收紧或中性
- 投资：商品、通胀保值债

### 滞胀期
- 货币：两难（抗通胀vs保增长）
- 财政：结构性政策
- 投资：商品、现金

### 衰退期
- 货币：降息宽松
- 财政：扩张刺激
- 投资：国债、防御性股票

## 历史周期定位示例

### 2007年Q3（美国）
- 增长：放缓但仍正
- 通胀：上升（油价）
- 定位：滞胀初期
- 实际：随后进入衰退

### 2009年Q3（美国）
- 增长：触底回升
- 通胀：低位
- 定位：复苏初期
- 实际：确认复苏

### 2021年Q3（美国）
- 增长：强劲
- 通胀：飙升
- 定位：过热
- 实际：政策收紧

### 2026年Q1（美国）
- 增长：温和（PMI 52-53）
- 通胀：回落但仍高于目标
- 就业：韧性
- 收益率曲线：倒挂
- 定位：复苏向过热过渡，但衰退风险存在

## 注意事项

### 1. 指标滞后性
- GDP：滞后
- 失业率：滞后
- PMI：同步偏领先
- 收益率曲线：领先

### 2. 结构性变化
- 潜在增速下降
- 通胀目标制影响预期
- 全球化改变传导

### 3. 外部冲击
- 疫情、战争、能源冲击
- 可能打乱周期节奏
- 需灵活调整判断
