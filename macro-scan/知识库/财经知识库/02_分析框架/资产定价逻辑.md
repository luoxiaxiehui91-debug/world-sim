# 资产定价逻辑

> 核心模型：DCF、CAPM、风险溢价
> 更新时间：2026-05-08

---

## 一、股票定价

### 1.1 DCF模型

```
股价 = Σ CF_t / (1+r)^t
```

其中：
- CF_t = 第t期现金流（股息、自由现金流）
- r = 折现率

### 1.2 折现率构成

```
r = 无风险利率 + 股权风险溢价
```

| 组成部分 | 当前水平 | 影响因素 |
|----------|----------|----------|
| 无风险利率 | 4-5%（10Y美债） | 美联储政策、通胀预期 |
| 股权风险溢价 | 4-6% | 风险偏好、不确定性 |

### 1.3 利率对股价的影响

```
利率↑
    ↓
折现率↑
    ↓
未来现金流现值↓
    ↓
股价↓
```

**经验**：利率上升1%→PE下降约15-20%

## 二、债券定价

### 2.1 收益率构成

```
收益率 = 实际利率 + 预期通胀 + 期限溢价 + 信用溢价
```

| 组成 | 含义 | 当前水平 |
|------|------|----------|
| 实际利率 | 实际回报 | 1-2% |
| 预期通胀 | 通胀补偿 | 2-2.5% |
| 期限溢价 | 持有长期风险补偿 | 0-0.5% |
| 信用溢价 | 违约风险补偿 | 0-5%（视评级） |

### 2.2 期限结构理论

| 理论 | 核心观点 |
|------|----------|
| 预期假说 | 长期利率=未来短期利率预期平均值 |
| 流动性偏好 | 长期利率=预期+期限溢价 |
| 市场分割 | 不同期限市场独立 |

## 三、风险溢价

### 3.1 CAPM模型

```
预期回报 = Rf + β × (Rm - Rf)
```

其中：
- Rf = 无风险利率
- β = 系统风险系数
- Rm = 市场回报
- Rm - Rf = 市场风险溢价

### 3.2 多因子模型

**Fama-French三因子**：
```
回报 = Rf + β_mkt × MKT + β_smb × SMB + β_hml × HML
```

| 因子 | 含义 |
|------|------|
| MKT | 市场风险 |
| SMB | 小盘股溢价 |
| HML | 价值股溢价 |

### 3.3 风险溢价的决定因素

| 因素 | 影响 |
|------|------|
| 经济不确定性 | ↑→风险溢价↑ |
| 投资者风险厌恶 | ↑→风险溢价↑ |
| 流动性 | ↓→风险溢价↑ |
| 杠杆 | ↑→风险溢价↑ |

## 四、股债相关性

### 4.1 正相关

**场景**：通胀驱动
- 通胀↑ → 央行加息 → 股债双杀

### 4.2 负相关

**场景**：增长驱动
- 增长预期↓ → 股跌债涨（避险）

### 4.3 当前状态

| 时期 | 相关性 | 主导因素 |
|------|--------|----------|
| 2000-2020 | 负 | 增长驱动 |
| 2022 | 正 | 通胀驱动 |
| 2023- | 混合 | 通胀+增长交替 |

## 五、估值指标

### 5.1 股票估值

| 指标 | 计算方式 | 当前水平 | 历史均值 |
|------|----------|----------|----------|
| PE（市盈率） | 价格/盈利 | 20-25x | 15-16x |
| CAPE（周期调整PE） | 价格/10年均盈利 | 30-35x | 16x |
| PB（市净率） | 价格/账面价值 | 3-4x | 2x |
| 股息率 | 股息/价格 | 1.5% | 2-3% |

### 5.2 债券估值

| 指标 | 含义 |
|------|------|
| 收益率水平 | 绝对回报 |
| 期限利差 | 经济预期 |
| 信用利差 | 风险偏好 |

## 六、资产配置逻辑

### 6.1 股债配比

| 环境 | 股票 | 债券 |
|------|------|------|
| 增长好+通胀低 | 超配 | 低配 |
| 增长好+通胀高 | 中性 | 低配 |
| 增长差+通胀低 | 低配 | 超配 |
| 增长差+通胀高 | 低配 | 低配（现金） |

### 6.2 战略vs战术

| 类型 | 时间框架 | 调整频率 |
|------|----------|----------|
| 战略配置 | 长期（5-10年） | 年度 |
| 战术配置 | 短期（1年） | 月度/季度 |
