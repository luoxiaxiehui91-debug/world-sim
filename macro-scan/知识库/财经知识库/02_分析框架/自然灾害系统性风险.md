> 创建：2026-06-11 | 维护：人工按需更新

## 1. 为什么大多数自然灾害对全球金融市场影响有限

这是理解本框架的关键起点。历史上绝大多数强震、洪灾、台风对全球股市的冲击在 1-2 周内基本消退，原因是：

1. **地理隔离**：损失集中于受灾地区，不形成全球供应链阻断
2. **保险覆盖**：成熟市场有再保险机制分散损失
3. **重建效应**：重建需求实际上提振 GDP（"破窗谬误"的现实版本）
4. **快速政策响应**：央行/政府通常 24-72 小时内表态，稳定预期

**触发全球冲击的条件必须同时满足：**
- 超强级别（地震 M≥7.5，热带气旋 5级+）
- 打击全球供应链关键节点（台湾半导体、日本汽车零部件、荷兰化工港口）
- 叠加脆弱因素（核电站、LNG 储运设施、金融中心）

## 2. 灾害分级与历史冲击对照

### 地震

| 震级 | 描述 | 历史 SPX 冲击 | 恢复周期 | 全球传导概率 |
|------|------|-------------|---------|------------|
| M < 6.0 | 轻微，局部破坏 | 0% | 即时 | 极低 |
| 6.0~7.5 | 中强，城市破坏 | -1%~-3%（局部市场）| 1~4 周 | 低（除非打击关键节点）|
| 7.5~8.5 | 强震，大规模破坏 | -5%~-15%（受灾国）| 1~6 个月 | 中（取决于地点）|
| > 8.5 | 超强，国家级灾难 | -10%~-20%（受灾国），全球-3%~-8% | 6~24 个月 | 高（核事故/关键港口）|

**关键变量**：震中是否在人口密集区、工业区、核电设施、主要港口附近。

### 海啸

通常由 M≥7.5 海底地震触发，传导速度极快（太平洋 500-800km/h），主要通过：
- 沿海工业设施损毁（炼油厂、港口、半导体工厂）
- 旅游业骤停（区域性）
- 农业减产（盐渍化）

### 火山

| 强度 | VEI等级 | 典型案例 | 主要传导路径 |
|------|--------|---------|------------|
| 小规模 | VEI 1-3 | 冰岛频繁小喷发 | 航空短暂中断 |
| 中等 | VEI 4-5 | 2010年冰岛艾雅法拉 | 欧洲航空6天瘫痪，损失约13亿欧元 |
| 大规模 | VEI 6+ | 1991年皮纳图博 | 全球气温下降0.5°C，次年农业减产 |
| 超级火山 | VEI 7+ | 印尼托巴（7.4万年前）| 理论上：全球粮食危机、气候变冷多年（极低概率，无现代先例）|

## 3. 核心传导链（量化时序）

```
极端自然灾害确认（T=0）
  ↓
当地基础设施瘫痪（T+0~7天）
  [港口关闭/工厂停产/电力中断/人员疏散]
  → 已有保险赔付预期开始定价
  ↓
直接供应链中断（T+1~4周）
  [上游零部件供应→下游制造商被迫减产]
  → 汽车/半导体/化工等行业股价-5%~-20%
  → 重建材料需求上升（水泥/钢材+10%~+30%）
  ↓
全球价格传导（T+1~3个月）
  [仅当关键产品全球供应紧缺时触发]
  → 半导体：智能手机/PC 交货期延长，价格+5%~+15%
  → 能源：如涉及核电/LNG→ 替代需求→天然气价格+20%~+80%
  → 粮食：如主产区受灾→ 粮价+5%~+30%
  ↓
宏观传导（T+3~12个月）
  [通常只有超强级别灾害才到这一步]
  → 受灾国 GDP -0.5%~-5%（同时有重建加成对冲）
  → 全球通胀+0.1%~+0.5%（如能源/粮食受波及）
```

## 4. 日本 2011 东日本大地震复盘（完整案例）

**时间**：2011-03-11，M9.0，里氏历史第4强

**触发条件**：震级超强 + 核电站（福岛第一）+ 汽车/半导体核心产区（宫城/福岛）

| 时间点 | 事件 | 市场反应 |
|--------|------|---------|
| T+0（3月11日）| M9.0地震+海啸 | 日经-3%当天 |
| T+4天 | 福岛核事故升级至7级 | 日经累计-15%，日元套利平仓 |
| T+2周 | 汽车/电子供应链中断确认 | Toyota/Honda全球工厂部分停产 |
| T+1个月 | 德国宣布弃核 | 欧洲天然气/煤炭需求预期上升 |
| T+3个月 | 供应链开始恢复 | 日经开始反弹 |
| T+1年 | 日本 GDP -0.5%（含重建加成后）| 基本恢复 |

**关键教训**：
- 核事故是放大器——没有核事故的同等震级（如2010海地M7.0）对全球市场冲击极小
- 供应链"最后一公里"效应：日本特定工厂（如汽车颜料、晶圆研磨液）是全球单一来源，少量供应中断导致全球生产线停摆
- 日元套利反向平仓：灾后机构大量汇回日元赔付→日元升值

## 5. 反面条件（不触发全球冲击）

大多数自然灾害不会触发全球金融冲击，以下条件**任意一项**成立时，冲击局限于区域：

1. **震中/风眼远离工业区**（如2004年印度洋海啸，死亡>22万，但全球股市1周内恢复）
2. **受灾国为小型经济体**（如尼泊尔地震，GDP<0.1%全球）
3. **充分的灾害保险**（日本/美国保险渗透率高，损失能被快速消化）
4. **供应链有冗余替代**（当一个供应商受损时，其他地区产能可以快速填补）
5. **重建规模提振需求**（灾后1-2年GDP往往高于基准，"重建效应"）

## 6. 与系统信号的接入

**`data/disaster_signals.json`**（`fetch_disaster_signals.py` 每日更新）：
```json
{
  "latest_significant": {
    "magnitude": 6.2,
    "location": "Japan",
    "depth_km": 35,
    "timestamp": "2026-06-11T04:23:00Z",
    "risk_level": "low"
  },
  "active_volcanoes": ["Etna", "Sakurajima"],
  "disaster_risk_score": 12
}
```

**触发推演的条件**（`ALERT_KEYWORDS["自然灾害"]` + 灾害信号）：
- `disaster_risk_score > 50`（M≥7.5 地震或 VEI≥5 火山）
- 震中位于关键工业节点（台湾/日本东海岸/荷兰鹿特丹/巴拿马运河沿线）
