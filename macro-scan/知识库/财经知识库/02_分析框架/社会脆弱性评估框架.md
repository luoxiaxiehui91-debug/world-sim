## 1. 四维脆弱性评分模型

社会动荡的根本驱动力来自**相对剥夺感**（预期-现实差距），四维指标是衡量这种积累的代理变量。

| 维度 | 高风险阈值 | 数据来源 | 更新频率 | 说明 |
|------|---------|---------|---------|------|
| **基尼系数** | > 0.45 | 世界银行 | 年度 | 越高说明不平等越严重 |
| **青年失业率**（15-24岁）| > 25% | ILO/FRED SNGISAUS | 月度（部分国家）| 社会动荡的点火器 |
| **外汇储备月数** | < 3 个月进口额 | IMF | 月度 | 政府应对危机的弹药 |
| **政治自由度** | < 40 分（Freedom House）| Freedom House | 年度 | 威权脆弱区间：高压下积累不满 |

**三项及以上触红** → 社会动荡概率非线性跳升（斯里兰卡2022为四维全红的极端案例）

## 2. 两类国家的不同传导机制

### 成熟民主国家

传导路径：社会不满 → 选举惩罚执政党 → 政策摇摆 → 资产短暂波动

资产影响：
- SPX 在选举年前后均值波动 ±3~5%，选举后12个月通常恢复
- 政策摇摆（如财政扩张←→紧缩）影响利率和企业盈利预期
- **货币稳定性强**：成熟民主货币体系不会因社会动荡直接崩溃

### 新兴市场国家

传导路径：社会压力 → 资本外流信号 → 货币贬值 → 进口通胀加剧 → 更深社会压力（反馈环）

资产影响（历史均值）：
- 货币：-15%~-50%（缅甸-50%，斯里兰卡-30%，阿根廷历次-30%~-70%）
- 股市（本地）：-20%~-40%
- 外资 FDI 撤出：-30%~-70%，且3-5年内难以恢复（比股市更持久）

## 3. 复合风险非线性效应（斯里兰卡模型）

**气候 × 债务 × 社会脆弱性 三重叠加**

2022年斯里兰卡崩溃路径：
```
气候干旱（2021-22）→ 农业减产 → 食品进口增加 → 外储消耗
     +
新冠旅游业崩溃 → 外汇收入骤降 → 外储进一步消耗
     +
大规模有机农业改革（政策失误）→ 2022年粮食产量-50%
     ↓
外储耗尽（2022年4月）→ 无法进口能源 → 停电18小时/天
     ↓
社会崩溃 → 民众冲入总统官邸 → 政府倒台 → IMF接管
```

**关键参数**：外储耗尽是触发点，而非不平等本身（基尼系数斯里兰卡并不算高）

## 4. 不平等→消费→政策传导链

财富高度集中时，财政政策传导效率下降：

| 基尼系数 | 财政乘数（针对全体）| 财政乘数（针对低收入群体）|
|---------|-------------|-------------|
| < 0.35（低不平等）| 1.0~1.3 | 1.5~2.0 |
| 0.35~0.45 | 0.7~1.0 | 1.2~1.5 |
| > 0.45（高不平等）| 0.5~0.8 | 1.2~1.5 |

含义：在高不平等社会，只有定向刺激低收入群体才能有效提振需求；宽泛的减税/直接发钱因为富人消费边际倾向低（MPC≈0.2），传导效率低。

## 5. 与信号系统的接入

**GDELT `social_stress` 维度**（`scan_weak_signals.py` 输出）：
- 当某国的 GDELT social_stress 分值 > 35 时，结合本框架检查该国四维评分
- 高分数 + 四维 ≥ 2/4 触红 → 标注为"社会压力二级预警"，在 `situation_tracker` 中相关事件升级为 escalating

**`signal_synthesizer` R09 规则**（初期 disabled，等数据积累）：
- 触发条件：社会政治危机类别 min_avg_ratio ≥ 2.0 × 30天 + social_stress > 35

## 7. 反面条件（高脆弱但未爆发的情景）

社会脆弱性高时仍不发生危机的条件：
1. **外部援助**：IMF 协议或盟友信用额度（巴基斯坦多次依赖沙特/中国援助）
2. **有效政治压制**：威权体制对组织抗议的成本足够高（中国/沙特）
3. **生存优先于反抗**：极端经济困境下人们忙于生存，无暇组织（反直觉规律）
4. **民族主义转移**：外部威胁叙事（战争/制裁）转移内部不满（俄罗斯2022+）
