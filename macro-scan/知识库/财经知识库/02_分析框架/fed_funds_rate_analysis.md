# 联邦基金利率（DFF）分析模块

## 核心定义

**联邦基金利率（Federal Funds Rate，DFF）**：美国商业银行之间隔夜拆借准备金的利率目标区间中值，由美联储联邦公开市场委员会（FOMC）设定，是美国货币政策最直接的操作锚。FRED代码：DFF（日度有效联邦基金利率）或DFEDTARU/DFEDTARL（目标区间上/下限）。

DFF 是**政策利率**，反映美联储主动选择，而非市场供需决定的市场利率。其变动方向与速度是判断货币政策松紧的第一信号。

---

## Workflow

### Step 1：DFF 绝对水平分档

根据 DFF 当前数值，判断政策利率所处历史区间，赋予宏观背景含义。

| 档位 | DFF 范围 | 政策立场 | 历史背景参考 |
|------|----------|----------|--------------|
| 极低（零利率/近零） | 0.00 % – 0.25 % | 极度宽松 / 非常规货币政策区间 | 2008年12月–2015年12月（金融危机后QE时代）；2020年3月–2022年3月（新冠冲击后二次归零） |
| 低 | 0.25 % – 1.50 % | 宽松偏中性 | 2015–2018年首轮正常化初段；2022年加息开始前数月 |
| 中低 | 1.50 % – 3.00 % | 中性偏紧 | 2018年正常化中段；2022年加息中段（Q3） |
| 中高 | 3.00 % – 4.50 % | 偏紧 | 2022年Q4–2023年Q1快速加息冲顶阶段 |
| 高 | 4.50 % – 6.00 % | 明显紧缩 | 2023年5月–2024年9月维持峰值5.25–5.50%；对应历史上1990年代初、2006–2007年峰值 |
| 极高 | ＞ 6.00 % | 强力压制通胀 / 经济代价极大 | 历史极值：1981年6月约20%（沃尔克时代对抗大通胀）；当代政策制定者将此视为不可重复的极端情形 |

**判断规则：**
- 取 DFF 最新可用数据点对应数值，对照上表定档。
- 若 DFF 正处于"目标区间"（如5.25–5.50%），取区间中值（5.375%）用于计算，文字表述保留区间形式。
- 档位本身仅提供背景锚定，不能单独用于判断政策是否偏紧——需结合 Step 3 实际利率。
- **核心框架打分对齐**：宏观情景打分器（macro_regime_framework）以 DFF < 2% 为 risk-on 档阈值。对应本表："极低"或"低"档（≤ 1.50%）直接满足；"中低"档（1.50%–3.00%）需进一步判断是否 < 2.00%，才能确认 risk-on 分档。

---

### Step 2：变动方向与速度判断

计算 DFF 的月环比变动（当月均值 vs 上月均值，或FOMC会议决议对比）。

| 变动幅度 | 判断标签 | 含义 |
|----------|----------|------|
| ≥ +50 bp | 大幅加息 | 紧缩信号强烈；2022年曾连续75bp，史上罕见；**同样满足核心框架 risk-off 触发条件（月环比 > 25bp）** |
| +25 bp – +49 bp | 标准加息 | FOMC正常操作步长；**月环比 ≥ +25bp 满足核心框架 risk-off 触发条件** |
| +10 bp – +24 bp | 小幅收紧 | 技术性调整或加息尾段 |
| ±10 bp 以内 | 暂停/按兵不动 | 政策观察期；等待数据指引 |
| -10 bp – -24 bp | 小幅宽松 | 技术性调整或降息尾段 |
| -25 bp – -49 bp | 标准降息 | FOMC正常操作步长 |
| ≤ -50 bp | 大幅降息 | 危机应对或衰退防御；2020年3月曾单次-150bp |

**周期阶段识别——关键区分：**

| 阶段标签 | 识别条件 | 宏观含义 |
|----------|----------|----------|
| 收紧开始（首次加息） | 前次变动为暂停/降息，本次≥+25bp | 美联储转向鹰派；金融条件将逐步收紧；市场重新定价信用风险 |
| 收紧持续 | 连续≥+25bp | 累计紧缩压力叠加；滞后效应尚未完全显现 |
| 收紧结束（最后一次加息） | 本次≥+25bp，其后连续暂停 | **含义与首次加息截然不同**：峰值利率确认；市场开始计价降息时间表；但紧缩效果仍在传导中（滞后12-18个月） |
| 高位暂停 | DFF处于高档位，变动±10bp内 | 限制性利率维持期；等待通胀/就业数据决定下一步；此阶段经济下行风险累积 |
| 宽松开始（首次降息/Pivot） | 前次变动为暂停，本次≤-25bp | 货币政策转向鹰转鸽；但**首次降息≠宽松周期确立**（见 Important Notes） |
| 宽松持续 | 连续≤-25bp | 降息节奏加快则说明经济或金融体系压力上升 |
| 宽松结束 | 本次≤-25bp，其后连续暂停 | 政策利率接近估算中性利率r* |

### Step 3：实际利率估算

**实际利率 ≈ DFF − 当期 CPI 同比（年率）**

此为费雪近似估算，用于判断货币政策对实体经济的实际松紧程度。

| 实际利率区间 | 政策实质 | 历史参考 |
|--------------|----------|----------|
| ＞ +2 % | 明显限制性 | 2023年下半年约+2%–+3%；1980年代沃尔克时期极高正实际利率 |
| 0 % – +2 % | 温和限制性 | 正常紧缩周期中段目标区域 |
| -1 % – 0 % | 接近中性 | 政策利率与通胀大致匹配 |
| -2 % – -1 % | 温和宽松 | 轻度刺激性政策 |
| ＜ -2 % | 强力宽松（负实际利率） | 2021年至2022年上半年：DFF约0%而CPI同比峰值达9.1%（2022年6月），实际利率最低约-8%；2022年3月后DFF开始快速上升，该阶段逐步结束。史上罕见的深度负实际利率区间。 |

**严格填写规则：**
- CPI 同比数据**必须来自当期已发布数据**（FRED：CPIAUCSL），不得使用预测值或推算值。
- 若 CPI 数据未获取（数据截止期不同步、尚未公布），实际利率一栏**填写 N/A**，不得估算，不得用上期CPI代替。
- 实际利率为正 → 货币政策偏紧（对经济有实质压制）。
- 实际利率为负 → 名义紧缩但实质仍宽松（通胀消耗了利率的限制效果）。

### Step 4：与收益率曲线的联动

结合 DFF 水平档位与当期收益率曲线形态（通常用 10Y-2Y 或 10Y-3M 利差），识别四种宏观组合：

| 组合 | 条件 | 宏观信号 | 历史案例 |
|------|------|----------|----------|
| A：DFF 高 + 曲线倒挂 | DFF ≥ 4.50 % 且 10Y-2Y ＜ 0 | 最强衰退预警信号：短端被政策压高，长端反映悲观增长预期；历史上此组合领先衰退12-24个月 | 2022年末–2023年：DFF升至5%+，10Y-2Y倒挂约-100bp；对应1980、1989、2000、2007年前的历史模式 |
| B：DFF 高 + 曲线正常/陡峭 | DFF ≥ 4.50 % 且 10Y-2Y ≥ 0 | 市场相信经济仍具韧性或通胀将持续；紧缩有效性存疑；软着陆预期主导 | 2023年底部分时段；1994–1995年格林斯潘软着陆案例 |
| C：DFF 低 + 曲线陡峭 | DFF ≤ 1.50 % 且 10Y-2Y ＞ 100bp | 典型复苏早期形态：宽松政策驱动短端压低，长端反映经济复苏和通胀预期回升 | 2009–2010年：QE后DFF近零，10Y-2Y一度达+250bp |
| D：DFF 低 + 曲线倒挂或平坦 | DFF ≤ 1.50 % 且 10Y-2Y ＜ 50bp | 异常组合：低利率仍无法提振增长预期，市场对长期停滞定价；日本化风险信号 | 2019年短暂出现；2020年后期部分时段 |

**DFF 处于中间区间（1.50%–4.50%）时的处理：**
- 四种组合（A/B/C/D）以高档（≥ 4.50%）或低档（≤ 1.50%）为触发条件，中间区间不完全匹配任一典型组合。
- 处理方式：描述 DFF 档位（来自 Step 1），结合收益率曲线形态，用文字说明最接近的情景，并注明"DFF 处于中间区间，不完全符合 A/B/C/D 任一典型组合"。
- 不得强行套入四种组合任意一项。

**收益率曲线数据填写规则：**
- 利差数值须来自当期 FRED 数据（T10Y2Y 或 T10Y3M），未获取则填 N/A。
- 仅判断"倒挂（＜0）/ 平坦（0–50bp）/ 正常（50–150bp）/ 陡峭（＞150bp）"四级，不精确引用利差具体数值（除非数据已确认）。

### 输出至宏观情景框架（macro_regime_framework）

完成 Step 1–4 后，将以下结果传递给宏观情景打分器：

| 传递项 | 来源 | 核心框架对应规则 |
|--------|------|-----------------|
| DFF 绝对水平是否 < 2% | Step 1 档位判断 | < 2% 且稳定 → risk-on 贡献分 |
| 月环比变动是否 ≥ +25bp | Step 2 变动幅度 | 月环比 > 25bp → risk-off 扣分 |
| 是否处于"高位平台"暂停期 | Step 2 周期阶段标签 | 高位平台 → neutral |
| 是否极度紧缩叠加信用压力 | Step 2 + 跨模块验证 | 极度紧缩叠加压力 → stress |

**注意**：DFF 模块提供打分输入，最终情景判断由 macro_regime_framework 综合所有模块得分后输出；DFF 模块不独立给出 regime 标签。

## Important Notes

### 1. 货币政策滞后效应

货币政策通过信贷成本、资产价格、汇率等渠道传导至实体经济，**通常存在12–18个月的滞后**（部分研究显示可达24个月）。这意味着：

- 当 DFF 处于峰值时，前12–18个月累积加息的完整效果尚未体现在 GDP、就业、通胀数据中。
- 美联储"看到效果再行动"存在内生的过度紧缩风险。
- 分析当前 DFF 时，**必须同时追溯过去4–6个季度的累计变动幅度**，不能仅看最新点位。

### 2. Pivot 信号识别——首次降息 ≠ 宽松开始

**Pivot**（政策转向）是市场高度关注的信号，但存在重大误读风险：

- **首次降息** 只代表方向改变，不代表宽松周期已确立。若首次降息后数据回暖，美联储可能再次暂停甚至加息（如1998年后的历史经验）。
- **宽松周期确立的真正信号**：连续2次以上降息 + 降息节奏未放缓 + FOMC 声明中明确移除"限制性"措辞。
- **高位暂停期**被市场误读为 Pivot 的情况极为常见，生成叙事时需明确区分"暂停观望"与"转向宽松"。
- 注意区分：**预防性降息**（经济仍健康，降息以防止过度紧缩）与**衰退式降息**（经济已明显恶化，降息被动应对），两者对风险资产的含义完全不同。

### 3. 历史锚点参考

| 时期 | DFF峰值/谷值 | 背景 | 对当代分析的参考意义 |
|------|-------------|------|---------------------|
| 1981年6月 | ~20% | 沃尔克对抗大通胀 | 极端案例；当代视为"不可重复"；但证明央行有意志牺牲增长压通胀 |
| 2008年12月–2015年12月 | 0–0.25% | 金融危机后零利率时代（ZIRP） | 零利率政策的长期副作用：资产价格泡沫、储蓄者受损、货币政策空间耗尽 |
| 2020年3月–2022年3月 | 0–0.25% | 新冠冲击二次归零 | 与财政刺激叠加，埋下2021-2022年通胀飙升的货币根源 |
| 2022年3月–2023年7月 | 0→5.25% | **史上最快加息周期之一**：17个月内加息525bp | 速度之快在历史上罕见；滞后效应仍在释放中；为理解当前金融条件的底色 |
| 中性利率 r* 估算 | ~2.5%–3.0% | 美联储长期点阵图中位估计 | r* 是判断"DFF是否真的限制性"的理论基准；r* 本身不可直接观测，有较大不确定性；不应将 r* 作为精确数字引用 |

### 4. DFF 的适用边界——不可替代的功能限制

DFF 是**已实现的政策利率**，以下功能**超出其适用范围**，不得用 DFF 替代：

| 需求 | 正确数据源 | 错误替代 |
|------|-----------|---------|
| 市场对未来加息/降息的预期 | FFR期货（CME FedWatch）、OIS利率 | DFF当前值无法反映预期 |
| 市场实际融资基准利率 | SOFR（担保隔夜融资利率）、LIBOR（已废止） | DFF是政策目标，非市场成交价 |
| 全球美元流动性条件 | DXY美元指数、FRA-OIS利差、交叉货币基差 | DFF仅代表美国境内政策立场 |
| 实际金融条件松紧 | 芝加哥联储NFCI（全国金融条件指数） | DFF不包含信用利差、波动率等维度 |

**严格规则**：生成叙事时，凡涉及"市场预期美联储将……"的表述，**必须来自 FFR 期货或 OIS 等市场化数据**，不得从 DFF 当前值推断市场预期。若此类数据未获取，相关叙述省略或标注 N/A。
