# 收益率曲线（T10Y2Y）解读框架

## 核心定义

T10Y2Y = 10年期美国国债收益率 - 2年期美国国债收益率。
正值 = 正常曲线（长端高于短端）；负值 = 倒挂（短端高于长端）。
倒挂是历史上最可靠的衰退领先指标之一，平均领先衰退约 12–18 个月。

## Workflow

### Step 1：判断曲线形态

| T10Y2Y 数值 | 形态 | 经济含义 |
|:------------|:-----|:---------|
| > +1.5% | 陡峭正斜率 | 强烈扩张预期，市场预计经济加速，通胀回升 |
| +0.5% ～ +1.5% | 正常正斜率 | 扩张周期中期，风险偏好正常 |
| 0 ～ +0.5% | 平坦化 | 经济动能减弱，货币政策偏紧或扩张尾声 |
| -0.5% ～ 0 | 轻度倒挂 | 衰退预警启动，历史上每次倒挂后18个月内均出现衰退（1980年以来） |
| < -0.5% | 深度倒挂 | 强衰退信号，市场定价大幅降息预期 |
| < -1.0% | 极端倒挂 | 对应 2022–2023年史上最深倒挂（峰值约 -1.08%），历史罕见 |

### Step 2：判断趋势方向（比绝对值更重要）

- **由负转正（去倒挂）**：历史上衰退往往在**去倒挂后**才真正到来，非利好信号，而是衰退临近的警报
- **持续倒挂加深**：市场在定价更激进的降息路径，表明对经济的悲观预期未消退
- **正斜率快速陡峭化**：若伴随强经济数据 = 扩张加速；若伴随弱数据 = 财政赤字驱动的长端上行，需区分

### Step 3：与货币政策周期关联

- **加息周期中倒挂**（短端被联储推高）：典型场景，市场认为加息已过度，未来必然降息
- **降息周期中去倒挂**（短端快速下降）：衰退确认或即将确认的信号
- **当前联邦基金利率位置**：与 DFF 联动分析，高 DFF + 倒挂 = 紧缩过度压力最大时期

### Step 4：生成收益率曲线叙事描述

> **填写规则**：方括号内占位符必须用本次已获取的实际数据填写；若某项数据未获取（包括 DFF、趋势方向），写 N/A，不得凭推测填入。

基于以上判断，输出格式：
> "当前 T10Y2Y 为 [数值]，收益率曲线呈现 [形态描述]。[趋势描述]。结合当前联邦基金利率 [DFF数值]，市场对 [加息/降息/暂停] 的定价为 [描述]，衰退风险 [高/中/低]，[一句话前景判断]。"

## Important Notes

- 倒挂本身不触发衰退，但反映信贷收紧预期，通过压缩银行息差进而影响实体信贷供给
- **去倒挂的时机最危险**：1989、2000、2006年均在倒挂消除后数月内出现衰退
- 2022–2023年倒挂创历史记录但衰退至今（2026年）未到来，可能原因：财政刺激规模空前、劳动力市场韧性、AI投资热潮。分析时应注明这一历史异常
- **2020年3月案例的特殊性**：当时 T10Y2Y 短暂转负后快速陡峭化，属外生冲击（疫情）导致的曲线形态扭曲，区别于内生信用周期衰退驱动的曲线形态变化，使用该案例作类比时应注明
- T10Y3M（10年-3月）利差也是重要参考，与 T10Y2Y 共同验证时信号更强
