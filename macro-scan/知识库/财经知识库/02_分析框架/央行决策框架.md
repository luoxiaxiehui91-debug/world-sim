## 二、泰勒规则

### 2.1 基本形式

```
i = r* + π + 0.5 × (π - π*) + 0.5 × (y - y*)
```

其中：
- i = 名义利率
- r* = 自然利率（约0.5-1%）
- π = 当前通胀
- π* = 目标通胀（2%）
- y = 产出
- y* = 潜在产出

### 2.2 简化应用

```
利率 = 2% + 通胀 + 0.5 × (通胀 - 2%) + 0.5 × 产出缺口
```

### 2.3 当前应用（2026-05 实况）

实际数据：
- 核心PCE ≈ 2.6%（2026-04）
- 通胀（CPI YoY）= 3.78%（2026-04）
- 产出缺口 ≈ 0%（软着陆，GDP接近潜在增速）
- FFR 当前 = 3.63%（2024年9月开始降息，累计降约160bp）

泰勒规则隐含利率：
```
i = 2% + 3.78% + 0.5 × (3.78% - 2%) + 0 ≈ 6.7%
```
**政策利率（3.63%）显著低于泰勒规则隐含值（~6.7%），意味着美联储仍在宽松路径上但关注通胀粘性。**

## 三、前瞻指引

### 3.1 类型

| 类型 | 内容 | 效果 |
|------|------|------|
| 时间指引 | "将维持低利率至某时间" | 明确时间点 |
| 状态指引 | "将维持低利率至某条件满足" | 更灵活 |
| 定性指引 | "将在一段时间内维持..." | 模糊 |

### 3.2 作用机制

```
央行承诺未来政策路径
    ↓
市场形成预期
    ↓
长期利率调整（提前反应）
    ↓
政策效果提前显现
```

### 3.3 美联储实践

| 时期 | 指引方式 |
|------|----------|
| 2008-2015 | "长时间维持低利率" |
| 2020-2022 | "直到劳动力市场充分恢复" |
| 2022- | 点阵图（利率预测） |

## 四、决策流程

### 4.1 FOMC会议

| 要素 | 说明 |
|------|------|
| 频率 | 每年8次 |
| 参与者 | 7理事+12储备银行行长 |
| 投票权 | 7理事+5储备银行行长 |
| 产出 | 政策声明、点阵图、发布会 |

### 4.2 信息输入

| 信息 | 来源 |
|------|------|
| 经济数据 | BEA、BLS、Census |
| 金融条件 | 市场数据 |
| 调查数据 | 企业、消费者调查 |
| 模型预测 | Fed模型 |

### 4.3 决策权衡

```
决策 = f(
    当前通胀 vs 目标,
    就业 vs 最大就业,
    金融条件,
    风险平衡,
    预期管理
)
```

## 七、当前政策分析（2024-2026）

### 7.1 美联储立场

| 阶段 | 时间 | 政策利率 | 立场 |
|------|------|----------|------|
| 加息周期 | 2022-2023 | 0%→5.25% | 紧缩 |
| 维持高位 | 2023.7-2024.9 | 5.25-5.5% | 限制性 |
| 降息周期 | 2024.9-至今 | 5.25%→**3.63%**（2026-05） | 逐步宽松 |

> 2024年共降息3次（9月/11月/12月），2025年节奏放缓，2026年初FFR稳定在3.5-3.75%区间。

### 7.2 决策考量

| 因素 | 当前状态（2026-05） | 政策含义 |
|------|----------|----------|
| 通胀 | CPI 3.78%，核心PCE 2.6%（均高于目标） | 降息空间有限，关注关税传导通胀再加速 |
| 就业 | 失业率低位（~4%），萨姆规则 0.2 | 尚未触发衰退信号 |
| 金融条件 | 穆迪下调美国信用评级（2026-05），长债承压 | 财政风险上升，联储需权衡利率路径 |
