# 宏观分析框架 — 如何解读经济数据

> 版本：v1.0 | 更新时间：2026-05-03
> 目标：帮助你理解数据发布后"意味着什么"和"怎么做"

---

## 一、宏观分析的底层逻辑

### 1.1 经济是个循环系统

```
企业生产 → 居民收入 → 消费/投资 → 企业营收 → 企业生产
    ↑                                        ↓
    ←←←←←← 政府调节（财政+货币） ←←←←←←←←←←←←
```

**三个关键观察点：**
1. **生产端**：企业生产了多少？（工业增加值、PMI）
2. **需求端**：大家买了多少？（社零、投资、出口）
3. **政策端**：政府在做什么？（财政收支、利率、M2）

### 1.2 三个核心问题

看任何宏观数据，问三个问题：

| 问题 | 含义 | 对应指标 |
|------|------|---------|
| **经济好不好？** | 增长动能强弱 | GDP、PMI、工业增加值 |
| **钱够不够？** | 流动性充裕程度 | M2、社融、利率 |
| **价格贵不贵？** | 通胀/通缩压力 | CPI、PPI |

### 1.3 同比 vs 环比

| 维度 | 同比 | 环比 |
|------|------|------|
| 含义 | 和去年同期比 | 和上个月/上季度比 |
| 优点 | 剔除季节性 | 反映短期趋势 |
| 缺点 | 掩盖近期变化 | 受季节因素扰动 |
| 适用 | 判断长期趋势 | 判断拐点 |

**实战技巧：**
- 同比看方向，环比看动能
- PMI本身就是环比指标（>50 = 环比改善）

## 二、关键指标解读手册

### 2.1 GDP — 经济的终极裁判

**发布时间**：季度（1/4/7/10月中旬）

**如何解读：**
1. **看增速**：5%以上=强劲，4-5%=稳健，4%以下=承压
2. **看结构**：消费贡献多少？投资贡献多少？出口贡献多少？
3. **看质量**：名义GDP增速 vs 实际GDP增速（差值=平减指数≈通胀）

**实战案例：**
> 2025年Q1 GDP同比5.3%，超预期
> - 解读：经济开局良好，但需看分项贡献
> - 如果主要靠投资拉动 → 持续性存疑
> - 如果消费贡献提升 → 内需修复，更健康

### 2.2 PMI — 最早发布的月度指标

**发布时间**：每月最后一天（官方）、次月1日（财新）

**如何解读：**
1. **看临界值**：>50=扩张，<50=收缩
2. **看趋势**：连续3个月上升/下降=趋势确立
3. **看背离**：官方PMI vs 财新PMI

**常见背离及含义：**
| 官方PMI | 财新PMI | 含义 |
|---------|---------|------|
| >50 | >50 | 全面扩张 |
| >50 | <50 | 大企业好，中小企业差 |
| <50 | >50 | 中小企业好，大企业差 |
| <50 | <50 | 全面收缩 |

**为什么PMI重要？**
- 它是每月最早发布的指标（比CPI、工业增加值早一周）
- 预测性强：PMI领先工业增加值1-2个月

### 2.3 CPI/PPI — 通胀的双面镜

**发布时间**：每月9-12日

**如何解读CPI：**
1. **看总量**：2-3%=温和通胀，<1%=通缩风险，>5%=高通胀
2. **看分项**：食品vs非食品，服务vs商品
3. **看核心CPI**：剔除食品能源，反映真实需求

**如何解读PPI：**
1. **看方向**：正增长=工业品涨价，负增长=工业品跌价
2. **看传导**：PPI领先CPI 3-6个月
3. **看企业利润**：PPI上涨=上游企业利润改善，下游企业成本上升

**CPI与PPI剪刀差：**
| 情况 | 含义 | 对企业影响 |
|------|------|-----------|
| CPI涨、PPI涨 | 需求拉动通胀 | 上下游都受益 |
| CPI跌、PPI跌 | 需求不足 | 上下游都承压 |
| CPI涨、PPI跌 | 成本下降、售价上升 | 企业利润改善 |
| CPI跌、PPI涨 | 成本上升、售价下降 | 企业利润恶化 |

### 2.4 社融/M2 — 钱流到哪里去了

**发布时间**：每月10-15日

**如何解读社融：**
1. **看总量**：超预期=信用扩张，不及预期=信用收缩
2. **看结构**：贷款vs债券vs表外
3. **看趋势**：连续3个月高增=宽信用确立

**如何解读M2：**
1. **看增速**：M2增速>GDP增速+CPI=流动性充裕
2. **看剪刀差**：M2-M1=准货币，剪刀差扩大=定期存款增加，经济活跃度下降

**社融-M2剪刀差：**
- 社融>M2：实体融资需求强于银行负债端
- 社融<M2：资金在金融体系空转

### 2.5 出口/进口 — 外需的温度计

**发布时间**：每月7-13日

**如何解读：**
1. **看增速**：正增长=外需改善，负增长=外需走弱
2. **看结构**：对美vs对欧vs对东盟
3. **看贸易差额**：顺差扩大=外汇流入增加

**出口的先行指标：**
- PMI新出口订单（领先1-2个月）
- 韩国出口增速（全球贸易风向标）
- BDI波罗的海干散货指数

## 三、数据发布后的分析流程

### 3.1 标准分析流程

```
数据发布 → 对比预期 → 看分项结构 → 联系其他指标 → 得出结论
```

**步骤详解：**

1. **对比预期**
   - 超预期：市场会如何反应？
   - 符合预期：维持原有判断
   - 不及预期：是否需要修正预期？

2. **看分项结构**
   - 总量好，分项也好 → 全面改善
   - 总量好，分项差 → 结构性问题
   - 总量差，分项好 → 有亮点

3. **联系其他指标**
   - PMI好 → 预期工业增加值也好
   - 社融高 → 预期后续投资改善
   - CPI低 → 央行有降息空间

4. **得出结论**
   - 对经济整体判断
   - 对政策的影响
   - 对市场的含义

### 3.2 实战案例：2025年11月数据解读

**背景**：PMI 49.5，低于预期50.2

**分析过程：**

1. **对比预期**：不及预期，经济动能减弱

2. **看分项**：
   - 新订单49.2 → 需求不足
   - 生产50.8 → 生产端尚可
   - 从业人员48.1 → 就业压力大

3. **联系其他指标**：
   - 社融增速下行 → 宽信用受阻
   - 出口增速回落 → 外需走弱
   - CPI接近0 → 通缩压力

4. **得出结论**：
   - 经济下行压力加大
   - 政策需加大力度
   - 债券收益率下行，股市承压

## 四、常见误区与陷阱

### 4.1 只看总量不看结构

❌ 错误："GDP 5%，经济很好"
✅ 正确："GDP 5%，但主要靠投资拉动，消费贡献下降，结构不均衡"

### 4.2 忽视基数效应

❌ 错误："出口同比大增30%，外需强劲"
✅ 正确："去年同期的低基数效应，两年平均增速只有5%"

### 4.3 过度依赖单一指标

❌ 错误："PMI跌破50，经济要衰退"
✅ 正确："PMI跌破50，但工业增加值、社零尚可，需综合判断"

### 4.4 混淆因果关系

❌ 错误："利率下降，说明经济不好"
✅ 正确："利率下降是央行为稳增长主动调降，是对经济下行的应对"

### 4.5 忽视季节性

❌ 错误："1-2月出口大降，外需崩了"
✅ 正确："春节错位因素，应合并1-2月看，或看同比"

## 五、政策传导机制

### 5.1 货币政策传导

```
央行降息 → LPR下调 → 贷款利率下降 → 企业/居民融资成本降低 → 投资消费增加
    ↓
债券收益率下行 → 股市估值提升
```

**观察指标：**
- 政策利率：7天逆回购利率、MLF利率
- 市场利率：DR007、10年国债收益率
- 实体利率：LPR、贷款加权平均利率

### 5.2 财政政策传导

```
赤字扩大 → 政府债券发行 → 基建投资增加 → 拉动上下游产业 → 就业增加
    ↓
减税降费 → 企业利润改善 → 投资意愿提升
```

**观察指标：**
- 财政赤字率
- 专项债发行进度
- 政府性基金支出

### 5.3 汇率传导

```
人民币贬值 → 出口价格竞争力提升 → 出口增加
    ↓
进口成本上升 → 输入性通胀
```

## 七、知识库使用指南

### 7.1 如何查询数据

**方式一：按分类浏览**
```
docs/财经知识库/01_宏观经济指标/[分类名]/
├── README.md          # 指标说明
└── raw_*.json         # 原始数据
```

**方式二：使用数据字典**
```
docs/财经知识库/19_数据字典/数据字典.md
```

**方式三：查看经济日历**
```
docs/财经知识库/16_经济日历/经济日历.md
```

### 7.2 数据更新机制

- **自动更新**：通过脚本定时刷新（需配置Cron）
- **手动更新**：运行 `python skills/neodata-financial-search/query_calendar_v3.py`

### 7.3 分析建议

1. **先看README**：了解指标含义和发布频率
2. **再看数据**：关注趋势而非单月波动
3. **交叉验证**：多个指标相互印证
4. **结合背景**：考虑政策和外部环境

---

**结语**：宏观数据是经济的体温表，但解读需要方法。这份框架提供的是"如何思考"，而非"标准答案"。真正的分析能力，来自持续的数据跟踪和逻辑推演。
