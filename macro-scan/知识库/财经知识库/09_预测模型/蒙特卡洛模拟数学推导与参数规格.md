## 一、概述

推演模型的蒙特卡洛模拟（Monte Carlo Simulation，MCS）通过大量随机路径采样，量化宏观经济未来状态的概率分布。本文档给出完整数学推导、参数标定方法和扩展方案。

**基础模拟**（当前v1）：高斯随机游走，5000次采样  
**扩展模拟**（v2目标）：跳跃扩散 + GARCH波动率聚类

## 二、基础模型：几何布朗运动（GBM）

### 2.1 随机过程定义

GDP增速、通胀率等宏观变量用如下SDE（随机微分方程）描述：

```
dX(t) = μ·X(t)·dt + σ·X(t)·dW(t)

其中：
  X(t)  = t时刻的变量值（如GDP增速）
  μ     = 漂移率（长期均值回归方向）
  σ     = 波动率（历史实现波动率）
  dW(t) = 维纳过程（标准布朗运动的微分）
  dW(t) ~ N(0, dt)
```

### 2.2 离散化（欧拉-马鲁亚马格式）

将连续SDE离散化为月度步长（dt = 1/12）：

```
X(t+dt) = X(t) · exp[(μ - σ²/2)·dt + σ·√dt·Z]

其中：
  Z ~ N(0, 1)  → 标准正态随机数
  
等价写法（对数变换后）：
  ln[X(t+dt)/X(t)] = (μ - σ²/2)·dt + σ·√dt·Z
```

### 2.3 均值回归版本（Ornstein-Uhlenbeck，OU过程）

宏观变量通常有均值回归特性，用OU过程更合适：

```
dX(t) = θ·(μ - X(t))·dt + σ·dW(t)

其中：
  θ = 均值回归速度（值越大，回归越快）
  μ = 长期均值（目标值）
  σ = 扩散系数（短期波动）
```

离散化：
```
X(t+dt) = X(t) + θ·(μ - X(t))·dt + σ·√dt·Z
```

## 三、扩展模型1：跳跃扩散（Jump Diffusion）

### 3.1 动机

标准GBM无法模拟**突发性极端事件**（黑天鹅）：金融危机、疫情、地缘冲突。跳跃扩散在GBM基础上叠加泊松跳跃过程。

### 3.2 默顿跳跃扩散模型（Merton, 1976）

```
dX(t) = μ·X(t)·dt + σ·X(t)·dW(t) + X(t-)·(J-1)·dN(t)

其中：
  dN(t)      = 泊松过程，跳跃到达强度为λ（每年平均跳跃次数）
  P(dN=1) = λ·dt（极小时间段内跳跃概率）
  J          = 跳跃幅度，服从对数正态分布：ln(J) ~ N(μ_J, σ_J²)
  J-1        = 跳跃相对变化量（-1=归零，正数=上涨）
```

### 3.3 离散化

每个时间步骤：
```python
# 伪代码
for step in range(T):
    # 连续扩散部分
    diffusion = (mu - 0.5*sigma**2) * dt + sigma * sqrt(dt) * norm.rvs()
    
    # 跳跃部分：泊松跳跃发生与否
    n_jumps = poisson.rvs(lambda_jump * dt)  # 通常=0或1
    
    # 每次跳跃的幅度
    if n_jumps > 0:
        jump_sizes = [lognorm.rvs(mu_J, sigma_J) - 1 for _ in range(n_jumps)]
        total_jump = sum(jump_sizes)
    else:
        total_jump = 0
    
    X[step+1] = X[step] * exp(diffusion) * (1 + total_jump)
```

### 3.4 跳跃参数标定（历史数据）

基于1970-2025年美国经济衰退事件标定：

| 参数 | 符号 | 值 | 标定方法 |
|:----|:----:|:---:|:--------|
| 年均跳跃频率（负向）| λ_down | 0.15 | 衰退频率（约15年一次大衰退）|
| 年均跳跃频率（正向）| λ_up | 0.05 | 突发性强增长（较少）|
| 跳跃幅度均值（负向）| μ_J_down | -0.08（即-8%）| 次贷/新冠实际数据 |
| 跳跃幅度均值（正向）| μ_J_up | +0.05 | 政策救市反弹 |
| 跳跃幅度标准差 | σ_J | 0.05 | 历史衰退深度方差 |

**极端情景跳跃参数**（2008级别危机）：
- λ_crisis = 0.05（20年一遇）
- μ_J_crisis = -0.15（GDP骤降15%）
- σ_J_crisis = 0.08

## 四、扩展模型2：GARCH波动率聚类

### 4.1 动机

金融时间序列中波动率呈**聚类特性**（volatile periods tend to cluster）：大波动后往往跟着大波动，小波动后跟着小波动。标准GBM假设固定σ是主要缺陷。

### 4.2 GARCH(1,1)模型

```
收益率方程：  r(t) = μ + ε(t)
误差项：      ε(t) = σ(t)·z(t)，其中z(t) ~ N(0,1) iid
条件方差方程：σ²(t) = ω + α·ε²(t-1) + β·σ²(t-1)

参数约束：
  ω > 0
  α ≥ 0（ARCH效应：过去冲击对当前波动的贡献）
  β ≥ 0（GARCH效应：过去波动对当前波动的持续性）
  α + β < 1（平稳性条件）

长期波动率：σ_LT = √(ω / (1 - α - β))
波动率持久性：HL = -ln(2) / ln(α + β)（半衰期，单位：时间步）
```

### 4.3 历史标定参数

对S&P500日收益率（2000-2024）的GARCH(1,1)拟合：

| 参数 | 估计值 | 标准误 | 说明 |
|:----|:------:|:------:|:----|
| ω | 0.0000025 | 0.0000005 | 极小基础波动 |
| α | 0.085 | 0.008 | ARCH项（冲击响应）|
| β | 0.910 | 0.010 | GARCH项（波动持久）|
| α+β | 0.995 | — | 接近1=高持久性 |
| 长期年化波动率σ_LT | 15.5% | — | 正常市场 |
| 波动率半衰期 | 138天 | — | 约5个月 |

宏观指标（月度GDP增速）的GARCH参数（相对温和）：
- α = 0.12, β = 0.82, ω ≈ 0.002, σ_LT ≈ 1.6%

### 4.4 GJR-GARCH（非对称版本）

捕捉"杠杆效应"（bad news对波动的冲击大于good news）：

```
σ²(t) = ω + α·ε²(t-1) + γ·ε²(t-1)·I[ε(t-1)<0] + β·σ²(t-1)

其中：
  I[ε<0] = 指示函数（负收益时=1，正收益时=0）
  γ > 0   = 杠杆效应系数（通常γ ≈ α，即负面冲击放大约1倍）
```

## 五、完整模拟流程（伪代码）

```python
def monte_carlo_v2(
    initial_state: dict,   # 当前宏观变量值
    horizon: int = 24,     # 预测期（月）
    n_paths: int = 5000,   # 路径数
    model: str = 'garch_jump'  # 'gbm' | 'jump' | 'garch' | 'garch_jump'
) -> dict:
    
    results = []
    
    for _ in range(n_paths):
        path = [initial_state.copy()]
        
        # 初始化GARCH方差
        current_sigma2 = PARAMS['sigma_LT']**2
        
        for t in range(horizon):
            new_state = {}
            
            for var in VARIABLES:
                # Step 1: GARCH更新波动率
                if model in ['garch', 'garch_jump']:
                    eps = path[t][var] - PARAMS[var]['mu']
                    current_sigma2[var] = (
                        PARAMS[var]['omega'] +
                        PARAMS[var]['alpha'] * eps**2 +
                        PARAMS[var]['beta'] * current_sigma2[var]
                    )
                    sigma = sqrt(current_sigma2[var])
                else:
                    sigma = PARAMS[var]['sigma']
                
                # Step 2: 扩散项（均值回归OU）
                drift = PARAMS[var]['theta'] * (PARAMS[var]['mu'] - path[t][var])
                diffusion = sigma * sqrt(DT) * norm.rvs()
                
                # Step 3: 跳跃项
                jump = 0
                if model in ['jump', 'garch_jump']:
                    n_jumps = poisson.rvs(PARAMS[var]['lambda_jump'] * DT)
                    for j in range(n_jumps):
                        jump += norm.rvs(PARAMS[var]['mu_jump'], PARAMS[var]['sigma_jump'])
                
                new_state[var] = path[t][var] + drift*DT + diffusion + jump
                
                # 边界条件（避免非物理解）
                new_state[var] = clip(new_state[var], BOUNDS[var]['min'], BOUNDS[var]['max'])
            
            path.append(new_state)
        
        results.append(path)
    
    return summarize_paths(results)


def summarize_paths(paths):
    """计算分位数分布"""
    return {
        'median': percentile(paths, 50),
        'p10': percentile(paths, 10),
        'p25': percentile(paths, 25),
        'p75': percentile(paths, 75),
        'p90': percentile(paths, 90),
        'recession_prob': mean([path_ends_in_recession(p) for p in paths]),
        'crisis_prob': mean([path_ends_in_crisis(p) for p in paths]),
        'soft_landing_prob': mean([path_is_soft_landing(p) for p in paths]),
    }
```

## 六、收敛性与精度

### 6.1 标准误差公式

```
SE(估计量) = σ_样本 / √n_paths

5000条路径时：
  - 均值估计误差：约±1.4%（σ=1%时）
  - 衰退概率误差：约±1.4%（p=50%时，最大误差情况）
  - 尾部概率（p5）误差：约±0.3%
```

### 6.2 路径数量建议

| 应用场景 | 最低路径数 | 推荐路径数 | 说明 |
|:--------|:---------:|:---------:|:----|
| 快速探索 | 1,000 | 1,000 | 误差约±3% |
| 标准报告 | 5,000 | 5,000 | 误差约±1.4% |
| 精细尾部风险 | 20,000 | 50,000 | 黑天鹅概率精度 |
| 重大决策参考 | 100,000 | 100,000 | 监管级精度 |

### 6.3 计算效率

Python单线程5000路径×24步×7变量：约2-5秒  
用NumPy向量化（批量采样）：约0.1-0.3秒  
多进程并行（4核）：约0.05-0.1秒
