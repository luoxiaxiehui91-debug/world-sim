# 早期预警信号体系 — 结构化知识文档

> 核心主题：系统性金融风险的早期识别框架——收益率曲线、TED利差、CLI指数与多维度预警信号评分
> 更新时间：2026-05-11

---

## 核心传导链

```
宏观金融系统压力积聚（通常6-18个月隐性发展）
        ↓
早期预警信号开始触发（单一→多重）
        ↓
┌──────────────────────────────────────────────┐
│  资金市场信号：TED利差/OIS-Libor/SOFR基差    │
│  实体经济信号：收益率曲线/PMI/失业率先行     │
│  信用市场信号：CDS利差/高收益债利差          │
│  资金流动信号：VIX/黄金/货币避险转移        │
└──────────────────────────────────────────────┘
        ↓
综合评分：绿灯（安全）→ 黄灯（警戒）→ 红灯（危险）
        ↓
政策决策窗口：提前行动 vs 观望成本权衡
        ↓
若无干预：压力显化 → 市场波动 → 经济传导
```

## 一、收益率曲线信号

### 1.1 收益率曲线形态与含义

**基础定义：**

| 形态 | 特征 | 经济含义 |
|------|------|---------|
| 正常（陡峭）| 长端利率 > 短端利率（10Y > 2Y > 0）| 经济扩张预期，正常借贷回报 |
| 平坦 | 10Y ≈ 2Y | 经济放缓或政策转折点 |
| 倒挂 | 短端利率 > 长端（2Y > 10Y）| 历史上最可靠的衰退预测信号 |
| 熊市陡峭 | 长端急升（期限溢价扩大）| 通胀/财政担忧，不同于正常陡峭 |

### 1.2 10Y-2Y利差：核心衰退预测指标

**历史记录：**

| 倒挂时间 | 深度（bp）| 随后衰退 | 滞后期 |
|---------|---------|---------|-------|
| 1978年 | -110bp | 1980年衰退 | 约18个月 |
| 1989年 | -60bp | 1990-91年衰退 | 约15个月 |
| 2000年 | -50bp | 2001年衰退 | 约14个月 |
| 2006年 | -60bp | 2008-09年危机 | 约19个月 |
| **2022年7月** | **-110bp（2023年7月峰值）** | **2024年？** | **待观察** |

**倒挂至衰退的滞后规律：**
```
收益率曲线倒挂开始
    ↓（平均约12-18个月）
衰退正式开始（NBER定义）

注意：
① 倒挂结束（重新陡峭化）时衰退往往即将开始（不是倒挂期间）
② 2022-2024年美国是罕见的"倒挂未衰退"案例——需关注是否仅仅是滞后
```

### 1.3 其他曲线利差信号

| 利差指标 | 含义 | 阈值 |
|---------|------|------|
| 10Y-3M（最短端） | 圣路易斯Fed研究发现比10Y-2Y更准确 | 负值为警戒 |
| 10Y-FFR（实际政策利率利差）| 政策是否过度紧缩 | <0时过度紧缩 |
| 30Y-5Y（超长端斜率）| 长期通胀预期+财政可持续性 | 快速陡峭=财政担忧 |
| 新兴市场外债-美债利差 | 全球风险溢价 | EMBI>350bp警戒 |

## 二、货币市场压力信号

### 2.1 TED利差（Ted Spread）

**定义：** 3个月期美国国债利率 vs 3个月期欧洲美元（LIBOR/SOFR）利率的差值

**经济含义：**
```
TED利差 = 银行间借贷信用风险溢价
    ↓
TED利差低：银行体系健康，资金流通顺畅
TED利差高：银行间不信任，担心对手方违约风险
    ↓（极端情况）
"惜贷"→ 信贷收缩 → 实体经济流动性危机
```

**历史数据：**

| 时期 | TED利差水平 | 含义 |
|------|-----------|------|
| 正常时期 | 10-40bp | 健康范围 |
| 2007年8月（次贷初期）| 约200bp | 开始警戒 |
| 2008年10月（雷曼后）| **约460bp（历史峰值）** | 系统性危机 |
| 2020年3月（新冠初）| 约140bp（短暂）| 流动性冲击 |
| 2024年 | 约20-30bp | 正常健康 |

**2023年后的变化：** LIBOR于2023年6月正式停用，替代指标为SOFR；TED利差的等效替代为SOFR vs T-bill利差，逻辑相同。

### 2.2 OIS-LIBOR利差（已演变为SOFR-OIS基差）

**定义：** 隔夜指数掉期（OIS，代表市场对政策利率预期）vs 银行间同业拆借利率的差值

**含义：** 银行间期限信用风险的纯度量

| 水平 | 含义 |
|------|------|
| <10bp | 正常（政策传导有效）|
| 20-50bp | 轻度压力 |
| >100bp | 显著压力（2008年高峰~350bp）|

### 2.3 美元FX互换基差（Cross-Currency Basis Swap）

**定义：** 非美元机构通过掉期获取美元融资的超额成本

**为什么重要：**
- 全球离岸美元需求的压力计量
- 基差扩大（负值变大）→ 非美洲机构美元融资困难
- 这是2008年和2020年危机传导的核心渠道

| 时期 | EUR/USD 3M基差 | JPY/USD 3M基差 |
|------|--------------|--------------|
| 正常 | -10至-20bp | -20至-40bp |
| 2008年危机 | 约-200bp | 约-150bp |
| 2020年3月 | 约-90bp | 约-120bp |
| 2024年 | 约-15bp | 约-30bp |

## 三、信用市场预警信号

### 3.1 信用利差体系

**利差层级（从安全到风险）：**

```
美国国债（基准，零信用风险）
    +
BBB投资级利差（约100-150bp，正常）
    +
BB高收益利差（约300bp，正常）
    +
CCC以下投机级（约700bp+，正常）
    +
主权危机级（>1000bp → 违约预期）
```

**预警阈值（美国市场）：**

| 利差类型 | 正常水平 | 警戒阈值 | 危险阈值 |
|---------|---------|---------|---------|
| IG（投资级，BBB）| 80-130bp | >200bp | >350bp |
| HY（高收益）| 300-400bp | >600bp | >1000bp |
| HY-IG利差倍数 | 3-4x | >5x | >8x |

**历史极值：**
- 2008年10月高收益利差：约2000bp（垃圾债几乎全部计入违约）
- 2020年3月高收益利差：约1000bp（快速飙升后Fed迅速介入）

### 3.2 主权CDS信号（全球层面）

| 国家/地区 | 正常5年期CDS | 警戒水平 | 危机水平 |
|----------|------------|---------|---------|
| 美国 | <30bp | >60bp | >100bp |
| 德国 | <30bp | >50bp | >80bp |
| 意大利 | 60-100bp | >200bp | >400bp |
| 新兴市场平均 | 150-250bp | >400bp | >700bp |
| 高风险新兴市场 | >400bp | >700bp | >1500bp（临近违约）|

## 四、实体经济先行指标

### 4.1 OECD综合领先指标（CLI）

**构成：** 每个国家约8-10个先行分量加权综合（包含股票/新订单/营建许可/利差等）

**解读框架：**

| CLI水平/方向 | 含义 |
|------------|------|
| >100且上升 | 经济活动高于趋势且加速扩张 |
| >100且下降 | 经济活动高于趋势但减速 |
| <100且下降 | **收缩加速**（预警信号）|
| <100且上升 | 收缩放缓/触底 |

**领先期：** CLI通常领先经济拐点约3-6个月

**局限性：**
- CLI修订频繁，实时数据可靠性低于事后数据
- 对服务业比重高的现代经济（制造业权重偏高）可能失真
- 2020年新冠等"外生冲击"对CLI完全没有预测作用

### 4.2 PMI信号

**制造业PMI：**

| PMI水平 | 含义 | 历史上的后续行为 |
|---------|------|---------------|
| >55 | 强劲扩张 | 若持续>12个月，警惕过热 |
| 50-55 | 温和扩张 | 正常 |
| 48-50 | 边界/轻度收缩 | 观察 |
| <47持续 | 明显收缩 | 衰退风险↑ |
| <45持续 | 深度收缩 | 衰退进行中 |

**全球PMI合成（J.P.Morgan/S&P Global）：**
- <50且下降：全球制造业收缩信号
- 2022年9月降至49.8，随后持续低于50（全球制造业衰退）

### 4.3 失业率信号（Sahm规则）

**Sahm规则（Claudia Sahm, 2019年Fed提出）：**
```
定义：若3个月移动平均失业率 较过去12个月最低值上升≥0.5pp
→ 美国经济已进入衰退
```

**历史验证：**
- 在1970年以来每次衰退中，此规则均在衰退开始后不久触发（事后验证率100%）
- 2024年7-8月：Sahm指标触达0.5（触发），但随后就业数据修正，引发关于适用性的讨论

**局限性：** 2020年代后移民驱动的劳动力供给扩张可能使Sahm规则失灵。

## 五、金融稳定综合预警体系

### 5.1 多维度评分模型（红绿灯体系）

**指标体系（共15项，分5类）：**

**A类：货币市场（权重20%）**

| 指标 | 绿灯 | 黄灯 | 红灯 |
|------|------|------|------|
| TED利差 | <40bp | 40-100bp | >100bp |
| SOFR-OIS基差 | <15bp | 15-40bp | >40bp |
| FX互换基差（EUR）| >-30bp | -30至-70bp | <-70bp |
| 美联储隔夜逆回购（ONRRP）| 缩减中（正常）| 骤升（流动性堆积）| 急速消耗（压力）|

**B类：利率市场（权重20%）**

| 指标 | 绿灯 | 黄灯 | 红灯 |
|------|------|------|------|
| 10Y-2Y利差 | >50bp | 0-50bp或<-50bp | -50bp至-200bp |
| 10Y-3M利差 | >100bp | 0-100bp | <0 |
| 实际利率（10Y TIPS）| 0-2% | >2%或<-1% | 快速变化>1pp/月 |

**C类：信用市场（权重25%）**

| 指标 | 绿灯 | 黄灯 | 红灯 |
|------|------|------|------|
| IG利差 | <130bp | 130-250bp | >250bp |
| HY利差 | <400bp | 400-700bp | >700bp |
| 主权利差（意大利-德国）| <150bp | 150-250bp | >250bp |

**D类：风险情绪（权重20%）**

| 指标 | 绿灯 | 黄灯 | 红灯 |
|------|------|------|------|
| VIX指数 | <20 | 20-30 | >30（>40危机级）|
| 黄金/铜比率 | 下降中（风险偏好）| 上升 | 急升（>15%/月）|
| 美元指数（DXY）| 稳定/弱 | 上升 | 急升>5%/月 |

**E类：实体经济（权重15%）**

| 指标 | 绿灯 | 黄灯 | 红灯 |
|------|------|------|------|
| 美国失业率（月变化）| <+0.1pp | +0.1-0.3pp | >+0.3pp（月增）|
| Sahm指标 | <0.3 | 0.3-0.5 | ≥0.5 |
| 全球制造业PMI | >51 | 48-51 | <48 |

### 5.2 综合评分与触发机制

**评分方法：**
- 绿灯=0分，黄灯=1分，红灯=2分
- 加权总分 = Σ(各指标分×权重)
- 满分=2.0

| 综合得分 | 风险等级 | 建议行动 |
|---------|---------|---------|
| <0.4 | 绿色（安全）| 正常监控，无特别行动 |
| 0.4-0.8 | 黄色（警戒）| 提高监控频率，检视持仓风险 |
| 0.8-1.2 | 橙色（警告）| 主动减少风险暴露，增加现金/防御配置 |
| >1.2 | 红色（危机）| 全面防御，等待政策介入信号 |

## 六、历史案例验证

### 6.1 2008年金融危机：预警信号时间线

| 时间 | 信号 | 级别 |
|------|------|------|
| 2006年12月 | 收益率曲线倒挂（10Y-2Y=-15bp）| 黄灯 |
| 2007年2月 | 次级抵押债券违约率上升 | 黄灯 |
| 2007年6月 | 贝尔斯登旗下对冲基金崩溃 | 橙灯 |
| 2007年8月9日 | TED利差从25bp→200bp（单日）| 红灯 |
| 2007年9月 | 英国北岩银行挤兑（公开危机第一例）| 红灯 |
| 2007-2008 | 信贷利差持续扩大，OECD CLI持续下行 | 持续红灯 |
| 2008年9月15日 | 雷曼兄弟破产 → TED利差460bp | 系统性危机 |

**教训：** 2006年底收益率曲线倒挂是最早、最显著的黄灯信号；如果决策者在2007年8月TED利差飙升时即采取系统性行动，危机规模可能大幅降低。

### 6.2 2019-2020年：新冠冲击（无法预警的外生冲击）

**2019年的信号状态：**
- 10Y-2Y在2019年8月一度倒挂（约-6bp）→ 黄灯
- ISM制造业PMI降至47-48 → 黄灯
- 多项CI/CLI下行 → 黄灯

**2020年2月底：**
- 信号几乎瞬间从黄灯→红灯（新冠疫情消息传出）
- TED利差在2周内从25bp→140bp
- VIX从15→65（历史峰值区间）
- 标普500在33天内下跌34%

**教训：** 早期预警体系对循环性风险（信贷周期、过热）有效；对外生黑天鹅冲击（疫情/自然灾害/地缘突发）几乎无效——区分"可预警"和"不可预警"风险至关重要。

### 6.3 2022年激进加息周期：多信号共振

**2021年底信号：**
- OECD CLI（美国）见顶下行 → 黄灯
- 10Y-2Y利差从200bp收窄至30bp（趋于平坦）→ 黄灯
- HY利差从270bp扩至350bp → 黄灯

**2022年信号演变：**
- 3月：收益率曲线首次倒挂 → 橙灯
- 6月：CPI达9.1%，滞胀担忧 → 红灯（通胀维度）
- 10月：英国LDI危机（收益率急升）→ 局部红灯

**结果：** 2022年美股-19.4%，美债-18%（双跌）——与预警信号吻合。

## 七、预警体系的局限性与注意事项

### 7.1 信号失真的常见原因

1. **央行干预扭曲：** Fed QE直接压制收益率曲线斜率，使倒挂预警失真（2010-2019年量化宽松期间，曲线长期被人为压平）

2. **全球化对利率传导的改变：** 全球储蓄过剩压低长端利率（伯南克"储蓄过剩论"），导致曲线偏平非衰退信号

3. **新型金融工具遮蔽：** CDS/CLO/ABS等结构性产品在危机爆发前会大幅低估真实违约风险（2006-2007年利差仍低但实际风险极高）

4. **幸存者偏差：** 回溯分析倾向于只记住"有效"的预警信号，忽略大量误报（False Positive）

### 7.2 使用建议

- **多指标共振原则：** 单一指标触发黄灯不足以行动；需要多类别指标同时转黄/红才升级预警
- **速度比水平更重要：** 指标在短期内急变（>1个标准差/周）往往比绝对水平更具预警价值
- **区分性质：** 流动性危机（TED利差飙升）vs 偿债能力危机（主权CDS飙升）vs 需求崩溃（PMI持续收缩）需要不同的政策应对
- **尾部校准：** 预警体系应定期用历史危机场景进行回测（如2008年9月情景下各指标的触发情况）
