## 核心传导链

```
宏观变量输入（增长/通胀/利率/信贷）
        ↓
情景识别与概率分配（主观贝叶斯 + 客观指标）
        ↓
四大情景框架：
  ① 金发姑娘（Goldilocks）：增长平稳+通胀低
  ② 滞胀（Stagflation）：增长低+通胀高
  ③ 通缩衰退（Deflationary Recession）：增长低+通胀低
  ④ 过热（Overheating）：增长高+通胀高
        ↓
情景→资产价格传导（跨资产相关性矩阵）
        ↓
组合配置建议与风险控制措施
```

## 一、四大情景框架

### 1.1 情景坐标系：增长-通胀矩阵

```
                   通胀 高
                      │
  ┌───────────────────┼───────────────────┐
  │                   │                   │
  │   ④ 过热          │   ② 滞胀          │
  │ 增长↑ 通胀↑        │ 增长↓ 通胀↑        │
  │ (Overheating)     │ (Stagflation)     │
  │                   │                   │
增长←──────────────────┼──────────────────→增长
高  │                   │                   低
  │   ① 金发姑娘       │   ③ 通缩衰退        │
  │ 增长↑ 通胀低        │ 增长↓ 通胀↓        │
  │ (Goldilocks)      │ (Deflationary)    │
  │                   │                   │
  └───────────────────┼───────────────────┘
                      │
                   通胀 低
```

### 1.2 情景①：金发姑娘（Goldilocks）

**定义：** 实际GDP增长在潜在增速附近（发达国家约1.5-2.5%），通胀接近央行目标（2%左右）

**宏观特征：**

| 变量 | 典型值 | 方向 |
|------|--------|------|
| 美国实际GDP增速 | 1.8-2.5% | 温和 |
| 核心PCE通胀 | 2.0-2.5% | 接近目标 |
| 失业率 | 4-5% | 自然失业率附近 |
| 联邦基金利率 | 中性（约2.5-3.5%）| 稳定/缓慢下降 |
| 信贷增速 | 健康（6-8%）| 温和扩张 |

**驱动因素：**
- 供应链修复 → 商品通胀消退
- 劳动市场软着陆（企业不裁员但不大幅加薪）
- 生产率提升（AI驱动）→ 抑制单位劳动成本
- 财政政策温和（不刺激也不紧缩）

**跨资产反应：**
- 股票：**上涨**（企业盈利稳定+折现率低）
- 债券：**稳定/小幅牛**（利率维稳或缓降）
- 信用利差：**收窄**（经济稳定+违约率低）
- 美元：**中性或小幅弱**（其他央行随之降息）
- 黄金：**中性**（无通胀恐惧，无避险需求）
- 大宗商品：**温和上涨**（需求稳定）

---

### 1.3 情景②：滞胀（Stagflation）

**定义：** 经济增长低于潜在水平（或衰退）但通胀持续高企，货币政策两难

**宏观特征：**

| 变量 | 典型值 | 方向 |
|------|--------|------|
| 美国实际GDP增速 | <1%或负 | 放缓/衰退 |
| 核心PCE通胀 | >3%（顽固）| 仍高 |
| 失业率 | 5.5-7% | 上升 |
| 联邦基金利率 | 两难（加息=衰退，降息=通胀）| 被迫维持高位 |
| 能源/大宗商品价格 | 高 | 供给冲击驱动 |

**历史参照：**
- 1973-1975年：石油危机 → 美国CPI峰值12.3%，失业率7.2%
- 1979-1982年：第二次石油危机 → 通胀13%，Volcker加息至20%，衰退严重
- 2022年（部分滞胀特征）：能源通胀+增长放缓，但未完全滞胀化

**典型触发路径：**
```
供给侧冲击（能源/粮食/地缘冲突）
    ↓
成本推动型通胀（CPI>5%）
    ↓
实际工资↓ → 消费下降 → GDP放缓
    ↓
企业成本↑ → 投资减少 → 更多失业
    ↓
央行两难：加息→衰退加深；降息→通胀再起
```

**跨资产反应：**
- 股票：**大幅下跌**（利润受压+折现率高）
- 债券：**下跌**（通胀侵蚀实际收益，利率高）
- 信用利差：**大幅扩大**（违约风险↑）
- 大宗商品：**上涨**（能源/黄金/贵金属）
- 美元：**视美国情况**（若美国滞胀>欧洲，美元弱）
- 黄金：**强势**（通胀对冲+避险）
- TIPS（通胀保值债）：**跑赢**

---

### 1.4 情景③：通缩衰退（Deflationary Recession）

**定义：** 需求崩溃驱动的经济衰退，通胀转负（通缩），货币政策空间受限

**宏观特征：**

| 变量 | 典型值 | 方向 |
|------|--------|------|
| 美国实际GDP增速 | <-1%（衰退）| 大幅下行 |
| 核心PCE通胀 | <1%或负 | 通缩趋势 |
| 失业率 | 7-12% | 快速上升 |
| 联邦基金利率 | 接近0%（零利率下限）| 被迫降至底部 |
| 信用市场 | 信贷收缩，利差飙升 | 流动性危机 |

**历史参照：**
- 1929-1933年大萧条：美国GDP-30%，CPI-27%，失业率25%
- 2008-2009年：全球金融危机，GDP-4.2%，CPI短暂转负
- 2020年新冠初期：GDP-3.4%（但政策迅速稳住，未深度通缩）
- 日本1990-2013年：轻度通缩长期化

**典型触发路径：**
```
资产价格泡沫破裂（房地产/股票/信贷）
    ↓
财富效应消失 → 消费骤降
银行资产减值 → 信贷收缩（资产负债表衰退）
    ↓
企业投资↓ → 失业↑ → 收入↓ → 消费↓（自我强化）
    ↓
通缩预期形成 → 推迟消费/投资 → 实际利率上升
    ↓
Fisher债务通缩螺旋（Debt Deflation）
```

**跨资产反应：**
- 股票：**大幅下跌**（企业盈利崩溃）
- 政府债券：**大幅上涨**（避险+通胀消失，实际收益高）
- 信用利差：**暴涨**（违约率飙升）
- 大宗商品：**大幅下跌**（需求崩溃）
- 美元：**大幅升值**（避险+去杠杆/美元荒）
- 黄金：**初期下跌**（美元荒→卖金求流动性），随后若政策反应→上涨
- 现金：**为王**

---

### 1.5 情景④：过热（Overheating）

**定义：** 经济增速持续超过潜在产出，需求过热推动通胀上升，央行被迫激进加息

**宏观特征：**

| 变量 | 典型值 | 方向 |
|------|--------|------|
| 美国实际GDP增速 | >3% | 过热 |
| 核心PCE通胀 | >3-4% | 上升 |
| 失业率 | <3.5% | 过度紧张 |
| 联邦基金利率 | 大幅上升（> 中性利率+200bp）| 紧缩 |
| 信贷增速 | 过热（>10%）| 扩张 |

**历史参照：**
- 1990年代末IT泡沫末期：美国GDP+4%+，Fed最终加息
- 2021年新冠后刺激过度：GDP+5.9%，通胀随后暴升到9%
- 1960年代末越战财政扩张导致的通胀种子期

**跨资产反应（过热→转向紧缩的路径）：**
- 股票：**初期继续上涨**（盈利好），随加息预期升温而承压
- 债券：**下跌**（利率上升预期，利率敏感性高）
- 信用利差：**先收窄后扩大**（盈利支撑→货币紧缩担忧）
- 大宗商品：**上涨**（需求旺盛）
- 美元：**升值**（加息预期）
- 黄金：**中性偏弱**（实际利率上升压制）

## 二、跨资产相关性矩阵

### 2.1 各情景下主要资产类别方向总结

| 资产类别 | 金发姑娘① | 滞胀② | 通缩③ | 过热④ |
|----------|----------|-------|------|------|
| 美国股票（S&P 500）| ↑↑ | ↓↓ | ↓↓↓ | ↑（初）→↓（后）|
| 美国国债（10年期）| ↔（轻微↑）| ↓↓ | ↑↑↑ | ↓↓ |
| 投资级信用 | ↑ | ↓↓ | ↓↓↓ | ↑（初）|
| 高收益债 | ↑↑ | ↓↓↓ | ↓↓↓ | ↑（初）→↓（后）|
| 黄金 | ↔ | ↑↑ | ↑（中期）| ↓ |
| 原油/大宗 | ↑ | ↑↑ | ↓↓ | ↑↑ |
| 美元指数 | ↔弱 | 分化 | ↑↑ | ↑↑ |
| 新兴市场股票 | ↑↑ | ↓↓ | ↓↓↓ | ↑（初）|
| 房地产（REITs）| ↑↑ | ↔（通胀保护）| ↓↓ | ↔→↓ |
| TIPS | ↔ | ↑↑ | ↓（实际利率↑）| ↑（短期）|

**符号说明：** ↑↑↑=大幅上涨；↑↑=明显上涨；↑=小幅上涨；↔=中性；↓=小幅下跌；↓↓=明显下跌；↓↓↓=大幅下跌

### 2.2 资产内部相关性结构（情景驱动的动态相关性）

**正常时期（金发姑娘）：**
- 股-债相关性：**负（约-0.3至-0.5）**——债券提供股票对冲
- 股-商品相关性：正（约+0.3）——同受经济周期驱动
- 美元-股票相关性：负（约-0.2）

**危机时期（通缩衰退/金融危机）：**
- 股-债相关性：**更负（约-0.5至-0.7）**——飞向安全
- 股-商品相关性：**暂时变正，随后同跌**（流动性危机时相关性→1）
- 美元-股票相关性：更负（美元荒推高美元，股票暴跌）

**滞胀时期（1970年代范式）：**
- 股-债相关性：**可能变正（约+0.3至+0.5）**——两者均被通胀侵蚀
- 股-大宗商品相关性：**负**（成本推动压缩利润，大宗上涨）
- 这是对传统60/40组合最危险的情景

**重要警示：相关性在极端情景下会崩溃：**
```
2008年9月：几乎所有资产相关性→+1（只有美元/美国国债例外）
    ↓
原因：强制去杠杆（对冲基金赎回）→ 抛售所有流动性好的资产
    ↓
对冲有效性完全失效（分散化无法提供保护）
    ↓
只有现金/超短期国债是真正的避风港
```

## 三、情景概率分配方法

### 3.1 贝叶斯更新框架

**基础概率（先验，基于历史频率）：**

| 情景 | 历史频率（战后美国）| 先验概率 |
|------|------------------|---------|
| 金发姑娘 | 约45%（扩张中的平稳期）| 40% |
| 过热 | 约20% | 20% |
| 通缩衰退 | 约25%（各类衰退）| 25% |
| 滞胀 | 约10%（相对罕见）| 15% |

**贝叶斯更新：根据当前宏观信号调整**

```
P(情景|信号) = P(信号|情景) × P(情景) / P(信号)

实操：
1. 识别"关键信号"（收益率曲线形态/ISM/失业率变化/CPI结构）
2. 评估该信号在每个情景下的出现概率
3. 更新各情景的后验概率
4. 组合加权
```

### 3.2 关键先行指标与情景关联

| 先行指标 | 金发姑娘① | 滞胀② | 通缩③ | 过热④ |
|----------|----------|-------|------|------|
| 10Y-2Y收益率曲线 | 正斜（陡峭化）| 正斜但实际收益低 | 倒挂→急速陡峭（衰退）| 正斜（加息前）|
| ISM制造业PMI | 50-55 | <50但CPI高 | <48（持续）| >57 |
| 非农就业月增 | +150k至+250k | <+50k | <0（失业）| >+300k |
| 核心CPI同比 | 1.5-2.5% | >3.5%（不降）| <1%（下行）| 2.5-4%（上升）|
| 油价（WTI）| $60-90 | >$90（冲击驱动）| <$60（需求崩溃）| $80-100（需求拉动）|
| 信用利差（IG）| <100bp | >150bp（扩大）| >200bp（危机）| <80bp（极窄）|
| 消费者信心指数 | 中高 | 低（通胀侵蚀）| 极低 | 高 |

### 3.3 情景矩阵评分法（实操工具）

**步骤：**
1. 列出10-15个关键宏观指标
2. 为每个指标打分：+2（强烈支持该情景）, +1（轻微支持）, 0（中性）, -1（不支持）
3. 加权平均得到各情景得分
4. 转化为概率（softmax或归一化）

**示例评分（2024年Q3情景）：**

| 指标 | 金发姑娘 | 滞胀 | 通缩 | 过热 |
|------|----------|------|------|------|
| 收益率曲线（倒挂收窄中）| +1 | 0 | +1 | 0 |
| 核心PCE 2.6%（下降中）| +2 | -1 | +1 | -1 |
| 非农+200k（稳定）| +2 | -1 | -1 | +1 |
| 油价$75-85（稳定）| +1 | -1 | 0 | +1 |
| 信用利差130bp（窄）| +1 | -1 | -1 | +2 |
| ISM制造业49（弱）| -1 | +1 | +1 | -2 |
| 消费者信心中等 | +1 | 0 | -1 | +1 |
| 加权总分 | **+7** | **-3** | **0** | **+2** |
| 概率分配 | **55%** | **10%** | **20%** | **15%** |

## 四、2024-2026年情景权重与核心判断

### 4.1 2024年情景概率（历史参考）

**2024年初市场共识：**

| 情景 | 概率 | 核心支持论据 |
|------|------|------------|
| 软着陆/金发姑娘 | 55-60% | 通胀持续下降+就业稳定+AI驱动生产率 |
| 通缩衰退 | 20-25% | 高利率滞后效应+信贷收紧+商业地产危机 |
| 滞胀 | 10-15% | 能源/地缘风险（中东）+服务通胀顽固 |
| 过热 | 5-10% | 财政刺激超预期+AI投资潮 |

**2024年实际走势：** 基本沿金发姑娘/软着陆路径演进，Fed在2024年9月首次降息50bp。

### 4.2 2025-2026年情景权重（截至2026年初）

**核心背景变量：**
- 美国关税政策升级（2025年特朗普上台后对等关税）→ 供给冲击风险
- Fed降息周期进行中但步伐谨慎
- 全球地缘风险（俄乌/中东/台海）仍高
- AI驱动生产率提升（分歧很大）

**2026年情景概率评估：**

| 情景 | 概率（2026年初）| 核心逻辑 |
|------|--------------|---------|
| **金发姑娘（修正版）** | **40%** | 关税冲击可控，Fed适时降息，就业韧性 |
| **滞胀** | **25%** | 关税→输入性通胀+全球贸易收缩=增长放缓+通胀反弹 |
| **通缩衰退** | **20%** | 高利率后遗症（商业地产/小银行)+全球需求疲软 |
| **过热（尾部）** | **15%** | AI投资狂潮+财政超级扩张→新一轮过热循环 |

**情景转换的关键观测点：**
```
如果：
  关税全面升级（>25%平均关税率）→ 滞胀概率↑
  信贷事件（区域银行危机/商业地产违约潮）→ 通缩衰退概率↑
  AI爆发+财政扩张→ 过热概率↑
  通胀平稳下行+就业稳定→ 金发姑娘概率↑
```

## 五、情景分析在投资组合中的应用

### 5.1 情景加权资产配置

**方法论：**
```
期望回报 = Σ(情景概率 × 情景回报)

风险-情景矩阵：
  对每类资产，计算在每个情景下的预期回报
  加权求和得到期望回报
  考虑情景转变的尾部风险（条件VaR）
```

**示例（2026年情景权重下的股债配置）：**

| 资产 | 金发姑娘(40%) | 滞胀(25%) | 通缩(20%) | 过热(15%) | 加权期望 |
|------|------------|---------|---------|---------|---------|
| S&P 500 | +12% | -20% | -35% | +15% | **-0.6%** |
| 美国国债10Y | +3% | -8% | +20% | -10% | **+1.6%** |
| 黄金 | +2% | +20% | +10% | -5% | **+8.3%** |
| 原油 | +8% | +30% | -30% | +15% | **+5.7%** |
| TIPS | +2% | +15% | -2% | +5% | **+5.8%** |

→ 结论：在当前情景权重下，黄金/TIPS/原油的加权期望远优于纯股票或纯债券

### 5.2 情景触发的动态调整机制

**预设触发器（Trigger Rules）：**

| 信号事件 | 情景转变方向 | 组合调整建议 |
|----------|------------|------------|
| CPI反弹>4%（3个月）| 金发姑娘→滞胀 | 减股增商品/TIPS，减久期 |
| 失业率>5.5%（快速上升）| 任意→通缩衰退 | 加国债，减高收益债，减新兴市场 |
| 非农连续3月>400k | 金发姑娘→过热 | 减久期，减债券，增短久期浮动利率 |
| 信贷利差扩200bp（快速）| 任意→通缩衰退 | 现金为王，减风险资产 |
| 油价>$120（地缘驱动）| →滞胀加权上升 | 减股票，增大宗商品/黄金 |

## 六、历史情景对照

### 6.1 典型金发姑娘期（1995-1999）

- Fed软着陆成功（1995年仅3次加息即控住通胀）
- CPI从3.5%→2%，GDP保持+3%+
- 纳斯达克5年上涨约500%，债券稳定
- **教训：** 软着陆会过渡到过热（IT泡沫），需关注信贷/估值过度

### 6.2 典型滞胀期（1973-1975）

- 石油禁运→CPI12%，GDP-0.5%
- 股票两年跌约48%，债券实际收益为负
- **教训：** 供给冲击驱动的滞胀中，传统组合60/40完全失效，大宗商品是唯一真正保护

### 6.3 典型通缩衰退（2008-2009）

- GDP-4.2%，CPI短暂转负，信用利差飙升至2000bp（高收益）
- 美国国债回报约+25%（30年期），S&P 500-57%
- **教训：** 政策反应速度决定衰退深度——Fed/财政同步大规模应对是关键

### 6.4 典型过热→转折（2021-2022）

- 财政超刺激（约5万亿美元新冠救助）+ 供应链冲击
- 通胀从2%飙升至9.1%（2022年6月）
- Fed被迫急速加息（+525bp，最快周期之一）
- 股债双杀：S&P -19%，美债-18%（2022年）
- **教训：** 过热期债券保护功能彻底消失，传统避险策略失效

## 七、当前状态（2026）

**2026年情景分析核心挑战：**
1. 关税政策不确定性创历史高位，情景分布比过去更分散（"肥尾"）
2. AI技术是否真正提升生产率，是金发姑娘延续还是过热的关键分歧变量
3. 地缘政治尾部风险（台海/中东）使滞胀概率的"隐含值"可能被低估
4. 全球债务高位（美国120% GDP/日本260%/欧洲115%+）使政策空间缩窄，任何情景的政策应对能力都弱于历史

**情景分析实践建议：**
- 不要将单一情景作为"基准"——使用加权期望和情景分布
- 关注情景转换点（早期预警指标）比预测具体情景更有价值
- 在高不确定性环境中，控制尾部风险（情景③和②）比优化期望回报更重要
