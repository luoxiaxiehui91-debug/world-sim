# 07_方法论

本目录存放**宏观分析的研究方法论文档**，偏向"如何系统性地做分析"而非具体工具。

## 目录内容

| 文件 | 说明 |
|:---|:---|
| 宏观情景分析手册.md | 情景分析的完整方法流程 |
| 多因子分析框架.md | 多维度因子的综合评估方法 |
| 央行政策评估框架.md | 评估央行政策立场和路径的方法论 |
| 早期预警信号体系.md | 识别系统性风险的信号框架 |
| 尾部风险压力测试框架.md | 极端情景下的压力测试方法 |

## 与其他目录的分工

- **本目录**：研究方法论（怎么做分析）
- **`04_分析框架/`**：具体分析工具（直接调用）
- **`08_推演元框架/`**：底层认知架构（为什么这样分析）
