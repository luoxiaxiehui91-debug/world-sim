## 一、全球宏观总体评估

### 1.1 核心研判（截至 2026 年 Q1–Q2）

```
美国：软着陆完成，但"高压平台"持续
  → GDP 增速维持 2.0–2.5%，失业率 4.0–4.3%
  → CPI 从峰值下行，但 3% 以上粘滞（服务通胀顽固）

  → GDP 增速 4.5–5.0%，官方目标"约5%"
  → 房地产去杠杆仍在进行，内需恢复缓慢
  → 出口驱动增长，贸易摩擦风险上升

欧元区：接近停滞
  → GDP 增速 0.5–1.0%，德国制造业持续萎缩
  → 通胀接近目标，ECB 降息周期已开始
  → 能源转型成本 + 地缘政治风险构成结构性压力

日本：从通缩走向"温和通胀"的历史性转变
  → BOJ 结束负利率时代，政策利率 0.25–0.5%
  → 日元汇率已从 160 部分回升，套利平仓仍有余震
  → 工资-通胀正向反馈初现（春斗加薪 5.5%+）
```

### 2.2 主要风险

**尾部风险1：二次通胀（⚠️ 已部分触发）**
- ~~油价重返 $100+~~ → **WTI 已达 $101.56（2026-05），F7 回路已激活**
- PPI YoY 9.82%（关税传导叠加油价），已向 CPI 渗透（CPI 3.78%，粘性超预期）
- 当前关注点：CPI 是否从 3.78% 进一步反弹突破 4%
- 触发：F7 油价滞胀回路（**当前状态：活跃**）
- 概率（升级为全面滞胀）：约 25–35%（从 15–20% 上调）

**尾部风险2：信贷收缩**
- 商业地产（CRE）贷款坏账（2026年到期高峰约 1.5万亿美元）
- 中小银行资本充足率压力
- 触发：F3 银行挤兑/F6 美元流动性枯竭
- 概率（基准）：约 10–15%

**尾部风险3：财政利率螺旋**
- 美国国债利息支出已超国防预算
- 2026 年到期债务再融资规模约 6–7 万亿美元
- 若 10Y 利率维持 4.5%+，债务利息/GDP 进一步上升
- 触发：F8 财政利率螺旋
- 概率（中期）：约 25–35%（缓慢累积）

### 2.3 联储政策路径

```
【已实况】截至 2026-05：FFR 已降至 3.63%（从 4.25–4.50% 降约 75–87bp）
  → 鸽派路径基本实现，但通胀数据（CPI 3.78%）与降息路径形成矛盾

基准路径（修订）：2026年下半年再降息 0–1次（0–25bp）
  → 条件：等待通胀从 3.78% 明确下行，同时劳动市场不恶化

鹰派路径（概率约 35%，上调）：下半年暂停降息甚至重新加息
  → 触发：CPI 继续反弹突破 4%，PPI 传导加速
  → 联储已陷入"就业恶化 vs 通胀再起"两难

鸽派路径（概率约 15%，下调）：追加降息 2次+
  → 触发：失业率快速突破 4.5%，萨姆规则 ≥ 0.3（当前 0.2）
```

## 三、中国：弱复苏的结构性约束

### 3.1 当前状态

| 指标 | 现值 | 趋势 |
|:---|:---:|:---:|
| GDP YoY | ~5.0% | 官方目标约5%，真实略偏弱 |
| 制造业 PMI | 50–51 | 温和扩张，出口拉动 |
| CPI YoY | 0.1–0.5% | 接近通缩边缘，内需不足 |
| PPI YoY | -1~0% | 仍负增长，工业品通缩 |
| M2 YoY | ~7–8% | 偏低（历史均值 ~11%） |
| 房价 YoY（70城） | -3~-5% | 仍在下行，去库存缓慢 |

### 3.2 三大结构性压力

1. **人口：劳动年龄人口已见顶**
   - 2023年起净减少，2030年加速
   - 抑制潜在增速上限，类日本化压力

2. **债务：地方政府隐性债务**
   - 城投债余额约 50–60 万亿
   - 2026 年部分平台债到期，依赖中央政府专项债置换

3. **贸易：出口驱动遭遇高关税墙**
   - 美国对华关税升至145%（2026-04高峰），中方反制125%
   - 2026-05-12 日内瓦峰会后90天暂停协议：美→30%，中→10%
   - 暂停到期：2026-08，延续谈判前景不确定
   - 欧盟对中国新能源车加征关税 17–38%
   - 转口贸易通过东南亚的摩擦增加

### 3.3 政策应对空间

```
货币：7天逆回购利率 1.5%，仍有 50–100bp 降息空间
财政：2026 赤字率 ~4%（突破3%红线），专项债约3万亿+
直接刺激：家电/汽车以旧换新补贴（2025年效果有限）
```

## 四、地缘政治背景（当前活跃风险）

### 4.1 俄乌战争

- **现状**：进入"冻结冲突"阶段可能性上升
- **能源影响**：欧洲已完成能源替代（LNG替代管道气），但价格仍高于战前
- **对美国影响**：通过 NATO 军费预算（间接财政压力）

### 4.2 台海

- **现状**：高度紧张但稳定，灰色地带行动持续
- **系统内评级**：地缘风险矩阵中 energy_shock=3–4/10（封锁风险）
- **触发条件**：若升级为军事冲突，oil_price_shock 可达 8–9/10

### 4.3 中东（红海/伊朗）

- **现状**：胡塞武装扰乱苏伊士航线持续
- **影响**：航运绕行好望角，运费上涨约 40–80%（已部分反映）
- **WTI 当前实况**：**$101.56（2026-05）**，已突破 $100 关口，地缘溢价已实质体现
- **系统内**：oil_price_shock = **6–7**/10（上调，$100+ 已实现；若伊朗直接介入则升至 9+）

### 4.4 贸易战升级与缓和（⚡ 2026-05 重大更新）

- **历史最高点**：2026-04 美对华145%，中对美125%，双边贸易接近停滞
- **日内瓦峰会（2026-05-12）**：达成90天暂停协议，美→30%，中→10%
- **市场反应**：SPX反弹+3-5%，人民币升值，风险资产普涨
- **后续关键节点**：2026-08 暂停到期，谈判能否延续是最大不确定因素
- **系统内**：`trade_tension` 从 5/10 下调至 **3/10**（暂停期内）；若2026-08延续则维持3，若破裂则升至8+

3. AI 投资爆发式增长的不确定性
4. 多极地缘政治格局下的结构性通胀
