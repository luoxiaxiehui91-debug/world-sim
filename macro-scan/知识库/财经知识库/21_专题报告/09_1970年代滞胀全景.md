# 1970年代滞胀全景：石油冲击、工资螺旋与沃尔克的终结

> 整理时间：2026-05-21 | 数据来源：美联储公开数据、BLS、EIA历史档案、FRED历史序列
> 覆盖周期：1973-1983（两次石油危机 + 沃尔克冲击）

---

## 一、为什么1970年代是理解通胀的必修课

1970年代是现代货币政策史上的关键十年。它回答了一个问题：**如果央行不够硬，通胀会到哪里去？**

这十年发生了两次石油危机、两次衰退、一次恶性通胀螺旋，最终由沃尔克用最激进的紧缩政策强行打断。

对2026年的意义：
- 当前WTI $112，CPI 3.78%，PPI 9.82%——与1973年初期的结构高度相似
- "油价→PPI→CPI"的传导链在1970年代已被彻底验证
- 美联储是否有意愿再次扮演沃尔克角色，是当前最大的政策不确定性

---

## 二、第一次石油危机（1973-1975）

### 2.1 导火索：阿拉伯石油禁运

```
1973年10月6日 — 赎罪日战争（以色列 vs 埃及/叙利亚）
    ↓
1973年10月17日 — OPEC阿拉伯成员国宣布对西方石油禁运
    ↓
油价：$3/桶 → $12/桶（+300%），4个月内
    ↓
美国：加油站排队、限速55英里/小时、奇偶限购
```

### 2.2 宏观传导

| 指标 | 战前（1972） | 峰值 | 时间 |
|:---|:---:|:---:|:---|
| WTI油价 | ~$3/桶 | ~$12/桶 | 1974年初 |
| CPI同比 | 3.3% | **12.3%** | 1974年12月 |
| 失业率 | 5.6% | **9.0%** | 1975年5月 |
| 实际GDP | +5.2% | **-3.2%** | 1974年 |
| 联邦基金利率 | 5.3% | 13.0% | 1974年7月 |

**核心矛盾**：1970年代初美国存在"尼克松工资价格管制"（1971-1974），管制解除后积压的通胀压力集中释放，与油价冲击叠加，形成**通货膨胀螺旋**：

```
油价上涨 → 生产成本上升 → 工资要求上涨（工会力量强）
    ↓                              ↓
CPI上升 ←─────── 企业涨价 ←──────┘
（工资-价格螺旋）
```

### 2.3 美联储的失误：伯恩斯的妥协

时任美联储主席**亚瑟·伯恩斯**（Arthur Burns）面临两个压力：
1. 白宫（尼克松→福特→卡特）不希望经济衰退
2. 理论上相信"通胀主要是结构性的，货币政策无法解决"

结果：美联储在1974年加息到13%后，就业压力一来立刻降息，未能将通胀真正打下去。

**关键错误**：通胀预期一旦去锚（工人和企业开始预期未来持续高通胀），工资-价格螺旋自我强化，货币政策必须更猛才能重新锚定。

## 三、通胀"复辟"（1976-1979）

1975-1976年，美联储降息、经济复苏，CPI从12.3%降至5.7%——看起来通胀被打败了。

但预期已经变了：

```
1977-1978：
  - 卡特政府实施扩张性财政政策（就业刺激）
  - 美元大幅贬值（布雷顿森林体系已崩溃@1971）
  - 石油输出国看到美元贬值，实际油价被侵蚀
    ↓
1978-1979：CPI重新加速，从5.7% → 9.0%
    ↓
第二次石油危机来袭
```

## 四、第二次石油危机（1979-1980）

### 4.1 双重冲击

| 事件 | 时间 | 影响 |
|:---|:---|:---|
| 伊朗伊斯兰革命 | 1979年2月 | 伊朗石油产量骤降 |
| 伊朗-伊拉克战争 | 1980年9月 | 两国出口同时受阻 |
| WTI油价 | 1979-1980 | $15 → $35（+130%） |

### 4.2 通胀到达顶峰

| 指标 | 峰值 | 时间 |
|:---|:---:|:---|
| CPI同比 | **14.8%** | 1980年3月 |
| 核心CPI | **13.6%** | 1980年3月 |
| 联邦基金利率 | **20.0%** | 1981年6月 |
| 10年期国债 | **15.8%** | 1981年9月 |

## 五、沃尔克冲击（1979-1983）

### 5.1 沃尔克的到来

1979年8月，卡特任命**保罗·沃尔克**（Paul Volcker）为美联储主席。

沃尔克的判断与伯恩斯完全相反：**通胀预期去锚是最危险的状态，必须用超高利率强行重新锚定，无论短期经济代价多大。**

```
1979年10月6日"周六大屠杀"：
  美联储宣布改变货币政策操作框架
  从"盯联邦基金利率"改为"控制货币供应量增速"
    ↓
  实际效果：允许短期利率自由上浮至市场出清水平
    ↓
  联邦基金利率从11.2% → 17.6%（1980年4月）→ 20.0%（1981年6月）
```

### 5.2 双底衰退的代价

沃尔克的紧缩制造了两次衰退：

| 衰退 | 时间 | GDP跌幅 | 特征 |
|:---|:---|:---:|:---|
| 第一次 | 1980年Q1-Q2 | -2.2% | 短暂，很快反弹 |
| 第二次 | 1981年Q3-1982年Q4 | **-3.0%** | 严重，失业率到10.8% |

**最痛苦的数据（1982年）**：
- 失业率：**10.8%**（战后最高）
- 银行倒闭数：增加
- 制造业就业：持续流失
- 住房开工：暴跌（30年期房贷利率>18%）

国会、白宫、工业界轮番向美联储施压要求降息，沃尔克顶住了。

### 5.3 通胀的终结

```
1982年：CPI从14.8%下降 → 3.2%
          失业率见顶 → 开始回落
          美联储开始降息（从20% → 9%@1983）
    ↓
1983年：里根经济复苏（"Morning in America"）
  GDP +7.2%，史上最强的战后复苏之一
    ↓
通胀预期重新锚定在低位
美联储公信力恢复
```

**收益率曲线的轨迹**：

| 时间 | 10Y-2Y利差 | 含义 |
|:---|:---:|:---|
| 1978年 | +1.5% | 正常 |
| 1980年 | **-3.0%** | 深度倒挂（紧缩最猛） |
| 1982年 | +0.5% | 逐步正常化 |
| 1983年 | +2.0% | 完全正常化 |

## 六、长期影响：货币政策的"沃尔克时刻"

### 6.1 央行独立性被确立

1970年代最重要的制度遗产：**央行必须有政治独立性，才能对抗通胀**。

伯恩斯服从白宫压力的教训 + 沃尔克顶住压力的成功，共同奠定了此后40年"央行独立性神圣不可侵犯"的共识。

### 6.2 通胀预期锚定的价值

```
锚定通胀预期（Anchored Expectations）：
  工人在谈工资时不假设通胀会持续 → 不要求过高的工资涨幅
  企业在定价时不假设原材料永远涨 → 不会预防性涨价
    ↓
即使有供给冲击（如油价上涨），通胀螺旋不会自我强化
    ↓
2022年美联储急加息的最终成功，依赖的正是1980年代建立的预期锚
```

### 6.3 油价与通胀的长期去相关

1973-1980年，油价每上涨10%，CPI会上涨约1.5-2%（强相关）。
1990年代以后，同样的油价冲击对CPI影响显著减小（强化绝缘）。

原因：
- 能源密集度下降（GDP/单位能耗改善）
- 服务业比重上升（制造业敏感度高，服务业低）
- 通胀预期锚定（不会自我强化）

## 七、与2026年的对照

| 维度 | 1973-1974 | 2026年当前 |
|:---|:---|:---|
| 油价冲击 | +300%（禁运） | +40% YTD（地缘+OPEC减产） |
| CPI峰值 | 12.3% | 3.78%（仍低，但再次上行） |
| PPI | 同步大幅上升 | 9.82%（极高，传导中） |
| 央行态度 | 伯恩斯：妥协 | 鲍威尔：态度模糊（两难） |
| 工资-价格螺旋 | 工会力量强，螺旋形成 | 工会力量弱，但科技/医疗等行业工资仍高 |
| 财政刺激 | 适度 | 财政赤字/GDP>6%，穆迪主权警告 |
| 通胀预期 | 去锚（关键转折点） | 仍基本锚定，但5年盈亏平衡通胀率上升 |

**关键差异**：2026年通胀预期仍基本锚定（这是2022年急加息建立的公信力的遗产），所以不会重演1980年的14.8%场景。

**关键相似**：油价通过PPI向CPI渗透的机制完全相同；若美联储过早降息（类似1975-1978年伯恩斯路径），第二波通胀的风险是真实的。
