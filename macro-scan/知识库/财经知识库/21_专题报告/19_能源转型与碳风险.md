# 能源转型与碳风险：物理风险、转型风险与通胀长期路径

> 整理时间：2026-05-21 | 数据来源：IEA《World Energy Outlook 2024》、BloombergNEF、IRENA、NGFS（央行绿色金融网络）、FRED历史档案、欧盟委员会
> 覆盖周期：2000-2050（化石燃料高峰 → 可再生能源爆发 → 2026当前转型临界点）

---

## 一、为什么能源转型是独立的宏观变量

现有 `climate_physical_risk` 维度只追踪极端天气等物理风险对油价/CPI的冲击，但能源转型带来的**转型风险**（Transition Risk）具有完全不同的宏观逻辑：

- **转型成本推高近期通胀**：快速脱碳需要大量基础设施投资（电网、储能、氢能），这是实际需求拉动通胀，与供给冲击通胀性质不同
- **搁浅资产的金融传导**：约$1-4万亿化石燃料资产面临在政策转型下提前贬值，影响持有这些资产的银行/养老金/主权财富基金（金融体系脆弱性联动）
- **油价长期路径的分叉**：物理需求（内燃车→电车替代）将逐步压缩石油需求，但转型期供给缺口可能先推高油价，再断崖式下跌
- **通胀长期基线改变**：若碳税/碳边境调节机制（CBAM）全面实施，等同于对所有碳密集型商品征收永久性额外税（能源、钢铁、水泥、化工）

对推演系统的意义：
- 当前 climate_physical_risk 维度的 MC 调整（油价→CPI传导系数）需要随可再生能源渗透率逐年更新
- 碳价格是新的结构性通胀来源，与货币政策逻辑不兼容（加息无法降低碳税通胀）
- 中国清洁能源制造主导地位（光伏/电池）是中国贸易顺差和供应链博弈的新维度

## 二、能源转型的当前进展数据

### 2.1 全球可再生能源装机（IEA 2024数据）

| 指标 | 2015年 | 2023年 | 2030年目标（IEA NZE） |
|:---|:---:|:---:|:---:|
| 全球可再生能源发电占比 | 23% | **30%** | 60%+ |
| 太阳能新增装机（GW/年） | 50 | **420** | 1000+ |
| 风电新增装机（GW/年） | 63 | 115 | 320+ |
| 电动车销售渗透率（全球） | <1% | **18%** | 35%+ |
| 光伏LCOE（度电成本，美分） | 28 | **4-5** | 2-3（预测） |

**光伏成本从2010年至今下降约89%**（BloombergNEF），是历史上最快的能源技术成本下降曲线。

### 2.2 中国在清洁能源制造的主导地位

| 产品 | 中国全球份额（2024） | 供应链控制 |
|:---|:---:|:---|
| 太阳能电池板 | **约80%** | 多晶硅→硅片→电池片→组件全链 |
| 锂电池单体 | **约75%** | 含CATL/BYD，成本领先全球 |
| 稀土精炼 | **约85-90%** | 永磁体（风电/电动车电机）关键 |
| 电解槽（绿氢） | 约40%，快速上升 | 成本优势显著 |
| 电动车销量 | 约60%（全球销量） | BYD超越特斯拉 |

**这意味着能源转型的制造层与地缘政治博弈深度交织**：西方国家的去碳化目标依赖中国制造的零部件，但同时推进贸易保护。

## 三、物理风险 vs. 转型风险：两种完全不同的冲击机制

```
物理风险（已在现有climate_physical_risk维度追踪）：
  极端天气 → 粮食减产/能源基础设施受损 → CPI上升
  海平面上升 → 沿海资产损失 → 保险成本上升
  时间框架：1-30年，随气候持续恶化

转型风险（本报告新增维度）：
  碳政策收紧（碳税/CBAM/排放标准）
         ↓
  ①  化石燃料企业盈利下降 → 搁浅资产
  ②  碳密集型产品价格上升（能源/钢铁/水泥）
  ③  新能源基础设施投资激增（需求推动通胀）
  时间框架：0-20年，政策驱动，可快速转向
```

## 四、碳价格与通胀的关系

### 4.1 欧盟ETS碳价格走势

| 时期 | EU ETS碳价 | 对欧元区CPI影响 |
|:---|:---:|:---|
| 2017-2020 | €5-25/吨 | 有限 |
| 2021年 | €50/吨 | CPI约+0.5ppt（能源占比高） |
| 2022年峰值 | **€95/吨**（2月） | +1-1.5ppt（叠加俄乌天然气危机） |
| 2024年 | €55-65/吨 | 约+0.3ppt |
| 2030年目标 | 政策预期€100-150/吨 | 估计+0.8-1.5ppt/年 |

**CBAM（碳边境调节机制）**：2026年全面生效。对进口钢铁/铝/水泥/化肥/电力和化工品征收等同于EU ETS的碳成本。直接影响：中国出口欧洲的相关产品面临约10-20%的额外关税，长期推高欧洲工业通胀。

### 4.2 碳税通胀的货币政策困境

```
碳税推高能源/工业品价格（一次性成本推动通胀）
     ↓
央行视角：是否加息应对？
     
历史先例：1970年代油价冲击的教训
  → 油价上涨是供给冲击，加息无法降低油价
  → 过度加息→经济衰退（沃尔克冲击代价）
  → 错误是把供给冲击当成需求通胀处理

碳税通胀 = 政策性供给成本推升
  → 加息无效（不能降低碳税）
  → 不加息则通胀预期有脱锚风险
  → 央行陷入两难：接受高通胀 OR 制造衰退
```

## 五、搁浅资产风险与金融体系

### 5.1 化石燃料搁浅资产规模估算

```
全球已探明化石燃料储量（现市值）：约$20-28万亿（IRENA、Carbon Tracker）
  其中：若实现《巴黎协定》1.5°C目标，
  约60-80%的化石燃料储量无法开采

潜在搁浅资产：$12-22万亿（长期）

当前持有者：
  - 石油主权财富基金（沙特PIF、挪威GPFG等）
  - 全球大型养老金（大量持有能源股）
  - 商业银行（化石燃料项目贷款）

金融传导路径：
  若政策加速收紧 → 化石燃料股/债价值骤降
  → 持有银行资产负债表受损（类CRE逻辑）
  → 信用收缩 → 经济冲击
  时滞：取决于政策速度，可以是3-15年
```

### 5.2 NGFS情景（央行绿色金融网络）

| 情景 | 政策路径 | 金融风险 | 物理风险 |
|:---|:---|:---:|:---:|
| **有序转型** | 碳价格平稳上升，政策可预期 | 低-中 | 低（2℃目标实现） |
| **无序转型** | 推迟后急剧收紧（类似当前路径） | **高**（搁浅资产骤然暴露） | 中 |
| **全球高温** | 政策失败，持续排放 | 低（化石燃料价值维持） | **极高**（物理损失积累） |

**当前全球路径最接近"无序转型"**：各国政策承诺与实际行动存在巨大差距，导致长期承诺→短期不作为→未来被迫急剧收紧的风险。

## 六、能源转型对油价长期路径的影响

```
短期（2026-2030）：供给不确定性主导
  OPEC+减产维持 + 俄罗斯受制裁 + 新能源投资挤压传统能源勘探投资
  → 供给收缩的风险仍在
  → 油价可能维持$70-100/桶区间，甚至脉冲式上涨

中期（2030-2040）：需求开始下行
  电动车渗透率→石油需求峰值（IEA预测2028年前后）
  → 石油需求绝对减少，但OPEC+会减产维价
  → 价格维持但波动性上升（需求下降+供给管理博弈）

长期（2040-2050）：价格路径高度不确定
  情景A（有序转型）：石油需求持续下降 → 油价跌至$30-40/桶（边际成本支撑）
  情景B（无序转型）：政策不连续 → 油价剧烈波动，尾部风险大
  
对MC模型：
  油价→CPI传导系数应随电动车渗透率逐年递减
  当前系数（2026）保持不变，预计2030年后需降低约20-30%
```

## 七、与2026年当前的对照

| 维度 | 当前状态 | 风险评估 |
|:---|:---|:---|
| 全球可再生能源增速 | 超预期（IEA连续上调预测） | 转型比预期快，化石燃料搁浅风险提前 |
| EU CBAM全面生效 | 2026年开始正式征收 | 全球贸易格局重新定价，欧洲工业通胀来源 |
| 中国清洁能源产能过剩 | 光伏/电池产能约为全球需求的2倍 | 全球输出通缩（清洁能源价格压低），但引发贸易摩擦 |
| 美国退出巴黎协定（特朗普2.0） | 2025年1月宣布退出 | 碳政策分歧扩大，CBAM适用范围争议 |
| 搁浅资产金融敞口 | 评估中，尚未充分定价 | 银行压力测试未完全纳入气候情景 |
| WTI油价（2026-05） | 约$60-65（FRED当前） | 转型压制+OPEC+支撑的均衡区间 |

## 八、关键传导机制汇总（供 MC 模型参考）

| 触发事件 | 传导路径 | 时滞 | 量级 |
|:---|:---|:---:|:---|
| 碳税每增加€20/吨（EU） | 能源/工业品价格上升 → CPI | 即时-6个月 | CPI约+0.3ppt（欧盟经验） |
| EU CBAM全面实施 | 进口钢铁/铝/水泥价格+10-20% | 2026年起渐进 | 欧洲工业品CPI+0.5-1ppt |
| 油价需求峰值后骤降 | 石油出口国外汇收入骤降→EM危机 | 1-3年 | 类1980年代油价崩溃：沙特/俄罗斯财政压力 |
| 清洁能源投资+$500B/年 | 建材/铜/铝需求→大宗商品通胀 | 即时-2年 | 铜价+10-20%（IEA预测） |
| 搁浅资产骤然暴露（无序转型） | 银行资产损失→信用收缩 | 1-5年 | 量级取决于政策速度，最坏情景类CRE危机规模 |
| 电动车渗透率每升10ppt | 石油需求减少约2-3Mb/d | 3-7年（车队替换） | 油价中性压力-$5至-$10/桶（若OPEC不减产） |

## 九、对结构层的建议

建议将 `climate_physical_risk` 拆分为两个子维度，或增加评估项：

```
climate_physical_risk（现有）：
  极端天气频率 + 粮食安全风险 + 海平面/洪水资产损失

新增 climate_transition_risk（本报告新增）：
  碳价格水平（EU ETS参考） + 政策收紧速度
  + 搁浅资产金融敞口 + 清洁能源替代速度

MC 传导调整：
  随电动车渗透率上升，逐步降低 oil_to_cpi_coeff
  当前（2026）维持 ×1.0，2030年后建议降至 ×0.8
  碳税型通胀：标记为"不可货币政策应对"的结构性通胀分量
```
