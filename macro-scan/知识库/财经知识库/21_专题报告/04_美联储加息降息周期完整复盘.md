## 二、加息周期详解（2022-2023）

### 2.1 触发因素

| 时间 | 美国CPI | 美联储反应 |
|:----:|:------:|:--------|
| 2021年11月 | 6.8% | 开始讨论Taper（削减QE） |
| 2022年1月 | 7.5% | 宣布3月开始加息 |
| 2022年3月 | 8.5% | 首次加息 |
| 2022年6月 | **9.1%** | 40年新高，启动75bp巨步 |

**关键转折**：2021年11月，美联储主席鲍威尔放弃"通胀暂时论"，承认通胀持续性超出预期——这是本轮政策周期的根本性转折点。

### 2.2 完整加息决议表

| 决议日期 | 加息幅度 | 利率区间（会后） | 背景 |
|:--------|:-------:|:--------------:|:-----|
| 2022-03-16 | +25bp | 0.25-0.50% | 启动加息 |
| 2022-05-04 | +50bp | 0.75-1.00% | 首次大步 |
| 2022-06-15 | +75bp | 1.50-1.75% | 首次巨步，历史少见 |
| 2022-07-27 | +75bp | 2.25-2.50% | 连续75bp |
| 2022-09-21 | +75bp | 3.00-3.25% | 三连75bp |
| 2022-11-02 | +75bp | 3.75-4.00% | 四连75bp |
| 2022-12-14 | +50bp | 4.25-4.50% | 放缓节奏 |
| 2023-02-01 | +25bp | 4.50-4.75% | 小步进入终端区间 |
| 2023-03-22 | +25bp | 4.75-5.00% | SVB危机后仍加息 |
| 2023-05-03 | +25bp | 5.00-5.25% | 接近终端 |
| 2023-07-26 | +25bp | **5.25-5.50%** | **本轮峰值** |

**统计摘要**：
- 持续时间：16个月（2022年3月 → 2023年7月）
- 加息次数：11次
- 累计幅度：**+525bp**（5.25个百分点）
- 这是1981年以来最激进的一轮加息周期

### 2.3 加息过程中的插曲：SVB银行危机（2023年3月）

2023年3月10日，硅谷银行（SVB）因持有大量低收益长期国债（高利率环境下价格暴跌），出现流动性危机，被监管机构接管。随后签名银行（Signature Bank）等也倒闭。

```
高利率 → 债券价格暴跌
    ↓
银行资产负债表出现巨额未实现亏损
    ↓
储户挤兑 → SVB倒闭（2023年3月10日）
    ↓
美联储仍然在3月22日加息25bp
（表明对金融稳定风险的判断：可控）
```

## 三、暂停期（2023年8月 - 2024年8月）

美联储在5.25-5.5%维持了整整**14个月**，这是一个深思熟虑的选择。

### 3.1 为什么长时间暂停？

**通胀路径**：
| 时间 | CPI | 核心CPI | 美联储判断 |
|:----:|:---:|:-------:|:--------|
| 2023年6月 | 3.0% | 4.8% | 核心通胀仍高 |
| 2023年9月 | 3.7% | 4.1% | 小幅反弹，谨慎 |
| 2023年12月 | 3.4% | 3.9% | 开始暗示降息 |
| 2024年3月 | 3.5% | 3.8% | 再次小反弹 |
| 2024年6月 | 3.0% | 3.4% | 下行趋势确立 |

**就业市场**：整个暂停期失业率维持在3.7-4.0%低位，就业强劲不给降息提供"救经济"的理由。

### 3.2 这段时间全球发生了什么？

```
高利率持续冲击：
├── 美债收益率升至4.5-5%区间
│   └── 2023年10月10年期突破5%（自2007年来首次）
├── 新兴市场资本外流，货币贬值压力
├── 日元跌至155（2024年4月）→日本央行被迫干预
└── 中美利差扩大至历史极值（倒挂约250bp）
```

## 四、降息周期（2024年9月起）

### 4.1 降息触发条件

- CPI从峰值9.1%回落至3%附近
- 就业市场开始出现裂缝（失业率从3.4%升至4.3%+）
- "最后一英里"通胀（2-3%区间）进展缓慢，但方向确定

### 4.2 降息决议表

| 决议日期 | 降息幅度 | 利率区间（会后） | 备注 |
|:--------|:-------:|:--------------:|:-----|
| 2024-09-18 | **-50bp** | 4.75-5.00% | 超预期大步，久违的"预防式降息" |
| 2024-11-07 | -25bp | 4.50-4.75% | — |
| 2024-12-18 | -25bp | 4.25-4.50% | — |
| 2025年（多次） | 合计约-62bp | 至3.63%附近 | ⚠️ 具体日期以官方公告为准 |

> 从峰值5.5%到当前约3.63%，累计降息约187bp。
> 注：2025年降息超出预期（原预期50bp），联储在就业松动信号下加快了步伐。

### 4.3 为什么降息如此缓慢？

```
"最后一英里"通胀（2-3%区间）黏性极强：
  - 核心服务通胀（尤其租金）仍顽固
  - 就业市场仍有韧性，工资通胀不降
  - 制造业PMI 52+，经济不差，无需救市

→ 每次只能25bp，不敢大幅降息
```

对比历史：
| 加息周期结束后首次降息的时机 | 2001年 | 2006年 | 2019年 | 2023年 |
|:----|:---:|:---:|:---:|:---:|
| 等待时间（月） | 7 | 12 | 4 | **14** |
| 首次降息幅度 | -50bp | -25bp | -25bp | **-50bp** |

本轮等待时间最长（14个月），但首次降息却是-50bp，说明美联储在拖了足够长时间后，选择了一次性的较大动作来"补偿"。

## 五、与中国的政策分化：史无前例的倒挂

本轮最特殊之处——中美货币政策史无前例地完全反向：

| 时间节点 | 美联储 | 中国央行 | 10年期利差（中-美） |
|:--------|:------|:--------|:---------------:|
| 2021年底 | 准备加息 | 准备降息 | +130bp（中高） |
| 2022年底 | 加息至4.5% | 降至历史低位 | -100bp（美高） |
| 2023年底 | 5.25-5.5% | 持续降息 | -170bp |
| 2024年底 | 4.25-4.5% | LPR 3.1% | ~-200bp |
| 2026年4月 | ~3.64% | LPR 3.0% | **~-250bp** |

**传导机制**：
```
利差倒挂（美高中低约250bp）
    ↓
外资持有中国债券的套利空间消失
    ↓
资本流出压力 → 人民币贬值压力
    ↓
PBOC需要在"宽松刺激内需"和"稳汇率"间两难权衡
    ↓
实际操作：以内部稳增长目标为主，接受一定汇率贬值
```

## 六、本轮降息周期对全球的影响

### 6.1 资产价格重新定价

```
美联储降息预期确立（2023年12月）
    ↓
全球风险资产重新定价：
  - 标普500 2023年底涨24%
  - 黄金突破2000美元/盎司
  - 比特币从16000回升至60000+
  - 新兴市场股市反弹
```

### 6.2 美元走弱

美联储降息 → 美元指数从2022年高点（114）回落至约100附近（2026年当前，贸易加权指数另有口径约119）。

对各方意义：
- 对中国：人民币贬值压力减轻
- 对日本：日元有所回升
- 对新兴市场：资本回流，货币贬值压力减轻

### 6.3 对中国的特殊影响

随着美联储降息、利差缩小，中国的汇率压力有所缓解，但PBOC仍保持独立的降息路径——因为中国面临的核心问题是内需不足，而非跟随美联储节奏。

## 七、前瞻：后续路径

**当前状态（2026年5月，实测数据）**：
- 联邦基金利率 **3.63%**（2026-05-19，FRED DFF）
- CPI **3.78%**（同比，2026年4月），已加速上行
- 核心PCE **3.50%**（2026年3月），显著高于2%目标
- PPI **9.82%**（2026年4月），关税传导叠加油价，已向CPI渗透
- WTI原油 **$112.25**（2026年5月），突破$100后继续上行
- 失业率 **4.3%**，萨姆规则 **0.2**（接近0.3衰退预警线）
- 穆迪警告（2026-05-18）：美国联邦债务/GDP升至127%，负面展望

**市场分歧**：
```
鸽派观点：利率已高于中性利率，就业边际恶化，应继续降息
鹰派观点：CPI 3.78% + PPI 9.82% 重新加速，暂停甚至考虑加息

当前最大矛盾：
  - 降息理由：就业开始松动（萨姆0.2→接近0.3）、制造业承压
  - 加息/暂停理由：CPI反弹 + PPI关税传导 + WTI $112
  → 联储陷入"就业恶化 vs 通胀再起"两难局面

更可能的路径：
  → 下半年暂停降息，等待CPI方向确认
  → 若WTI继续上行或CPI突破4%，讨论重新加息
  → 若萨姆规则≥0.3且就业明显恶化，被迫再次降息
```
