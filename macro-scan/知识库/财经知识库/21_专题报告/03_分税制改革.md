# 分税制改革：土地财政的起源与地方财政的博弈

> 财经知识库专题报告 | 数据来源：研报整理 | 整理时间：2026-05-02

---

## 一、为什么会有分税制？

理解分税制，先要理解它的"前传"：**财政包干制**。

### 1.1 1980年代的"财政包干"

改革开放后，中央对地方实行"财政包干"：地方每年向中央上缴固定金额（或比例），超额部分归地方留用。

**问题来了：**
- 沿海省份经济发达，留成多，越来越富
- 中央财政收入占比持续下降（从1978年的37%降至1993年的22%）
- 中央穷得连教育、医疗、军费都难以保障
- 地方政府反而"藏富于企、藏富于民"

朱镕基后来回忆说，当时中央财政"穷得只剩下裤腰带"。1993年，中央财政收入占全国财政收入比重仅**22%**，远低于同期美国的50%、日本的60%。

财政虚弱，中央调控能力就弱——这不是小问题，而是涉及国家治理能力的根本问题。

## 二、1994年：分税制改革

### 2.1 改革核心逻辑

1994年1月1日，分税制改革正式启动，核心是**重新划分中央与地方的税种**：

**中央税（归中央）：**
- 关税
- 消费税
- 海关代征增值税
- 中央企业利润

**地方税（归地方）：**
- 营业税（不含银行、铁道、保险总公司）
- 土地增值税
- 地方企业所得税

**共享税（中央拿大头）：**
- 增值税：中央75%，地方25%
- 资源税：中央60%，地方40%（后调整）
- 证券交易印花税：中央97%，地方3%

### 2.2 改革的"副作用"：财权上收，事权下放

**关键数字验证（来源：国家统计局历史数据）：**
| 年份 | 中央财政收入占全国比重 | 说明 |
|------|---------------------|------|
| 1978 | 37% | 改革前夕 |
| 1993 | **22%** | 历史最低谷 |
| 1994 | **55%** | 分税制当年一次性跃升 |
| 2000 | ~52% | 稳定在50%一线 |
| 2010 | ~51% | |
| 2020 | ~45% | 营改增后有所回落 |
| 2025 | ~43% | |

分税制一下解决了中央"钱不够"的问题——中央财政收入占比从22%跃升至55%，此后稳定在45-52%区间，成为国家治理能力的重要物质基础。


分税制一下子解决了中央"钱不够"的问题——中央财政收入占比从22%跃升至55%以上，到2000年代稳定在50%左右。

**但代价是：**
- 地方承担了大量事权（教育、医疗、基建、社会保障）
- 地方的"钱袋子"被大幅收紧
- 地方要做事，却没有足够的钱

这是一个结构性缺口。

### 2.3 填补缺口：土地财政

| 时期 | 地方收入来源 | 说明 |
|------|------------|------|
| 1994-2001 | 预算内收入+少量土地 | 地方财政偏紧 |
| 2002-2011 | 土地财政崛起 | 土地出让金大幅增长 |
| 2012-至今 | 土地财政+城投债 | 土地+债务双轮驱动 |

2002年，国土资源部明确"经营性用地必须通过招拍挂"，**土地出让金制度**正式确立。

从此，地方政府发现了一条"生财之道"：
- 低价征收农地 → 整理 → 高价拍卖给开发商
- 土地财政成为地方最重要的可支配收入来源

## 三、土地财政的规模与结构

### 3.1 土地出让金的规模

| 年份 | 土地出让金（万亿） | 占地方财政收入比例 |
|------|----------------|-----------------|
| 2003 | 0.54 | ~30% |
| 2009 | 1.42 | ~60% |
| 2010 | 2.94 | ~70% |
| 2016 | 3.75 | ~60% |
| 2021 | **8.7** | **~90%+（历史峰值）** |
| 2022 | 6.7 | ~80% |
| 2023 | 5.3 | ~70% |
| 2024 | ~4.1 | ~65% |

> 注：2021-2024年土地收入缩水超过50%（8.7万亿→4.1万亿），是地方财政压力的核心来源。

### 3.2 2025年财政收入分项（最新数据）

来源：方正中期期货研报，2025年11月财政数据

| 税种 | 2025年11月当月（亿元） | 当月同比 | 说明 |
|------|---------------------|--------|------|
| 公共财政收入 | **14,026** | 0.0% | 增速为0 |
| 中央财政收入 | 6,608 | -4.2% | 下滑 |
| 地方本级财政收入 | 7,418 | +4.1% | 小幅增长 |
| 税收收入合计 | 11,450 | +2.8% | 正增长 |
| 其中：国内增值税 | 4,771 | +3.3% | 主力税种 |
| 其中：个人所得税 | 1,326 | **+11.4%** | 居民收入改善信号 |
| 其中：房产税 | 341 | **+13.3%** | 持续高增，改革信号 |
| 其中：外贸出口退税 | -917 | +14.9% | 出口支持政策 |

> **观察**：个税（+11.4%）和房产税（+13.3%）高增，反映居民收入增长和持有环节税收改革加速；出口退税大增（+14.9%）反映贸易摩擦下的对冲政策力度。

> 注：2021年是历史高峰，2022年后随房地产下行而萎缩

### 3.2 土地财政的结构

地方政府对土地收入的依赖有两种形式：

**直接形式**：土地出让金（一次性收入）
- 卖地收入归入"政府性基金收入"
- 不计入一般公共预算

**间接形式**：土地抵押融资
- 地方政府以土地为抵押，向城投公司/银行借款
- 城投债规模迅速膨胀

城投债+土地出让金，构成了地方财政的"两条腿"。

## 四、分税制对地方经济的深层影响

### 4.1 激励结构的变化

分税制后，地方政府的行为模式发生了根本转变：

**"招商引资"成为最重要的任务：**
- 吸引企业入驻 → 带来增值税（共享税，中央拿75%）
- 但企业多了，人口就多 → 带动房价 → 卖地收入增加（地方独享）

**制造业vs服务业：**
- 制造业能带来GDP、税收和就业，地方政府积极性高
- 服务业（金融、科技）虽然税收更高，但地方政府"不擅长"

这直接塑造了各地以制造业为主的经济发展模式。

### 4.2 "土地财政依赖症"

土地财政让地方财政对房地产市场产生了深度依赖：

```
房地产兴 → 地价涨 → 卖地收入↑ → 地方财政充裕
房地产衰 → 地价跌 → 卖地收入↓↓ → 地方财政紧张
```

2021年以来房地产市场深度调整，地方财政随之承压。"化债"成为近年最重要的政策议题之一。

## 五、2016年：营改增与央地关系再调整

2016年5月1日，全面推开"营改增"（营业税改增值税）。

**这意味着：**
- 地方失去最大税种（营业税曾是地方第一大税）
- 中央通过转移支付、税收返还补偿地方
- 但地方实际可支配财力仍有所下降

营改增后，中央进一步加大转移支付力度，同时推进"中央地方财政事权和支出责任划分"改革。

## 六、当前地方财政的挑战

### 6.1 土地收入萎缩

| 年份 | 土地出让金 | 同比 |
|------|-----------|------|
| 2021 | 8.7万亿 | 历史峰值 |
| 2022 | 6.7万亿 | -23% |
| 2023 | 5.3万亿 | -21% |
| 2024E | ~4万亿 | -20% |

三年间土地收入缩水超过50%，地方财政受到严重冲击。

### 6.2 化债压力

**2025年政府性基金运行数据（来源：NeoData API，2026年4月发布）：**

| 指标 | 数值 | 说明 |
|------|------|------|
| 政府性基金赤字（2025年累计） | **12,636亿元** | 卖地收入不足以覆盖支出 |
| 中央政府性基金赤字 | -510亿元 | 中央层面基本平衡 |
| 赤字进度 | 20.9% | 1-3月完成全年约1/5 |
| 财政赤字累计同比 | **+3.7%** | 赤字规模在扩大 |

化债的核心逻辑：地方隐性债务（城投债等）规模庞大，中央通过"特殊再融资债券"置换，将隐性债务显性化、短期化债务长期化。2023-2024年一揽子化债方案已落地，2025年持续推进。


- 地方隐性债务（城投债等）规模庞大
- 中央允许地方政府发行"特殊再融资债券"置换隐性债务
- 推动"一揽子化债方案"（2023-2024年）

### 6.3 地方财政的新来源探索

| 方向 | 内容 |
|------|------|
| 消费税改革 | 将部分消费税征收环节从生产端移至消费端，增加地方收入 |
| 房产税 | 立法推进，试点扩容，增加持有环节税收 |
| 数据资产 | 部分地方探索数据要素市场化 |
| 国有资本 | 盘活地方国企资产 |

## 七、分税制的历史评价

| 维度 | 评价 |
|------|------|
| **积极面** | 增强中央财政实力，提升国家治理能力；建立了与现代市场经济相适应的税收制度 |
| **问题面** | 地方财权与事权不匹配；催生土地财政；加剧地区间发展不平衡 |
| **未完成** | 央地财政关系仍需深化改革；地方税体系不完善；房地产税等直接税缺失 |
