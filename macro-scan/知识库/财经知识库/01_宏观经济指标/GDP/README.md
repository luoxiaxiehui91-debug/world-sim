## 改革开放以来GDP增长阶段

1. **1978-1988 高速起步期**：改革开放初期年均增速10%以上
2. **1989-1991 调整期**：治理整顿，增速回落至5%左右
3. **1992-1997 新一轮高速增长**：邓公南巡后，增速重回两位数
4. **1998-2001 亚洲金融危机冲击**：增速降至8%左右
5. **2002-2007 黄金增长期**：入世后年均10%以上
6. **2008-2009 全球金融危机**：4万亿刺激，V型反弹
7. **2010-2019 中高速增长**：从10%逐步降至6%左右
8. **2020-2022 疫情冲击**：2020年2.2%，2022年3.0%
9. **2023-2025 恢复期**：5%左右，结构转型
