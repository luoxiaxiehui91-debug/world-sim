## 如何解读

**城镇调查失业率 ≈ 劳动力市场温度**

- 失业率 > 5.5%：就业压力大，政策需加码
- 失业率 5.0-5.5%：温和压力
- 失业率 < 5.0%：就业市场紧张

**求人倍率**（需求/供给）：>1=岗位多；<1=求职难

**传导逻辑**：
```
就业改善 → 居民收入↑ → 消费↑ → 企业营收↑ → 扩大招聘（正循环）
就业恶化 → 居民消费↓ → 企业营收↓ → 裁员（负循环）
```
