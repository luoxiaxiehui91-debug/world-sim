## 如何解读

**社会消费品零售总额 ≈ 居民消费能力**

- 同比 > 8%：消费旺盛，内需强劲
- 同比 3-8%：温和增长
- 同比 < 3%：消费疲软，内需不足
- 同比 < 0%：消费收缩，警惕通缩风险

**餐饮收入**：服务消费代表消费升级，是比商品消费更领先的内需指标

**核心逻辑**：
```
就业→收入→消费→企业营收→扩大招聘
```
