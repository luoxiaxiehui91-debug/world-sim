## 二、PMI到底是什么（人话版）

### 2.1 一句话定义

PMI = 每月采购经理们对"现在比上月好不好"的投票结果。

```
>50 = 多数经理认为"本月比上月好" → 景气扩张
<50 = 多数经理认为"本月比上月差" → 景气收缩
=50 = 刚好一半一半 → 景气持平
```

**为什么PMI重要？**
- 月末就发布（比GDP早3个月，比工业增加值早2周）
- 基于调查，不受统计方法论争议
- 全球统一口径，可以直接跨国比较

### 2.2 PMI的构成

```
制造业PMI由5个分项加权：
  新订单（权重30%） ← 最重要，代表未来需求
  产出（权重25%）
  就业（权重20%）
  供应商交货（权重15%）
  库存（权重10%）
```

**实战技巧：先看新订单**——新订单>50且上升，意味着未来2-3个月产出还会增加；新订单<50，当前PMI再高也撑不住。

### 2.3 PMI的局限性

| 局限 | 说明 |
|:-----|:-----|
| 方向性指标，非数量指标 | PMI=52不代表产出增加2%，只是"扩张"的信号 |
| 受季节因素影响 | 中国春节前后PMI波动大，需结合去年同期对比 |
| 中小企业代表性不足 | 中国官方PMI样本偏大企业，财新PMI更能反映中小企业 |
| "情绪因素"可能放大波动 | PMI反映预期，有时会领先太多而发生"假信号" |

### 2.4 中国双PMI体系

| 指标 | 样本 | 特点 | 更反映 |
|:-----|:----:|:----:|:------|
| 官方PMI（国家统计局） | 3000家以上，偏大型国有 | 更稳定，波动小 | 工业整体景气 |
| 财新PMI（IHS Markit） | 430家，偏私营中小 | 波动大，更敏感 | 市场化景气 |

**关键分歧信号**：
- 官方>50，财新<50 → 大企业强，中小企业弱（内需不均）
- 两者均>50 → 全面扩张（当前：4月两者均微弱扩张）
- 两者均<50 → 全面收缩（2025年底曾出现）

## 三、2026年PMI格局：制造业反弹之谜

### 3.1 全球制造业为什么在2026年集体走强？

```
2025年12月：美国PMI 47.9，多国制造业收缩
2026年1月：美国PMI 52.6（+4.7！），后来各国纷纷跟进
```

**主因：关税"抢跑效应"**

```
特朗普宣布大规模关税 → 企业恐慌性抢进口、提前备货
→ 制造商订单爆发 → PMI急拉
→ 但这是"消费明天的需求" → 关税实施后订单可能断崖
```

这解释了为什么制造业PMI看上去很强，但实际GDP、消费信心、企业投资意愿同时走弱——PMI数字靠不住，要看是不是"虚胖"。

### 3.2 服务业PMI：欧洲的结构性困境

欧元区服务业PMI 47.4，德国46.9，法国46.5，都在收缩——为什么服务业跑输制造业这么多？

```
制造业：受关税抢跑+出口爆发（韩国出口+48%）→ PMI虚高
服务业：反映真实内需 → 消费者口袋没钱/没信心 → 服务需求弱
```

**一个判断规则**：
- 服务业PMI < 50 + 消费者信心极差 → 经济实际上在收缩（尽管制造业PMI看上去不错）
- 典型案例：德国制造业51.2扩张，但Gfk消费者信心-33.3，ZEW -17.2，GDP仅0.3%——**PMI骗了你**

### 3.3 中国PMI：50的守卫战

```
2026年1月：官方PMI 49.1（跌破荣枯线）
2026年2月：49.9（春节后回升）
2026年3月：50.5（反弹）
2026年4月：50.3（略有回落）
```

中国的PMI在50线附近反复争夺，背后是两股力量的拉锯：
- 📈 高技术制造（PMI 52.2）、装备制造（51.8）：政策支持+出口有需求
- 📉 高耗能行业（PMI 47.9）：产能过剩+房地产下行压制需求

**结论**：总PMI数字掩盖了内部的严重分化。中国制造业的增长靠科技板块，老经济（钢铁、水泥、化工）在收缩。

## 四、PMI与经济周期的关系

### 4.1 PMI领先GDP几个月？

```
PMI（月度，月末发布）→ 领先工业增加值 1-2个月
                    → 领先季度GDP     2-3个月
                    → 领先市场反应   0-4周
```

**实战意义**：
- 3月PMI > 50 且持续上行 → Q2 GDP大概率好于Q1
- PMI连续3个月下降 → 警惕经济下行趋势形成
- PMI跌破50不代表衰退，但连续3个月<49才是真正的警报

### 4.2 PMI新订单：看下一期的望远镜

| 新订单状态 | 含义 | 1-2个月后的PMI走势 |
|:---------|:----:|:----------------|
| 新订单>PMI（差值为正） | 订单积累，未来产出将增加 | PMI大概率上行 |
| 新订单<PMI（差值为负） | 订单消化中，未来产出放缓 | PMI大概率下行 |
| 新订单和PMI同步高位 | 全面景气 | 高位维持 |
| 新订单先跌 | 景气触顶信号 | PMI即将回落 |

### 4.3 PMI的"结构性背离"信号

```
情况A：制造业PMI高 + 服务业PMI低
  → 外需驱动/出口拉动，内需不振
  → 经济结构不平衡，不可持续
  → 2026年欧洲典型案例

情况B：PMI高 + 消费者信心极低
  → 企业端看到订单（关税抢跑）但消费端感受悲观
  → PMI被短期因素扭曲，不可信
  → 2026年德国典型案例

情况C：PMI低 + 就业健康
  → 制造业收缩但服务业/就业支撑
  → 软着陆信号，不是衰退
  → 中国2025年底至2026年初
```

## 五、PMI传导链（人话版）

### 链条一：PMI→利率（最快，1-4周）

```
PMI超预期高 → 市场预期央行推迟降息/加息
           → 国债收益率上行 → 股债双杀
PMI不及预期低 → 市场预期央行降息
           → 国债收益率下行 → 股市反弹
```

**2026年案例**：日本PMI 55.1超预期强劲→市场加大BOJ进一步加息预期→10年国债收益率升至2.23%。

### 链条二：PMI新订单→工业增加值（1-2个月）

```
PMI新订单连续3月>53 → 工厂备货增加 → 1-2个月后工业增加值加速
PMI新订单跌破50 → 工厂减产 → 1-2个月后工业增加值回落
```

**中国案例**：高技术制造业PMI持续在52+，驱动工业增加值中高技术部分贡献提升，是当前工业增加值维持5-6%的核心支撑。

### 链条三：PMI分项→大宗商品需求（1-3个月）

```
全球制造业PMI集体>52 → 铜、铁矿石、原油工业需求上升
PMI中"购进价格分项"上升 → 上游大宗商品涨价信号
PMI中"库存分项"下降 → 去库完成，即将补库 → 大宗需求将升
```

**2026年案例**：全球制造业PMI集体反弹，铜价涨至$12,996/吨，布伦特油价$108，均与PMI信号一致。
