## 核心品种解读

### 原油：最重要的战略商品

| 指标 | 说明 |
|------|------|
| WTI原油 | 美国西德克萨斯中质油，纽约商品交易所基准 |
| 布伦特原油 | 欧洲北海原油，全球定价基准 |
| 原油→汽柴油 | 影响交通运输成本，进而影响CPI |
| 原油→化工原料 | 影响PPI（工业品出厂价格） |

**近年走势：**
- 2020年4月：负油价（-37美元/桶），疫情冲击库存爆满
- 2022年：俄乌战争爆发，布伦特最高涨至$139
- 2024年：OPEC+减产支撑油价在$80-90区间
- 2025-2026年：地缘风险+供需博弈，高位震荡

### 黄金：避险与货币之锚

| 功能 | 说明 |
|------|------|
| 避险资产 | 地缘风险、战争、金融危机时大涨 |
| 抗通胀 | 实际利率下行时，金价上涨 |
| 央行储备 | 全球央行近年持续增持黄金（去美元化） |
| 人民币国际化 | 黄金是中国外储多元化的重要方向 |

**近年走势：**
- 2020年：疫情避险，金价突破$2000
- 2022年：俄乌战争，金价再冲$2000
- 2024年：全球去美元化，金价屡创历史新高

### 铜：经济晴雨表

铜被称为"铜博士"，因为铜的应用极其广泛（电线、管道、建筑），铜价与全球经济需求高度相关。

- 铜价涨 → 经济预期好，需求旺盛
- 铜价跌 → 经济预期差，需求疲软

## CRB指数

CRB（Commodity Research Bureau）指数是大宗商品综合指数，涵盖能源、金属、农产品等19种商品。

- CRB上涨 → 全球通胀压力加大
- CRB下跌 → 大宗商品熊市，通胀缓解

## 大宗商品与中国的关系

| 商品 | 中国进口依赖度 | 主要来源 |
|------|--------------|----------|
| 原油 | ~70% | 中东（沙特、伊朗）、俄罗斯 |
| 铁矿石 | ~85% | 澳大利亚、巴西 |
| 铜 | ~80% | 智利、秘鲁 |
| 天然气 | ~40% | 澳大利亚、卡塔尔 |
| 大豆 | ~85% | 美国、巴西 |

**输入性通胀机制：**
```
大宗商品上涨 → 进口成本上升 → 国内原材料价格上升 → PPI上行 → 传导至CPI
```
