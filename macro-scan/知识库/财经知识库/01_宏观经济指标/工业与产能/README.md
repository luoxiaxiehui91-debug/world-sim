## 如何解读

**工业增加值同比 ≈ 工业景气度**

- 同比 > 10%：工业繁荣，产能紧张
- 同比 5-10%：温和扩张
- 同比 < 5%：工业偏弱
- 同比 < 0%：工业收缩

**发电量 ≈ 经济活跃度**

- 发电量↑ → 经济活动旺盛
- 发电量↓ → 经济活动放缓
- 分能源类型看：火电（工业）/水电（气候）/核电（基建）/风电（新能源）

**核心逻辑**：
```
出口↑ + 内需↑ → 工业生产↑ → 发电量↑ → 就业↑ → 收入↑ → 消费↑
```
