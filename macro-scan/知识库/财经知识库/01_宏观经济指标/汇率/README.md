## 汇率影响机制

- **出口**：人民币贬值 → 出口商品价格竞争力提升
- **进口**：人民币升值 → 进口成本降低
- **资本流动**：利差驱动跨境资本流动，影响汇率
- **外汇储备**：央行干预，维持汇率稳定

---

## 重要节点：改革开放以来汇率改革

1. **1978-1994**：官方汇率与市场汇率双轨制
2. **1994年**：汇率并轨，1美元=8.27人民币
3. **2005年**：放弃单一盯美元，实行参考一篮子货币
4. **2015年**：中间价形成机制改革
5. **2020年至今**：保持汇率在合理均衡水平基本稳定
