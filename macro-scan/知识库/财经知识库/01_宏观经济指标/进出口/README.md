## 如何解读

**出口同比 ≈ 外需温度计**

- 出口同比 > 10%：外需强劲，制造业景气
- 出口同比 0-10%：温和增长
- 出口同比 < 0%：外需疲软，可能拖累GDP

**关键传导链**：
```
出口↑ → 制造业产能利用率↑ → 工业增加值↑ → 就业↑ → 消费↑
```

**贸易差额（净出口）**：正值=顺差，对GDP贡献正；负值=逆差，拖累GDP
