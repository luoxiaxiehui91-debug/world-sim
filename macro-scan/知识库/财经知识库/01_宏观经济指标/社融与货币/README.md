## 如何解读

**M2 ≈ 货币政策松紧的刻度盘**

- M2同比 > 12%：货币政策非常宽松
- M2同比 8-12%：中性偏松
- M2同比 < 8%：偏紧

**社融增量 ≈ 实体经济融资意愿**

- 单月社融 > 2万亿元：信用扩张
- 单月社融 < 1万亿元：信用收缩
- 人民币贷款占比高（>60%）：居民和企业贷款积极，质量好
- 企业债占比高：直接融资活跃，融资结构优化

**核心逻辑**：M2高≠钱流入实体，要看社融是否同步跟上。
