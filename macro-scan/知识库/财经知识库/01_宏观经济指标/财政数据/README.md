## 如何解读

**财政收入 ≈ 经济晴雨表**

- 税收同比 > 10%：经济繁荣，企业盈利好
- 税收同比 0-5%：经济平稳
- 税收同比 < 0%：经济下行压力大

**财政支出 ≈ 政府逆周期力度**

- 支出同比 > 15%：积极财政，刺激经济
- 支出同比 5-15%：温和扩张
- 支出同比 < 5%：财政偏紧

**核心逻辑**：
```
经济下行 → 税收收入↓ → 财政压力↑ → 财政支出受限 → 经济进一步下行
经济上行 → 税收收入↑ → 财政空间↑ → 支出扩张 → 经济进一步上行
```

**关注信号**：财政赤字率突破3% → 积极信号；收入增速远低于支出增速 → 财政可持续性风险
