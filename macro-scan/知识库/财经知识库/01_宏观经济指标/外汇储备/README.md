## 如何解读

**外汇储备 ≈ 国际收支安全垫**

- 储备 > 3万亿美元：国际收支稳健
- 储备在2-3万亿：面临资本外流压力
- 储备 < 2万亿：汇率稳定面临挑战

**黄金储备**：央行黄金储备增加→去美元化信号，人民币国际化进程

**汇率稳定器**：外汇储备充足时，央行干预汇市能力强
