## 近年CPI走势要点

- **2022年**：CPI同比上涨2.0%，全年温和
- **2023年**：猪肉价格波动，服务价格支撑
- **2024年**：核心CPI低位运行，内需偏弱
- **2025年**：CPI有所回升，消费复苏
- **2026年Q1**：环比负增长，通胀压力低

## PPI（工业生产者出厂价格）

数据中包含PPI联动数据，PPI走势与CPI形成互补：
- PPI反映工业品出厂价格，影响企业盈利
- PPI下行往往先于CPI，是通胀的先行指标
