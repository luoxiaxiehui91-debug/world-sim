## 二、CPI到底是什么（人话版）

### 2.1 一句话定义

CPI = 一篮子普通人常买东西的价格，今年比去年贵了多少？

```
这篮子东西包括：
  食品（菜、肉、粮食） → 占比高，波动大
  能源（油价、电费） → 波动大，影响通胀节奏
  住房（租金、房贷利息） → 占比高，变化慢
  服务（医疗、教育、餐饮） → "核心通胀"主要来源，粘性强
  商品（服装、家电） → 全球化降价，压低通胀
```

### 2.2 核心CPI vs 总CPI

| 指标 | 包含 | 特点 | 央行更看哪个 |
|:----|:----:|:----:|:----------:|
| 总CPI | 全部 | 受能源/食品波动大 | 参考 |
| 核心CPI（剔除食品能源） | 其余 | 更稳定，反映内生通胀 | ✅ 主要参考 |
| PCE（美国专用） | 调整消费结构 | 美联储官方盯住指标 | ✅ 美联储最看 |
| HICP（欧元区） | 统一口径 | 跨国比较标准 | ✅ ECB看 |

**关键规律**：总CPI波动 → 追责能源/食品；核心CPI粘性 → 反映通胀是否"扎根"。

## 三、2026年通胀格局的"三分天下"

### 第一世界：高通胀困境国（美国、欧元区、英国）

```
2022年：能源危机+供应链冲击 → 通胀飙升至8-10%
2023-2024年：大幅加息 → 通胀从峰值回落
2025-2026年：以为通胀已杀死，却在反弹

为什么通胀反弹？
  美国：对华关税 → 进口商品涨价 → CPI 2.4%→3.3%
  欧元区：能源反弹（中东危机） → 食品+能源驱动HICP升至3.0%
  英国：工资增长粘性 + 输入PPI从0.5%飙至5.4% → 通胀最顽固
```

**央行两难**：刚说可以降息，通胀又起来了，市场降息预期一再推迟。

### 第二世界：通胀受控新兴市场（印度、越南、韩国、印尼）

```
特点：CPI在目标区间内，但存在上行风险
  印度：CPI 3.21%（目标2-6%），但WPI批发通胀+15.8%，上游传导是风险
  韩国：CPI 2.2%刚破2%目标，BOK降息受限
  印尼：CPI逼近3.5%目标上限，BI降息窗口关闭
```

**关键观察**：能源价格（中东危机影响）是这些国家通胀上行的公共风险点。

### 第三世界：通缩孤岛（中国）

```
中国CPI：0%附近徘徊 → 3月环比-0.7%
  原因：消费不振 + 房价下跌 + 产能过剩压价竞争

这不是"价格稳定"，而是"有效需求不足"的信号。
区别在于：
  价格稳定 = 供需均衡，企业盈利健康
  通缩 = 企业不敢投资，居民推迟消费，自我强化螺旋
```

**中国独特性**：全球其他主要经济体都在对抗通胀，中国在对抗通缩——货币政策方向完全相反。

## 四、CPI与央行政策的关系

### 4.1 "泰勒规则"的人话版

```
CPI高于目标 → 央行加息（压需求、降通胀）
CPI低于目标 → 央行降息（刺激需求、拉通胀）
CPI在目标附近 → 央行观望（看其他指标）
```

但现实远比这复杂——

### 4.2 2026年各央行的通胀困境

| 央行 | 目标 | 当前通胀 | 通胀vs经济 | 矛盾 |
|:----|:----:|:-------:|:--------:|:-----|
| 美联储（Fed） | 2% PCE | 3.3% CPI | 通胀超目标 + 增速尚可 | 不能轻易降息，但关税可能伤经济 |
| ECB | 2% HICP | 3.0% HICP | 通胀反弹 + 经济停滞 | 德法在滞胀边缘，降息vs控通胀两难 |
| 日本央行（BOJ） | 2% CPI | 1.5% CPI（接近） | 通胀接近目标 + 企业信心弱 | 加息目标达成，但不敢激进加息 |
| 英国央行（BOE） | 2% CPI | 3.3% CPI | 通胀最顽固 + 增长最弱 | 典型滞胀困境，降息受限 |
| 印度RBI | 2-6% CPI | 3.21% | 目标内但上行 | 降息空间有，但WPI风险不能忽视 |
| 中国人民银行（PBOC） | ~3% | CPI近0% | 通缩+经济弱 | 急需宽松，但汇率和美债倒挂限制空间 |
| 巴西央行（BCB） | 3%±1.5% | 4.14% | 通胀超标 + 增速放缓 | 降息节奏完全被通胀制约 |

### 4.3 降息还是加息？各央行方向一览

```
正在/准备降息：
  ✅ 中国（已在历史低位，仍有空间）
  ✅ 印度（2026年4月启动）
  ⚠️ ECB（本想降，通胀反弹打乱节奏）

观望/暂停降息：
  → 美联储（通胀3.3%，不敢动）
  → 日本央行（0.75%观望，谨慎加息）
  → 英国（3.3%通胀，减速降息）
  → 韩国、印尼（通胀逼近上限）

仍在高位（不降息）：
  🔴 巴西（14.75%，通胀挡路）
  🔴 俄罗斯（14.5%，战时通胀顽固）
```

## 五、通胀传导链（人话版）

### 链条一：能源→CPI（最快，1-3个月）

```
中东冲突 → 油价↑($108布伦特) → 汽油费↑ → 运输成本↑ → 所有商品涨价
    同时 → 电价↑ → 制造业成本↑ → PPI↑ → 3-6个月后传导CPI
```

**2026年案例**：美伊对峙升级→布伦特油价飙至$108-$112→法国CPI 2.2%近两年新高（能源驱动）

### 链条二：工资→服务通胀（最慢，6-12个月，最顽固）

```
就业市场紧张（失业率低）→ 工人要求涨工资 → 企业人力成本↑ → 服务价格↑ → 核心CPI↑
```

**2026年案例**：英国工资增长强劲→核心CPI 3.1%持续顽固→BOE降息一再推迟

### 链条三：关税→进口通胀（中期，3-6个月）

```
美国对中国加征关税 → 中国商品进口价↑ → 美国进口商品涨价 → CPI↑
→ 但同时：中国出口减少 → 中国内部供给过剩 → 中国CPI↓（通缩）
```

**2026年案例**：特朗普关税→美国CPI 2.4%→3.3%（同步中国通缩加剧）
