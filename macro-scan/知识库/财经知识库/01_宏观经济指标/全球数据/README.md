## 六、使用建议

### 如何获取全球数据对比

```python
# 查询全球PMI对比
data = query_api("全球PMI")
# 返回中国、欧元区、美国PMI数据
```

### 如何获取单一国家数据

```python
# 查询美国CPI
data = query_api("美国CPI")
# 返回美国通胀数据
```

### 如何获取经济日历

```python
# 查询美国经济日历
data = query_api("经济日历 美国")
# 返回美国经济数据发布时间表
```
