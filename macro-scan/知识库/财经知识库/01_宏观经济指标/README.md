# 01_宏观经济指标

本目录按**指标类别**组织的数据参考库，每个子目录对应一类宏观指标。

## 子目录一览

| 子目录 | 说明 |
|:---|:---|
| CPI | 通胀与物价指数 |
| GDP | 经济增长数据 |
| PMI | 采购经理人指数 |
| 利率 | 政策利率与市场利率 |
| 汇率 | 主要货币汇率 |
| 社融与货币 | 信贷、M1/M2、社会融资规模 |
| 财政数据 | 财政收支、赤字 |
| 房地产 | 房价、成交、库存 |
| 大宗商品 | 油价、金属、农产品 |
| 进出口 | 贸易数据 |
| 固定资产投资 | 投资增速与结构 |
| 工业与产能 | 工业增加值、产能利用率 |
| 消费与居民收入 | 零售、消费者信心 |
| 人口与就业 | 就业、失业率、人口结构 |
| 外汇储备 | 各国外汇储备规模 |
| 全球数据 | 跨国横向对比数据 |
| 全球经济对比 | 多国经济指标对比 |

## 与其他目录的分工

- **本目录**：单一指标的数据参考（这个指标是什么、怎么读）
- **`03_按经济体/`**：以国家为维度的综合指标速查
- **`02_核心变量因果链/`**：指标之间的传导关系和量化框架
