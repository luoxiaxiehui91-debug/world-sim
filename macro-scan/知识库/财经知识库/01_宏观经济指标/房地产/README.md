---

## 核心地位

房地产是中国经济最重要的"周期之母"：

| 指标 | 占比 |
|------|------|
| 房地产+建筑业占GDP | ~25-30% |
| 居民家庭资产中房产占比 | ~60-70% |
| 地方政府收入来源（土地出让金） | 峰值时超50% |
| 钢铁、水泥、家具、家电上下游产业链 | 影响数十个行业 |

## 房地产40年简史

| 阶段 | 时间 | 特征 |
|------|------|------|
| 福利分房 | ~1998年前 | 住房靠单位分配，商品化程度极低 |
| 房改启动 | 1998年 | 国务院23号文，住房货币化改革启动 |
| 黄金时代 | 2003-2013 | 房价单边上涨，供不应求 |
| 调控时代 | 2010-2020 | 限购、限贷、限价，调控频繁 |
| 高位盘整 | 2017-2021 | 房价高位，增速放缓 |
| 深度调整 | 2021-至今 | 恒大暴雷、三条红线、去库存 |

---

## 2021年以来的调整

**恒大暴雷（2021年9月）触发连锁反应：**

| 事件 | 影响 |
|------|------|
| 三道红线政策 | 开发商融资受限，现金流断裂 |
| 恒大负债2.4万亿 | 史上最大房企破产 |
| 碧桂园等多家暴雷 | 民营房企系统性危机 |
| 销售面积暴跌 | 2023-2024年同比-20%~-30% |
| 土地市场冰封 | 地方卖地收入锐减 |

**政策应对（2022-至今）：**
- 银行信贷支持（"金融16条"）
- 三个不低于
- 城中村改造/保障房/"白名单"贷款
- 取消限购、降低首付比例

---

## 当前状态（2025-2026）

- 销售面积底部企稳，但尚未明显回暖
- 房价指数仍处于调整通道
- 开发商资金链仍然偏紧
- 政策持续宽松，但居民购房信心恢复需要时间
- "三大工程"（城中村改造、保障性住房、平急两用）成为新增长点
