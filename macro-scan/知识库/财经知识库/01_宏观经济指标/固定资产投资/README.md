## 如何解读

**制造业投资 ≈ 民间投资信心**

- 同比 > 10%：企业扩产积极，经济内生动力强
- 同比 0-10%：中性
- 同比 < 0%：企业收缩，投资信心不足

**基建投资 ≈ 政府逆周期调节力度**

- 同比 > 10%：财政积极托底
- 同比 > 0%：温和托底
- 同比 < 0%：财政收缩，依赖其他手段

**房地产投资 ≈ 地产链景气度**

- 同比 > 0%：地产正增长
- 同比 -5%~-15%：深度调整
- 同比 < -15%：系统性风险信号

**三者关系**：制造业>基建>房地产，是健康的投资结构
