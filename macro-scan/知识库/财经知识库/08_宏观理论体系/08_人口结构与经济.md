# 08 人口结构与经济

---

## 1. 核心传导链

```
┌─────────────────────────────────────────────────────────────┐
│                      人口结构变化                            │
│    出生率 ↓  / 预期寿命 ↑  / 移民政策                        │
└────────────────────┬────────────────────────────────────────┘
                     ▼
      ┌──────────────┴──────────────────┐
      │                                 │
      ▼                                 ▼
┌──────────────┐                 ┌──────────────┐
│ 劳动年龄人口  │                 │ 年龄分布结构  │
│ 规模与增速    │                 │ （老龄化程度） │
└──────┬───────┘                 └──────┬───────┘
       │                                │
       ▼                                ▼
┌──────────────┐                 ┌──────────────┐
│ 劳动力供给    │                 │ 抚养比上升    │
│ （潜在产出）  │                 │ （财政压力）  │
└──────┬───────┘                 └──────┬───────┘
       │                                │
       ▼                                ▼
┌──────────────────────────────────────────────┐
│                 宏观经济影响                   │
│  储蓄率  │  消费结构  │  房地产  │  利率趋势   │
└──────────┬───────────────────────────────────┘
           ▼
┌──────────────────────────────────────────────┐
│          财政与政策压力                        │
│  养老金缺口 │ 医疗支出 │ 债务/GDP持续上升      │
└──────────────────────────────────────────────┘
```

**核心逻辑**：人口结构 → 劳动供给与储蓄模式 → 总需求与资本积累 → 长期增长率 → 政府财政可持续性。人口老龄化通过**三条主渠道**发挥作用：①减少有效劳动投入；②压低储蓄率；③推高公共支出（养老、医疗），形成财政-增长双重压力。

## 2. 关键阶段

| 阶段 | 核心特征 | 典型时长 | 历史数据 |
|------|----------|----------|----------|
| **高出生/高死亡** | 抚养比高（儿童为主），储蓄率低，资本积累慢 | 工业化前数百年 | 19世纪欧洲，儿童抚养比＞50% |
| **人口转型期** | 死亡率先降，出生率随后下降；劳动年龄人口比例快速扩张 | 20-40年 | 日本1950-1975；中国1970-2010 |
| **人口红利期** | 劳动年龄人口（15-64岁）占比峰值，抚养比降至低点（40-50%），储蓄率高，投资旺盛 | 20-30年 | 东亚四小龙1965-1990；中国1980-2015：老年抚养比仅8-13% |
| **人口老化加速** | 老年抚养比快速上升（年增0.5-1个百分点），储蓄率下滑，劳动力短缺初现 | 20-30年 | 日本1990-2010；中国2015-2040（预测） |
| **深度老龄化** | 老年抚养比≥50%，养老金系统承压，财政赤字结构化，潜在增速低于1% | 持续性 | 日本2020年代，老年抚养比约52%；意大利≥40% |

**人口红利量化**：世界银行估算，劳动年龄人口占比每提升1个百分点，GDP增速提升约0.5-1个百分点。东亚经济体约有1/3的快速增长归因于有利的人口结构（Bloom & Williamson，1998）。

## 3. 关键变量

| 变量 | 含义 | 关键阈值 / 历史数据 |
|------|------|---------------------|
| **总抚养比（TDR）** | （0-14岁 + 65岁以上）/ 15-64岁人口 | <50%：人口红利期；>70%：高压力区 |
| **老年抚养比（OADR）** | 65岁以上 / 15-64岁人口 | >20%：老龄化社会；>30%：超老龄化；日本2025年约52% |
| **儿童抚养比（YADR）** | 0-14岁 / 15-64岁人口 | 前工业化国家可达70-80% |
| **劳动参与率（LFPR）** | 劳动力 / 劳动年龄人口 | 日本通过女性与老年就业将整体维持在55-60%；中国约67% |
| **总和生育率（TFR）** | 妇女一生平均生育子女数 | 2.1=人口更替；日本1.2、韩国0.72、中国约1.0（2023年） |
| **净移民率** | 移入减移出 / 千人 | 美国约+3‰，德国约+8‰（2022-2023）；可部分补充劳动力 |
| **老龄化速度** | 65岁以上占比从7%升至14%所需年数 | 法国115年；日本24年；中国预计21年（最快之一） |
| **退休年龄与预期寿命差** | 退休后平均余命 | OECD平均男性退休后约18年；日本约20年；直接决定养老金成本 |
| **出生率（粗）** | 每千人活产数 | 中国2023年约6.4‰；全球平均约18‰；韩国2022年约4.9‰ |

## 4. 传导机制详解

### 4.1 生命周期与储蓄率（Modigliani假说）

```
年龄段        储蓄行为           宏观含义
─────────────────────────────────────────────
15-30岁  │  净借贷（教育、置业）  │ 消费>收入；需信贷供给
30-55岁  │  高储蓄期（育儿+养老  │ 资本积累主力；储蓄率高
         │  双重储蓄动机）       │
55-65岁  │  储蓄率开始下降       │
65岁以上 │  消耗储蓄（净负储蓄）  │ 国民储蓄率下降
─────────────────────────────────────────────
```

**量化证据**：日本国民储蓄率从1990年约33%下降至2023年约26%；中国高储蓄率（2008年峰值约52%）与中年人口占比高度正相关。IMF研究显示，老年抚养比每上升10个百分点，国民储蓄率下降约3-5个百分点。

### 4.2 劳动力供给与工资

老龄化 → 劳动年龄人口缩减 → 劳动力供给曲线左移 → 实际工资上升压力（若技术/移民不能补充）→ 企业用工成本上升 → 通胀预期强化或产出下移。

日本案例：2000-2020年劳动年龄人口下降约750万，劳动缺口通过外籍劳工（持1B签证）和自动化部分填补，但生产率提升未能完全对冲。

### 4.3 房地产需求传导

```
工作年龄人口增量（25-44岁购房主力）
          │
          ▼
    首次购房需求 ──► 住宅新开工量 ──► 建材/家具需求
          │
          ▼
    人口峰值/负增长 ──► 需求萎缩 ──► 房价下行压力
          │
          ▼
    空置率上升 ──► 银行不良贷款 ──► 信贷紧缩风险
```

**日本经验**：1990年泡沫破裂后，人口因素强化了去杠杆效应。2000-2020年日本空置住宅（空き家）数量从480万套增至849万套，占总住宅存量13.6%（2018年普查）。

**中国经验**：2021年25-44岁人口开始绝对萎缩，与房地产市场深度调整时间高度吻合。

### 4.4 财政压力传导

```
老年抚养比上升
    │
    ├──► 养老金支出增加（缴费人减少、领取人增加）
    │         │
    │         ▼
    │    缴费比率上升 ──► 劳动力成本上升 ──► 竞争力下降
    │
    └──► 医疗支出增加（人均医疗支出60岁后指数级上升）
              │
              ▼
         财政赤字扩大 ──► 债务/GDP上升 ──► 利率上行风险
```

**数据**：日本社会保障支出占GDP从2000年的15%升至2023年约24%；政府债务/GDP超过260%（2024年），居全球最高之列。OECD测算，若退休年龄不调整，绝大多数成员国养老金系统在2050年前将面临精算赤字。

### 4.5 移民的补充作用与局限

移民在短期内可提高劳动年龄人口比例，延缓抚养比上升。美国1990-2020年净移民累计约3500万人，劳动参与率保持在较高水平。德国2015年难民潮及2023年技术移民法改革，年均净移民约40-80万，但争议在于：
- **短期有效**：补充劳动力缺口，尤其是建筑、护理、IT等行业
- **技能匹配**：低技能移民可能增加社会支出而非净贡献财政
- **社会整合成本**：语言、文化整合需5-10年，存在过渡期摩擦
- **长期极限**：若全球均进入老龄化（2050年全球65岁以上人口将从今天的10%升至16%），可迁移劳动力总量本身将缩减

## 6. 历史案例

### 案例A：日本"失去的三十年"——人口老龄化的经济代价

**时间线**

```
1970年代   TFR开始低于2.1，人口转型启动
1990年     资产泡沫破裂，老年抚养比约11%
2000年     老年抚养比达25%，超过OECD平均（18%）
2005年     日本人口首次出现自然负增长
2010年代   老年抚养比突破40%，劳动年龄人口减少约1000万
2023年     老年抚养比约52%，人口约1.25亿（峰值2008年约1.28亿）
2025年     65岁以上占总人口约30%，全球最高
```

**核心数据**
- 储蓄率：1990年约33% → 2023年约26%，中年储蓄人口比例下降所致
- 实际GDP增速：1990年代平均约1.0%；2000-2020年平均约0.7%
- 社会保障支出/GDP：2000年约15% → 2023年约24%
- 政府债务/GDP：1990年约67% → 2024年约261%（IMF数据）
- 核心CPI：1999-2012年间多次陷入通缩，通缩与老龄化形成互强循环

**机制分析**

老龄化通过四条路径强化了资产负债表衰退：①退休人口消耗储蓄，压低消费倾向和信贷需求；②劳动年龄人口萎缩抑制了房地产的换手需求，放大了泡沫破裂后的价格下行；③社保支出刚性增长消耗财政空间，挤出公共投资；④人口预期悲观化导致企业长期资本支出保守。安倍经济学（2013年起）通过QQE（量化质化宽松）暂时提振通胀和出口，但未能逆转人口结构基本面。

### 案例B：中国"未富先老"——提前到来的人口拐点

**时间线**

```
1980年     独生子女政策正式实施，TFR从约3.0快速下降
1990年     TFR降至约2.2，接近更替水平
2000年     TFR约1.8（争议：实际可能约1.5）；老年抚养比约10%
2011-2012年 劳动年龄人口（15-59岁）见顶：约9.4亿（2011年国家统计局数据）
2015年     独生子女政策废止，放开二孩；出生人口约1655万
2020年     第七次人口普查：TFR约1.3；出生人口1202万
2022年     人口首次负增长：当年减少约85万；出生率约6.77‰
2023年     出生人口902万（历史新低）；人口减少208万；出生率约6.4‰
```

**核心数据**
- 劳动年龄人口（15-64岁）占比：2010年峰值约74% → 2023年约69%
- 老年抚养比：2000年约10% → 2010年约12% → 2023年约22%，预计2035年超过35%
- 人均GDP：2022年约12,741美元（中等收入上限），远低于日本1970年代进入老龄化时的水平（日本约8,000-10,000美元，1980年代）
- 人口红利对中国1980-2010年GDP增速的贡献估算：约15-25%（Cai & Lu，2013）
- 制造业工资：2000-2015年实际工资年均增速约12-15%，反映劳动力供给转紧

**机制分析**

中国案例的特殊性在于：人口老龄化速度（7%→14%历时约21年，快于多数发达国家）与经济发展阶段的错位——在人均GDP仍处于中等收入阶段时便承受了高收入国家才有的人口结构压力。这一"未富先老"格局意味着：①养老体系（城镇职工养老金、城乡居民养老金）覆盖率和积累率不足；②家庭代际负担（4-2-1结构）对中年劳动者形成双重压力；③刘易斯转折点（劳动力无限供给结束）已过，低成本制造业优势趋于消失。2022年人口负增长标志着中国正式进入人口收缩阶段，比联合国原先预测（2030年前后）提前约10年。

## 7. 政策应对

| 政策工具 | 类型 | 主要经验 | 效果评估 |
|----------|------|----------|----------|
| **提高退休年龄** | 财政结构性 | 法国2023年将退休年龄从62→64岁（引发大规模罢工）；德国已至67岁 | 直接提升缴费年数、减少领取年数；政治阻力大；需15-20年过渡期才见效 |
| **养老金参数改革** | 财政结构性 | 计算方式从DB（受益确定）→DC（缴费确定）；瑞典NDC模式 | 减少精算赤字；但收入风险转嫁给个人；市场波动加剧老年贫困风险 |
| **鼓励生育补贴** | 供给侧人口 | 匈牙利（GDP约4-5%用于生育补贴）；法国家庭补贴历史悠久 | 效果有限：长期证据显示可将TFR推高约0.1-0.2，但无法逆转大趋势；延迟生育比不生育更常见 |
| **技术移民吸引** | 供给侧劳动力 | 加拿大积分制（Express Entry）；德国《技术移民法》2020/2024年修订；日本特定技能签证 | 短期补充劳动力最有效；长期融合成本需评估；需配套住房与公共服务 |
| **提高女性劳动参与率** | 供给侧劳动力 | 日本"女性经济学"（Womenomics）；北欧托育补贴 | 日本女性LFPR从2012年约60%→2023年约73%；有效补充劳动力缺口，但托育基础设施投资回报期约5-10年 |
| **延迟退休+银发就业** | 供给侧劳动力 | 日本《高年龄者雇用安定法》要求企业提供70岁就业选择；2022年修订 | 实践中多为低薪再雇用；对技能密集岗位贡献有限 |
| **自动化与AI替代** | 生产率提升 | 日本制造业机器人密度全球最高（2022年约397台/万工人，IFR数据） | 可部分对冲劳动力减少；但岗位极化风险（中技能岗位消失快于低/高技能） |
| **财政整合（增值税/消费税）** | 财政收入侧 | 日本消费税从3%（1989）→10%（2019）；欧盟成员国增值税普遍20-25% | 缓解养老支出压力；但短期压制消费，老龄化叠加税率上升形成需求双重压制 |
| **移民积分制度优化** | 结构性制度 | 澳大利亚、加拿大定期校准技能缺口需求方向 | 精准填补行业缺口；社会融合挑战仍存 |

**综合评价**：单一政策无法逆转人口趋势，最有效的组合为：**延迟退休（直接减少缺口） + 技术移民（短期补充劳动力） + 生产率提升（替代要素数量增长）**。生育补贴的成本效益比偏低，但在维护社会凝聚力和信号效应上仍有意义。

## 8. 当前状态（2026）

### 8.1 中国：加速老龄化叠加人口负增长

- **出生率**：2023年约6.4‰，2024-2025年估计在6.0-6.5‰区间（全球最低之列）
- **总和生育率**：2023年约1.09，低于日本（1.2）和韩国（0.72），与韩国共同构成全球极低生育率代表
- **人口规模**：2022年起连续负增长；2024年约14.08亿，预计2026年约14.05亿
- **老龄化速度**：65岁以上占比预计2026年约15-16%，进入深度老龄化（超过14%）
- **政策现状**：三孩政策（2021）效果有限；地方补贴差异大；养老金统筹层次正向全国统筹推进，但城乡二元结构下农村老人保障仍薄弱
- **关键风险**：东北、西北等人口萎缩地区的财政压力已提前暴露；制造业成本优势窗口加速收窄

### 8.2 印度：人口红利窗口期（2025-2045）

- **规模**：2023年正式超越中国成为世界第一人口大国（约14.4亿）
- **年龄结构**：中位年龄约28岁（中国约39岁）；劳动年龄人口（15-64岁）占比约68%，且未来20年继续扩张
- **TFR**：全国平均约2.0，城市约1.6，基本接近更替水平，人口转型较为温和
- **人口红利潜力**：联合国估算2025-2045年印度每年新增劳动力约800-1000万
- **制约因素**：教育质量（ASER报告显示约50%的小学五年级学生无法阅读简单文章）；就业吸收能力（正规就业占比仅约10-15%）；女性劳动参与率约24%（全球偏低）
- **关键观察**：能否将人口优势转化为实质性人口红利，取决于未来10年职业技能培训和工业化深度

### 8.3 欧洲：养老金系统承压与移民政治张力

- **德国**：65岁以上占比约22%（2025年），老年抚养比约36%；法定养老金替代率约48%；《技术移民机会法》（2024年生效）大幅放宽技能评估要求，年均净移民维持约60-80万；劳动力短缺行业：护理、建筑、IT
- **法国**：马克龙政府2023年将退休年龄从62→64岁，引发超过100次全国性罢工，最终强行通过；TFR约1.68，欧盟最高，与家庭政策长期投入（GDP约3.5%）密切相关
- **意大利/西班牙**：TFR约1.2-1.3，老年抚养比约40%，净移民可部分缓解但政治争议大
- **整体压力**：欧盟委员会《老龄化报告2024》预测，若政策不变，成员国社会保障支出/GDP至2050年将平均上升约4.5个百分点，相当于新增巨额财政缺口

### 8.4 日本：深度老龄化的财政可持续性危机

- **老年抚养比**：2025年约52%，即约每1.9个劳动年龄人口供养1个老年人；2035年预计超过55%
- **财政状况**：政府债务/GDP约260%（2024年，IMF估计），利息支出占税收约8-10%；日本央行2024年结束YCC（收益率曲线控制）和负利率政策，10年期国债收益率升至约1.5-2.0%，利息负担上升压力显现
- **劳动力对策**：2024年外国劳工约342万（占就业人口约5%，创历史新高）；技能实习制度于2024年废止，改为"育成就労"制度，放宽长期留居权利
- **人口预测**：2026年日本人口约1.22亿，2050年预计降至约1.05亿，2100年可能低于7000万
- **关键指标**：基础财政收支（除社保）仍存在约2%GDP的结构性赤字；若长期利率升至3%，债务可持续性面临严峻考验
