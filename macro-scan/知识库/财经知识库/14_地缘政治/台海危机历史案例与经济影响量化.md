## 一、台湾的全球经济地位

理解台海危机风险必须先认识台湾的战略经济地位：

| 维度 | 数据 | 全球排名/意义 |
|:----|:----:|:------------|
| 半导体先进制程产能 | 台积电占全球先进芯片（≤7nm）约90% | 全球唯一不可替代 |
| 全球GDP贡献 | 约$7500亿（2023）| 第22大经济体 |
| 贸易地位 | 全球第15大贸易体 | — |
| 航运通道 | 台湾海峡年货运量约55%全球贸易 | 全球最重要航运咽喉 |
| 关键出口：PCB | 全球最大PCB生产国 | 电子供应链核心 |
| 关键出口：DRAM/NAND | 第三大内存生产地 | — |

**核心结论**：台海冲突对全球经济的冲击潜力远超乌克兰（粮食+能源），主要通过**半导体供应链断裂**和**航运中断**传导。

## 二、历史危机案例

### 2.1 第一次台海危机（1954-1955）

| 维度 | 内容 |
|:----|:----|
| 背景 | 解放军炮击金门、马祖 |
| 经济影响 | 极小（当时台湾经济体量小，全球化程度低）|
| 美国反应 | 签署《共同防御条约》，第七舰队巡逻 |
| 教训 | 军事威慑（核威慑）稳定了后续数十年局势 |

### 2.2 第二次台海危机（1958年）

| 维度 | 内容 |
|:----|:----|
| 背景 | 解放军大规模炮击金门（47天），约47万枚炮弹 |
| 经济影响 | 有限（冷战封闭经济体系）|
| 结局 | 双方默契：奇偶数日炮击成"仪式化"，1979年正式停止 |
| 历史意义 | 标志台海进入"管控下的对峙"阶段 |

### 2.3 第三次台海危机（1995-1996）：最重要的现代参照

| 维度 | 内容 |
|:----|:----|
| 背景 | 李登辉访美、台湾首次总统直选引发北京强烈反应 |
| 军事行动 | 解放军在台湾附近海域进行大规模导弹演习（1996.03）|
| 美国反应 | 尼米兹+独立号双航母战斗群穿越台海 |

**1995-96年台海危机的经济影响**：

| 资产/指标 | 变化 |
|:---------|:----:|
| 台湾加权股价指数 | 从7228→4503，跌幅-38% |
| 台湾货币 | 贬值约9%（NT$/USD）|
| 新台币外储（前3个月）| 下降约80亿美元（资本外流）|
| 对台直接投资 | 短期中断，危机后快速恢复 |
| 全球股市影响 | 局限于亚太区，美国股市几乎无影响 |

**关键洞察**：1996年危机影响相对有限，原因是台湾经济体量仍小、半导体依赖度尚低、危机持续时间短。

### 2.4 准危机：2022年南希·佩洛西访台

| 时间 | 事件 | 市场影响 |
|:----|:----|:-------:|
| 2022.08.02 | 美国众议院议长佩洛西访台 | 台股-3%，大盘短暂波动 |
| 2022.08.03-07 | 解放军围台军演（有史以来最大规模）| 台积电股价-5%，然后快速恢复 |
| 2022.08.10 | 军演结束 | 市场完全恢复 |

**洞察**：市场认为中短期实质冲突概率低，事件性冲击很快被消化。

## 三、假设情景：台海冲突的经济冲击模型

### 3.1 情景分类

| 情景 | 描述 | 冲突烈度 | 发生概率估计 |
|:----|:----|:-------:|:-----------:|
| S1：军事恐吓（准危机）| 封锁演习、飞越、导弹测试 | 低 | 30%/5年 |
| S2：局部封锁 | 对台湾实施海上封锁，无直接开火 | 中 | 10%/5年 |
| S3：有限武力冲突 | 夺取部分外岛（金门/马祖），有限交火 | 高 | 5%/5年 |
| S4：全面冲突 | 对台湾本岛武力行动，美军介入 | 极高 | 2%/5年 |

### 3.2 S2：海上封锁情景（经济影响）

持续时间：假设3-6个月

| 影响渠道 | 量化估计 | 说明 |
|:--------|:-------:|:----|
| 台积电产能中断 | -90%先进制程产能 | 台湾厂区停工 |
| 全球芯片短缺（AI/汽车/消费电子）| 12-18个月供应中断 | 无法替代 |
| 航运绕行马六甲或绕道 | 运费+50-100% | 所有货物绕行 |
| 台股暴跌 | -50%以上 | 资本外逃 |
| 全球科技公司 | 营收损失约$5000亿/年 | 直接 |
| 全球GDP损失（第一年）| -2% ~ -4% | 取决于持续时间 |
| S&P500预估跌幅 | -30% ~ -45% | 类2008级别 |

### 3.3 S4：全面冲突情景（极端估算）

持续时间：假设1-3年

| 影响渠道 | 量化估计 | 来源 |
|:--------|:-------:|:----|
| 全球GDP损失（1年）| -$10T（约10%）| Bloomberg经济学家估计 |
| 对比：新冠疫情损失 | -$3.8T（2020）| 参照 |
| 半导体供应断裂持续 | 3-5年（建新产能）| 无法快速替代 |
| 全球汽车产量 | -50%以上（芯片短缺）| — |
| 美中双边贸易 | 接近归零 | 制裁/战时 |
| 全球金融市场 | 类1929大崩溃 | 不可预测 |

## 四、半导体地缘风险：核心量化

### 4.1 台积电的不可替代性

| 公司 | 最先进制程 | 产能（晶圆/月）| 可替代时间 |
|:----|:----------:|:--------------:|:--------:|
| 台积电（台湾）| 2nm/3nm | 约15万片 | — |
| 三星（韩国）| 3nm | 约3万片 | 约5-10年达到台积电水平 |
| 英特尔（美国）| 3-5nm | 约2万片 | 10年以上 |

## 五、推演模型中的台海风险评估

```python
def taiwan_strait_risk_score(metrics):
    """
    台海风险评分：0（稳定）到 10（极高风险）
    """
    score = 0
    
    # 军事指标
    if metrics['pla_incursions_adiz_monthly'] > 100: score += 2
    elif metrics['pla_incursions_adiz_monthly'] > 50: score += 1
    
    # 外交指标
    if metrics['us_taiwan_official_visits_senior'] >= 1: score += 1
    if metrics['china_diplomatic_channel_suspended']: score += 1
    
    # 政治指标
    if metrics['taiwan_election_within_6m']: score += 1
    if metrics['china_party_congress_within_6m']: score += 0.5
    
    # 市场指标
    if metrics['taiwan_stock_drawdown_pct'] > -15: score += 1
    if metrics['tsmc_stock_drawdown_pct'] > -20: score += 1
    
    # 美国政策
    if metrics['us_arm_sales_to_taiwan_bn'] > 2: score += 1
    if metrics['us_7th_fleet_exercises_near_taiwan']: score += 0.5
    
    return min(10, score)

def apply_taiwan_scenario_to_portfolio(risk_score, market_state):
    """根据台海风险调整市场预期"""
    if risk_score < 3:
        modifier = 1.0  # 无调整
    elif risk_score < 6:
        # 风险溢价提升：科技股-5%，VIX+5
        modifier = {'tech_stocks': -0.05, 'vix_add': 5, 'usd_yen': -0.03}
    elif risk_score < 8:
        # 局部危机：全球股市-15%，半导体-30%
        modifier = {'global_equity': -0.15, 'semiconductor': -0.30, 'vix_add': 25}
    else:
        # 极端：使用S3/S4情景参数
        modifier = {'global_equity': -0.40, 'semiconductor': -0.80, 'gdp_shock': -0.05}
    return modifier
```
