## 一、贸易摩擦概述

2018-2020年的中美贸易战是全球化时代最大规模的双边贸易冲突，直接影响全球贸易体系、供应链格局和地缘政治格局。2020年后，摩擦从关税转向技术制裁、供应链脱钩，进入新阶段。

**关键数据**：
- 美国对华关税：从平均3.1%（2017年）→ 24.3%（2021年第一阶段协议后）
- 受影响贸易额：约5000亿美元（占中美双边贸易总额约65%）
- 中国对美反制关税：约1850亿美元进口商品
- 全球贸易政策不确定性指数（2018-19年）：历史峰值

## 四、供应链重构：贸易战的长期影响

### 4.1 "中国+1"战略的兴起

2018年后，跨国企业开始采用"中国+1"策略：保留中国生产基地，但新增一个备选产地。

| 产业 | 主要迁出目的地 | 规模 |
|:----|:-----------:|:----|
| 服装/纺织 | 越南、孟加拉国 | 大量 |
| 电子组装 | 印度、越南 | 中等（苹果部分产线）|
| 家具/家居 | 墨西哥、越南 | 大量 |
| 汽车配件 | 墨西哥（近岸）| 大量 |
| 半导体代工 | 台湾（已有）、美国（新建）| 巨额 |

### 4.2 "友岸外包"（Friendshoring）

拜登政府将供应链重构提升至国家安全层级：
- 芯片：$520亿美国芯片法补贴，台积电/英特尔在美新建
- 关键矿产：锂/稀土本地化或盟友来源
- 电动车：IRA补贴要求在美或盟友生产

## 五、关税与汇率的相互对冲

### 5.1 2019年人民币贬值的关税抵消效应

```
美国对2000亿美元商品加税25%
  ↓
理论上：美国进口商成本+25%
  ↓（但）
人民币/美元从6.3→7.0（贬值约11%）
  ↓
实际：美国进口商成本净增约14%（25%-11%）
  ↓（中国出口商主动降价）
实际传导至美国消费者约：+10-12%

结论：人民币贬值约抵消了约一半关税效果
```

### 5.2 美国"汇率操纵国"认定的荒谬性

美国在人民币自然贬值时（市场压力）认定为"操纵"，但这正是汇率市场机制的正常反应。实际上，中国央行在此期间多次入市阻止过度贬值（不是操纵贬值，而是托底升值）。

## 六、技术战：比贸易战更长期的冲击

2022年起，中美摩擦重心从关税移向技术封锁：

| 领域 | 主要措施 | 影响 |
|:----|:-------:|:----|
| 先进芯片 | 禁止向中国出口≥7nm制造设备 | 中国先进制程被限制 |
| AI芯片 | 限制向中国出口H100/A100 | 中国AI基础设施受限 |
| 量子计算 | 技术出口管制 | 长期影响 |
| 航空航天 | 多家中国公司实体清单 | 波音/空客零件禁售 |
| 电信设备 | 华为/中兴实体清单 | 5G建设受阻 |

## 七、推演模型中的贸易摩擦评估

```python
def trade_war_risk_score(metrics):
    """
    中美贸易/技术摩擦风险评分（0低风险，5高风险）
    """
    score = 0
    
    # 关税水平
    if metrics['avg_us_tariff_on_china'] > 25: score += 1
    if metrics['avg_us_tariff_on_china'] > 50: score += 1
    
    # 科技出口管制范围
    if metrics['entities_on_us_list'] > 1000: score += 1
    if metrics['chip_export_control_scope'] == 'broad': score += 1
    
    # 外交温度指标
    if metrics['diplomatic_meetings_last_6m'] == 0: score += 1
    if metrics['taiwan_strait_tension_index'] > 7: score += 1
    
    # 供应链多元化进度（反向，越多越低风险）
    if metrics['china_share_of_us_imports'] < 0.15:
        score -= 1  # 去风险化进展
    
    return max(0, min(5, score))
```
