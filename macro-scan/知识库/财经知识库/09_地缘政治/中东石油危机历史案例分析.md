## 一、中东能源的全球战略地位

中东是全球能源安全的核心节点：

| 维度 | 数据（2023）|
|:----|:----------|
| 中东原油储量 | 全球已探明储量约48%（沙特/伊拉克/伊朗/UAE等）|
| 中东原油日产量 | 约3500万桶/天（全球约35%）|
| 霍尔木兹海峡日通过量 | 约2000万桶/天（全球约20%的石油贸易）|

**霍尔木兹海峡**是全球最重要的单一能源咽喉，其战略脆弱性是中东地缘风险的核心。

## 二、历史案例一：第一次石油危机（1973年）

### 2.1 背景与触发

- **直接原因**：1973年10月第四次中东战争（赎罪日战争）
- **OAPEC制裁**：阿拉伯产油国对支持以色列的美国、荷兰等国实施石油禁运
- **OPEC减产**：同期决定减产5%，每月递增，并大幅提价

### 2.2 油价变化

| 时间 | 油价（美元/桶）| 变化 |
|:----|:------------:|:----:|
| 1973年10月前 | $3.0 | — |
| 1974年初 | $11.7 | **+290%** |
| 禁运结束（1974.03）| 逐步回落 | — |

### 2.3 经济冲击

| 影响 | 美国 | 西欧 | 日本 |
|:----|:----:|:----:|:----:|
| 通胀（1974）| 11.0% | 13-15% | 23% |
| GDP增速（1974-75）| -0.5%、-0.2% | 衰退 | -1.4% |
| 失业率上升 | +3.5pp | +3pp | +1pp |
| 当时汽油价格 | +70%（美国）| — | — |

### 2.4 历史意义

- **滞胀（Stagflation）定义**：此次危机首次证明"通胀与经济衰退可以同时发生"，推翻了菲利普斯曲线传统认知
- **能源政策变革**：美国建立战略石油储备（SPR）、推进节能立法、日本大力发展核能
- **美元-石油体系**：与沙特达成协议，全球石油以美元计价（石油美元体系形成）

## 三、历史案例二：第二次石油危机（1979-1980年）

### 3.1 背景与触发

- **直接原因**：伊朗伊斯兰革命（1979.02），巴列维国王被推翻，伊朗石油产量骤降
- **加剧因素**：1980年9月两伊战争爆发，进一步冲击中东供应

### 3.2 油价变化

| 时间 | 油价（美元/桶）| 变化 |
|:----|:------------:|:----:|
| 1978年 | $13 | — |
| 1979年底 | $32 | +146% |
| 1980年峰值 | $40 | +208%（vs1978）|

### 3.3 经济冲击与政策响应

- 美国通胀：1980年达到13.5%（近历史峰值）
- **沃尔克冲击**：美联储主席沃尔克将联邦基金利率提至20%，是打断通胀的核心手段
- 美国GDP：1980年+0.3%，1982年-1.8%（滞后衰退）
- 大宗商品超级周期开启：铜/黄金/白银同期大涨

## 四、历史案例三：海湾战争石油冲击（1990-1991年）

### 4.1 触发事件

- 1990年8月2日：伊拉克入侵科威特（世界第六大石油储量）
- 伊拉克+科威特合计占全球石油产量约9%，一夜之间从市场消失

### 4.2 油价变化

| 时间 | 油价（美元/桶）|
|:----|:------------:|
| 1990.07（战前）| $18 |
| 1990.10（峰值）| $41（+128%）|
| 1991.02（战争结束）| $20 |

### 4.3 经济冲击

- 美国GDP：1990Q3-1991Q1 衰退（但温和，仅-0.1%~-1.5%）
- 通胀：CPI从4%→5.4%（有限）
- 衰退原因：主要是石油冲击+此前信贷收紧，非油价单一导致

**关键教训**：战争结束快（43天地面战）→ 油价快速回落 → 对经济的实质冲击比预期小。

## 五、历史案例四：OPEC+减产周期（2014-2016年）

### 5.1 背景

2014年美国页岩油革命导致全球石油供应过剩，OPEC选择**不减产以保市场份额**，油价暴跌。

| 时间 | 油价（美元/桶）| 变化 |
|:----|:------------:|:----:|
| 2014.06峰值 | $115 | — |
| 2016.01谷底 | $28 | -76% |

**宏观影响**：
- 沙特/中东产油国：财政赤字扩大，引发改革压力（沙特视野2030）
- 俄罗斯：外汇储备大幅消耗，经济衰退
- 美国页岩油：大量小企业破产，但大公司整合后更有效率
- 全球通缩压力：大宗商品下跌→全球通胀压低，为各国央行宽松提供空间

## 六、历史案例五：2019年沙特油田无人机袭击

| 时间 | 事件 | 油价反应 |
|:----|:----|:-------:|
| 2019.09.14 | 胡塞武装无人机袭击沙特阿布凯格/库赖斯油田 | 开盘跳涨+15%（单日最大涨幅之一）|
| 被袭产能 | 约570万桶/天（全球约5.7%）| — |
| 2周后 | 产能基本恢复 | 油价回落至袭击前水平 |

**洞察**：即使全球最大油田之一遭受攻击，只要恢复预期强，市场冲击就是短暂的。关键变量是**供应中断持续时间**。

## 八、霍尔木兹封锁情景模拟

如果霍尔木兹海峡被封锁（极端情景，通常<1%概率）：

| 时间 | 影响估计 |
|:----|:--------|
| 第1周 | 油价+50-100%（市场恐慌定价）|
| 第1个月 | 全球供应短缺约2000万桶/天（约20%）|
| 第3个月 | 全球GDP年化影响约-3%至-5% |
| 政策响应 | SPR释放（美国+盟国）、紧急增产（不过需要时间）|
| 解封后 | 价格快速回落，但持续数月高位 |

## 九、推演模型中的能源风险评估

```python
def middle_east_energy_risk_score(metrics):
    """
    中东能源地缘风险评分（0低风险，5极高风险）
    """
    score = 0
    
    # 直接冲突风险
    if metrics['iran_us_military_incident_last_30d']: score += 2
    if metrics['hormuz_shipping_disrupted']: score += 3  # 极高权重
    
    # OPEC政策
    if metrics['opec_surprise_cut_pct'] > 0.05: score += 1  # 超预期减产
    
    # 地区紧张度
    if metrics['israel_iran_escalation_level'] > 7: score += 1
    if metrics['houthi_red_sea_attacks_weekly'] > 5: score += 1
    
    # 油价水平
    if metrics['brent_oil'] > 100: score += 0.5
    if metrics['brent_oil'] > 130: score += 1
    
    return min(5, score)


def oil_shock_macro_impact(oil_price_change_pct, duration_months):
    """
    油价冲击宏观影响估算
    基于历史回归：油价每涨10%，全球GDP约-0.1%~-0.15%（12个月滞后）
    """
    gdp_impact = -oil_price_change_pct * 0.012  # per %涨幅，GDP变化
    inflation_impact = oil_price_change_pct * 0.03  # 通胀压力
    duration_factor = min(1.5, duration_months / 6)  # 超过6个月倍增
    
    return {
        'gdp_impact_annual': gdp_impact * duration_factor,
        'cpi_impact_annual': inflation_impact * duration_factor,
        'policy_direction': 'hawkish' if inflation_impact > 0.5 else 'neutral',
    }
```
