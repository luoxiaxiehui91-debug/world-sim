## 一、危机概述

2022年通胀冲击是1980年以来最严重的全球通胀事件，起源于2020-21年新冠疫情后的过度财政刺激与供给侧瓶颈叠加，随后因2022年2月俄乌战争推动能源/粮食价格暴涨而大幅恶化。美联储以1980年代沃尔克式的速度紧缩应对，引发了一次历史上最快速的加息周期（+525bp/16个月）。

**关键数据**：
- 美国CPI峰值：9.1%（2022年6月），40年来最高
- 美国核心PCE峰值：5.5%（2022年2月）
- 美联储加息幅度：0.25% → 5.50%（+525bp，2022.03-2023.07）
- 美国2年期国债收益率：0.76%（2022.01）→ 5.15%（2023.07）
- 全球债券损失：约$30T（2022年债券熊市，史上最大）
- 美元指数（DXY）：95（2022.01）→ 114.7（2022.09），+21%

## 三、传导路径分析

### 3.1 多重叠加冲击结构

```
来源1：财政主导的需求过热（2020-21）
  $5T财政刺激 → 需求+20% vs 供给仅+5%（供给受约束期）

来源2：供给侧瓶颈（2021）
  港口拥堵 → 容器短缺 → 航运价格+400%
  芯片短缺 → 汽车/电子减产
  劳动力退出（1000万美国人"Great Resignation"）

来源3：能源与粮食冲击（2022）
  俄乌战争 → 欧洲天然气危机（TTF +600%）
  乌克兰粮食封锁 → 小麦/玉米+30-50%

= 需求拉动 + 成本推升 + 输入性通胀 三重叠加
```

### 3.2 通胀传导链

```
PPI（生产者价格）：2022年峰值11.6%（美国）
  ↓（滞后2-4个月）
CPI（消费者价格）：2022年6月9.1%
  ↓
工资增速上升（AHE 5.5%/年）→ F2工资-价格螺旋部分激活
  ↓（但未完全形成螺旋，因就业市场预期锚定）
核心服务通胀持续黏性（2023-24仍3-4%）
```

### 3.3 全球差异化传导

| 地区 | 通胀峰值 | 加息力度 | 特殊因素 |
|:----|:--------:|:-------:|:--------|

| 欧元区 | HICP 10.6% | +450bp | 能源危机主因（天然气）|

| 中国 | CPI 2.8% | 降息（反向）| 内需疲弱，未输入 |

## 六、中国在此轮通胀中的特殊地位

中国是这轮全球通胀中**唯一逆势宽松**的主要经济体，原因：
- 内需疲弱（清零政策+房地产下行）
- CPI长期低于2%（2022年峰值仅2.8%）
- PPI快速回落（从+13.5%→2022年末-1.3%）

**中国对全球通胀的双重作用**：
1. **输出通缩**：制造业产能过剩→廉价商品出口压低全球PPI
2. **输入通胀缓冲**：能源/大宗商品需求放缓→油价/铜价上涨受限

### 7.2 通胀→衰退传导模型

```
通胀高企（CPI>6%）
  → 实际工资下降（购买力侵蚀）
  → 消费下降（尤其中低收入）
  → 美联储激进加息（FFR>5%）
  → 信贷成本飙升（企业+消费者）
  → 房地产降温（抵押贷款利率7%+）
  → 投资下滑
  → 企业盈利压缩
  → 就业放缓（非农月增<100K为预警）
  = 硬着陆 OR 软着陆（取决于就业韧性）
```

## 八、推演启示

1. **过度财政刺激的教训**：超过GDP损失22%的刺激规模是后续通胀的决定性因素
2. **央行预期管理**：美联储"暂时性"错误表述导致通胀预期脱锚，代价：加息幅度多525bp
3. **F4（货币政策稳定回路）的极限**：过度通胀时F4与F2螺旋激烈竞争，激进加息可能引发金融不稳定
4. **地缘政治风险定价**：能源依赖型经济体对地缘冲击的暴露无法用货币工具对冲
