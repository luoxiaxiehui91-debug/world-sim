## 一、中国财政政策框架

中国财政政策由**财政部**主导，但在中国体制下，财政政策与货币政策、产业政策、国有企业投资高度融合，界限远比西方模糊。

**中国特色财政工具**：
1. 中央政府财政支出（预算内）
2. 地方政府专项债券（定向基建）
3. 政策性银行贷款（国开行/农发行/进出口行）
4. 国有企业投资（不算政府预算但政策驱动）
5. 特别国债（非常时期，历史上4次）

**中国财政赤字口径问题**：
- 官方赤字/GDP：通常3%左右（如2022年为2.8%）
- "广义赤字"（含专项债+政策性银行）：实际约8-10% GDP

## 二、案例一：2008年四万亿刺激计划

### 2.1 背景与规模

| 维度 | 内容 |
|:----|:----|
| 宣布时间 | 2008年11月9日（雷曼破产后7周）|
| 规模 | 4万亿人民币（约5850亿美元，占GDP约12%）|
| 执行期 | 2009-2010年 |
| 配合政策 | M2增速放开（2009年达27.5%），信贷规模约9.6万亿 |

### 2.2 资金分配

| 领域 | 金额（亿元）| 占比 |
|:----|:----------:|:----:|
| 铁路/公路/机场/城市交通 | 15000 | 37.5% |
| 汶川地震灾后重建 | 10000 | 25.0% |
| 农村基础设施 | 3700 | 9.3% |
| 保障性安居工程 | 4000 | 10.0% |
| 医疗卫生教育文化 | 1500 | 3.7% |
| 生态环境/节能减排 | 2100 | 5.3% |
| 科技创新/产业结构调整 | 1600 | 4.0% |
| 其他 | 2100 | 5.3% |

### 2.3 经济效果

| 指标 | 2007（刺激前）| 2008 | 2009（政策效果）| 2010 |
|:----|:------------:|:----:|:---------------:|:----:|
| GDP增速 | 14.2% | 9.7% | 9.4% | 10.6% |
| 固定资产投资增速 | 24.8% | 25.9% | 30.4% | 23.8% |
| 基建投资增速 | 24.2% | 29.3% | 42.2% | 21.9% |
| M2增速 | 16.7% | 17.8% | **27.5%** | 19.7% |
| 新增信贷（万亿元）| 3.8 | 4.9 | **9.6** | 7.9 |
| CPI | 4.8% | 5.9% | -0.7% | 3.3% |

**结论**：四万亿成功保住中国2009年GDP增速9.4%（全球唯一主要正增长），但代价是杠杆率大幅上升和产能过剩。

### 2.4 长期后遗症

1. **地方政府债务**：地方融资平台（城投）债务从约1万亿→2012年约12万亿→2023年约65万亿
2. **产能过剩**：钢铁、水泥、电解铝大量过剩，2015年后需要"供给侧改革"去产能
3. **房价上涨**：2009年信贷宽松推动房价大涨，2010年开始首轮调控
4. **影子银行**：银行贷款转表外，影子银行从约10万亿→2016年约100万亿
5. **城投套娃**：地方政府依赖土地出让金+城投举债，形成"土地财政"依赖

## 三、案例二：2015-16年供给侧改革与定向刺激

### 3.1 背景

2012年后，四万亿刺激效应退去，经济进入"三期叠加"：增速换档期、结构调整阵痛期、前期刺激消化期。GDP增速从10%以上下滑至7%。

| 问题 | 具体表现 |
|:----|:--------|
| 产能过剩 | 钢铁产能利用率<70%，煤炭行业大量亏损 |
| 房地产去库存 | 三四线城市去化周期>24个月 |
| 企业高杠杆 | 非金融企业债务/GDP突破160% |
| 金融风险累积 | P2P、影子银行爆雷频繁 |

### 3.2 供给侧改革五大任务（"三去一降一补"）

| 任务 | 内容 | 2016-2020年成效 |
|:----|:----|:----------------|
| 去产能 | 钢铁去1-1.5亿吨/年，煤炭去5亿吨/年 | 钢铁价格回升，煤矿大量关闭 |
| 去库存 | 货币化棚改安置（PSL工具）| 三四线城市去库存有效，但推高了房价 |
| 去杠杆 | 压降国企债务，金融去杠杆 | 部分去杠杆，2018年后重点转向 |
| 降成本 | 减税降费（制造业增值税降低）| 企业税负减轻约1万亿 |
| 补短板 | 基础设施、公共服务、脱贫攻坚 | 脱贫攻坚超额完成 |

### 3.3 货币化棚改（2015-2018）

这是一个被忽视但极其重要的政策工具：

```
政策路径：
  PBOC通过PSL（抵押补充贷款）向国开行注入资金
    ↓
  国开行向地方政府棚改项目发放低息贷款
    ↓
  地方政府拆迁棚户区，给居民现金补偿（而非实物安置）
    ↓
  居民拿到现金直接购房（三四线去库存）
    ↓
  2015-18年三四线城市房价上涨30-50%

总规模：PSL累计约5万亿，直接推动房价上涨
终止：2018年政策转向，棚改货币化收窄
```

## 四、案例三：2020年应对新冠

### 4.1 政策组合

| 工具 | 规模 | 说明 |
|:----|:----:|:----|
| 特别国债 | 1万亿人民币（首次自2007年以来）| 直接支持疫情防控和基建 |
| 新增地方政府专项债 | 3.75万亿（高于往年）| 提前下达，加速使用 |
| 降准+MLF降息 | 释放1.3万亿，降息15-25bp | 配合财政 |
| 助企纾困减税 | 约2.6万亿 | 社保减免、税费缓缴 |
| 就业补贴 | 多项措施 | 稳就业 |

### 4.2 效果

- 中国2020年GDP：+2.3%（全球主要经济体唯一正增长）
- 二季度GDP从-6.8%反弹至+3.2%（最快修复）
- 出口意外强劲（全球供给受损，中国率先复工）

## 五、案例四：2022-24年稳经济大礼包

### 5.1 背景

2022年上海封城+房地产下行+外需疲弱，叠加三重压力。政府出台系列"稳经济"政策。

### 5.2 主要措施

| 时间 | 措施 | 规模/内容 |
|:----|:----|:---------|
| 2022.05 | 国务院33条稳经济 | 退税减税2.64万亿 |
| 2022.08 | 国常会19条接续政策 | 政策性银行8000亿专项贷款 |
| 2022.11 | 房地产"三支箭" | 信贷+债券+股权全面放开 |
| 2023.07 | 恢复和扩大消费20条 | 购车/家电补贴 |
| 2023.10 | 万亿国债（增发）| 1万亿特别国债（灾后重建）|
| 2024.09 | "一揽子金融政策" | 降准50bp+降息20bp+房贷5年期LPR-25bp |
| 2024.10 | 财政政策发力信号 | 10万亿地方债置换+2万亿化债 |

## 六、中国财政刺激的结构特点

### 6.1 "基建为主"的投资偏好

中国历次刺激均以基建为主，原因：
1. 基础设施仍有实质补短板空间（2008年远不如今）
2. 地方政府执行基建比消费刺激效率更高
3. 国有建筑/钢铁/水泥企业吸纳就业能力强
4. 基建有抵押物，可通过专项债、城投债融资

### 6.2 消费刺激的历史局限

| 情景 | 消费刺激手段 | 效果评估 |
|:----|:----------:|:-------:|
| 2008-09 | 家电下乡、汽车以旧换新 | 短期有效，停止即反转 |
| 2020-22 | 发放消费券（各地不同）| 局部有效，乘数小 |
| 2023-24 | 汽车/家电补贴 | 效果温和 |

**根本原因**：中国居民储蓄率高（35-40%），消费刺激不如基建刺激立竿见影；社会保障体系不完善导致预防性储蓄强。

## 七、推演模型中的中国财政政策评分

```python
def china_fiscal_policy_score(metrics):
    """
    评分：0（无刺激）到 5（最大力度刺激）
    """
    score = 0
    
    # 专项债发行节奏
    if metrics['special_bonds_issued_pct_annual_quota'] > 0.8:  # 年内80%以上
        score += 1
    
    # 基建投资增速
    if metrics['infrastructure_investment_yoy'] > 10:
        score += 1
    if metrics['infrastructure_investment_yoy'] > 20:
        score += 1  # 叠加
    
    # 特别国债信号
    if metrics['special_treasury_bonds_announced']:
        score += 1
    
    # 财政赤字广义口径/GDP
    if metrics['augmented_deficit_pct_gdp'] > 8:
        score += 1
    
    return min(5, score)
```
