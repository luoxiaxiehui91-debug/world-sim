## 一、危机概要

| 项目 | 内容 |
|:----|:----|
| 时间 | 2007年8月（萌发）→ 2008年9月（雷曼破产，全面爆发）→ 2009年Q2（触底）|
| 核心触发 | 美国次级抵押贷款市场崩溃，叠加金融系统过度杠杆和证券化失控 |
| 峰值烈度 | 美国GDP单季度下跌8.9%（年化，2008Q4），全球贸易量跌12% |
| 政策响应 | 美联储降息至零、QE、TARP 7000亿救助计划、G20协调财政刺激 |
| 全球影响 | 全球GDP下跌约2.1%（2009年，1930年代以来最大跌幅）|

## 二、危机时间线

### Phase 1：泡沫积累（2003-2006）

| 时间 | 事件 | 指标变化 |
|:----|:----|:--------|
| 2003-04 | 联邦基金利率降至1%（格林斯潘宽松）| FFR: 6.5%→1.0% |
| 2004-06 | 房价快速上涨，次级贷款激增 | Case-Shiller全国+45% |
| 2004-06 | MBS、CDO市场爆炸性增长 | CDO发行量+500% |
| 2006 | 住房开工触顶，房价开始滞涨 | 新屋开工-20% |

### Phase 2：裂缝显现（2007年）

| 时间 | 事件 | 市场影响 |
|:----|:----|:--------|
| 2007.02 | HSBC警告次贷损失18亿美元 | 首次公开确认次贷问题 |
| 2007.06 | 贝尔斯登两只对冲基金崩溃 | ABX信用违约指数暴跌 |
| 2007.08 | BNP暂停旗下基金赎回 | LIBOR-OIS利差飙升（"钱荒"信号）|
| 2007.09 | 英国北岩银行挤兑 | 二战以来英国首次银行挤兑 |
| 2007.12 | 美联储建立TAF（定期拍卖工具）| FFR从5.25%开始降息 |

### Phase 3：系统性危机（2008年）

| 时间 | 事件 | 市场影响 |
|:----|:----|:--------|
| 2008.03 | 贝尔斯登濒临破产，摩根大通以2美元/股收购 | 危机蔓延确认 |
| 2008.07 | 房利美/房地美危机（"两房"）| 政府接管，10年期MBS信用崩塌 |
| 2008.09.07 | 美国政府接管两房（4.5T负债）| 全球债市短暂稳定 |
| 2008.09.15 | **雷曼兄弟破产**（6130亿负债）| VIX从25→80，LIBOR-OIS+350bp |
| 2008.09.16 | AIG被政府850亿救助 | 全球信贷市场冰封 |
| 2008.09-10 | 全球银行同业拆借几乎停止 | 货币市场基金破净 |
| 2008.10 | TARP通过，7000亿美元救助计划 | 短暂稳定，但衰退已成定局 |
| 2008.12 | 美联储降息至0-0.25%（ZLB）| QE1随后宣布 |

### Phase 4：触底与复苏（2009年）

| 时间 | 事件 | 指标 |
|:----|:----|:----|
| 2009.02 | 奥巴马签署7870亿财政刺激法案 | 财政支出冲击 |
| 2009.03.09 | S&P500触底（666点，峰值-57%）| VIX峰值89.5 |
| 2009.03 | G20伦敦峰会，协调全球刺激 | 1.1万亿SDR承诺 |
| 2009.Q2 | GDP环比转正（2季度延迟）| 失业率继续上升至10% |
| 2010.04 | 欧债危机萌发（希腊主权评级下调）| 次生危机启动 |

## 四、传导路径分析

```
美国次级贷款违约↑
    ↓（证券化连锁）
MBS/CDO价值暴跌
    ↓（杠杆爆仓）
金融机构资产负债表缩水
    ↓（系统性去杠杆）
信贷市场冻结（LIBOR飙升）
    ↓（实体经济）
企业融资困难→投资下降→裁员
    ↓（全球联动）
新兴市场资本外流+大宗商品暴跌
    ↓（政策响应）
各国财政+货币双宽松→缓慢复苏
```
