## 更新频率规则

| 指标类型 | 建议频率 | 说明 |
|:--------|:------:|:-----|
| PMI | 每月 | 月初发布，变化快，最需要及时更新 |
| CPI/PPI | 每月 | 通胀数据，月中前后发布 |
| 政策利率 | 按议息 | 央行会议后立即更新，附简短解读 |
| GDP | 每季度 | Q1→5月，Q2→8月，Q3→11月，Q4→2月 |
| 汇率 | 不定期 | 有重大波动（±2%+）或央行干预时更新 |
| 贸易数据 | 每月 | 进出口月率，重点关注顺逆差变化 |
| 就业/失业 | 每月 | 美国非农最重要，其余国家按发布时更新 |
| 国际形势 | 随时 | 地缘事件突发随时追加，每月整理一次 |

## 写作规范

- **结论先行**：先说"意味着什么"，再说数据本身
- **数据必须标注时间**：每条数据注明月份/季度，不写裸数字
- **不预测，不建议投资**：只描述事实和逻辑链，不做方向性判断
- **不确定时注明**：用"预测值"、"估算"、"⚠️"标注非确认数据
- **时间戳格式**：文件末尾统一用 `> 📅 数据更新：YYYY-MM-DD | 🔄 下次更新：YYYY-MM`
