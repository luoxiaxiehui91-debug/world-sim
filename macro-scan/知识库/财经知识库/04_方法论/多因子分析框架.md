# 多因子分析框架

## 核心思想

经济现象由多个因子驱动，识别并量化各因子贡献：

```
结果 = α + β₁×因子₁ + β₂×因子₂ + ... + βₙ×因子ₙ + ε
```

## 分析流程

### Step 1：因子识别
- 理论推导
- 历史经验
- 数据探索

### Step 2：因子筛选
- 相关性分析
- 显著性检验
- 共线性处理

### Step 3：权重确定
- 回归分析
- 主成分分析
- 专家判断

### Step 4：模型验证
- 样本内拟合
- 样本外预测
- 稳健性检验

### Step 5：动态更新
- 滚动回归
- 因子权重调整
- 新因子纳入

## 常见因子类别

### 宏观因子
- 增长因子：GDP、PMI、工业产出
- 通胀因子：CPI、PPI、工资
- 货币因子：利率、M2、信用
- 外部因子：汇率、贸易、外债

### 市场因子
- 估值因子：PE、PB、股息率
- 动量因子：价格趋势
- 波动因子：VIX、历史波动率
- 流动性因子：成交量、利差

### 风险因子
- 信用风险：违约率、利差
- 政策风险：监管变化
- 地缘风险：冲突指数
- 尾部风险：极端事件概率

## 应用示例

### GDP增长分解
```
GDP增速 = 潜在增速 + 周期项 + 结构项 + 冲击项

周期项 ≈ 0.3×消费周期 + 0.4×投资周期 + 0.2×出口周期
结构项 ≈ 人口贡献 + 全要素生产率 + 资本深化
冲击项 ≈ 政策冲击 + 外部冲击
```

### 通胀分解
```
CPI = 核心CPI + 食品贡献 + 能源贡献

核心CPI ≈ 工资增速×劳动份额 + 进口价格×开放度
       + 通胀预期 + 产出缺口
```

### 资产收益分解
```
股票收益 = 无风险利率 + 股权风险溢价 + 盈利增长 + 估值变化

风险溢价 ≈ β₁×经济增长 + β₂×通胀 + β₃×信用利差
         + β₄×波动率 + β₅×流动性
```

## 注意事项

### 1. 因子相关性
- 多因子可能共线性
- 需正交化处理
- 或使用主成分

### 2. 时变性
- 因子权重可能变化
- 需滚动估计
- 或状态空间模型

### 3. 非线性
- 线性模型可能不足
- 考虑交互项
- 或非线性模型

### 4. 结构变化
- 制度变化可能改变关系
- 需识别结构断点
- 分段建模

### 5. 过拟合风险
- 因子过多易过拟合
- 交叉验证
- 简约原则

## 实践建议

### 简约性
- 从少数核心因子开始
- 逐步增加
- 避免过度复杂

### 可解释性
- 选择有经济含义的因子
- 权重符合理论预期
- 结果可解释

### 稳健性
- 多种方法交叉验证
- 样本外检验
- 敏感性分析

### 动态性
- 定期更新模型
- 监测因子有效性
- 及时调整
