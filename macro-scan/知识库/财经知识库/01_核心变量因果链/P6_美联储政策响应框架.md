# P6：美联储政策响应框架

> 本文档定义美联储政策响应的分析框架，包括利率决策传导路径、历史周期对比、当前周期定位。
> 数据来源：FRED时序数据库（DFF/DGS10/DGS2/M2SL/FEDFUNDS/总资产）

---

## 一、美联储政策工具体系

### 1.1 政策利率（联邦基金利率）

| 工具 | 当前范围 | 操作方式 |
|:-----|:---------|:---------|
| **联邦基金利率** | 3.63%（2026-05） | FOMC设定目标区间（当前3.50-3.75%） |
| **ON RRP利率** | 3.55% | 隔夜逆回购利率（利率走廊下限） |
| **IORB利率** | 3.40% | 准备金利率（利率走廊上限附近） |
| **超额准备金利率（IOER）** | 逐步退出 | 2008年后引入 |

### 1.2 量化工具

| 工具 | 说明 | 传导路径 |
|:-----|:-----|:---------|
| **QE（量化宽松）** | 购买长期国债/MBS | 压低长端利率 + 信号效应 + 流动性注入 |
| **QT（量化紧缩）** | 缩表，减少持有资产 | 退出宽松，提高长端利率压力 |
| **Maturity Extension Program（MPT/扭曲操作）** | 卖出短债买长债 | 直接压低长端利率 |
| **正回购/逆回购** | 日间流动性管理 | 短期利率稳定 |

## 二、利率决策传导路径

### 2.1 完整传导链（政策利率 → 实体经济）

```
FOMC政策利率（联邦基金利率）
    ↓
隔夜拆借利率（DFF ≈ IORB-IOER区间中点）
    ↓
短期国债收益率（2Y国债 ≈ DFF + 预期路径）
    ↓
中期利率（5Y国债）
    ↓
长期利率（10Y国债 = 短期利率预期 + 期限溢价）
    ↓
抵押贷款利率（MORTGAGE30US ≈ 10Y + 150-200bp）
    ↓
企业融资成本（投资级/BAA ≈ 10Y + 信用利差）
    ↓
消费信贷（信用卡利率 ≈ 联邦基金 + 滞后传导）
    ↓
住房需求/企业投资 → GDP增长
```

### 2.2 传导效率的关键因素

| 阶段 | 传导速度 | 关键决定因素 |
|:-----|:---------|:---------|
| 政策利率 → 2Y国债 | 即时 | 市场对FOMC预期 |
| 2Y → 10Y国债 | 3-12个月 | 期限溢价，QE规模 |
| 10Y → 抵押贷款利率 | 1-6个月 | 机构MBS市场结构 |
| 抵押贷款利率 → 房市 | 3-12个月 | 可负担性，库存 |
| 企业融资 → 投资 | 6-18个月 | 产能利用率，需求前景 |

## 三、美联储双目标框架评估

### 3.1 泰勒规则实时计算

**标准泰勒规则**：
```
联邦基金利率 = 中性利率(≈2%) + 通胀缺口(通胀-2%) + 产出缺口(GDP偏离潜力)
```

**改良版（包含金融条件）**：
```
利率调整幅度 = 
  0.5 × 通胀偏离目标
+ 0.5 × 产出缺口（gap）
+ 0.25 × 信用利差变化
+ 0.25 × 股市变化
```

### 3.2 政策利率"舒适区"判断

| 当前状态 | 通胀压力 | 就业市场 | 适当政策 |
|:---------|:---------|:---------|:---------|
| **完美舒适** | 2% | 4% | 3-4%（中性利率附近） |
| **通胀过热** | >5% | <4% | >6%（加息抑制） |
| **失业危机** | <3% | >8% | <1%（零利率/负利率） |
| **滞胀** | >5% | >6% | 两难（需权衡） |
| **软着陆** | 2-3% | <4.5% | 3-4%（维持现状） |

### 4.2 2022-2023加息周期详细复盘（与当前最相关）

**背景**：
- 2021年CPI飙升至7%，市场批评美联储"暂时性通胀"误判
- 2022年3月开启加息（0.25%），随后加速（5月50bp，6月75bp）

**关键时间节点**：

**软着陆成功要素**：
1. 劳动力市场极强（初始失业率3.4%，历史最低）
2. 通胀预期锚定良好（长期breakeven未大幅脱锚）
3. 供给侧改善（供应链正常化，能源价格回落）
4. 政策沟通清晰（鲍威尔明确传递加息路径）
5. 经济结构变化（服务业主导，劳动力老龄化降低菲利普斯曲线陡峭程度）

## 五、当前周期定位（2026年）

### 5.1 当前关键数据

根据FRED数据（2026年5月）：
- **联邦基金利率**: ~3.63%（3.50-3.75%目标区间）
- **10Y国债**: 4.38%（实际收益率约2.0%，仍偏高）
- **CPI**: 3.2%（核心PCE应接近2.5%）
- **失业率**: 4.3%
- **10Y-2Y利差**: -0.37%（持续倒挂）

### 5.2 美联储当前处境

**问题1：实际利率仍然偏高**
```
实际利率 = 名义利率 - 通胀
         = 3.63% - 3.2%
         = +0.43%（正实际利率，紧缩立场）
         
但：10Y实际收益率 ≈ 4.38% - 3.2% ≈ 1.18%（更高）
→ 长端实际利率仍然偏高，对经济构成压力
```

**问题2：利差持续倒挂**
- T10Y2Y = -0.37bp，持续倒挂已超过18个月
- 历史：持续深度倒挂后通常跟随衰退（但2020s例外）
- 可能的解释：期限溢价异常（QE后遗症），或市场定价错误

**问题3：通胀粘性**
- 服务业主通胀（住房、医疗）回落缓慢
- 工资增长：~4%/年（仍高于2%目标所需的3-3.5%）

### 5.3 基准情景预测

| 情景 | 概率 | 触发条件 | 利率路径 |
|:-----|:----:|:---------|:---------|
| **软着陆（基准）** | 45% | CPI持续回落至2.5%，失业率<5% | 2026年降息2-3次（50-75bp） |
| **不着陆** | 25% | CPI回升至4%+，劳动力市场过热 | 加息1-2次，然后观望 |
| **浅衰退** | 20% | 失业率升至5.5%+，信贷市场收紧 | 2026Q4前降息4-5次 |
| **滞胀** | 10% | 油价冲击+CPI>5%+增长停滞 | 利率维持高位，衰退加深 |

## 六、政策响应评估模板

### 当分析FOMC会议时，使用以下检查清单：

**Step 1：评估通胀压力**
- CPI同比 vs 目标（2%）：差距越大，加息压力越大
- 核心PCE：更可靠的通胀趋势指标
- 通胀预期：5Y breakeven > 2.5% → 风险上升

**Step 2：评估就业市场**
- 失业率 vs 自然失业率（~4.2%）：低于自然率 → 过热信号
- JTSJOL职位空缺：>1000万 → 极度紧张
- ICSA趋势：持续上升 → 裁员增加

**Step 3：评估金融条件**
- 信用利差（BAA10Y-DGS10）：>200bp → 紧缩过度风险
- 股市：从高点跌>20% → 负财富效应
- 美元指数（DXY/DTWEXBGS）：强美元抑制进口通胀

**Step 4：综合评分**

```
FOMC响应信号：
- 通胀过热 + 就业强劲 → 加息
- 通胀下行 + 就业稳健 → 按兵不动/降息试探
- 通胀粘性 + 就业疲软 → 滞胀两难
- 市场大跌 + 信贷收紧 → 宽松信号
```
