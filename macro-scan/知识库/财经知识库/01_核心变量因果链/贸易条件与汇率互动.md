# 贸易条件与汇率互动

## 核心传导链

```
贸易条件改善 → 出口价格↑/进口价格↓ → 贸易顺差↑
            ↓
         本币需求↑ → 汇率升值 → 出口竞争力↓
            ↓
         实际收入↑ → 国内消费↑ → 进口↑
            ↓
         贸易条件改善效应部分抵消
```

## 关键概念

### 贸易条件（Terms of Trade）
- **定义**：出口价格指数 / 进口价格指数
- **改善**：出口价格上涨快于进口（或进口下跌）
- **恶化**：进口价格上涨快于出口

### 实际汇率 vs 名义汇率
- **名义汇率**：市场报价的汇率
- **实际汇率** = 名义汇率 × (外国物价/本国物价)
- **实际汇率升值** → 出口竞争力下降

## 传导机制

### 1. 价格传导
```
大宗商品价格↑ → 资源出口国贸易条件改善
             → 贸易顺差↑ → 外汇储备↑
             → 本币升值压力 → 央行干预或汇率升值
```

### 2. 收入传导
```
贸易条件改善 → 实际收入↑ → 国内消费↑
             → 进口需求↑ → 贸易顺差部分抵消
```

### 3. 资本流动传导
```
贸易顺差↑ → 外汇流入↑ → 本币升值压力
         → 央行买入外汇 → 外汇储备↑
         → 基础货币↑ → 通胀风险（如不冲销）
```

## 不同经济体的典型模式

### 资源出口国（澳大利亚、加拿大、智利）
- **大宗商品繁荣**：贸易条件大幅改善
- **荷兰病风险**：资源部门繁荣 → 汇率升值 → 制造业萎缩
- **政策应对**：主权财富基金、财政规则

### 制造业出口国（德国、中国、日本）
- **贸易条件相对稳定**：进出口价格联动
- **汇率敏感度高**：升值直接压缩利润
- **竞争力维持**：生产率提升、产业升级

### 资源进口国（日本、韩国、印度）
- **大宗商品涨价**：贸易条件恶化
- **成本推动通胀**：进口价格传导
- **汇率贬值压力**：贸易逆差扩大

## 汇率制度的影响

### 浮动汇率
- 贸易条件改善 → 自动升值 → 自动调节
- 缓解央行干预压力
- 但可能过度波动

### 固定/管理汇率
- 贸易条件改善 → 央行买入外汇 → 外汇储备积累
- 需冲销操作防止通胀
- 积累失衡风险

### 一篮子货币
- 根据贸易权重调整
- 降低对单一货币波动
- 中国参考一篮子货币

## 历史案例

### 2000年代大宗商品超级周期
- 铁矿石、石油价格大涨
- 澳大利亚贸易条件从60升至100+
- 澳元从0.50升至1.10（兑美元）
- 制造业占比下降（荷兰病症状）

### 2014年石油价格暴跌
- 产油国贸易条件恶化
- 俄罗斯卢布贬值50%+
- 沙特财政赤字扩大
- 挪威主权基金缓冲

### 2022年俄乌战争
- 能源价格飙升 → 欧洲贸易条件恶化
- 欧元贬值
- 德国贸易顺差收窄

## 当前动态（2026）

### 美国
- 页岩油/气出口 → 能源自给 → 贸易条件改善
- 美元强势 → 制造业出口承压

### 中国
- 产业升级 → 出口附加值提高
- 人民币管理浮动
- 一带一路多元化贸易

### 欧洲
- 能源转型 → 减少对俄依赖
- 但转型成本推高进口价格

## 政策含义

### 对资源出口国
- 建立稳定基金（挪威、智利模式）
- 避免顺周期财政支出
- 投资人力资本和基础设施

### 对制造业出口国
- 生产率提升抵消汇率升值
- 产业升级提高附加值
- 汇率灵活性增强调节能力

### 对资源进口国
- 能源多元化降低依赖
- 战略储备缓冲价格冲击
- 本币贬值时收紧货币政策
