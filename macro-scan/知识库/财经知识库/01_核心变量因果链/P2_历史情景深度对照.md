## C01：1929大萧条（1929-1939）— 史上最深衰退

### 背景与触发
- **导火索**：1929年9-10月股票市场崩盘（道指从381跌至198年底的248）
- **深层原因**：金本位制度限制了货币政策灵活性；银行体系脆弱（1920-1929年间约600家银行倒闭）；农业长期不景气
- **演变**：普通银行恐慌 → 货币供给崩塌 → 物价暴跌 → 失业飙升

### 关键数据（FRED验证）
- **工业产出（INDPRO）**：从1928年高位跌至1932年7月低谷（3.689），跌幅约43%
- **CPI**：从1929年的~17.1跌至1933年的~12.9（通缩约25%）
- **失业率**：据历史数据（官方统计1930年后）最高达24.9%（1933年5月）
- **GDP**：历史估算约萎缩30-35%（部分年份年率-13%至-15%）
- **银行倒闭**：1929-1933年约9000家银行倒闭（占总数1/3）

### 政策响应
1. **1933年金本位废除**：罗斯福1933年4月签署行政令，美元贬值30%启动价格稳定
2. **罗斯福新政**：银行法(Glass-Steagall)、田纳西流域管理局、最低工资、社保体系
3. **货币政策**：从紧缩转为扩张，但银行惜贷导致流动性陷阱

### 衰退机制（因果链）
```
股市崩盘 → 财富效应 → 消费萎缩 → 企业减产
    ↓
银行恐慌（600家倒闭/1929-30） → 信贷收缩
    ↓
金本位约束 → 货币供给被动收缩
    ↓
物价暴跌(通缩螺旋) → 实际债务负担上升 → 更多违约 → 银行更多倒闭
    ↓
失业率飙升 → 消费进一步萎缩（恶性循环）
```

### 关键教训
- **政策滞后**：胡佛政府坚持金本位+预算平衡1930-32年，加剧通缩（教训：危机初期需快速宽松）
- **银行恐慌的放大器效应**：单一银行倒闭可通过银行间支付系统传导
- **通缩螺旋的自我强化**：债务实际价值上升 → 违约增加 → 银行资产恶化 → 惜贷
- **推理触发条件**：CPI同比<-2%且失业率>10%且银行体系承压 → 可参照大萧条机制

## C02：1987年10月19日黑色星期一 — 程序化踩踏

### 背景与触发
- **导火索**：1987年10月19日（周一）道指暴跌22.6%，为史上最大单日跌幅
- **放大机制**：组合保险（portfolio insurance）程序化卖出 + 流动性枯竭
- **背景**：1987年美股估值偏高（CAPE约21倍）；程序化交易在下跌时形成正反馈卖出

### 关键数据（FRED验证）
- **失业率**：1987年初7.3% → 1992年峰值7.8%（加息周期尾声）
- **10Y国债**：1985年初高峰11.7% → 1987年10月约10% → 1992年低位6.23%
- **2Y国债**：1985年高峰10.03% → 1992年低位3.67%
- **10Y-2Y利差**：1989年3月倒挂-0.45bp（滞后于危机）

### 政策响应
1. **格林斯潘紧急降息**：10月20日（周二）宣布"提供流动性"，联邦基金利率下调
2. **熔断机制（B Circuit Breaker）**：1988年SEC引入个股和指数级熔断
3. **总统声明**：里根总统和财政部长贝克发表声明稳定市场信心

### 衰退机制（因果链）
```
程序化卖出 → 股价下跌 → 触发更多程序化卖出
    ↓
流动性枯竭（bid-side消失） → 跌幅远超基本面
    ↓
格林斯潘紧急降息 → 流动性注入 → 恐慌平息
    ↓
1988年后震荡修复
```

### 关键教训
- **程序化交易的踩踏效应**：1987年的组合保险在下跌时强制卖出，放大跌幅
- **熔断机制的有效性**：1988年后引入的熔断有效防止了类似踩踏
- **VIX暴涨的指示意义**：VIX从14飙升至150+后，快速政策响应平息恐慌
- **推理触发条件**：VIX>40且下跌由程序化卖出主导 → 可参照流动性踩踏机制

## C03：2000科网泡沫（2000-2003）

### 背景与触发
- **导火索**：2000年3月10日NASDAQ见顶5048；4月微软反垄断案 + 美联储加息 + 盈利泡沫破裂
- **深层原因**：科技公司过度资本支出+盈利造假（安然/世通）；互联网用户渗透率接近饱和
- **导火索引爆**：盈利不及预期 → 股价下跌 → 抵押贷款炒股爆仓 → 强制平仓

### 关键数据（FRED验证）
- **失业率**：2000年4月低点3.8% → 2003年6月峰值6.3%（增加约300万人失业）
- **10Y国债**：2000年1月高峰6.79% → 2003年6月低谷3.13%
- **2Y国债**：2000年5月高峰6.93% → 2003年6月低谷1.10%（极度平坦）
- **INDPRO（工业产出）**：2000年6月高峰 → 2001年Q4低谷（信息技术相关产出暴跌）
- **非农就业**：2001年2月见顶132,788K → 2003年2月低谷130,589K（减少约220万）
- **S&P500**：从2000年3月1553（历史高位，按当时记录）跌至2002年10月735（-52.6%）

### 政策响应
1. **格林斯潘降息**：联邦基金利率从6.5%（2001年1月）降至1%（2003年6月）
2. **小布什财政扩张**：2001年减税、2003年第三轮减税（Jobs and Growth Tax Relief Act）
3. **9/11后宽松**：进一步降息+国土安全支出

### 衰退机制（因果链）
```
互联网渗透率见顶 → 盈利增长减速
    ↓
盈利不及预期 → 股价下跌 → 科技股估值(PE)崩塌
    ↓
抵押股票融资爆仓 → 强制平仓
    ↓
财富效应 → 消费减速 → 非科技公司盈利也受影响
    ↓
裁员增加 → 消费进一步萎缩
    ↓
估值恢复需要盈利追上（2003年后）
```

### 关键教训
- **估值的均值回归**：高估值（CAPE>30）最终需要盈利大幅增长或股价下跌来匹配
- **盈利泡沫（Enron/WorldCom）的审计失败**：制度性缺陷加剧恐慌
- **利率敏感的延迟效应**：降息到经济稳定有12-18个月滞后
- **推理触发条件**：CAPE>30 + 科技股PE>50 + 盈利下调趋势 → 可参照科网泡沫

## C04：2008金融海啸（2007-2012）— 大萧条以来最严重危机

### 背景与触发
- **导火索**：2007年Q2次级房贷拖欠率上升 → 2007年8月BNP Paribas冻结货币基金 → 信贷市场冻结
- **演变**：次贷 → MBS → CDO → 有毒资产 → 银行资本金蒸发 → 雷曼倒闭（2008-09-15）→ 全球信贷冻结
- **深层原因**：监管放松（1999年GLB法废除Glass-Steagall）、影子银行膨胀、风险模型错误

### 关键数据（FRED验证）
- **失业率**：2006年10月低点4.4% → 2009年10月峰值10.0%（+560bp，增加870万失业）
- **非农就业**：2007年12月见顶138,395K → 2010年2月低谷129,706K（减少约870万）
- **10Y国债**：2007年6月高峰5.26% → 2012年7月低谷1.43%（避险资金流入）
- **2Y国债**：2006年6月高峰5.29% → 2011年9月低谷0.16%（近零利率）
- **工业产出**：2007年12月高峰 → 2009年6月低谷（-17.5%，战后最严重）
- **10Y-2Y利差**：2006年11月短暂倒挂 → 2007年深度倒挂 → 衰退确认

### 政策响应
1. **救助AIG**（2008-09-16）：Fed向AIG提供850亿美元过桥贷款（防止CDS清算链崩塌）
2. **雷曼倒闭**：没有买家，破产引发全球恐慌
3. **TARP法案**（2008-10-03）：7000亿美元救助银行
4. **QE1**（2008-11-2010-03）：购买1.75万亿MBS/国债
5. **联邦基金利率**：从5.25%（2007年9月）降至0-0.25%（2008-12-16）
6. **扭曲操作**（Operation Twist，2011-2012）：压低长期利率
7. **欧洲央行LTRO**（2011-2012）：向欧洲银行提供3年期低息贷款

### 衰退机制（因果链）
```
次级房贷 → CDO结构复杂化 → 评级机构误判 → 银行资产负债表隐含有毒资产
    ↓
房价下跌 → 次贷违约率上升 → CDO减值 → 银行资本金蒸发
    ↓
雷曼倒闭 → 信用违约掉期(CDS)清算恐慌 → 信贷市场冻结
    ↓
银行惜贷 → 企业融资困难 → 裁员 → 消费萎缩
    ↓
信用卡违约 → 消费进一步萎缩 → 衰退加深
    ↓
M2暴增但货币乘数崩塌 → 流动性陷阱风险
```

### 关键教训
- **系统重要性机构的"大而不能倒"困境**：雷曼不救助导致全球恐慌，后续用TARP救助其他人
- **影子银行的脆弱性**：SPV/SIV不在银行资产负债表内，监管盲区
- **有毒资产的传染性**：CDO评级机构失职，复杂化掩盖了风险
- **避险与风险资产的两极化**：国债和黄金暴涨，高收益债崩溃
- **推理触发条件**：银行间隔夜拆借利率飙升 + 商业票据利差扩大 + 信用违约互换飙升 → 可参照金融海啸机制

## C05：2010欧债危机（2009-2012）

### 背景与触发
- **导火索**：2009年10月希腊政府承认财政数据造假，赤字率达12.7%；随后评级机构连续下调希腊主权评级
- **演变**：希腊 → 爱尔兰 → 葡萄牙 → 西班牙（银行危机） → 意大利（政治危机）
- **深层原因**：欧元区制度缺陷（统一货币+独立财政）；边缘国家竞争力的相对丧失；银行持有大量主权债

### 关键数据（欧元区整体）
- **GDP（美国GDP参考）**：2008年高峰 → 2009年低谷（-3.1%）
- **失业率**：2008年2月低点4.9% → 2009年10月峰值10.0%
- **边缘国家10Y国债**：希腊10Y一度超过1000bp；西班牙、意大利10Y达600-700bp
- **ECB政策**：2011年加息（错误！滞后于美联储）→ 2012年降息+LTRO + OMT（2012-09，宣布无限量购债）

### 政策响应
1. **希腊救助**（2010-05）：EU/IMF 1100亿欧元贷款 + 财政紧缩条件
2. **爱尔兰/葡萄牙救助**：EU/IMF提供贷款
3. **欧洲金融稳定基金（EFSF）**：4400亿欧元担保
4. **ECB的OMT**（2012-09-06）：德拉吉"不惜一切代价"，无限量购买三年期国债 → 危机平息
5. **财政紧缩条件**：附加条件导致边缘国家深度衰退，加剧政治动荡

### 衰退机制（因果链）
```
希腊财政数据曝光 → 评级下调 → 国债收益率飙升
    ↓
银行持有希腊国债减值 → 银行资产负债表恶化
    ↓
爱尔兰房地产崩盘 → 银行危机 → 救助 → 主权债务增加
    ↓
投资者担忧蔓延至西班牙/意大利 → 欧洲央行观望（2011年加息错误）
    ↓
德拉吉OMT宣布 → 危机逆转
```

### 关键教训
- **货币同盟+独立财政的制度缺陷**：无法内部贬值，只能通过内部贬值（工资/物价下跌）
- **ECB延迟行动的代价**：2011年加息加剧衰退；2012年OMT才稳住市场
- **紧缩政策的双刃剑**：财政紧缩加剧衰退，税收减少反而扩大赤字
- **推理触发条件**：边缘国家10Y利差>400bp + ECB资产负债表收缩 → 可参照欧债危机

## C06：2015年中国A股股灾（2015-2016）

### 背景与触发
- **导火索**：2015年6月12日上证综指见顶5178点；杠杆牛市（融资融券+场外配资）崩盘
- **深层原因**：场外配资（P2P贷款流入股市）+ 杠杆率高（估算1-10倍）+ 散户主导的市场结构
- **政策失误**：2016年1月引入熔断机制（沪深300指数触及5%/7%熔断），反而加速恐慌

### 关键数据（FRED/历史验证）
- **上证综指**：2015-06-12高峰5178 → 2016-01-27低谷2638（-49.1%）
- **USD/CNY**：2015年8月汇改前约6.20 → 2016年底约6.90（贬值约11%）
- **国内M2/流动性**：2015年降息降准，但场外资金快速外流
- **失业率**：数据区间内（2013-2017）约4.1-8.0%，变化不显著

### 政策响应
1. **央行双降**：2015年降息（5次）+ 降准（4次）；一年期存款基准利率从2.75%降至1.5%
2. **国家队救市**：证金公司+21家券商+公募基金买入蓝筹股稳定市场
3. **暂停IPO**：2015年7月IPO暂停4个月
4. **熔断机制暂停**：2016年1月8日（实施仅4天后）暂停
5. **资本管制加强**：限制外汇流出

### 衰退机制（因果链）
```
宽松货币+监管松散 → 场外配资激增 → 杠杆牛市
    ↓
监管清查场外配资 → 强制平仓 → 踩踏
    ↓
流动性枯竭 → 指数暴跌 → 融资盘爆仓 → 进一步强制平仓
    ↓
恐慌蔓延至汇率 → 资本外流 → 央行外汇干预 → 外汇储备下降
    ↓
熔断机制反而加剧恐慌（磁吸效应）
```

### 关键教训
- **杠杆牛市+监管松散=必然泡沫破裂**：场外配资是系统性风险
- **熔断机制需要适配市场结构**：A股散户主导+涨跌停板=磁吸效应
- **汇率与股市的联动**：资本外流压力在股灾后明显上升
- **国家队干预的局限性**：无法改变基本面，只能延缓跌势
- **推理触发条件**：杠杆率快速上升 + 监管清查配资 + 汇率承压 → 可参照A股股灾

## C07：2020新冠冲击（2020Q1-Q2）— 史上最快政策响应

### 背景与触发
- **导火索**：2020年1月COVID-19全球扩散 → 3月WHO宣布大流行 → 各国封锁
- **特点**：供给冲击（封锁）而非需求冲击；下跌速度史无前例（33天从高点跌入熊市）
- **特殊背景**：2020年2月美国经济处于历史最强状态之一（低失业率+GDP增长）

### 关键数据（FRED验证）
- **GDP**：2020Q1（年化）下跌4.3% → Q2下跌31.2%（战后最严重，单季年化-31.2%=实际-8.8%）
- **失业率**：2019年9月低点3.5% → 2020年4月峰值14.8%（大萧条后最高，增加约2200万失业）
- **非农就业**：2020年2月高峰155,165K → 2020年4月低谷130,426K（减少约2474万，两月内）
- **10Y国债**：2020年2月高峰2.66% → 2020年8月低谷0.52%（避险资金流入）
- **M2货币供应**：2020年1月$14.46万亿 → 2022年3月高峰$21.79万亿（+50.7%，QE）
- **工业产出**：2019年高位 → 2020年4月低谷（INDPRO指数约84.562，-18%）

### 政策响应
1. **美联储**：降息至0-0.25% + QE无限量（3月23日宣布）+ 大规模流动性工具（CPFF/MMLF/TSLF）
2. **财政刺激**：CARES Act（2.2万亿，2020-03-27）+ PPP + 每周$600额外失业救济
3. **总财政规模**：约$5万亿（含后续刺激）
4. **疫苗**：2020年12月辉瑞/Moderna疫苗紧急授权 → 2021Q2经济重新开放

### 衰退/复苏机制（因果链）
```
COVID-19全球扩散 → 各国封锁 → 消费/生产骤停
    ↓
失业率飙升（非自愿性） → 消费萎缩
    ↓
美联储+财政部联合出击 → 直升机撒钱
    ↓
居民储蓄率飙升（可支配收入增加） → 封锁解除后V型反弹
    ↓
需求激增+供应链瓶颈 → 通胀飙升（2021-2022后遗症）
```

### 关键教训
- **V型复苏的独特性**：封锁是供给冲击而非需求冲击，解封后需求快速恢复
- **超宽松政策的后遗症**：M2+50%导致2021-2022年高通胀（CPI峰值9.1%）
- **政策协调的重要性**：美联储+财政部的协调行动比单独行动更有效
- **失业救济的意外效果**：每周$600额外补贴反而降低就业意愿（2020Q3）
- **推理触发条件**：供给冲击+家庭资产负债表未受损+政策快速响应 → V型复苏概率高

## C08：2022美联储急加息（2022-2023）— 成功软着陆案例

### 背景与触发
- **导火索**：2021年供应链瓶颈+能源价格+住房租金上涨 → CPI持续超预期
- **深层原因**：2020-2021年超量宽松政策后遗症；劳动力市场极度紧张（职位空缺>1000万）
- **特殊背景**：通胀性质混合（供给侧+需求侧）；俄乌战争（2022-02）加剧能源/食品通胀

### 关键数据（FRED验证）
- **CPI**：2022年6月峰值9.1%（1981年以来最高）
- **联邦基金利率**：2022年3月0.25% → 2023年7月5.25-5.50%（11次加息，+500bp）
- **失业率**：2022年3月低点3.4%（50年最低！） → 2023年2-3月峰值6.4%（硅谷银行危机） → 2024年4.1%
- **10Y国债**：2021年初0.93% → 2023年10月高峰4.98%（加息传导）
- **2Y国债**：2021年2月低点0.09% → 2023年10月高峰5.19%（极度倒挂）
- **10Y-2Y利差**：2022年12月深度倒挂-1.08bp（1980年以来最深度倒挂）
- **GDP**：2022全年正增长（未衰退） → 2023年稳健增长
- **S&P500**：2022年1月4796 → 2022年10月低谷3577（-25.4%），2024年创新高

### 政策响应
1. **史上最速加息**：2022年单年加息7次（累计425bp）；2023年再加息4次至5.25-5.50%
2. **缩表（QT）**：2022年6月开始每月缩表$950亿
3. **前瞻指引**：鲍威尔清晰沟通加息路径，市场预期锚定较好
4. **软着陆成功**：2023年下半年开始降息预期升温；失业率峰值6.4%远低于历史危机水平

### 加息传导机制（因果链）
```
大规模QE+财政刺激 → 需求过热 → 供给瓶颈 → 通胀
    ↓
美联储激进加息 → 抵押贷款利率上升 → 房市降温
    ↓
科技公司估值压缩（利率敏感） → 科技股暴跌
    ↓
银行持有长久期资产减值 → 硅谷银行倒闭（2023-03）
    ↓
信贷条件收紧 → 消费减速 → 通胀回落
    ↓
软着陆：通胀回落+失业率仅温和上升+GDP正增长
```

### 关键教训
- **软着陆的可能性**：当劳动力市场初始极强时，有一定缓冲空间
- **前瞻指引的价值**：清晰的沟通帮助锚定长期通胀预期
- **加息传导的滞后性**：2022年3月加息，但通胀到2023年才明显回落
- **金融条件指数的重要性**：不只是政策利率，还需关注整体金融条件（信用利差+股市+汇率）
- **软着陆的窗口**：就业市场过热+通胀刚起来时加息，衰退概率较低
- **推理触发条件**：通胀>6%且劳动力市场紧张 + 政策利率<2% → 需快速加息 → 可参照本情景
