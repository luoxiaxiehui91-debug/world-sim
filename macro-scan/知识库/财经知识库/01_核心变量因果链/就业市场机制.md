## 二、贝弗里奇曲线

### 2.1 定义

失业率与职位空缺率的负相关关系

```
职位空缺率
    ↑
    │   ╱
    │  ╱  正常曲线
    │ ╱
    │╱
    └────────→ 失业率
```

### 2.2 曲线移动的含义

| 移动方向 | 含义 | 原因 |
|----------|------|------|
| 向外移动 | 匹配效率↓ | 技能错配、地理错配 |
| 向内移动 | 匹配效率↑ | 在线招聘、培训改善 |

### 2.3 当前状态分析（2024）

- 空缺率：~5%（高位）
- 失业率：~4%（低位）
- 空缺/失业比：~1.5（劳动力紧张）

**解读**：曲线向外移动，匹配效率下降（疫情后结构性变化）

## 三、菲利普斯曲线

### 3.1 原始菲利普斯曲线

失业率与通胀的负相关关系

```
通胀率
    ↑
    │ ╲
    │  ╲
    │   ╲
    │    ╲
    └─────→ 失业率
```

### 3.2 附加预期的菲利普斯曲线

```
通胀 = 预期通胀 - β × (失业 - 自然失业) + 供给冲击
```

**含义**：
- 只有当失业<自然失业时，通胀才高于预期
- 长期：垂直线（失业=自然失业）

### 3.3 菲利普斯曲线平坦化

| 时期 | 曲线斜率 | 原因 |
|------|----------|------|
| 1960-1980 | 陡峭 | 预期未锚定 |
| 1990-2020 | 平坦 | 预期锚定、全球化 |
| 2021-2022 | 重新陡峭？ | 供给冲击主导 |

## 四、自然失业率

### 4.1 定义

不引发通胀加速的失业率（NAIRU）

### 4.2 估计

| 时期 | NAIRU估计 | 原因 |
|------|-----------|------|
| 1980s | 6-7% | 结构性高 |
| 1990s | 5-6% | 改善 |
| 2000s | 4.5-5% | 继续改善 |
| 2010s | 4-4.5% | 进一步改善 |
| 2020s | 4-4.5% | 疫情后不确定 |

### 4.3 影响因素

| 因素 | 影响 |
|------|------|
| 人口结构 | 老龄化→自然失业率↓ |
| 匹配效率 | 效率↑→自然失业率↓ |
| 劳动力市场制度 | 灵活→自然失业率↓ |
| 结构性变化 | 错配↑→自然失业率↑ |

## 五、薪资决定机制

### 5.1 薪资驱动因素

```
薪资增速 = f(
    劳动力市场紧张度,
    通胀预期,
    生产率增速,
    最低工资,
    工会谈判力
)
```

### 5.2 薪资-生产率关系

长期：薪资增速 ≈ 生产率增速 + 通胀

| 情况 | 含义 |
|------|------|
| 薪资 > 生产率+通胀 | 单位劳工成本↑→利润压缩 |
| 薪资 = 生产率+通胀 | 可持续 |
| 薪资 < 生产率+通胀 | 劳动份额下降 |

### 5.3 监控指标

| 指标 | FRED代码 | 正常范围 |
|------|----------|----------|
| 时薪同比 | CES0500000003 | 3-4% |
| ECI同比 | ECIWAG | 3-4% |
| 生产率 | OPHNFB | 1-2% |
| 单位劳工成本 | ULCNFB | ≈通胀 |

## 六、就业与经济周期

### 6.1 就业的周期性

| 阶段 | 就业表现 | 失业率变化 |
|------|----------|------------|
| 扩张早期 | 就业快速增加 | 快速下降 |
| 扩张晚期 | 就业增长放缓 | 企稳低位 |
| 衰退早期 | 就业快速减少 | 快速上升 |
| 衰退晚期 | 就业企稳 | 高位企稳 |

### 6.2 就业的滞后性

就业是滞后指标：
- 衰退开始后，就业才明显恶化
- 复苏开始后，就业最后改善

**原因**：
- 企业先减产，再裁员
- 复苏时先增加工时，再招人

### 6.3 Sahm规则

**定义**：失业率3月均值 - 过去12月最低值 > 0.5%

**意义**：实时衰退指标，比NBER更及时

## 七、当前就业市场分析（2024-2026）

### 7.1 现状

| 指标 | 数值 | 评价 |
|------|------|------|
| 失业率 | 3.7% | 历史低位 |
| 劳动参与率 | 62.5% | 略低于疫情前 |
| 职位空缺 | 850万 | 高位但下降 |
| 空缺/失业比 | 1.4 | 劳动力紧张 |
| 薪资增速 | 4% | 高于趋势 |

### 7.2 结构性变化

- 提前退休（劳动参与率↓）
- 远程办公（办公需求↓）
- 技能错配（匹配效率↓）
- "大辞职潮"后遗症
