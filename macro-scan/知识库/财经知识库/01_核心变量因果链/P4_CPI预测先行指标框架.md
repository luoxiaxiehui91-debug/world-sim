# P4：CPI通胀预测先行指标框架

> 本文档提供CPI通胀的预测框架，涵盖需求拉动型、成本推动型、预期锚定型三类通胀的先行指标体系。
> 数据来源：FRED时序数据库（已收录：CPIAUCSL, PCECTPI, MICH, PPIFIS, M2SL, DCOILWTICO, DEXCHUS, CSUSHPINSA）

---

## 一、通胀的类型与来源

### 1.1 三种通胀机制

| 类型 | 驱动因素 | 典型案例 | 政策响应 |
|:-----|:---------|:---------|:---------|
| **需求拉动型** | 总需求超过潜在产出 | 2021-2022美国超额财政刺激 | 收紧货币政策抑制总需求 |
| **成本推动型** | 供给侧冲击（能源/食品/供应链） | 1970s石油危机、2022俄乌 | 供给管理+短期忍受 |
| **预期锚定型** | 通胀预期自我实现（工资-物价螺旋） | 1970s大滞胀 | 前瞻指引+可信的央行承诺 |

### 1.2 核心CPI指标体系

| 指标 | FRED代码 | 更新频率 | 覆盖范围 |
|:-----|:---------|:---------|:---------|
| CPI同比 | CPIAUCSL | 月度 | 总体通胀（基准） |
| PCE同比 | PCECTPI | 月度 | 美联储首选通胀指标 |
| 核心PCE | PCECTPI | 月度 | 波动性更小 |
| 通胀预期（5Y breakeven） | DGS5-T5YIE | 日度 | 5年市场预期 |
| 通胀预期（10Y breakeven） | DGS10-T10YIE | 日度 | 10年市场预期 |
| 密歇根消费者长期预期 | MICH | 月度 | 定性通胀预期 |

|:-----|:-----------|:---------|:------------|

| **供应链压力指数** | 1-2个月 | 全球供应链瓶颈推高商品价格 | r=0.7 |
| **制造业PMI交付时间** | 1-3个月 | 交付延迟→供给不足→通胀 | r=0.6 |
| **WSJ调查通胀预期** | 1-3个月 | 专业预测者预期自我实现 | r=0.7 |

### 2.2 中期指标（3-12个月）

| 指标 | 领先CPI周期 | 预测逻辑 | 历史相关系数 |
|:-----|:-----------|:---------|:------------|
| **M2货币供应同比** | 6-12个月 | 货币超发→需求过剩→通胀 | r=0.6 |

| **USD/CNY汇率** | 3-6个月 | 美元贬值→进口通胀 | r=0.5 |

### 2.3 长期指标（12-36个月）

| 指标 | 领先CPI周期 | 预测逻辑 | 历史相关系数 |
|:-----|:-----------|:---------|:------------|
| **10Y breakeven通胀率** | 12-24个月 | 长期通胀预期的锚定 | r=0.8 |

| **M2/GDP比率** | 18-36个月 | 货币深化程度与长期通胀关系 | r=0.7 |

## 三、关键指标的预测逻辑详解

### 3.1 原油 → CPI能源项

```
DCOILWTICO（WTI原油价格）
    ↓
CPI能源项（权重约8-10%）
    ↓
CPI总体（能源项传导系数约0.08）
    ↓
传导滞后：1-3个月（非线性，有突变阈值）
```

**关键阈值**：
- 原油>100美元/桶：CPI能源项贡献>+1.5pp
- 原油>120美元/桶：社会/政治压力，可能倒逼政策
- 原油<50美元/桶：CPI能源项贡献<-0.5pp，通缩压力

### 3.2 M2 → CPI（货币数量论）

```
M2同比变化率
    ↓
货币流通速度调整
    ↓
MV=PY（费雪方程式）
    ↓
通胀率 ≈ M2增速 + 流通速度变化 - GDP增速
```

**历史验证**：
- 2020-2021年：M2同比+25%，通胀12-18个月后升至9.1%
- 1970s：M2持续高增，但通胀受供给冲击主导
- 2010s：M2高增但通胀持续低于2%（流动性陷阱）

### 3.3 通胀预期 → 实际通胀（自实现机制）

```
10Y breakeven = DGS10 - TIPS_real_yield
    ↓
Breakeven > 3%：市场定价通胀超标
    ↓
工资谈判上调（合同通常含通胀保护条款）
    ↓
工资-物价螺旋（1970s模式）
    ↓
实际通胀上升
```

**关键锚定指标**：
- **MICH<2.5%**：通胀预期良好锚定，央行可信
- **MICH>3.5%**：预期开始脱锚，工资螺旋风险
- **Breakeven>3%**：市场定价再通胀
- **Breakeven>4%**：严重通胀定价，可能引发政策过度收紧

## 四、通胀拐点预测矩阵

### 4.1 拐点识别信号

| 拐点方向 | 领先信号 | 触发条件 | 历史平均领先时间 |
|:---------|:---------|:---------|:--------------|
| **CPI见顶** | 原油价格下跌 | 原油环比-15%以上 | 2-4个月 |
| **CPI见顶** | M2同比转负 | M2同比<-5% | 6-9个月 |
| **CPI见顶** | 职位空缺下降 | JTSJOL环比-10% | 6-12个月 |
| **CPI见底** | 油价触底反弹 | 原油环比+20%以上 | 1-2个月 |
| **CPI见底** | M2同比回升 | M2同比>+10% | 6-9个月 |
| **CPI持续性风险** | breakeven上升 | breakeven>+1pp/月 | 即时 |

### 4.2 通胀情景矩阵

| M2趋势 | 原油趋势 | 通胀预期 | 预测情景 |
|:-------|:---------|:---------|:---------|
| ↓下降 | ↓下降 | 锚定<3% | **良性消退**：通胀自然回落，软着陆 |
| ↓下降 | ↑上升 | 上升>3% | **滞胀风险**：货币紧+供给冲击，政策两难 |
| ↑上升 | ↑上升 | 上升>3% | **失控通胀**：需求+成本双驱动，需强力收紧 |
| ↑上升 | ↓下降 | 锚定<2.5% | **金发女孩**：理想情景，央行可以保持宽松 |

## 五、CPI分项权重与传导分析

### 5.1 CPI主要分项（2024年参考权重）

| 分项 | 权重 | 波动性 | 先行指标 |
|:-----|:-----|:------|:---------|
| 住房（OER+Utilities） | ~33% | 低 | CSUSHPINSA（房价），利率（MORTGAGE30US） |
| 交通运输 | ~17% | 高 | DCOILWTICO（油价） |
| 食品 | ~13% | 中 | 农产品指数，进口价格 |
| 医疗服务 | ~7% | 低 | 工资增长，医疗保险通胀 |
| 教育通信 | ~6% | 低 | 工资增长 |
| 服装 | ~3% | 高 | 进口价格，供应链 |
| 娱乐 | ~5% | 中 | 综合 |

### 5.2 核心CPI vs 总体CPI

- **总体CPI**：含能源和食品，波动大，政策关注度较低
- **核心CPI（Core=CPI excl. Food&Energy）**：更反映基础通胀趋势
- **PCE核心**：美联储实际目标指标，更全面（考虑替代效应）

**预测建议**：重点跟踪核心PCE，兼顾核心CPI（市场常用）

## 六、通胀实时预测模板

### Step 1：查M2趋势（判断中期方向）
```
M2同比 > 15% → 未来6-12个月通胀压力上升
M2同比 > 25% → 类似2020-2021，通胀失控风险
M2同比 < 5% → 通胀消退信号
M2同比 < 0% → 通缩风险
```

### Step 2：查原油（判断短期方向）
```
原油 > 100美元 → CPI能源项+1pp至+2pp
原油 > 120美元 → 社会/政治压力，可能政策干预
原油从高位下跌 > 20% → 未来3个月CPI能源项回落
```

### Step 3：查通胀预期（判断持续性）
```
Breakeven < 2% → 通胀预期锚定，政策从容
Breakeven 2-3% → 警惕但可控
Breakeven 3-4% → 需要政策回应
Breakeven > 4% → 严重通胀，脱锚风险
```

### Step 4：综合评分

```
# 通胀上行风险信号
+ M2同比 > 10%
+ 原油 > 80美元
+ Breakeven > 2.5%
+ 失业率 < 4%（菲利普斯曲线压力）
+ 工资增长 > 4%YoY
+ 产出缺口 > 2%

# 通胀下行风险信号
- M2同比 < 5%
- 原油 < 70美元
- Breakeven < 2%
- 失业率 > 5.5%
- 产能利用率 < 75%
- 消费收缩

# 综合判断：
上行信号 > 4个 → 未来3-6个月CPI同比 > 4%，美联储难以宽松
各半 → CPI同比 3-4%，政策两难
下行信号 > 4个 → CPI同比 < 3%，关注通缩风险
```

## 七、历史数据验证（FRED时序数据库）

### 关键历史验证点

| 时期 | CPI峰值 | M2同比峰值 | 原油峰值 | Breakeven峰值 | 触发机制 |
|:-----|:--------|:-----------|:---------|:--------------|:---------|
| 1974-1975 | 12.3% | ~10% | 1974年$12→$36 | 约8% | 石油危机+尼克松管控失败 |
| 1980 | 14.8% | ~8% | 1980年$37 | 约12% | 第二轮石油危机+货币宽松 |
| 1990 | 6.3% | ~5% | 1990年$41 | 约5% | 海湾战争油价冲击 |
| 2008 | 5.6% | ~10% | 2008年7月$145 | 约2.8% | 金融危机前大宗泡沫 |
| 2011 | 4.5% | ~10% | 2011年$113 | 约2.7% | 欧债危机+QE传导 |
| 2022 | 9.1% | ~27% | 2022年3月$130 | 约3% | 俄乌+供应链+货币超发 |

### 传导滞后实证

| 指标变化 | → CPI变化的典型滞后 |
|:---------|:------------------|
| 原油价格↑20% | CPI能源项↑约1.5-2pp（3个月） |
| M2同比↑10pp | CPI↑约0.5-1pp（6-12个月） |
| Breakeven↑1pp | CPI↑约0.3-0.5pp（3-6个月） |
| 工资增长↑2pp | 核心CPI↑约0.5pp（9-12个月） |
