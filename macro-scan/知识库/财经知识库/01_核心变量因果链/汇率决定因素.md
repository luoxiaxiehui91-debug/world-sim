# 汇率决定因素

> 核心机制：利差、购买力平价、资本流动、风险溢价
> 更新时间：2026-05-08

---

## 一、汇率决定理论

### 1.1 购买力平价（PPP）

**绝对PPP**：汇率 = 国内价格/国外价格

**相对PPP**：汇率变化 = 通胀差

```
Δe = π_dom - π_foreign
```

**局限性**：
- 短期不成立（价格粘性）
- 仅适用于可贸易品
- 忽略交易成本、关税

**长期验证**：有一定解释力，但收敛很慢

### 1.2 利率平价（IRP）

**无抛补利率平价（UIP）**：
```
i_dom = i_foreign + E[Δe]
```

含义：高利率货币预期贬值

**抛补利率平价（CIP）**：
```
i_dom = i_foreign + forward premium
```

**验证**：CIP成立较好，UIP实证支持弱

### 1.3 资产组合平衡理论

汇率由各国资产相对供给和需求决定

```
e = f(资产供给, 资产需求, 风险偏好)
```

## 二、汇率的影响因素

### 2.1 利差

**机制**：
```
利差扩大（本国利率↑）
    ↓
外资流入套利
    ↓
本币需求↑
    ↓
本币升值
```

**案例**：
- 2022-2023：美联储激进加息→美元走强
- 2024：美联储降息预期→美元走弱

### 2.2 经常账户

**机制**：
```
经常账户顺差
    ↓
外汇净流入
    ↓
本币需求↑
    ↓
本币升值
```

**悖论**：美国经常账户逆差，但美元强势
- 原因：资本账户顺差（资本流入）

### 2.3 资本流动

| 流动类型 | 驱动因素 | 对汇率影响 |
|----------|----------|------------|
| FDI | 长期回报 | 顺差→升值 |
| 证券投资 | 利差、风险 | 流入→升值 |
| 热钱 | 短期利差 | 波动大 |
| 避险流动 | 风险事件 | 流入避险货币 |

### 2.4 风险溢价

```
汇率 = 基本面价值 × 风险溢价
```

**风险溢价来源**：
- 政治风险
- 政策不确定性
- 金融脆弱性
- 地缘风险

### 2.5 央行干预

| 干预类型 | 方法 | 效果 |
|----------|------|------|
| 直接干预 | 买卖外汇 | 短期有效 |
| 间接干预 | 利率政策 | 中期有效 |
| 口头干预 | 前瞻指引 | 短期影响预期 |

## 三、美元的特殊地位

### 3.1 美元霸权来源

| 因素 | 说明 |
|------|------|
| 经济规模 | 最大经济体 |
| 金融市场 | 最深、最流动 |
| 网络效应 | 全球使用→继续使用 |
| 安全资产 | 美债避险地位 |
| 计价单位 | 大宗商品美元计价 |

### 3.2 美元指数（DXY）

**构成**：
- 欧元 57.6%
- 日元 13.6%
- 英镑 11.9%
- 加元 9.1%
- 瑞典克朗 4.2%
- 瑞士法郎 3.6%

### 3.3 美元周期

| 阶段 | 特征 | 驱动因素 |
|------|------|----------|
| 美元升值 | DXY↑ | 加息、避险、美国增长领先 |
| 美元贬值 | DXY↓ | 降息、风险偏好、美国增长放缓 |

## 四、汇率对经济的影响

### 4.1 对贸易的影响

```
本币贬值
    ↓
├── 出口价格↓ → 出口竞争力↑
├── 进口价格↑ → 进口需求↓
└── 净出口↑ → GDP↑
```

### 4.2 对通胀的影响

```
本币贬值
    ↓
进口价格↑
    ↓
├── 直接：进口消费品价格↑
└── 间接：进口原材料→生产成本↑
    ↓
通胀↑
```

**经验**：贬值10%→通胀+0.5-1%（新兴市场更大）

### 4.3 对资本流动的影响

```
本币贬值预期
    ↓
资本外逃
    ↓
进一步贬值
    ↓
恶性循环
```

## 六、汇率预测框架

### 6.1 短期（<1年）

```
汇率变化 ≈ 利差 + 风险偏好变化 + 政策意外
```

**关键**：利差交易、风险事件

### 6.2 中期（1-3年）

```
汇率变化 ≈ 利差 + 经常账户变化 + 相对增长
```

### 6.3 长期（>3年）

```
汇率 ≈ PPP + 结构性因素
```
