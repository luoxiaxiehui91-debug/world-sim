# P8：大类资产联动框架

> 本文档定义股/债/汇/商品/加密货币的轮动规律和相关性结构，包括宏观周期定位→资产配置映射。
> 数据来源：FRED时序数据库（SP500/DGS10/DCOILWTICO/DTWEXBGS）、Bloomberg

---

## 一、资产类别与宏观驱动

### 1.1 核心资产→宏观因子映射

| 资产类别 | 代表指标 | 核心驱动因子 | 次要驱动 | 对经济周期敏感度 |
|:---------|:---------|:------------|:---------|:---------------:|
| **美股** | SP500 | 盈利增长+利率+风险偏好 | 流动性/估值 | 高（顺周期） |
| **美债** | DGS10 | 通胀预期+实际利率+避险需求 | 期限溢价 | 中-高（逆周期） |
| **美元** | DTWEXBGS | 利差+避险+相对增长 | 资本流动 | 中（双属性） |
| **原油** | DCOILWTICO | 供需+地缘+美元 | OPEC+决策 | 高（顺周期） |
| **黄金** | GOLDAMGBD228NLBM | 实际利率+避险+美元 | 央行购金 | 中（逆周期） |
| **加密** | BTC/ETH | 风险偏好+流动性+监管 | 技术创新 | 极高（顺周期） |

### 1.2 六大宏观因子

| 因子 | 指标 | 影响 |
|:-----|:-----|:-----|
| **增长因子** | GDP YoY / ISM PMI | 股票正相关，债券负相关 |
| **通胀因子** | CPI YoY / PCE YoY | 原油正相关，债券负相关，股票不确定 |
| **利率因子** | FFR / 10Y UST | 债券负相关，成长股负相关，价值股中性 |
| **信用因子** | BAA-10Y利差 / EMBI+ | 高利差→股票跌、债券避险涨 |
| **流动性因子** | M2 YoY / 美联储资产负债表 | 全资产正相关（水涨船高） |
| **风险偏好因子** | VIX / FRA-OIS | VIX高→股票跌、美债涨、美元涨、商品跌 |

|  | 美股 | 美债 | 美元 | 原油 | 黄金 | 加密 |

> 相关系数为长期均值，危机期间会发生剧烈变化（见2.2）

### 2.2 危机态相关性漂移

| 资产对 | 常态 | 2008危机 | 2020新冠 | 2022滞胀 | 规律 |
|:-------|:----:|:--------:|:--------:|:--------:|:-----|
| 美股-美债 | -0.30 | +0.50 | +0.60 | -0.40 | 危机中股债同跌（流动性危机） |
| 美股-美元 | -0.20 | +0.40 | +0.30 | +0.10 | 危机中美元与美股同涨（避险） |
| 原油-美股 | 0.30 | +0.70 | +0.60 | +0.50 | 供给冲击时相关性增强 |
| 黄金-美股 | -0.10 | -0.30 | -0.40 | -0.20 | 黄金避险效应在危机中增强 |
| 加密-美股 | 0.50 | +0.80 | +0.85 | +0.60 | 加密在危机中完全变身为风险资产 |

> **核心教训**：分散化在危机中失效！相关性趋同→风险平价策略失灵

## 三、经济周期→资产轮动

### 3.1 美林时钟（改良版）

| 周期阶段 | GDP | CPI | 最佳资产 | 最差资产 | 当前权重建议 |
|:---------|:---:|:---:|:---------|:---------|:-----------:|
| **复苏** | ↑ | ↓ | 股票 | 债券 | 股60/债20/商品20 |
| **过热** | ↑ | ↑ | 商品 | 债券 | 股40/商品40/债10/现金10 |
| **滞胀** | ↓ | ↑ | 现金/黄金 | 债券 | 黄金30/现金30/债20/股20 |
| **衰退** | ↓ | ↓ | 债券 | 商品 | 债60/股20/黄金20 |

### 3.2 当前定位（2026年5月）

- **GDP增速**：2.66%（温和扩张）
- **CPI**：3.78%（高于目标）
- **利差**：10Y-2Y = +0.47%（未倒挂）
- **信用利差**：BAA-10Y = 1.65%（正常）

**判断：过热→滞胀过渡期**

| 资产 | 观点 | 逻辑 |
|:-----|:-----|:-----|
| 美股 | 偏多，但需警惕估值 | 盈利增长支撑，但高利率压制估值 |
| 美债 | 偏空 | 通胀粘性+美联储鹰派，收益率难下 |
| 美元 | 中性偏强 | 利差优势+避险需求 |
| 原油 | 震荡 | 地缘溢价 vs 需求放缓 |
| 黄金 | 偏多 | 实际利率见顶+央行购金+避险 |
| 加密 | 高波动 | 流动性预期敏感，监管不确定性 |

## 四、跨市场传导路径

### 4.1 美股→全球股市

```
标普500下跌
    ├── 风险偏好下降 → 全球股市联动下跌
    │   ├── 发达市场：0.8-0.9x传导（高度同步）
    │   ├── 新兴市场：0.6-0.8x传导（滞后1-2天）
    │   └── A股：0.3-0.5x传导（资本管制缓冲）
    ├── ETF被动赎回 → 流动性冲击
    │   └── 新兴市场ETF资金外流→当地股市抛售
    └── 投资者风险预算调整
        └── 风险平价基金rebalance→债涨股跌
```

### 4.2 利率→资产估值

```
10Y UST收益率变化
    ├── 股票估值
    │   ├── DCF折现率↑ → 估值↓（成长股>价值股）
    │   └── 经验法则：10Y↑100bp → SP500 PE↓1.5-2.0x
    ├── 债券价格
    │   └── 久期风险：10Y↑100bp → 10Y债券价格↓8%
    ├── 房地产
    │   └── 抵押贷款利率↑ → 住房需求↓
    └── 黄金
        └── 实际利率↑ → 黄金持有成本↑ → 金价↓
```

### 4.3 原油→跨资产

```
原油价格飙升
    ├── 通胀预期↑ → 债券收益率↑
    ├── 消费者购买力↓ → 零售/消费股↓
    ├── 能源股↑ → 指数内部轮动
    ├── 制造业成本↑ → 利润率压缩
    ├── 央行可能更鹰 → 利率预期↑ → 成长股↓
    └── 新兴市场分化
        ├── 进口国受损（印度/中国）
        └── 出口国受益（沙特/俄罗斯）
```

## 六、风险平价与分散化

### 6.1 分散化失效条件

| 条件 | 机制 | 应对 |
|:-----|:-----|:-----|
| **流动性危机** | 全资产抛售→现金 | 增加现金/短债配置 |
| **通胀冲击** | 股债双杀 | 商品/黄金/TIPS对冲 |
| **美元荒** | 新兴市场+商品暴跌 | 美元现金+美债 |
| **政策突变** | 市场定价重构 | 降低杠杆，增厚安全垫 |

### 6.2 尾部风险对冲

| 策略 | 成本 | 保护 | 适用场景 |
|:-----|:----:|:-----|:---------|
| SP500看跌期权 | 年化2-4% | 下跌保护 | 高估值+利差倒挂 |
| VIX看涨期权 | 年化5-10% | 波动率飙升 | 地缘风险上升 |
| 黄金多头 | 机会成本 | 通胀+避险 | 滞胀环境 |
| 长债多头 | 收益率风险 | 衰退避险 | 利差倒挂确认 |
| 现金增配 | 通胀侵蚀 | 流动性 | 全环境安全垫 |

## 七、推演应用

### 情景1：美联储2026Q3降息

```
FFR↓50bp → 10Y↓25bp → 实际利率↓
  → 美股PE↑3-5% → 成长股>价值股
  → 黄金↑5-8% → 实际利率下降
  → 美元↓2-3% → 新兴市场喘息
  → 原油影响中性 → 需求预期改善 vs 美元走弱
```

### 情景2：油价飙至150美元

```
WTI 150 → CPI↑1.5-2.0pp → 美联储被迫维持高利率
  → 股票PE↓3-5x → 消费股/航空股重挫
  → 债券收益率↑50-80bp → 通胀预期锚定
  → 黄金↑10-15% → 通胀对冲需求
  → 新兴市场分化 → 出口国涨/进口国跌
  → 加密→跟随风险偏好下降
```

### 情景3：美股回调20%

```
SP500 -20% → VIX>35
  → 美债收益率↓30-50bp（避险）
  → 黄金↑5-10%（避险）
  → 美元先涨后跌（避险→美联储宽松预期）
  → 新兴市场↓15-25%
  → 加密↓30-50%（高风险β）
  → 信用利差扩大100-200bp
```
