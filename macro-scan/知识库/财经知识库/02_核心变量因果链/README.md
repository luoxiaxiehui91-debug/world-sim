# 02_核心变量因果链

本目录是知识库的**量化框架核心**，存放指标间传导机制的分析框架、量化参数和历史数据。

## 内容分类

### 分析框架文档（P系列）
10篇结构化框架，涵盖：利率传导、GDP/CPI先行指标、美联储政策响应、国际传导、大类资产联动、风险压力测试、地缘政治量化等。

### 量化参数与数据
- `历史情景_量化指标.csv`：历史危机案例的量化基准（VIX峰值、GDP跌幅等）
- `反馈回路_量化参数.csv`：各传导路径的速度/幅度系数
- `量化表_*.csv`：各框架对应的量化参数表
- `series_*.csv`：FRED 原始时序数据

### 机制说明文档
利率传导、汇率决定、信贷周期、就业市场、财政政策、贸易条件、通胀动力学等核心机制。

## 与其他目录的分工

- **本目录**：指标之间"为什么联动、联动多强、多快"的量化答案
- **`01_宏观经济指标/`**：单一指标的数据参考
- **`04_分析框架/`**：面向具体分析场景的应用工具（央行决策框架、板块轮动等）
- **`09_预测模型/`**：蒙特卡洛等预测模型的数学推导
