# P9：风险压力测试框架

> 本文档定义宏观经济极端情景的压力测试方法论，包括情景构建、冲击传导、损失估计、反馈回路。
> 数据来源：P0因果链量化表(181条)、P1时序数据库(39指标)、P2历史危机对照(8大危机)

---

## 一、压力测试方法论

### 1.1 三层架构

```
层1：情景定义（外部冲击假设）
    ↓
层2：传导模拟（因果链+时滞+条件）
    ↓
层3：损失估计（资产/经济/金融影响量化）
    ↓
反馈回路检测（正反馈→尾部风险放大）
```

### 1.2 情景构建原则

| 原则 | 说明 |
|:-----|:-----|
| **合理性** | 基于历史先例或可推演的逻辑链条 |
| **极端性** | 超出95%置信区间，但非不可能 |
| **完整性** | 覆盖增长/通胀/利率/信用/地缘五大维度 |
| **可量化** | 每个冲击有具体的数值和时序假设 |

### 2.2 情景参数表

#### S1：油价冲击

| 参数 | 基准 | 冲击值 | 传导路径 |
|:-----|:-----|:-------|:---------|
| WTI原油 | $110 | $150→$180 | 供给中断（中东/OPEC+减产） |
| CPI YoY | 3.8% | 5.5%→7.0% | 能源→核心通胀传导 |
| 美联储FFR | 3.63% | 维持4.0-4.5% | 被迫抗通胀 |
| GDP增速 | 2.66% | 0.5%→-1.0% | 消费抑制+成本上升 |
| 失业率 | 4.3% | 5.0%→6.5% | 滞胀冲击就业 |

**传导链**：
```
油价→150
  → 能源CPI↑30-40% → 核心CPI↑1.5-2pp（二轮效应，时滞6-12月）
  → 美联储被迫维持高利率 → 10Y UST↑50-80bp
  → 消费者实际收入↓3-5% → 零售销售↓
  → 制造业成本↑ → 利润率↓ → 资本支出↓
  → SP500↓15-25% → 风险偏好下降
  → 新兴市场分化：出口国涨/进口国跌
  → 反馈：通胀预期脱锚→工资-价格螺旋
```

#### S2：美国硬着陆

| 参数 | 基准 | 冲击值 | 传导路径 |
|:-----|:-----|:-------|:---------|
| GDP增速 | 2.66% | -2.0%→-4.0% | 信用紧缩+消费崩塌 |
| 失业率 | 4.3% | 7.0%→10.0% | 企业裁员潮 |
| CPI YoY | 3.8% | 1.0%→-0.5% | 需求崩溃→通缩 |
| FFR | 3.63% | 0-0.25% | 紧急降息至零 |
| SP500 | 7412 | 4500-5000 | -35%~-40% |

**传导链**：
```
信用事件触发（商业地产/高收益债违约）
  → 银行收紧信贷 → BAA-10Y利差>3%
  → 企业融资困难 → 投资下降 → 裁员
  → 消费者信心崩塌 → 消费↓ → 零售业裁员
  → 失业率飙升 → 房贷违约 → 银行损失
  → 正反馈：银行损失→信贷更紧→更多违约
  → 美联储紧急降息至零+重启QE
  → 10Y UST↓至2.5-3.0% → 黄金暴涨
  → 新兴市场：先跌（风险偏好）→后涨（美元宽松）
```

#### S3：通胀失控

| 参数 | 基准 | 冲击值 | 传导路径 |
|:-----|:-----|:-------|:---------|
| CPI YoY | 3.8% | 6.0%→8.0% | 工资-价格螺旋 |
| 核心PCE | 3.5% | 5.0%→6.5% | 通胀预期脱锚 |
| FFR | 3.63% | 5.5%→7.0% | 沃尔克式紧缩 |
| GDP增速 | 2.66% | -1.0%→-3.0% | 故意制造衰退 |
| 失业率 | 4.3% | 6.0%→8.0% | 萨姆规则触发 |

**传导链**：
```
通胀预期脱锚（密歇根5年预期>4%）
  → 工资要求↑ → 劳动力成本↑ → 企业提价
  → CPI持续加速 → 美联储 credibility危机
  → 美联储激进加息 → FFR→6-7%
  → 房地产市场崩塌 → 建筑业失业
  → 企业利息支出飙升 → 高收益债违约潮
  → SP500↓25-35%（估值+盈利双杀）
  → 债券收益率飙升 → 债券价格暴跌
  → 40/60组合创记录亏损
  → 反馈：紧缩→衰退→但通胀仍高→继续紧缩→深衰退
```

**传导链**：
```
美元流动性收紧 + 某国政治危机
  → 资本外逃 → 货币暴跌
  → 外债偿付困难 → 主权评级下调
  → 蔓延至同区域国家（传染效应）
  → 全球银行新兴市场敞口损失
  → 避险情绪→美元走强→更多国家承压
  → 正反馈循环
  → 对中国：贸易渠道（出口↓）+ 资本渠道（有限）
  → 对美国：金融回传（银行损失）+ 需求回传（出口↓）
```

## 三、损失估计方法

### 3.1 资产损失估计

| 资产 | 方法 | 输入 | 输出 |
|:-----|:-----|:-----|:-----|
| 美股 | 情景PE×EPS | EPS增速↓x% + 估值压缩y% | 指数跌幅 |
| 美债 | 久期×收益率变动 | 10Y变动Δbp × 久期8 | 价格变动 |
| 信用 | 利差扩大×DTS | 利差Δbp × 利差久期 | 价格跌幅 |
| 原油 | 供需缺口+地缘溢价 | 中断量(mbd) × 紧缺度 | 价格水平 |
| 汇率 | 利差+风险溢价 | 息差变动 + 风险溢价 | 贬值幅度 |

### 3.2 GDP损失估计

| 方法 | 公式 | 适用场景 |
|:-----|:-----|:---------|
| **Okun法则** | ΔGDP = -2×Δ失业率 | 需求冲击 |
| **信用脉冲** | ΔGDP = 0.4×Δ信贷增速 | 信用紧缩 |
| **贸易乘数** | ΔGDP = 1.5×Δ净出口 | 外部冲击 |
| **财政乘数** | ΔGDP = 0.8×Δ财政支出 | 政策对冲 |

## 五、压力测试执行流程

### 5.1 标准化步骤

```
Step 1：选择情景（S1-S6或自定义）
    ↓
Step 2：设定冲击参数（基准→冲击值，含时序路径）
    ↓
Step 3：沿因果链传导（P0 181条因果链+时滞+条件）
    ↓
Step 4：计算资产损失（3.1方法）
    ↓
Step 5：计算经济影响（3.2方法）
    ↓
Step 6：检测反馈回路（4.1清单+4.2阻断条件）
    ↓
Step 7：叠加历史对照（P2 8大危机）
    ↓
Step 8：输出压力测试报告
```

### 5.2 输出模板

```markdown
# 压力测试报告：[情景名称]

## 情景假设
- 核心冲击：...
- 持续时间：...
- 概率评估：...

## 传导路径
1. [冲击] → [一阶效应] → [二阶效应] → ...
2. 反馈回路：[F1-F6哪些被激活]

## 损失估计
| 资产 | 基准值 | 冲击值 | 损失率 |
| 美股 | 7412 | xxx | -xx% |
| ...

## 经济影响
- GDP：2.66% → x.x%
- 失业率：4.3% → x.x%
- CPI：3.78% → x.x%

## 历史对照
- 最接近危机：[P2中的案例]

- 阻断条件：...

```
