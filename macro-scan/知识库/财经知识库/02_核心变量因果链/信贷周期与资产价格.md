# 信贷周期与资产价格

## 核心传导链

```
信贷扩张 → 资金供给↑ → 资产价格↑ → 抵押品价值↑
        ↓                              ↓
   抵押贷款能力↑ ←─────────────── 抵押品增值
        ↓
   信贷进一步扩张 → 资产价格继续↑（正反馈）
        ↓
   杠杆率过高 → 风险积累 → 触发点 → 信贷紧缩
        ↓
   资产价格暴跌 → 抵押品贬值 → 强制去杠杆
        ↓
   恶性循环：价格↓ → 抵押品↓ → 信贷↓ → 价格继续↓
```

## 信贷周期的四个阶段

### 1. 扩张期
- 信贷增长快于GDP
- 资产价格上涨
- 风险溢价下降
- 杠杆率上升
- 典型时长：5-7年

### 2. 危机期
- 触发事件（利率上升、外部冲击）
- 资产价格急跌
- 违约率飙升
- 信贷冻结
- 典型时长：1-2年

### 3. 紧缩期
- 去杠杆化
- 资产价格低迷
- 信贷标准收紧
- 风险溢价高企
- 典型时长：3-5年

### 4. 恢复期
- 杠杆率企稳
- 信贷逐步恢复
- 资产价格回升
- 风险溢价正常化

## 关键变量

### 杠杆率
- **家庭杠杆**：债务/可支配收入
  - 美国：峰值130%（2007），现约100%
  - 中国：快速上升至60%+
- **企业杠杆**：债务/EBITDA 或 债务/资产
  - 高杠杆行业：房地产、基建
- **金融杠杆**：资产/资本
  - 银行杠杆受监管限制
  - 影子银行杠杆更高

### 信贷标准
- **宽松指标**：
  - 首付比例下降
  - 收入证明要求放松
  - 贷款期限延长
- **收紧指标**：反向变化

### 资产价格估值
- **房价收入比**：长期均值回归
- **股票市盈率**：周期调整市盈率（CAPE）
- **商业地产资本化率**：与利率联动

## 传导机制详解

### 抵押品通道
```
资产价格↑ → 抵押品价值↑ → 可贷额度↑
         → 信贷扩张 → 资产价格继续↑
         → 正反馈循环
```

### 预期通道
```
资产价格上涨 → 预期继续上涨 → 投机需求↑
             → 价格进一步上涨
             → 泡沫形成
```

### 银行资本通道
```
资产价格↓ → 银行持有资产减值 → 资本充足率↓
         → 信贷收缩 → 资产价格继续↓
```

## 预警指标

| 指标 | 阈值 | 含义 |
|------|------|------|
| 信贷/GDP增速差 | >3% | 信贷过热 |
| 房价收入比 | >历史均值+2σ | 房价泡沫 |
| 家庭债务/收入 | >100% | 家庭杠杆过高 |
| 企业债务/EBITDA | >6x | 企业债务风险 |
| 新增信贷中投机占比 | >30% | 投机过热 |

## 历史案例

### 美国次贷危机（2007-2009）
- **扩张期**：2000-2006，信贷/GDP从140%升至170%
- **触发点**：利率上升，次贷违约
- **传导**：房价暴跌 → 抵押品贬值 → 信贷冻结
- **结果**：房价下跌30%，信贷萎缩

### 西班牙房地产泡沫（2008-2012）
- **扩张期**：1997-2007，房价上涨200%
- **杠杆**：私人债务/GDP从120%升至220%
- **崩溃**：房价下跌40%，失业率26%
- **去杠杆**：私人债务降至150%

### 中国房地产（2015-至今）
- **信贷扩张**：居民贷款快速增长
- **房价上涨**：一线城市房价收入比超20
- **政策应对**：限购、限贷、三道红线
- **风险**：房企债务违约、地方政府土地财政

## 政策应对

### 宏观审慎政策
- 逆周期资本缓冲
- 贷款价值比（LTV）限制
- 债务收入比（DTI）限制
- 房地产税

### 货币政策
- 利率工具：加息抑制过热
- 但可能影响整体经济
- 需与宏观审慎配合

### 危机应对
- 流动性支持：防止信贷冻结
- 资产购买：稳定资产价格
- 债务重组：有序去杠杆
