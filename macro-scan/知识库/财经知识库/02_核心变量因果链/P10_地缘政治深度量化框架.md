## 1. 主要地缘风险情景（量化参数）

### S1. 台海紧张升级（2024-2026 持续）

**概率评估**：15%（基准）| 30%（如果美国大选后政策激进）| 5%（中美重启对话）

**量化影响参数**：

| 指标 | 短期（1-3月） | 中期（6-12月） | 长期（1-3年） |
|:-----|:-------------|:--------------|:-------------|
| USD/CNY | +3%~8% | +5%~15% | +10%~25% |
| 全球供应链 | -5%~-15% | -10%~-20% | -15%~-30% |
| 半导体 | -10%（台湾代工） | -20%~-30% | -30%~-50% |
| 原油 | +5%~+15% | +10%~+20% | +5%~+15% |
| S&P 500 | -8%~-20% | -15%~-30% | -20%~-40% |
| 黄金 | +5%~+15% | +10%~+20% | +5%~+15% |

**传导路径**：
1. 军事紧张 → 航运保险费 ↑ → 台湾出口成本 ↑
2. 科技制裁升级 → 半导体设备禁运 → 台湾代工厂产能 ↓
3. 金融制裁威胁 → USD/CNY 跳升 → 离岸流动性收紧
4. 消费电子需求 ↓ → 全球科技链条 ↓

**阻断条件**：
- 中美恢复战略对话（概率极低）
- 台湾维持现状（经济利益优先）
- 第三方斡旋（东盟/欧盟）

**历史参照**：1996年台海危机（+1.5% USD/CNY，1周内恢复）；2016年南海仲裁（+0.8% USD/CNY）

### S2. 中美科技脱钩升级（2024-2026 加速）

**概率评估**：40%（基准，持续演进）| 60%（如果中国对台更激进）

**量化影响参数**：

| 指标 | 短期（1-3月） | 中期（6-12月） | 长期（1-3年） |
|:-----|:-------------|:--------------|:-------------|
| 中国GDP | -0.5%~-1.5% | -1%~-3% | -2%~-5% |
| 半导体设备出口 | -60%~-80% | -80%~-95% | -95%+ |
| 中国科技出口 | -3%~-8% | -8%~-15% | -15%~-30% |
| USD/CNY | +1%~+3% | +2%~+5% | +3%~+8% |
| 台湾GDP | -1%~-3% | -3%~-8% | -5%~-15% |

**传导路径**：
1. 芯片出口管制 → AI/云计算产能受限 → 中国科技企业竞争力 ↓
2. 设备禁运 → 中芯国际14nm以下产能扩张受阻 → 成熟制程竞争加剧
3. 中国反制 → 稀土出口管制 → 全球半导体原材料成本 ↑
4. 供应链重构 → 东南亚/印度接受产能转移 → 短期效率损失

**关键阈值**：
- Nvidia H系列全面禁运 → 中国AI发展减速30%~50%
- 成熟制程（28nm）也管制 → 全球芯片价格+15%~25%
- 台湾代工份额>60% → 任何冲击对全球影响成倍放大

## 4. 地缘风险量化纳入宏观分析

### 4.1 纳入 run_macro_analysis.py 的方法

在 Layer 2 风险评分中增加"地缘风险评分"：

```
geo_risk = {
    "台海": current_score * 0.15,
    "科技脱钩": current_score * 0.40,
    "能源冲击": (oil_price - 80) / 50 * 10,  # 油价每涨$50，+10分
    "贸易碎片化": global_trade_index - 100,  # 贸易指数偏离100的程度
    "金融制裁": credit_default_swap / 200 * 5,  # CDS每200bp，+5分
}
geo_total = sum(geo_risk.values()) / len(geo_risk) * 10  # 0-100
```
