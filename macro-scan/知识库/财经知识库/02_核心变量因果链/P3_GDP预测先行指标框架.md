# P3：GDP预测先行指标框架

> 本文档为GDP增长预测提供系统性框架，整合领先指标、预测模型、实时校准方法，适用于美国GDP环比年率（鏟QGDP）的季度预测。
> 数据来源：FRED时序数据库（已收录39个指标）

---

## 一、核心预测模型：鏟Q→QQGDP先行指标体系

### 1.1 先行指标分类（按领先周期）

| 指标 | FRED代码 | 领先周期 | 预测方向 | 置信度 |
|:-----|:---------|:---------|:---------|:------:|
| **ISM制造业PMI** | MANEMP/NMANHOR(已收录) | 1-2季度 | PMI>50→GDP正增长 | ★★★★ |
| **首次申请失业金（初请）** | ICSA | 1-2季度 | ICSA飙升→GDP负增长 | ★★★★ |
| **职位空缺数（JOLTS）** | JTSJOL | 2-3季度 | JOLTS下降→GDP放缓 | ★★★ |
| **平均周工时** | AWHMAN | 1季度 | 周工时下降→GDP放缓 | ★★★★ |
| **消费者信心指数** | UMCSENT | 1-2季度 | 信心下降→消费萎缩→GDP放缓 | ★★★★ |
| **10Y-2Y利差（倒挂预警）** | T10Y2Y | 4-6季度 | 深度倒挂后12-18月→衰退 | ★★★★★ |
| **M2货币供应变化** | M2SL | 2-3季度 | M2收缩→GDP放缓 | ★★★★ |
| **营建许可** | PERMIT | 1-2季度 | 许可下降→固定资产投资放缓 | ★★★★ |
| **新屋开工** | HOUST | 1-2季度 | 开工下降→GDP放缓 | ★★★ |
| **耐用品订单（出货/库存比）** | 需补充 | 1-2季度 | 比值上升→未来产出下降 | ★★★ |
| **S&P500（财富效应）** | SP500 | 1-2季度 | 股市下跌→消费减少→GDP放缓 | ★★★★ |
| **信用利差（BAA-国债）** | BAA10Y-DGS10 | 2-3季度 | 利差扩大→信贷收缩→GDP放缓 | ★★★★ |
| **GDPNOW实时预测** | ALLOWED_FRED/亚特兰大联储 | 当前季度 | 实时校准 | ★★★★ |
| **褐皮书（Beige Book）** | 定性 | 1季度 | 12个联储区经济状况 | ★★★ |

### 1.2 先行指标权重分配

基于实证研究（NBER、纽约联储、旧金山联储）：

```
GDP预测信号 = 
  PMI偏离度        × 0.20   （方向信号）
+ ICSA偏离度       × 0.20   （劳动力市场）
+ 利差信号         × 0.20   （衰退预警）
+ 消费信号(UMCSENT) × 0.15  （内需）
+ 投资信号(PERMIT)  × 0.10  （固定投资）
+ M2变化率         × 0.10  （货币条件）
+ 股市信号(SP500)   × 0.05  （财富效应）
```

## 四、GDP数据校准（使用FRED时序数据库）

### 4.1 GDPC1 vs GDPPOT（产出缺口）

```python
# 潜在GDP vs 实际GDP
产出缺口 = (GDPC1 - GDPPOT) / GDPPOT × 100%

# 历史参考：
# 2009Q2：产出缺口约 -6.2%（大衰退低谷）
# 2020Q2：产出缺口约 -9.7%（新冠冲击，更深但恢复更快）
# 2023Q4：产出缺口约 +0.5%（略超潜在）
# 正常区间：-2% 至 +2%
```

### 4.2 季度GDP预测锚点

基于历史数据（1932-2024）的GDP季度分布：

| 季度变化 | 分位数 | 历史含义 |
|:--------|:-------|:---------|
| <-8%（年化）| <5% | 严重衰退（如新冠、2008Q4） |
| -4%至-8% | 5-20% | 轻度衰退 |
| -2%至-4% | 20-35% | 增长放缓 |
| -2%至+2% | 35-65% | 正常区间 |
| +2%至+4% | 65-80% | 稳健增长 |
| >+4% | >80% | 强劲扩张 |

### 4.3 关键转折点识别

使用利差（10Y-2Y）和初请（ICSA）的组合识别：

```
# 衰退确认信号（两个条件同时满足）
条件1: T10Y2Y < -30bp（当前或最近6个月内）
条件2: ICSA 4周均值 > 25万（趋势性上升）

→ 结合PMI和消费信心 → 预测GDP下一季度走势
```

## 五、实时预测模板

### 当拿到一个新季度数据时，执行以下检查：

**Step 1：查利差（T10Y2Y）**
- 如果倒挂且持续>3个月 → 衰退预警灯亮
- 如果陡峭化（利差扩大） → 衰退风险降低

**Step 2：查劳动力市场（ICSA + JTSJOL + AWHMAN）**
- ICSA>25万趋势 → 负面信号
- JTSJOL下降但ICSA未大幅上升 → 软着陆路径
- AWHMAN下降 → 企业开始缩短工时，先于裁员

**Step 3：查PMI（ISM制造业）**
- PMI>52 → 制造业扩张，支持GDP>2%
- PMI<48 → 制造业萎缩，GDP下行压力
- PMI<44 → 严重制造业衰退信号

**Step 4：查消费信号（UMCSENT + PCE）**
- 消费者信心>110 → 消费稳健
- UMCSENT<70 → 消费萎缩预警

**Step 5：综合评分**
```
信号计数：
- 负面信号>4个 → GDP<1%或负增长概率>60%
- 负面信号3个 → GDP 1-2%
- 正负各半 → GDP 2-3%
- 正面信号>4个 → GDP>3%
```

**Step 6：RAG检索历史对照**
使用`crisis_lookup.py`或RAG查询当前指标组合最接近的历史情景：
```
"当前指标：ICSA={X}，PMI={Y}，利差={Z}，历史上哪段时期最接近？"
```

## 六、预测局限与注意事项

1. **实时数据修正**：GDP初值→修正值→终值，三版数据可能差异巨大（最大修正幅度约3个百分点）
2. **异常值处理**：2020Q2单季-31.2%年化是历史极端值，需单独处理
3. **结构变化**：2000年后全球化/服务业主导改变了部分指标的预测效力
4. **政策干扰**：大规模财政/货币刺激可暂时扭曲领先指标
5. **国际传导**：中国/欧洲经济通过出口渠道影响美国GDP，需关注全球PMI
