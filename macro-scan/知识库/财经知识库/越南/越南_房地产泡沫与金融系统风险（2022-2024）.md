# 越南房地产泡沫与金融系统风险（2022—2024）

> 系列：越南经济深度分析 · D篇 · 第三篇

---

## 核心机制

越南房地产危机的核心是**开发商债务—银行信贷—监管套利三角循环的崩溃**。2016–2021年低利率环境叠加城镇化预期，驱动土地价格和房价大幅上涨，开发商通过企业债（债券市场）和银行贷款双渠道杠杆化拿地开发。但越南资本市场基础薄弱，债券发行缺乏信用评级约束，大量债券由银行和零售投资者直接持有。

2022年政府反腐行动触发流动性危机，暴露了这一系统的内在脆弱性：

```
开发商无法续债
  → 工地停工
  → 购房者维权（烂尾楼）
  → 银行坏账风险上升
  → 金融系统信心动摇
```

## 传导路径

### 路径一：反腐行动 → 债券市场冻结

2022年政府打击债券欺诈（部分开发商被指使用虚假项目发行债券） → 债券监管收紧（Decree 65/2022/ND-CP） → 新债无法发行 → 开发商再融资渠道封闭 → 流动性断裂 → 工程停工 → 购房者烂尾楼风险。

### 路径二：SCB 危机 → 银行系统传染

Van Thinh Phat 通过关联网络大量占用 SCB 信贷资源 → 主要股东被捕后 → 储户恐慌性挤兑（2022年10月一周内挤兑金额估计超过 **170 万亿越南盾**） → SBV 紧急注入流动性 → 引发市场对其他银行关联房企敞口的担忧 → 银行间市场利率急升（隔夜利率一度超过 **8%**）。

### 路径三：信贷收缩 → 实体经济冷却

银行收紧房地产贷款 → 开发商资金断裂 → 建材、施工、家电等上下游产业链收缩 → 就业压力上升 → 居民消费意愿下降 → 2023年越南 GDP 增速降至 **5.05%**，低于政府 6.5% 目标，为 2012 年以来（除疫情年）最低增速。

## 反面条件与历史反例

### 反面条件一：政府救市力度超预期

2023年越南政府推出一系列刺激措施：

- SBV 四次降息，合计 **150bps**
- 减税、基建支出加速
- 房地产法规松绑（允许部分停工项目续建）

2024年上半年部分一线城市成交量出现回暖迹象，显示危机扩散速度慢于预期。

### 反面条件二：越南缺乏影子银行系统性问题

与中国恒大危机相比，越南金融系统证券化程度低，房贷证券化（MBS）几乎不存在，危机传染路径相对简单，政府可以通过直接注资银行来切断传染链条。

### 历史反例：2011–2013年越南不良贷款危机

2012年越南银行业 NPL 曾高达约 **8.6%**（部分估计超过 10%），政府通过成立越南资产管理公司（**VAMC**）大规模收购坏账，将 NPL 数字压低，换来银行账面修复，但未解决根本问题——VAMC 持有的债务多数未真正清收。

2022–2024年危机某种程度上是 2012 年未清算遗留风险在更大规模上的复现。

### 反面条件三：城镇化基本面支撑长期出清

越南城镇化率约 **38%**（2023年），远低于中国约 65%，长期住房需求真实存在。泡沫挤出后，在需求支撑下市场存在自然出清机制，不太可能出现日本式长期通缩型崩盘。

但需注意：短期流动性危机对金融系统的损伤是**独立于长期需求基本面之外的风险**，两者不可混淆。
