## 一、中国货币政策框架概述

中国人民银行（PBC/PBOC）采取**以数量型工具为主、价格型工具为辅**的货币政策框架，近年来逐步向价格型（利率）传导机制转型。

**双重目标（法定）**：
1. 维护货币价值稳定（通胀目标：约3%，软目标）
2. 促进经济增长（GDP增长目标，由国务院设定）

**隐含目标（实际操作）**：
- 汇率稳定（人民币相对美元的波动管理）
- 金融系统稳定（防范系统性风险）
- 就业（隐含在增长目标中）

## 二、核心政策工具体系

### 2.1 政策利率层级（2019年利率改革后）

```
短端（隔夜）：
  DR007（银行间质押式回购7天利率）← 最市场化的基准
       ↑ 由
  OMO利率（公开市场操作7天逆回购利率）← PBOC官方政策利率
                                      = 1.80%（2024年9月调降后）

中端（1年期）：
  MLF利率（中期借贷便利，1年期）← PBOC对银行定向融资
      = 2.00%（2024年）

长端（零售信贷）：
  LPR（贷款市场报价利率）← 18家银行报价，每月20日发布
    ├── 1年期LPR = MLF利率 + 银行加点 ≈ 3.35%（2024）
    └── 5年期LPR（房贷基准）≈ 3.85%（2024）
```

### 2.2 传导机制图

```
PBOC政策意图
    ↓（OMO/MLF调整利率信号）
金融市场利率（DR007/SHIBOR）
    ↓（银行间市场）
银行负债成本（存款利率间接调整）
    ↓（银行定价调整）
LPR（贷款市场报价利率）
    ↓（新增+存量贷款重定价）
实体经济融资成本（企业+居民）
    ↓（投资/消费变化）
总需求 → GDP/通胀
```

## 三、MLF（中期借贷便利）

### 3.1 基本机制

- **定义**：PBOC向商业银行提供1年期（有时3个月、6个月）抵押贷款的工具
- **抵押品**：国债、政策金融债、高等级信用债
- **利率**：PBOC设定，是LPR的"锚定利率"
- **每月操作**：通常在每月15日前后，规模根据银行缺口需求

### 3.2 MLF利率历史

| 时间 | MLF利率 | 调整幅度 | 背景 |
|:----|:-------:|:-------:|:----|
| 2016年 | 3.00% | — | 建立初期 |
| 2019.11 | 3.25% → 3.00% | -25bp | 支持经济 |
| 2020.02-04 | 3.00% → 2.95% → 2.85% | -15bp | 新冠应对 |
| 2022.01 | 2.85% → 2.75% | -10bp | 稳增长 |
| 2023.06 | 2.75% → 2.65% | -10bp | 内需疲弱 |
| 2024.07 | 2.50% → 2.30% | -20bp | 大幅宽松 |
| 2024.09 | 2.30% → 2.00% | -30bp | 超预期宽松 |

### 3.3 MLF与LPR的联动

- 自2019年8月LPR改革后，**LPR = MLF利率 + 加点**
- 加点反映银行资金成本和市场状况（通常不变动）
- 实践中：MLF降息往往先于LPR降息，但LPR不必然随MLF等幅调整

## 四、LPR（贷款市场报价利率）

### 4.1 改革背景（2019年8月改革）

改革前：贷款基准利率由PBOC直接设定，传导效率低、市场化程度不够  
改革后：18家报价银行每月20日以MLF为基础自主报价，PBOC不再直接干预贷款利率

### 4.2 LPR历史（关键时点）

| 时间 | 1年期LPR | 5年期LPR（房贷）| 调整背景 |
|:----|:--------:|:--------------:|:--------|
| 2019.08（建立）| 4.25% | 4.85% | 基准 |
| 2020.04 | 3.85% | 4.65% | 新冠宽松 |
| 2022.05 | 3.70% | 4.45% → 4.25% | 5年期大幅降 |
| 2023.06 | 3.55% | 4.20% | 稳经济 |
| 2024.07 | 3.35% | 3.85% | 历史最低 |
| 2024.10 | 3.10% | 3.60% | 超预期 |

**5年期LPR的政策信号意义**：专门影响新增房贷，调降5年期LPR是支持房地产市场的直接信号。

### 4.3 LPR传导的局限性

1. **存量房贷重定价滞后**：每年1月1日才重定价，传导最慢
2. **企业信贷需求不足**：降息但企业不借（流动性陷阱倾向）→ 2022-24年"宽货币，紧信用"
3. **利差压缩**：银行息差持续收窄（2024年降至约1.5%，低于1.8%警戒线）→ 银行限制传导

## 五、存款准备金率（RRR）

### 5.1 机制

- 银行必须将存款的一定比例存入PBOC
- **降准**：释放银行可贷资金 → 信贷扩张能力增强
- **每降1%**：释放约1-1.5万亿人民币流动性（取决于存款基数）

### 5.2 RRR历史

| 时间 | 大型银行RRR | 调整幅度 | 释放流动性 |
|:----|:-----------:|:-------:|:---------:|
| 2011年峰值 | 21.5% | — | — |
| 2015-16（去杠杆）| 17.0% | -450bp | — |
| 2018-19（贸易战）| 13.5% | 多次降准 | 万亿级 |
| 2020（新冠）| 12.5% | -100bp | 释放约1.3T |
| 2022-23 | 11.0% → 10.5% | -100bp | 释放约1.2T |
| 2024.09 | 10.5% → 9.5% | -50bp | 释放约1T |

**当前状态（2024年末）**：大型银行RRR约9.5%，历史最低，进一步降准空间有限。

## 六、定向工具：结构性货币政策

PBOC区别于美联储的重要特点：使用**大量定向/结构性工具**，精准导向特定领域：

| 工具 | 目标领域 | 规模 | 利率优惠 |
|:----|:--------|:----:|:-------:|
| 支农再贷款/再贴现 | 农业 | 数百亿 | 低于MLF约1-2% |
| 支小再贷款 | 小微企业 | 数百亿 | 低于MLF约1-2% |
| PSL（抵押补充贷款）| 政策性住房 | 万亿级 | 2.4-2.85% |
| 碳减排支持工具 | 绿色能源 | 3000亿+ | 低于MLF约0.5% |
| 房地产"白名单"再贷款 | 房地产纾困 | 3000亿 | 低利率 |
| 设备更新再贷款 | 制造业升级 | 3000亿 | 优惠利率 |

## 七、人民币汇率政策与货币政策联动

### 7.1 中间价制度

每日交易前，PBOC公布人民币/美元中间价，实际汇率在±2%范围内波动。

**逆周期因子**：在中间价计算中引入，PBOC用于抑制贬值/升值的单向预期。

### 7.2 汇率-货币政策的两难

| 情境 | 汇率压力 | 货币政策意图 | 两难 |
|:----|:--------:|:-----------:|:----|
| 中美利差收窄 | 人民币贬值压力 | 想降息（稳增长）| 降息→加剧贬值 |
| 美联储加息 | 资本外流 | 想维持宽松 | 不加息→汇率贬 |
| 内需不足 | 贬值动力 | 需大幅宽松 | 外部均衡约束 |

**实际应对**：PBOC在汇率贬值时通过逆周期因子"稳汇率"，在外汇储备充足时优先稳增长。

## 八、推演模型中的中国货币政策评分

```python
def china_monetary_policy_score(metrics):
    """
    评分：-2（极度宽松）到 +2（极度收紧）
    负值=宽松，有利于增长；正值=收紧，有利于通胀控制
    """
    score = 0
    
    # LPR趋势
    if metrics['lpr_1y_change_12m'] < -30:   # 降息超过30bp
        score -= 1
    elif metrics['lpr_1y_change_12m'] > 30:  # 加息
        score += 1
    
    # RRR趋势
    if metrics['rrr_change_12m'] < -50:       # 降准
        score -= 0.5
    
    # 社融增速（广义信贷）
    if metrics['social_financing_yoy'] < 8:   # 社融增速低
        score -= 1  # 需要更宽松
    elif metrics['social_financing_yoy'] > 15: # 社融过热
        score += 1
    
    # 中美利差
    if metrics['cn_us_10y_spread'] < -100:    # 倒挂严重
        score += 0.5  # 汇率压力限制宽松空间
    
    return max(-2, min(2, score))
```
