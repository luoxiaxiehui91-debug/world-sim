## 一、美联储货币政策框架概览

美联储通过**联邦公开市场委员会（FOMC）**制定货币政策，主要目标为：
1. **最大就业**（dual mandate之一）
2. **价格稳定**（通胀目标2%，2020年起为平均通胀目标AIT）
3. 兼顾**长期温和利率**（第三目标，通常隐含在前两者中）

**主要政策工具**：
- 联邦基金利率目标区间（FFR）
- 资产购买（QE/QT）
- 前瞻指引（Forward Guidance）
- 紧急信贷工具（危机期）

## 二、泰勒规则：标准形式与历史参数

### 2.1 原版泰勒规则（1993年）

```
FFR = r* + π + 1.5(π - π*) + 0.5(y - y*)

其中：
  r*  = 中性实际利率（长期自然利率）≈ 2.5%（1993年估计）
  π   = 当前通胀率（PCE核心）
  π*  = 通胀目标 = 2%
  y   = 实际GDP增速
  y*  = 潜在GDP增速
  (y-y*) = 产出缺口（正=过热，负=衰退）
```

### 2.2 不同时期的参数估计

| 时期 | r*估计 | 通胀系数 | 产出缺口系数 | 背景 |
|:----|:------:|:-------:|:-----------:|:----|
| 1993-2000（格林斯潘繁荣）| 2.5% | 1.5 | 0.5 | 强增长低通胀 |
| 2001-08（伯南克前期）| 2.0% | 1.5 | 0.5 | 互联网泡沫后低利率 |
| 2009-15（零利率时代）| 0.0%~0.5% | 1.5 | 1.0 | ZLB约束，扩大产出缺口权重 |
| 2015-18（渐进正常化）| 2.0% | 1.5 | 0.5 | 经济复苏 |
| 2022-23（抗通胀紧缩）| 2.5% | 2.0+ | 0.0 | 高通胀驱动，忽视产出缺口 |
| 2024-25（后紧缩）| 2.5%~3.0% | 1.5 | 0.5 | 软着陆探索 |

### 2.3 r*（中性利率）的长期趋势

```
1990年代：r* ≈ 3.5%（高增长，互联网时代）
2000年代：r* ≈ 2.5%（渐进下降）
2010年代：r* ≈ 0.5%（人口老龄化+全球化压低）
2020-23：r* ≈ 0.5%（疫情低点）→ 2024上调至 2.5%（财政赤字驱动）

注：r*不可直接观测，当前学界争议较大：
  - Holston-Laubach-Williams (HLW) 模型：r*≈0.8%（2024）
  - 市场隐含（5y5y TIPS）：r*≈2.2%（2025）
```

## 三、美联储决策框架：实际操作逻辑

### 3.1 加息决策触发条件

| 指标 | 阈值 | 说明 |
|:----|:----:|:----|
| 核心PCE | > 2.5%（连续3个月）| 主要通胀指标 |
| 核心CPI | > 3.0% | 辅助参考 |
| 失业率 | < 4.0%（充分就业）| 就业目标 |
| 非农就业 | > +200K/月（连续3月）| 劳动力市场强劲 |
| 实际GDP增速 | > 潜在增速（约2%）| 过热信号 |
| 工资增速（AHE）| > 4%（年化）| 通胀压力来源 |

### 3.2 降息决策触发条件

| 指标 | 阈值 | 说明 |
|:----|:----:|:----|
| 失业率 | > 4.5%（上升>0.5pp/3个月）| 萨姆规则触发 |
| 核心PCE | < 1.5%（连续3个月）| 通缩风险 |
| 信贷市场收紧 | SLOOS紧缩>50%银行 | 信贷传导阻塞 |
| 收益率曲线 | 10y-2y < -0.5%（持续6月）| 衰退预警 |
| 实际GDP | 负增长（连续2季度）| 技术性衰退 |

### 3.3 萨姆规则（Sahm Rule）

```
萨姆指标 = 失业率3个月均值 - 过去12个月最低失业率均值

触发阈值：萨姆指标 ≥ 0.5 → 衰退大概率已开始

历史验证（1970-2023）：
  - 准确率：100%（每次≥0.5均为衰退期）
  - 首次触发领先GDP负增长：中位数1个月
  - 当前局限：2022-24后移民激增扭曲失业率分子
```

## 四、FOMC会议决策模式

### 4.1 年度日历与节奏

- **每年8次会议**（约每6-8周一次）
- **重要发布**：3、6、9、12月发布经济预测摘要（SEP）+ 点阵图
- **政策调整节奏**：通常每次调整25bp；紧急情况可50bp或75bp

### 5.2 点阵图解读方法

| 点阵图特征 | 信号 | 推演影响 |
|:----------|:----:|:-------:|
| 中位数上移 | 紧缩预期增强 | 金融条件收紧，增长下修 |
| 中位数下移 | 宽松预期增强 | 金融条件宽松，增长上修 |

| 长期点位（r*）上移 | 高中性利率 | 估值重压，负债成本上升 |

## 六、量化宽松（QE）与量化紧缩（QT）

### 6.1 历史QE规模

| 轮次 | 时间 | 月购买规模 | 总规模 | 主要品种 |
|:----|:----|:----------:|:------:|:-------:|
| QE1 | 2008.11-2010.06 | 不固定 | $1.7T | MBS+国债 |
| QE2 | 2010.11-2011.06 | $75B | $0.6T | 国债 |
| QE3 | 2012.09-2014.10 | $85B（峰值）| $1.7T | MBS+国债 |
| QE4（新冠）| 2020.03-2022.03 | $120B | $4.6T | MBS+国债 |

### 6.2 QE对金融市场影响

- **每1万亿QE对10年国债收益率影响**：约 -15 ~ -25bp（学界估计范围）
- **QE对股市影响**：持续期内S&P500平均年化+15%（但因果难分离）
- **QT反向效应**：约为QE的50-70%（不对称性：削减资产负债表比增加影响小）

### 6.3 推演系统中的QE/QT建模

```python
# 金融条件指数（FCI）调整公式
def adjust_fci_for_qe(base_fci, fed_balance_sheet_gdp_pct):
    """
    fed_balance_sheet_gdp_pct: 美联储资产/GDP比例（%）
    历史范围：6%（2007）→ 22%（2014）→ 36%（2021）→ 28%（2024）
    """
    # 超过8%的部分每增加1%GDP，FCI宽松约0.2单位
    qe_effect = max(0, fed_balance_sheet_gdp_pct - 8) * 0.2
    return base_fci - qe_effect  # 负值=宽松
```

## 八、推演模型政策信号评分系统

```python
# 美联储政策信号评分（-2极鹰 到 +2极鸽）
def fed_policy_signal_score(metrics):
    score = 0
    
    # 通胀状态
    if metrics['core_pce'] > 3.0: score -= 1
    if metrics['core_pce'] > 4.0: score -= 1
    if metrics['core_pce'] < 2.0: score += 1
    
    # 就业状态
    if metrics['unemployment'] > 5.0: score += 1
    if metrics['unemployment'] < 3.5: score -= 1
    
    # 收益率曲线（倒挂=降息压力）
    if metrics['yield_curve_10y_2y'] < -0.3: score += 1
    
    # 金融条件
    if metrics['fci'] > 1.0: score += 1  # 条件过紧
    
    return max(-2, min(2, score))
```
