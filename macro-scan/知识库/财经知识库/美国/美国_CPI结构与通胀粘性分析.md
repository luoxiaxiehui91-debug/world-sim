# 美国_CPI结构与通胀粘性分析 — 结构化知识文档

> 核心主题：美国通胀的结构性来源、住房通胀滞后机制、工资-价格螺旋与粘性通胀的政策含义
> 更新时间：2026-05-11

---

## 核心传导链

```
供给冲击（能源/食品）+ 需求过热（财政刺激）
        ↓
标题通胀（Headline CPI）快速飙升
        ↓
核心通胀（剔除食品能源）逐步升温
        ↓
住房通胀（OER，Owner's Equivalent Rent）
→ 滞后实际市场租金12-18个月
→ 成为通胀粘性的主要来源
        ↓
工资-价格螺旋风险
→ 工人要求加薪补偿生活成本上升
→ 企业转嫁成本 → 服务业通胀粘性
        ↓
美联储被迫维持限制性利率更长时间
        ↓
需求持续抑制 → 经济衰退风险↑（软着陆 vs 硬着陆之争）
```

## 一、CPI分项权重结构

### 1.1 主要分项权重（2024年调整后）

| 分项 | 权重 | 子分项 | 说明 |
|------|------|--------|------|
| **住房（Housing）** | **36.2%** | 租金（7.6%）+ OER（25.4%）+ 酒店（2.3%）+ 水电煤（0.9%） | 最大单一权重 |
| **交通运输（Transportation）** | **15.6%** | 新车（4.1%）+ 二手车（2.7%）+ 汽车保险（2.7%）+ 燃油（4.0%）| 波动大 |
| **食品（Food）** | **13.5%** | 在家（8.5%）+ 餐馆（5.0%） | 全球大宗商品联动 |
| **医疗保健（Medical Care）** | **6.5%** | 服务（4.8%）+ 药品（1.7%） | CPI医疗 vs PCE医疗差异大 |
| **教育与通信** | **5.8%** | 学费 + 手机/互联网 | 通信价格长期通缩 |
| **娱乐** | **5.5%** | 门票/体育/宠物等 | 服务类较粘性 |
| **服装** | **2.6%** | 季节性强 | 全球化抑制通胀 |
| **能源（单独）** | **7.0%** | 电力（3.0%）+ 燃料油（1.1%）+ 天然气（2.9%） | 政策敏感，波动大 |
| 其他商品和服务 | ~7.3% | 个人护理、烟草等 | — |

### 1.2 CPI vs PCE的差异

美联储官方目标以**PCE通胀**（2%）为准，而非CPI：

| 维度 | CPI | PCE |
|------|-----|-----|
| 计算方法 | 固定权重篮子 | 链式权重（随消费行为调整） |
| 住房权重 | 36% | 约15%（OER） |
| 医疗权重 | 6.5% | 约16%（含雇主/政府支付部分） |
| 历史差异 | — | PCE通常低于CPI约0.3-0.5pp |
| 美联储关注度 | 次要参考 | 主要目标（2%） |

## 二、超级核心通胀（Supercore）：粘性来源解析

### 2.1 从CPI到Supercore的层层剥离

```
标题CPI（Headline）
    去除：食品 + 能源
    ↓
核心CPI（Core CPI）
    去除：住房（OER + 租金）
    ↓
超级核心（Supercore）= 核心服务通胀剔除住房
    包含：医疗服务、交通服务、教育、娱乐、个人护理等
    ↑
美联储主席鲍威尔2022年11月重点提出的指标
```

### 2.2 Supercore的政策含义

Supercore被认为是**工资-价格螺旋最直接的反映**，因为服务业价格的核心驱动是劳动力成本（约70%的服务业成本为工资）：

```
劳动力市场紧俏（失业率<自然失业率）
    ↓
工人议价能力↑ → 薪资增速超出生产率增长
    ↓
服务业企业转嫁成本 → 服务价格上涨
    ↓
Supercore CPI居高不下
    ↓
美联储判断：通胀粘性未消除 → 维持限制性利率
```

**历史数据：**
- 2022年Supercore峰值：约6.3%（年化）
- 2024年底Supercore：约4-4.5%，仍高于2%目标
- 历史上Supercore从高峰回落到2%需要3-5年（参考1980s）

## 三、住房通胀（OER）的滞后机制

### 3.1 OER是什么

**Owner's Equivalent Rent（业主等价租金）**：
- 定义：业主"如果出租自己的房子能收到多少租金"
- 调查方法：美国劳工统计局（BLS）对业主进行调查
- 特点：不是真实市场租金，而是调查估算值

### 3.2 OER vs 市场租金：12-18个月滞后

```
实际市场租金（Zillow/Apartment List指数）
    ↓
领先OER约12-18个月
    ↓
理由：
  ① OER反映所有现有租约（含长期合同）
  ② 市场租金只反映新签租约（边际租金）
  ③ 租约通常1年一签，故存在滞后效应
```

**关键数据（2022-2025年）：**

| 时间 | Zillow市场租金同比 | CPI中OER同比 | 差值 |
|------|--------------------|--------------|------|
| 2022年3月 | +17% | +4.5% | +12.5pp |
| 2022年9月 | +12% | +6.6% | +5.4pp |
| 2023年3月 | +5% | +8.0% | -3pp（OER继续上升） |
| 2023年9月 | +3% | +7.1% | — |
| 2024年3月 | +3.5% | +5.7% | — |
| 2024年12月 | +3% | ~5% | OER开始下降但缓慢 |

**政策含义：**
- 2022年市场租金开始回落，但OER直到2023年才见顶
- 这人为延长了CPI整体通胀的高位时间，导致美联储加息持续时间更长
- 预计OER下行将延续至2025-2026年，是通胀最终回2%的关键路径

### 3.3 新租金通胀（New Tenant Rent Index）

美联储旧金山分行建立了"新租客指数"（仅追踪新签租约），与BLS CPI方法形成对比，可以更早提示OER走向：

```
新签租约价格指数（领先12-18个月）
    ↓
将逐渐传导至所有现有租约
    ↓
CPI中OER开始下行
    ↓
核心通胀随之下行（推迟但终将发生）
```

## 四、工资-价格螺旋：1970年代教训与当前对比

### 4.1 1970年代工资-价格螺旋的形成

**触发条件（1973-1974）：**
- 第一次石油危机→标题通胀飙升
- 工会力量强大（私营部门工会率约24%）
- 工资合同中含自动通胀联动条款（COLA）
- 美联储失去公信力，允许通胀预期失锚

**螺旋机制：**
```
油价暴涨 → 标题通胀↑
    ↓
工人要求COLA加薪
    ↓
企业成本↑ → 产品涨价
    ↓
通胀↑ → 工人再次要求加薪
    ↓
恶性循环（1973-1981年）
    ↓
直到沃尔克冲击（FFR升至20%）才打破
```

### 4.2 当前（2022-2026）与1970年代的对比

| 维度 | 1970年代 | 2022年至今 |
|------|----------|------------|
| 工会率 | ~24%（私营） | ~6%（私营） |
| COLA工资合同 | 普遍 | 罕见 |
| 通胀预期锚定 | 严重失锚 | 基本维持在2-2.5% |
| 能源依赖 | 极高 | 美国已成净出口国 |
| 美联储可信度 | 低 | 高（2024-2025年证明) |
| 实际工资增速 | 长期负值（1973-1980） | 2024年起实际工资转正 |

**结论：**当前工资-价格螺旋风险显著低于1970年代，但非零。"无工会的工资螺旋"（via 劳动力短缺+职位跳槽的"Great Resignation"效应）是新型传导路径，美联储需持续监测。

## 五、预警指标

| 指标 | 阈值/信号 | 含义 |
|------|-----------|------|
| 核心CPI同比 | >4%警惕，>5%危险 | 通胀脱锚信号 |
| Supercore CPI月环比（年化） | >3.5%持续3个月+ | 服务业通胀粘性 |
| OER月环比 | >0.4%（即>4.8%年化） | 住房通胀再加速 |
| 亚特兰大联储工资增长追踪（Wage Growth Tracker） | >5%警惕 | 工资-价格螺旋风险 |
| 密歇根大学5-10年通胀预期 | >3%危险 | 长期通胀预期脱锚 |
| 纽约联储消费者预期调查（1年通胀） | >4%警惕 | 短期通胀预期 |
| 空缺职位/失业者比率（V/U比率） | >1.5为劳动力紧俏 | 工资上行压力 |
| 非农时薪同比 | >5%警惕 | 工资增速过快 |

## 六、历史案例

### 6.1 2021-2023年通胀飙升的完整路径

**第一波：供给冲击型通胀（2021年）**

| 时间 | 关键事件 | CPI同比 |
|------|----------|---------|
| 2021年3月 | 苏伊士运河"长赐"号堵塞，全球供应链受扰 | 2.6% |
| 2021年6月 | 二手车短缺（芯片不足）价格暴涨 | 5.4% |
| 2021年9月 | 能源价格开始飙升，海运费暴涨 | 5.4% |
| 2021年12月 | 奥密克戎冲击服务业，劳动力短缺 | 7.0% |

**第二波：战争叠加（2022年）**

| 时间 | 关键事件 | CPI同比 |
|------|----------|---------|
| 2022年2月24日 | 俄罗斯入侵乌克兰 | — |
| 2022年3月 | 油价突破130美元/桶 | 8.5% |
| 2022年6月 | 通胀峰值，二手车/能源/食品同步高峰 | **9.1%** |
| 2022年9月 | 能源分项开始回落，但核心通胀粘性明显 | 8.2% |

**第三波：核心通胀粘性（2022年底-2024年）**

| 时间 | 关键特征 | 核心CPI同比 |
|------|----------|-------------|
| 2023年上半年 | OER继续拉升核心通胀 | 5.5-5.6% |
| 2023年下半年 | 能源/商品通缩，但服务通胀顽固 | 4.0-4.3% |
| 2024年全年 | OER缓慢下行，Supercore高位企稳 | 3.2-3.5% |
| 2025年初 | 新关税压力重燃商品通胀担忧 | ~3.0-3.5% |

### 6.2 1970年代：失锚与沃尔克冲击

**沃尔克治理通胀的代价：**
- 1979年8月：沃尔克就任美联储主席，FFR从约11%开始快速上调
- 1981年6月：FFR达峰值约20%
- 1982年12月：失业率触顶10.8%
- 1983年：CPI从1980年峰值14.8%下降至3.2%
- 代价：两次衰退（1980年、1981-1982年），合计GDP损失约1.5万亿美元（2024年价格）

**教训：** 通胀预期一旦失锚，重新锚定的代价极高。这正是美联储2022年起决心快速加息的历史背景。

## 七、政策应对

### 7.1 美联储的"数据依赖"策略

**OER问题的应对：**
美联储官员2022年起明确表示：
- 已知道OER会滞后下行
- 但必须"穿透"这一滞后效应，关注领先指标（新租约指数）
- 不能以"知道OER会下来"为由过早停止加息

**Supercore框架的引入：**
- 2022年11月：鲍威尔首次明确提出Supercore
- 意义：剔除住房后的服务通胀更直接反映工资压力
- 若Supercore持续高企，即使整体通胀下行，美联储仍维持高利率

### 7.2 财政政策的助推与制约

| 政策 | 通胀效应 | 时机 |
|------|----------|------|
| 2020年CARES法案（2.2万亿） | 强烈刺激性 | 疫情初期，适当 |
| 2021年ARP（1.9万亿） | 过度刺激（被批评加剧通胀） | 经济已回暖，时机争议 |
| 2022年IRA/CHIPS法案 | 长期供给侧提升，短期需求刺激 | 通胀高位期争议 |

## 八、当前状态（2026）

| 指标 | 2022年峰值 | 2025年初 | 2026年预期 |
|------|-----------|---------|------------|
| 标题CPI同比 | 9.1% | ~2.8% | 2.5-3.0% |
| 核心CPI同比 | 6.6% | ~3.2% | 2.5-3.0% |
| Supercore同比 | ~6.3% | ~4.0% | ~3-3.5% |
| OER同比 | ~8.0% | ~5.0% | ~3.5-4.5% |
| 新签租约指数同比 | — | ~3% | ~2-3% |
| PCE同比（美联储目标） | ~7.1% | ~2.5% | 2.3-2.8% |

**核心矛盾（2026）：**
1. OER下行路径仍漫长，预计2026年底才接近3%以下
2. 新关税（2025年起）重新推高商品通胀，抵消住房通胀下行的进展
3. Supercore韧性意味着美联储降息路径更谨慎，不会快速回到中性利率（2.5-3%）
4. 通胀"最后一公里"（从3%回到2%）可能是最难的部分
