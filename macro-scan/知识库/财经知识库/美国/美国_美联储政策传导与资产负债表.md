## 一、美联储资产负债表结构与工具

### 1.1 资产端：持有资产构成

美联储资产负债表（总规模峰值约9万亿美元，2022年4月）的资产端主要由以下部分构成：

| 资产类型 | 峰值规模 | 当前（2026估计） | 说明 |
|----------|----------|-----------------|------|
| 美国国债（UST） | ~5.8万亿 | ~4.3万亿 | 最主要持有资产，期限从短期T-Bill到30年期 |
| 机构抵押支持证券（MBS） | ~2.7万亿 | ~2.2万亿 | 房利美/房地美/吉利美发行 |
| 隔夜逆回购（ONRRP） | 极小（负债端） | — | 资产端不含此项 |
| 其他资产（黄金凭证、SPV） | ~0.5万亿 | — | 新冠SPV已基本退出 |

### 1.2 负债端：准备金与货币发行

| 负债类型 | 峰值 | 机制说明 |
|----------|------|----------|
| 银行准备金（Reserves） | ~3.9万亿（2022年初） | 商业银行在美联储的存款 |
| 隔夜逆回购（ONRRP） | ~2.55万亿（2022年12月） | 货币基金等非银机构的存款替代 |
| 财政部一般账户（TGA） | 波动大（0.1~0.9万亿） | 财政部资金→流入银行体系→变为准备金 |
| 流通货币 | ~2.3万亿 | 相对稳定，缓慢增长 |

### 1.3 量化宽松（QE）与量化紧缩（QT）的非对称性

**扩表为何快：**
```
美联储购买国债/MBS
    ↓
在卖方（银行/主要交易商）账户创造准备金
    ↓
准备金立即存在、立即影响银行流动性
    ↓
金融条件即时宽松（利率下行、风险溢价收窄）
```

**缩表为何慢：**
```
美联储仅让到期债券自然滚出（不再续期）
    ↓
每月缩减上限：国债$600亿 + MBS$350亿 = $950亿（2023年起）
    ↓
MBS提前还款取决于房主再融资行为 → 实际缩减远低于上限
    ↓
市场流动性收紧更渐进、不确定性更小
    ↓
避免触发类似2019年9月准备金稀缺危机
```

**关键不对称性数据：**
- QE4（2020年3月–2022年3月）：从4.2万亿扩至8.9万亿，历时约24个月，净增4.7万亿
- QT（2022年6月–至今）：从8.9万亿缩至约7.1万亿（2026估计），历时约36个月，净减1.8万亿
- 结论：扩表速度约为缩表速度的2.5倍（以月均金额计）

## 二、利率传导链：联邦基金利率→全社会融资成本

### 2.1 完整传导链条

```
联邦基金利率（FFR）目标区间
        ↓（即时）
IOER（超额准备金利率）/ ONRRP利率
        ↓（即时）
SOFR（担保隔夜融资利率）
        ↓（1-5个工作日）
商业票据利率 / 货币市场基金收益率
        ↓（1-4周）
3个月/6个月SOFR期货
        ↓（1-3个月）
1年期SOFR互换 → 企业浮动利率贷款（新签）
        ↓（3-6个月）
银行主贷款利率（Prime Rate = FFR+300bp）
→ 消费信贷（汽车贷款、信用卡、HELOC）
        ↓（取决于预期，可超前或滞后）
2年期国债收益率（高度同步政策预期）
        ↓
30年期固定房贷利率（主要锚定10年期国债+信用利差约170bp）
        ↓
企业债收益率（投资级BBB = 10年Treasury + 信用利差）
```

### 2.2 SOFR替代LIBOR的影响（2023年6月完成切换）

| 维度 | LIBOR | SOFR |
|------|-------|------|
| 基准类型 | 无担保银行间报价 | 有担保（国债回购）隔夜实际交易 | 
| 操纵风险 | 高（2012年丑闻） | 极低 |
| 覆盖期限 | 隔夜至12个月 | 主要为隔夜，衍生出期限SOFR |
| 信用风险溢价 | 含银行信用风险 | 近乎无风险，接近OIS |
| 对经济的影响 | 危机时跳升，传导失真 | 更平稳，与货币政策传导更一致 |

**SOFR过渡后的关键变化：**
- 约15万亿美元浮动利率合同（贷款、债券、衍生品）完成转换
- 危机时信用利差不再自动嵌入基准利率，银行融资压力需通过OIS-SOFR利差单独观测
- TED利差（LIBOR-T-Bill）概念由"SOFR-OIS利差"替代，通常极小（<5bp）

### 2.3 各传导渠道时滞对比

| 渠道 | 传导时滞 | 传导效率 | 当前状态 |
|------|----------|----------|----------|
| 政策利率→短端市场利率 | 即时-1周 | 极高 | 完整传导 |
| 政策利率→30年房贷利率 | 1-6个月（预期驱动） | 高 | 已充分反映 |
| 政策利率→企业投资 | 6-18个月 | 中 | 存在滞后效应 |
| 政策利率→通胀 | 12-24个月 | 低（多因素干扰） | 仍在传导 |
| 政策利率→就业 | 6-18个月 | 中 | 有限滞后 |

## 三、ONRRP的崛起与消退

### 3.1 ONRRP（隔夜逆回购）的机制

ONRRP允许货币市场基金等合格参与方将资金"存入"美联储，获得固定收益（= FFR下限）。

**为何在2021-2022年规模爆发至2.55万亿：**
```
大规模QE → 银行准备金泛滥 → 短期利率被压至零附近
    ↓
货币市场基金面临"负收益"压力（国库券利率≈0%）
    ↓
选择停泊至ONRRP获取固定利率（哪怕极低但正值）
    ↓
ONRRP余额从2021年初<200亿 → 2022年12月峰值2.55万亿
```

**2023-2025年ONRRP消退的驱动因素：**
- 美联储加息后T-Bill利率超过ONRRP利率 → 货基重新配置T-Bill
- TGA余额重建（债务上限解决后）吸收准备金
- 银行准备金重新变得稀缺，ONRRP不再作为流动性蓄水池
- 2025年初ONRRP余额降至约1500亿，基本恢复正常

### 3.2 ONRRP变化与金融条件的关系

```
ONRRP余额↓（资金流出）
    ↓
流向T-Bill和短期回购市场
    ↓
短期利率承压上行 OR 准备金充裕维持
    ↓
银行体系流动性不立即收紧（缓冲效应）
```

| 指标 | 阈值/信号 | 含义 |
|------|-----------|------|
| 准备金/GDP比率 | <8%为稀缺警戒线 | 2019年危机时约8.5%触发 |

## 五、历史案例

### 5.1 2013年"缩减恐慌"（Taper Tantrum）

**时间线：**

| 时间 | 事件 | 市场反应 |
|------|------|----------|
| 2013年5月22日 | 伯南克国会证词暗示缩减QE | 10年期国债利率从1.94%开始攀升 |
| 2013年6月 | 美联储会议纪要证实讨论Taper | 10年期利率突破2.5% |
| 2013年8-9月 | 市场预期9月Taper宣布 | 10年期利率触及3.0% |
| 2013年9月18日 | 美联储意外"不缩减"决定 | 利率快速回落至2.7% |
| 2013年12月 | 正式宣布缩减（$100亿/月） | 市场已消化，反应平稳 |

**影响量化：**
- 10年期国债利率4个月内从1.6%升至3.0%，涨幅140bp
- 30年期房贷利率从3.35%升至4.58%，美国房市明显降温
- 新兴市场遭遇资本外流：巴西雷亚尔贬值约20%，印度卢比贬值18%，印尼盾贬值15%
- "Taper Tantrum"揭示美联储沟通策略的重要性

### 5.2 2022-2024年激进加息缩表周期

**加息路径：**

| 时间 | 事件 | FFR目标区间 |
|------|------|-------------|
| 2022年3月16日 | 首次加息 | 0.25%-0.50% |
| 2022年5月4日 | 加息50bp | 0.75%-1.00% |
| 2022年6月-11月 | 连续4次加息75bp | 3.75%-4.00% |
| 2022年12月 | 加息50bp | 4.25%-4.50% |
| 2023年2月-7月 | 渐进加息至峰值 | 5.25%-5.50% |
| 2023年7月 | 最后一次加息 | 5.25%-5.50% |
| 2024年9月 | 首次降息50bp | 4.75%-5.00% |
| 2025年底（估计） | 降息至约3.5-4% | — |

**缩表路径：**
- 2022年6月启动QT，初始上限：国债300亿+MBS175亿/月
- 2022年9月上调上限：国债600亿+MBS350亿/月（=950亿/月）
- 2024年6月放慢：国债上限降至250亿/月（MBS不变），预防准备金过度收紧
- 2024年底-2025年：资产负债表约7.2万亿，较峰值缩减约1.7万亿

**传导效果评估：**
- 30年期房贷利率从3.0%（2021年底）升至7.8%（2023年10月峰值），房屋销量同比跌逾35%
- 美元指数（DXY）从95升至114（2022年9月峰值）
- 标普500最大跌幅约25%（2022年全年）
- CPI从9.1%（2022年6月峰值）降至2.4%左右（2025年初）
- 就业市场韧性超预期：失业率未突破4.5%，实现"软着陆"

## 六、政策应对框架

### 6.1 美联储工具箱全景

| 工具 | 类型 | 传导方向 | 当前状态（2026） |
|------|------|----------|-----------------|
| 联邦基金利率目标 | 价格型 | 全面 | 降息周期中，约3.5-4% |
| ONRRP利率 | 利率走廊下限 | 货币市场 | 正常化 |
| IOER/IORB | 利率走廊上限 | 准备金管理 | 主动工具 |
| QT缩表 | 数量型（收紧） | 长端利率 | 进行中 |
| QE购债 | 数量型（宽松） | 长端利率+风险溢价 | 待机 |
| 前瞻指引 | 预期管理 | 全期限 | 关键工具 |
| 紧急贷款设施（BTFP等） | 危机工具 | 流动性 | 2024年3月关闭 |

### 6.2 政策边界与约束

**零利率下限（ZLB）问题：**
- 名义利率理论上不能有效低于零（存款搬家至现金）
- 实践中欧元区/日本测试了-0.1%~-0.5%的负利率，但效果有限
- 应对：QE、前瞻指引、YCC（收益率曲线控制）

**财政主导风险：**
- 联邦债务/GDP超过120%，每年利息支出约1万亿美元（2025年）
- 若美联储为压低融资成本被迫"货币化债务" → 通胀信誉受损
- 当前尚未进入财政主导，但这是中长期尾部风险

## 七、当前状态（2026）

### 7.1 利率与资产负债表现状

| 指标 | 2022年峰值 | 2026年估计 |
|------|-----------|------------|
| FFR | 5.25-5.50% | 3.50-4.00% |
| 美联储资产规模 | 8.9万亿 | ~7.0-7.2万亿 |
| 银行准备金 | 3.3万亿 | ~3.0万亿 |
| ONRRP余额 | 2.55万亿 | ~1000-2000亿 |
| 10年期国债收益率 | ~4.2%（2022年10月） | ~4.0-4.5% |
| 30年期房贷利率 | 7.8%（2023年10月） | ~6.5-7.0% |

### 7.2 核心矛盾与前瞻

1. **降息路径不确定**：通胀粘性（尤其住房通胀）制约降息空间，市场对2026年底利率预期分歧较大
2. **缩表终点未明**：美联储需在"充裕准备金"和"缩表目标"之间找到平衡，类似2019年准备金稀缺危机的风险仍存在
3. **美债供给压力**：财政赤字持续，净发债规模大，在美联储不再续期的背景下，私人市场需吸收更多供给 → 长端利率存在上行压力
4. **全球外溢效应持续**：高美元利率继续抑制新兴市场资本回流，地缘政治叠加美元强势，全球金融脆弱性偏高
