## 二、传导机制

### 2.1 能源渠道

```
俄乌战争
    ↓
俄罗斯能源制裁/自限
    ↓
┌─────────────────────────────┐
│  石油                        │
│  ├── 俄罗斯占全球供应12%     │
│  ├── 制裁→供应减少           │
│  └── 油价：$75→$120（+60%）  │
└─────────────────────────────┘
    ↓
┌─────────────────────────────┐
│  天然气                      │
│  ├── 俄罗斯占欧洲供应40%     │
│  ├── 北溪管道中断            │
│  └── 欧洲气价：+900%         │
└─────────────────────────────┘
    ↓
欧洲能源危机
```

### 2.2 通胀传导

```
能源价格↑
    ↓
┌─────────────────────────────┐
│  直接影响                    │
│  ├── 汽油价格→交通成本       │
│  ├── 取暖成本→家庭支出       │
│  └── 电力价格→全行业成本      │
└─────────────────────────────┘
    ↓
┌─────────────────────────────┐
│  间接影响                    │
│  ├── 化工成本↑→化肥价格↑     │
│  ├── 运输成本↑→商品价格↑     │
│  └── 能源密集行业成本↑        │
└─────────────────────────────┘
    ↓
通胀飙升
```

## 三、政策应对

### 3.1 央行反应

| 央行 | 政策 | 原因 |
|------|------|------|
| 美联储 | 加息至5.25% | 抗通胀 |
| 欧央行 | 加息至4% | 抗通胀 |
| 英国央行 | 加息至5.25% | 抗通胀 |

### 3.2 财政应对

| 措施 | 国家 | 内容 |
|------|------|------|
| 能源补贴 | 德国 | 2000亿欧元 |
| 价格管制 | 多国 | 限制气价 |
| 减税 | 多国 | 降低燃油税 |

### 3.3 供给应对

| 措施 | 效果 |
|------|------|
| 释放战略储备 | 短期缓解 |
| 增产呼吁OPEC | 效果有限 |
| LNG进口多元化 | 中长期解决 |
