# 12_历史案例

本目录存放**快速查阅复盘**，精炼记录历史上各类经济/金融事件的关键要素，适合推演时快速定位历史先例。

## 与 13_历史危机情景/ 的分工

| 维度 | 本目录（12_历史案例）| 隔壁目录（13_历史危机情景）|
|:---|:---|:---|
| 定位 | 快速复盘 | 深度分析 |
| 篇幅 | 精炼摘要，覆盖面广 | 完整机制拆解，含传导路径 |
| 典型用途 | 推演时快速检索"有没有类似历史" | 构建推演框架、深究情景类比 |

## 目录内容

涵盖以下主题：
- 滞胀周期（1970s）、亚洲金融危机（1997）、欧债危机（2010）
- 2008金融危机、2015中国股灾、2020疫情冲击复盘
- 2022-2026 美联储紧缩降息完整周期
- 日元套利交易与2024崩盘、俄乌战争能源通胀传导
- 拉美债务危机、墨西哥龙舌兰危机、英国LDI养老金危机
- 日本失落三十年（详细）
- 美国财政可持续性风险、货币政策泰勒规则2026现状
