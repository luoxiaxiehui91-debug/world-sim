# 1997亚洲金融危机复盘

## 危机时间线

| 时间 | 事件 |
|------|------|
| 1997-07-02 | 泰国放弃固定汇率，泰铢暴跌20% |
| 1997-08 | 马来西亚、印尼货币受冲击 |
| 1997-10 | 韩国危机爆发，韩元贬值 |
| 1997-11 | 日本山一证券倒闭 |
| 1998-01 | 印尼暴乱，苏哈托下台 |
| 1998-08 | 俄罗斯违约，LTCM危机 |
| 1999 | 大部分经济体开始复苏 |

## 危机根源

### 1. 固定汇率制度
- 多国盯住美元
- 央行承诺汇率稳定
- 但外汇储备不足

### 2. 经常账户赤字
- 泰国：赤字占GDP 8%
- 印尼：赤字占GDP 4%
- 依赖外资流入弥补

### 3. 短期外债过高
- 企业借入美元债务
- 期限错配（短债长投）
- 汇率风险敞口巨大

### 4. 金融体系脆弱
- 银行监管薄弱
- 关系贷款普遍
- 道德风险严重

### 5. 资产泡沫
- 房地产价格高企
- 股市估值过高
- 泡沫破裂加剧危机

## 传导机制

### 货币攻击
```
投机者借入本币 → 抛售换汇 → 央行消耗储备
               → 储备耗尽 → 放弃固定汇率
               → 本币暴跌 → 债务负担激增
```

### 债务螺旋
```
本币贬值 → 美元债务本币价值↑ → 企业违约
        → 银行坏账↑ → 信贷收缩
        → 经济衰退 → 资本外流 → 进一步贬值
```

### 区域传染
```
一国危机 → 投资者风险规避↑
        → 撤出相似国家
        → 危机扩散
```

## 应对措施

### IMF方案
- 紧缩财政
- 提高利率
- 结构改革
- 争议：加剧衰退

### 马来西亚资本管制
- 固定汇率
- 资本流出限制
- 争议：但较快恢复

### 香港保卫战
- 提高利率
- 政府买入股票
- 成功守住联系汇率

## 教训与启示

### 1. 汇率制度选择
- 固定汇率需充足储备
- 或选择浮动汇率
- 中间状态最脆弱（不可能三角）

### 2. 外债管理
- 限制短期外债比例
- 鼓励长期投资
- 避免货币错配

### 3. 金融监管
- 强化银行监管
- 建立存款保险
- 处理不良资产

### 4. 区域合作
- 清迈倡议（货币互换）
- 区域外汇储备库
- 危机预防机制

### 5. 宏观审慎
- 监控资本流动
- 逆周期调节
- 防范资产泡沫

## 对当前的意义

### 新兴市场脆弱性
- 外债水平
- 外汇储备充足性
- 经常账户平衡

### 汇率灵活性
- 多数亚洲国家已转向管理浮动
- 缓冲外部冲击能力增强

### 区域安全网
- 清迈倡议多边化
- 金砖国家储备池
- 但规模仍有限

### 美联储加息周期
- 资本流出压力
- 汇率贬值压力
- 需关注外债高企国家
