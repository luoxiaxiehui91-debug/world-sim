# 2010欧债危机复盘

## 危机时间线

| 时间 | 事件 |
|------|------|
| 2009-10 | 希腊新政府披露赤字占GDP 12.7% |
| 2010-04 | 希腊申请援助，首笔1100亿欧元 |
| 2010-11 | 爱尔兰援助850亿欧元 |
| 2011-04 | 葡萄牙援助780亿欧元 |
| 2011-07 | 希腊第二轮援助1090亿欧元 |
| 2012-06 | 西班牙银行援助1000亿欧元 |
| 2012-09 | ECB宣布OMT（直接货币交易） |
| 2013-03 | 塞浦路斯援助100亿欧元 |

## 危机根源

### 1. 欧元区制度缺陷
- **货币统一，财政分散**
- 无统一财政转移机制
- 无最后贷款人（初期）

### 2. 南欧国家结构性问题
- **希腊**：财政赤字长期高企，数据造假
- **意大利**：增长低迷，债务高企
- **西班牙**：房地产泡沫破裂
- **葡萄牙**：低增长，高债务

### 3. 银行-主权债务螺旋
```
银行持有本国国债 → 国债价格↓ → 银行资本↓
                 → 银行需政府救助 → 政府债务↑
                 → 国债价格继续↓ → 恶性循环
```

### 4. 竞争性贬值缺失
- 无法通过货币贬值恢复竞争力
- 内部贬值（工资下调）政治困难
- 导致长期衰退

## 危机传导

### 市场传染
```
希腊危机 → 市场质疑其他南欧国家
        → 国债利差扩大
        → 融资成本上升
        → 债务可持续性恶化
```

### 银行传导
```
银行持有问题国家国债 → 减值损失
                    → 信贷收缩
                    → 实体经济受损
```

### 政治传染
```
危机 → 紧缩政策 → 经济衰退 → 失业上升
    → 政治极端化 → 反欧盟势力上升
    → 市场进一步担忧
```

## 应对措施

### 财政紧缩
- 削减支出
- 提高税收
- 争议：加剧衰退

### 结构改革
- 劳动力市场改革
- 养老金改革
- 提高竞争力

### 金融救助
- EFSF/ESM设立
- 提供贷款援助
- 条件：紧缩+改革

### 货币政策
- ECB降息
- LTRO（长期再融资操作）
- OMT（直接货币交易）
- 最终：量化宽松

## 各国影响

### 希腊
- GDP累计下降25%
- 失业率峰值27%
- 债务/GDP从120%升至180%
- 三轮援助总计约3000亿欧元

### 西班牙
- 房地产价格下跌30%
- 失业率峰值26%
- 银行资本重组

### 意大利
- 衰退持续
- 债务/GDP升至130%+
- 但无需正式援助

### 德国
- 经济相对稳定
- 承担最大救助份额
- 政治争议

## 教训与启示

### 1. 货币联盟需要财政联盟
- 统一货币需统一财政框架
- 转移支付机制应对冲击
- 银行联盟（正在进行）

### 2. 结构改革的重要性
- 提高生产率
- 灵活劳动力市场
- 避免竞争力差距扩大

### 3. 危机预防机制
- 财政规则（稳定与增长公约）
- 过度赤字程序
- 欧洲学期（政策协调）

### 4. 最后贷款人
- ECB角色演变
- OMT消除尾部风险
- 但道德风险需管理

### 5. 债务可持续性
- 债务重组可能更早介入
- 私人部门参与（PSI）
- 避免债务螺旋

## 对当前的意义

### 欧元区改革进展
- 银行联盟部分完成（SRM）
- 资本市场联盟推进中
- 财政联盟仍有限

### 新风险点
- 意大利债务高企
- 政治极端化
- 增长乏力

### 政策工具
- OMT存在但未使用
- PEPP（疫情购债）
- TPI（反碎片化工具）
