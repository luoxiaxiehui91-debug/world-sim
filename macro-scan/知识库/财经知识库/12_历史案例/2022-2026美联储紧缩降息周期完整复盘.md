# 2022-2026 美联储紧缩—降息周期完整复盘

> 时间跨度：2022.03 - 2026.05（进行中）
> 更新时间：2026-05-21
> 分析角度：政策路径 / 通胀传导 / 资产配置影响

---

## 一、加息周期（2022.03 - 2023.07）

### 背景
- 2021-2022：新冠后财政刺激（4.5万亿美元）叠加供应链瓶颈、俄乌战争能源冲击
- 2022.06 CPI峰值：9.1%（40年最高）
- Fed误判通胀为"暂时性"延误行动，后急剧纠偏

### 加息时间线

| 日期 | 行动 | FFR |
|------|------|-----|
| 2022.03 | +25bp | 0.25-0.5% |
| 2022.05 | +50bp | 0.75-1% |
| 2022.06 | +75bp（首次）| 1.5-1.75% |
| 2022.07 | +75bp | 2.25-2.5% |
| 2022.09 | +75bp | 3-3.25% |
| 2022.11 | +75bp | 3.75-4% |
| 2022.12 | +50bp | 4.25-4.5% |
| 2023.02 | +25bp | 4.5-4.75% |
| 2023.03 | +25bp | 4.75-5% |
| 2023.05 | +25bp | 5-5.25% |
| 2023.07 | +25bp（最终）| 5.25-5.5% |

- 共加息 525bp，历史最快速度（11次，18个月）

### 市场影响
- 标普500从高点（4800）回撤至3500（-27%）
- 10Y国债从1.5%升至5%（2023.10触顶）
- T10Y2Y从+100bp倒挂至-107bp（2022.12-2023.07历史深度倒挂）

## 二、维持高位期（2023.07 - 2024.09）

### 背景
- 通胀从9.1%峰值回落至3%附近，但最后一公里进展迟缓
- 劳动市场强韧：失业率维持4%以下
- CPI降至3%后在2.8-3.4%区间震荡，核心PCE未能降至2%

### 政策立场
- "Higher for Longer"：2023年9月点阵图显示2024年仅降息50bp
- 市场预期屡次被纠正（2024年初市场预期降息6次，最终仅3次）

### 警示教训
- 1970年代"停走"（Stop-Go）政策教训：过早降息导致通胀二次反弹
- 2024年1-3月CPI连续超预期（3.1%→3.2%→3.5%），推迟降息预期

## 三、首次降息周期（2024.09 - 2025.末）

### 2024年首次降息
- 2024.09.18：-50bp（FFR：5.25-5.5% → 4.75-5%），超预期大幅开局
- 2024.11：-25bp
- 2024.12：-25bp（年末累计降息100bp）

### 2025年继续降息
- 2025年上半年：通胀降至2.5%以下，失业率稳定约4.1%
- 累计降息约150-175bp（全年）
- FFR从5.25%降至约3.5-3.75%（2025末）

## 四、2026年"二次通胀"威胁期（当前）

### 背景与指标
- WTI原油：112.25美元（2026.05.18），较2025末约100美元上升10.5%
- PPI同比：9.82%（2026.04）— 上游成本压力重燃
- CPI同比：3.78%（2026.04）— 已离目标2%较远，且有重返4%+风险
- 核心PCE：3.5%（2026.03）— 粘性通胀未降
- FFR：3.63%（实际有效利率）

### 泰勒规则诊断（2026.05）
- 泰勒规则推算：CPI=3.78%，产出缺口=0.5%（轻微正产出缺口）
  - i = 2% + 3.78% + 0.5×(3.78%-2%) + 0.5×0.5% = **约7.3%**
- 实际FFR = 3.63%
- 政策缺口 = -3.6ppt（货币政策实质仍偏宽松）

### 主要风险路径
1. **油价传导链**：WTI 112 → PPI 9.82% → 制造成本 → CPI 4%+ → PCE 4%+ → FOMC被迫暂停/反转降息
2. **财政可持续性**：债务/GDP = 127%，穆迪警告；10Y收益率4.61%已含约20bp信用溢价
3. **消费信心崩塌**：Michigan CSI = 53.3（低于2022年衰退期边缘水平）；油价+房贷6.36%双重挤压

### 政策选项与约束
| 情景 | 概率 | FFR路径 |
|------|------|---------|
| 按兵不动到Q3 | 65% | 3.63% → 3.63%（9月可能-25bp） |
| 年内降息 | 25% | 3.63% → 3.13%（Q3+Q4各-25bp） |
| 被迫加息 | 10% | 3.63% → 4%+（油价140+触发） |

### 与1970s对比
- 1973-74：阿拉伯石油禁运 → 油价翻四倍 → CPI 12% → Fed "停走"
- 2026：OPEC+维持减产+中东供给扰动 → WTI 112 → 政策两难
- 关键区别：2026年美联储实际利率仍为正（DFII10=2.13%），有别于1970s负实际利率状态

## 五、关键结论

### 对美国的影响
- 短期（3个月）：消费承压，GDP增速可能从2.66%降至2.0-2.4%
- 中期（6-12月）：若油价不回落，二次通胀风险上升；若降息预期完全逆转（无降息），对股市（标普7354）有10-15%的估值压缩风险

### 领先指标关注序列
1. **WTI原油** — 每周观察；若突破120美元，通胀压力加速传导
2. **美国国债拍卖覆盖率** — 6月拍卖（2026.06）：覆盖率<2.0x为重大预警
3. **核心PCE月度** — 若连续2个月不降，9月降息概率将归零
4. **消费者信心** — 若降至45以下，GDP下行风险显著上升

### 资产配置含义
| 资产 | 3个月方向 | 核心逻辑 |
|------|----------|---------|
| TIPS | 超配↑ | 实际收益率2.13%正值+通胀尾部风险 |
| 原油/能源ETF | 超配↑ | 供给约束维持，短期无明显回调动力 |
| 黄金 | 超配↑ | 美债信用担忧+通胀+财政风险三重支撑 |
| 美股（科技） | 低配↓ | 高估值（PE 26x）+ 利率维持高位=分子分母双压 |
| 30Y美债 | 低配↓ | 财政赤字+通胀预期上移，长端压力 |
| 美元 | 标配→ | 高利率支撑 vs 财政风险，双力均衡 |
