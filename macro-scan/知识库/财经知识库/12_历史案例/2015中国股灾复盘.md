# 2015中国股灾复盘

## 时间线

| 时间 | 事件 | 上证指数 |

## 牛市成因

### 1. 杠杆资金推动
- **融资融券**：从4000亿增至2.2万亿
- **场外配资**：估计1-2万亿
- **伞形信托**：结构化产品
- 总杠杆估计：4-5万亿

### 2. 政策预期
- 改革预期（国企改革、一带一路）
- 货币宽松（降息降准）
- "国家牛市"叙事

### 3. 散户入场
- 新开户数激增
- "全民炒股"
- 羊群效应明显

### 4. 估值泡沫
- 创业板PE超100倍
- 中小板PE超60倍
- 蓝筹相对合理

## 暴跌机制

### 杠杆去化螺旋
```
股价下跌 → 触发平仓线 → 强制平仓
        → 抛售增加 → 股价继续下跌
        → 更多账户触发平仓 → 恶性循环
```

### 流动性枯竭
- 千股跌停（连续多日）
- 停牌避跌（超半数停牌）
- 买盘消失

### 情绪崩溃
- 恐慌性抛售
- 多杀多
- 信心丧失

## 救市措施

### 1. 资金入市
- 证金公司出资1.5万亿
- 券商出资1200亿
- 汇金增持ETF

### 2. 政策调整
- 暂停IPO
- 减免交易费用
- 放宽融资平仓线

### 3. 限制卖出
- 大股东减持限制
- 程序化交易限制
- "恶意做空"调查

### 4. 舆论引导
- 官媒喊话
- 打击"谣言"

## 救市效果与争议

### 正面
- 阻断恐慌螺旋
- 稳定市场信心
- 防止系统性风险

### 负面
- 道德风险
- 市场扭曲
- 退出困难
- 政策不确定性

## 后续影响

### 监管收紧
- 去杠杆持续
- 场外配资清理
- 程序化交易监管

### 市场变化
- 散户离场
- 机构占比上升
- 价值投资理念强化

### 制度改革
- 熰断机制（试行后废除）
- 注册制推迟
- 信息披露强化

## 教训与启示

### 1. 杠杆风险
- 杠杆是双刃剑
- 需总量控制和监测
- 场外杠杆难以监管

### 2. 救市原则
- 救流动性，不救价格
- 透明、可预期
- 及时退出

### 3. 投资者教育
- 风险意识
- 理性投资
- 避免"政策市"思维

### 4. 监管体系
- 跨部门协调
- 实时监测
- 预警机制

### 5. 市场机制
- 让市场发挥决定性作用
- 减少行政干预
- 完善基础制度

## 对当前的意义

### A股现状（2026）
- 杠杆水平可控
- 估值相对合理
- 机构占比提升
- 但散户特征仍明显

### 风险点
- 结构性杠杆（衍生品）
- 外资流动影响
- 与债市联动

### 监管方向
- 全面注册制
- 信息披露
- 投资者保护
