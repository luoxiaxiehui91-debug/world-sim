## 一、反馈回路体系概述

推演模型包含6条核心反馈回路，描述宏观经济中的自我强化与自我修复机制。正反馈回路放大冲击（危机加速），负反馈回路吸收冲击（自我稳定）。

| 回路 | 名称 | 类型 | 主导场景 |
|:-----|:-----|:----:|:-------:|
| F1 | 信贷-增长螺旋 | 正反馈 | 繁荣/衰退 |
| F2 | 通胀-工资螺旋 | 正反馈 | 高通胀期 |
| F3 | 资产价格-财富效应 | 正反馈 | 资产泡沫 |
| F4 | 货币政策-需求稳定 | 负反馈 | 常态调节 |
| F5 | 汇率-经常账户调整 | 负反馈 | 失衡修正 |
| F6 | 流动性陷阱-财政替代 | 混合 | 零利率期 |

## 二、F1：信贷-增长螺旋（Credit-Growth Spiral）

### 2.1 机制描述

```
经济增长↑ → 信贷需求↑ → 银行放贷意愿↑ → 信贷供给↑
    ↑________________________投资/消费↑__________________/
```

危机方向（逆转）：
```
资产价格↓ → 抵押品价值↓ → 银行收紧信贷 → 企业投资↓
    ↑_______________________GDP↓_______________________/
```

### 2.2 量化参数

| 参数 | 符号 | 基准值 | 危机时 | 单位 |
|:----|:----:|:------:|:------:|:----:|
| 信贷乘数 | α_credit | 1.8 | 0.6 | 无量纲 |
| GDP对信贷增速弹性 | β_gdp | 0.35 | 0.20 | pp/pp |
| 银行信贷惜贷阈值 | θ_bank | NPL>5% | NPL>3% | — |
| 螺旋启动延迟 | τ_F1 | 2季度 | 1季度 | 季度 |
| 峰值放大倍数 | A_F1 | 2.2x | 3.5x | 无量纲 |
| 回路衰减系数 | δ_F1 | 0.15/季 | 0.08/季 | 季度⁻¹ |

### 2.3 历史标定案例

| 事件 | 螺旋启动信号 | 放大倍数（实测） |
|:----|:-----------:|:--------------:|
| 2007-09美国次贷 | HPI下跌>8%（6个月） | 3.2x |
| 2015-16中国去杠杆 | M2增速跌破10% | 1.8x |
| 2011-12欧债危机 | CDS利差>300bp | 2.6x |
| 2020新冠冲击 | 信贷骤停2周 | 短暂4.1x（政策快速干预后逆转）|

### 2.4 预警触发条件

```python
# F1螺旋激活判断逻辑
def f1_spiral_active(credit_growth, gdp_growth, npl_ratio):
    if credit_growth < -5 and gdp_growth < 0:
        return "NEGATIVE_SPIRAL", multiplier=3.0
    elif credit_growth > 15 and gdp_growth > 3:
        return "POSITIVE_BUBBLE", multiplier=2.0
    else:
        return "STABLE", multiplier=1.0
```

## 三、F2：通胀-工资螺旋（Wage-Price Spiral）

### 3.1 机制描述

```
通胀预期↑ → 工人要求加薪↑ → 工资成本↑ → 企业涨价↑
    ↑_________________________实际通胀↑__________________/
```

### 3.2 量化参数

| 参数 | 符号 | 基准值（常态） | 危机激活值 | 说明 |
|:----|:----:|:------------:|:---------:|:----|
| 工资通胀弹性 | α_wage | 0.45 | 0.65 | 工资对通胀的敏感度 |
| 价格-工资传导比 | β_price | 0.55 | 0.75 | 工资涨幅转化为价格 |
| 预期锚定强度 | γ_anchor | 0.70（强央行）| 0.30（弱央行）| 预期管理效果 |
| 螺旋自持条件 | 触发 | 连续6个月工资实际增速>3% | — | — |
| 最大放大系数 | A_F2 | 1.5x | 2.8x | 取决于央行反应 |
| 解锚时间 | τ_anchor | 12-18个月 | 24-36个月 | 需要政策强力干预 |

### 3.3 激活条件（历史数据标定）

1970年代美国滞胀案例：
- **触发**：WTI油价+200%（1973），工资增速达11%/年
- **峰值**：CPI=13.5%，工资=9%，形成稳定螺旋
- **破解**：沃尔克货币紧缩（联邦基金利率→20%），历时3年

2021-23欧美通胀案例：
- **触发**：疫情供应冲击+财政补贴叠加
- **工资弹性**：美国实测α_wage=0.52，低于1970s
- **预期锚定**：强央行下螺旋未完全形成（A_F2=1.6x）

### 3.4 中国适用性说明

中国工资-价格螺旋传导较弱，原因：
1. 劳动力市场分割（城乡户籍）
2. 国有企业薪酬行政管制
3. 通胀预期长期锚定（PBC信誉）

**中国适用参数**：α_wage=0.20，β_price=0.35，γ_anchor=0.80

## 四、F3：资产价格-财富效应回路（Wealth Effect Loop）

### 4.1 机制描述

```
股价/房价↑ → 家庭财富↑ → 消费↑ → 企业盈利↑ → 股价↑
    ↑___________________________（泡沫强化）_______________/
```

### 4.2 量化参数

| 参数 | 符号 | 美国基准 | 中国基准 | 欧元区基准 |
|:----|:----:|:-------:|:-------:|:---------:|
| 股价财富效应MPC | MPC_stock | 0.035 | 0.015 | 0.025 |
| 房价财富效应MPC | MPC_house | 0.055 | 0.040 | 0.045 |
| 资产价格-GDP乘数 | κ_asset | 0.18 | 0.12 | 0.15 |
| 泡沫持续中位时长 | T_bubble | 5.2年 | 3.8年 | 4.5年 |
| 泡沫破裂速度 | v_crash | 18-24个月 | 12-18个月 | 15-21个月 |
| 负财富效应放大 | A_neg | 1.4x（vs正向）| 1.6x | 1.5x |

**说明**：负财富效应普遍大于正财富效应（损失厌恶心理），破裂速度快于积累速度。

### 4.3 楼市崩盘传导路径（中国特殊模型）

```
房价下跌10% → 
  ├── 居民消费降低约0.6%（财富效应）
  ├── 地方政府土地出让收入下降约15%
  ├── 房地产投资下降约8%（占GDP约5-6%）
  └── 钢铁/水泥/建材需求下降约12%
  
总GDP影响：-1.2% ~ -1.8%（含乘数效应，2年累计）
```

## 五、F4：货币政策-需求稳定回路（Taylor Rule Loop）

### 5.1 机制描述（负反馈稳定器）

```
通胀↑/产出缺口↑ → 央行加息 → 需求冷却 → 通胀↓/产出缺口收窄
```

### 5.2 泰勒规则参数（各主要央行）

标准泰勒规则：`i = r* + π* + 1.5(π - π*) + 0.5(y - y*)`

| 央行 | 中性利率r* | 通胀目标π* | 通胀系数 | 产出缺口系数 | 实测反应速度 |
|:----|:----------:|:---------:|:-------:|:-----------:|:-----------:|
| 美联储 | 2.5% | 2.0% | 1.5 | 0.5 | 2-3次会议 |
| 欧央行 | 2.0% | 2.0% | 1.5 | 0.3 | 3-4次会议 |
| 英格兰银行 | 2.5% | 2.0% | 1.5 | 0.5 | 2-3次会议 |
| 人民银行 | 3.0%（估计）| 3.0% | 0.8 | 1.2 | 4-8次（偏慢）|
| 日本银行 | -0.5%（实际）| 2.0% | 0.5 | 0.3 | 极慢（YCC约束）|

**中国人民银行特殊性**：双目标制（通胀+增长），产出缺口权重更高；加息阈值更高，减息更积极（不对称反应）。

### 5.3 负反馈失效条件

以下情况下F4稳定回路失效（需切换F6逻辑）：
1. 政策利率触达零下界（ZLB）
2. 通胀与衰退同时存在（滞胀）
3. 金融系统断裂（传导阻塞）
4. 主权债务危机（市场不信任央行）

## 六、F5：汇率-经常账户调整回路（J-Curve Loop）

### 6.1 机制描述（负反馈）

```
经常账户赤字↑ → 货币贬值 → [J曲线效应] → 出口竞争力↑ → 经常账户改善
```

### 6.2 量化参数

| 参数 | 符号 | 美国 | 中国 | 欧元区 |
|:----|:----:|:----:|:----:|:------:|
| 汇率贬值对出口弹性（长期）| ε_export | -1.5 | -1.2 | -1.3 |
| 汇率贬值对进口弹性（长期）| ε_import | 0.8 | 0.6 | 0.7 |
| J曲线初期恶化持续时间 | T_J | 6-12个月 | 3-6个月 | 6-9个月 |
| 汇率贬值10%对CA改善（GDP%，2年）| ΔCA | +0.8% | +0.6% | +0.7% |
| 马歇尔-勒纳条件满足 | 条件 | ε_X+ε_M>1 | 1.8（满足）| 2.0（满足）|

**中国汇率弹性较低原因**：出口定价多以美元计，短期汇率贬值对出口量提振有限；进口多为刚性能源/粮食，弹性低。

## 七、F6：流动性陷阱-财政替代回路（Keynesian Loop）

### 7.1 机制描述（混合回路）

```
ZLB → 货币政策失效 → 财政扩张接管 → 需求刺激 → 增长↑
                    ↘ 公债↑ → 债务可持续性风险 → 负反馈
```

### 7.2 量化参数

| 参数 | 符号 | 基准值 | 说明 |
|:----|:----:|:------:|:----|
| 财政乘数（ZLB期间）| M_fiscal | 1.5 ~ 2.0 | 常态仅0.6~0.8 |
| 财政乘数（常态期）| M_fiscal_normal | 0.6 | — |
| 债务-GDP可持续阈值 | D_threshold | 90%（Reinhart-Rogoff）| 存在争议 |
| 量化宽松对长端利率效果 | ΔQE | -25bp/GDP1%购买 | 美国实测 |
| 流动性陷阱激活条件 | 条件 | 实际利率<0且货币乘数<1 | — |
| 财政退出延迟 | τ_exit | 12-24个月 | 政治阻力 |

### 7.3 历史案例：ZLB期间财政乘数实测

| 案例 | 实测乘数 | 持续时间 | 政策退出结果 |
|:----|:-------:|:-------:|:----------:|
| 日本1990s QE | 0.9 | 10年+ | 低效 |
| 美国2009-11刺激 | 1.4 | 18个月 | 温和复苏 |
| 欧元区2012紧缩 | -1.5（负乘数）| 2年 | 衰退加深 |
| 美国2020 CARES | 2.1 | 12个月 | 过度刺激→通胀 |
| 中国2020特别国债 | 1.3 | 6个月 | 局部过热 |

## 八、回路互动矩阵

回路之间的交互关系（+ 正向强化，- 负向对冲，0 独立）：

|  | F1信贷 | F2工资 | F3资产 | F4货币政策 | F5汇率 | F6财政 |
|:--|:------:|:------:|:------:|:----------:|:------:|:------:|
| **F1信贷** | — | + | ++ | -- | 0 | + |
| **F2工资** | + | — | 0 | -- | + | + |
| **F3资产** | ++ | 0 | — | - | - | + |
| **F4货币政策** | -- | -- | - | — | + | - |
| **F5汇率** | 0 | + | - | + | — | 0 |
| **F6财政** | + | + | + | - | 0 | — |

**最危险组合**：F1+F3同时激活（正反馈叠加），F4失效（ZLB），F6被约束（主权债务上限）→ 日本1990s泡沫破裂原型。
