## 一、GDP（国内生产总值）

| 字段 | 内容 |
|------|------|
| 分类目录 | `01_宏观经济指标/GDP/` |
| 数据文件 | `raw_GDP.json` |
| 发布机构 | 国家统计局 |
| 发布频率 | 季度（1/4/7/10月中旬） |
| 发布时间 | 季后15-19日 10:00 |
| 单位 | 亿元 / % |

### 核心指标

| 指标名 | 说明 | 单位 |
|--------|------|------|
| GDP(现价):年 | 按当年价格计算的GDP总量 | 亿元 |
| GDP(不变价):年 | 剔除价格变动后的实际GDP | 亿元 |
| GDP年率-单季度(%) | 当季同比增速 | % |
| GDP年率-年初至今(%) | 累计同比增速 | % |
| GDP季率-单季度(%) | 环比增速（季调） | % |
| GDP总量-单季度(亿元) | 当季GDP绝对值 | 亿元 |

### 关键概念
- **现价GDP**：名义值，包含价格变动
- **不变价GDP**：实际值，剔除通胀，基准年定期调整
- **同比**：与去年同期比，反映长期趋势
- **环比**：与上季比（季调后），反映短期动能

## 二、CPI / PPI（居民消费价格 / 工业生产者价格）

| 字段 | 内容 |
|------|------|
| 分类目录 | `01_宏观经济指标/CPI/` |
| 数据文件 | `raw_CPI_PPI.json` |
| 发布机构 | 国家统计局 |
| 发布频率 | 月度 |
| 发布时间 | 次月9-12日 09:30 |
| 单位 | % |

### 核心指标

| 指标名 | 说明 | 单位 |
|--------|------|------|
| CPI:同比:月 | 居民消费价格指数同比涨幅 | % |
| CPI:环比:月 | 居民消费价格指数环比变动 | % |
| CPI:食品类:同比:月 | 食品分项同比 | % |
| CPI:非食品类:同比:月 | 非食品分项同比 | % |
| CPI:核心（剔除食品能源） | 核心通胀 | % |
| CPI(上月=100):月 | 定基指数 | - |
| PPI:同比:月 | 工业生产者出厂价格同比 | % |
| PPI:环比:月 | 工业生产者出厂价格环比 | % |
| PPIRM:环比:月 | 工业生产者购进价格环比 | % |

### 关键概念
- **CPI**：衡量居民购买消费品和服务价格变动，是通胀的核心指标
- **PPI**：衡量工业品出厂价格变动，是CPI的先行指标
- **核心CPI**：剔除食品和能源，反映底层通胀趋势
- **PPIRM**：购进价格指数，反映企业成本端压力

## 三、PMI（采购经理指数）

| 字段 | 内容 |
|------|------|
| 分类目录 | `01_宏观经济指标/PMI/` |
| 数据文件 | `raw_PMI.json` |
| 发布机构 | 国家统计局（官方）/ 财新（财新PMI） |
| 发布频率 | 月度 |
| 发布时间 | 官方：当月最后1日 09:30；财新：次月1日 09:45 |
| 单位 | -（指数） |

### 核心指标

| 指标名 | 说明 | 临界值 |
|--------|------|--------|
| 制造业PMI | 官方制造业采购经理指数 | 50 |
| 非制造业PMI | 官方非制造业商务活动指数 | 50 |
| 综合PMI:产出指数 | 制造业+非制造业加权 | 50 |
| PMI:消费品行业 | 消费品类企业PMI | 50 |
| PMI:装备制造业 | 装备制造类企业PMI | 50 |
| PMI:高技术制造业 | 高技术类企业PMI | 50 |
| PMI:高耗能行业 | 高耗能类企业PMI | 50 |
| 财新制造业PMI | 财新/Markit制造业PMI | 50 |
| 财新服务业PMI | 财新/Markit服务业PMI | 50 |

### 关键概念
- **PMI > 50**：经济扩张；**PMI < 50**：经济收缩
- **官方PMI**：样本以大中型国企为主，偏向重工业
- **财新PMI**：样本以中小企业为主，偏向轻工业和出口
- 两者常出现背离，反映经济结构分化

## 四、货币与利率

| 字段 | 内容 |
|------|------|
| 分类目录 | `01_宏观经济指标/利率/` |
| 数据文件 | `raw_货币与利率.json` |
| 发布机构 | 中国人民银行 |
| 发布频率 | LPR月度（每月20日）；逆回购日度 |
| 单位 | % / 亿元 |

### 核心指标

| 指标名 | 说明 | 当前值 |
|--------|------|--------|
| LPR:1Y | 1年期贷款市场报价利率 | 3.0% |
| LPR:5Y | 5年期LPR（房贷基准） | 3.5% |
| 逆回购利率:7天 | 7天期逆回购操作利率 | 1.4% |
| 逆回购利率:14天 | 14天期逆回购操作利率 | 1.65% |
| 逆回购操作量 | 央行公开市场操作规模 | 亿元 |
| 贷款利率:6个月~1年 | 短期贷款基准利率 | 4.35% |
| 贷款利率:1~3年 | 中长期贷款基准利率 | 4.75% |
| 贷款利率:5年以上 | 长期贷款基准利率 | 4.9% |

### 关键概念
- **LPR**：贷款市场报价利率，由18家银行报价形成，是实际贷款定价基准
- **逆回购**：央行向市场注入流动性的操作，利率反映政策意图
- **7天逆回购利率**：被视为中国的"政策利率"

| 发布机构 | 中国人民银行 |
| 发布频率 | 月度 |
| 发布时间 | 月后10-15日 |
| 单位 | 亿元 / % |

### 核心指标

| 指标名 | 说明 | 单位 |
|--------|------|------|
| 社会融资规模-年初至今 | 累计社融增量 | 亿元 |
| M2:月 | 广义货币供应量 | 亿元 |
| M2:同比:月 | M2同比增速 | % |

- **社融-M2剪刀差**：正差表示实体融资需求强于银行负债端

| 字段 | 内容 |
|------|------|
| 分类目录 | `01_宏观经济指标/汇率/` |
| 数据文件 | `raw_汇率.json` |
| 发布机构 | 中国外汇交易中心 |
| 发布频率 | 实时（交易日） |
| 单位 | 人民币/美元 |

### 核心指标

| 指标名 | 说明 |
|--------|------|
| USDCNY | 美元兑人民币在岸汇率 |
| 昨收/今开/最高/最低 | 日内行情 |
| 涨跌幅 | 当日变动 |
| 年初至今涨跌幅 | 年内累计变动 |
| 52周最高/最低 | 年内极值 |

### 关键概念
- **在岸价(CNY)**：国内银行间市场交易价，受央行调控
- **离岸价(CNH)**：海外市场交易价，更市场化
- **CNY-CNH价差**：离岸强于在岸=升值预期，反之贬值预期
