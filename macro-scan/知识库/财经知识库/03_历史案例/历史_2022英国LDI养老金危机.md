# 历史_2022英国LDI养老金危机 — 结构化知识文档

> 核心主题：LDI策略机制解析、Kwarteng迷你预算触发机制、BOE65亿英镑紧急干预与监管改革
> 更新时间：2026-05-11

---

## 核心传导链

```
数十年低利率环境 → 英国固收养老金（DB Pension）收益率不足
        ↓
养老金采用LDI（负债驱动投资）策略+杠杆
  持有长期国债（Gilts）+利率衍生品（IRS/Swaps）对冲利率风险
  通过抵押品贷款增加杠杆（获取超额收益）
        ↓
2022年9月23日：Kwarteng"迷你预算"
  无财源的大规模减税（450亿英镑） → 市场对财政可持续性丧失信心
        ↓
英国长期国债（30年期Gilt）收益率单日急升约60bp，数日内+130bp
（从约3.5%→约5%）
        ↓
LDI策略触发大规模追缴抵押品（Margin Call）
  持有长期债的养老金：债券价值大幅下跌
  → 杠杆部分的抵押品价值不足 → 被要求补充抵押品
        ↓
养老金被迫在极短时间内抛售长期国债（求现金补保证金）
        ↓
抛售→收益率进一步上升→更多追缴→更多抛售（正反馈循环）
        ↓
英格兰银行（BOE）紧急介入（9月28日）：宣布购买长期国债
  规模：65亿英镑/每日，持续13个工作日
        ↓
市场暂时稳定 → Kwarteng随后被撤职 → 特拉斯首相辞职
        ↓
系统性危机被遏制，但暴露了DB养老金监管的重大漏洞
```

## 一、英国DB养老金体系背景

### 1.1 固收养老金（DB Pension）的结构性压力

**定义：** 固收养老金（Defined Benefit，DB）承诺为员工提供基于工资/工龄的固定退休收入，与资本市场表现无关。

**英国DB养老金规模：**
- 约5000-6000个DB养老金计划（2022年）
- 总资产约1.5万亿英镑（约占英国GDP 60%）
- 主要为大型企业（钢铁/铁路/教育机构等）的职工养老

**DB养老金的核心挑战：**

```
负债侧：固定承诺 → 需要按精算假设折现
  折现率通常与长期国债收益率挂钩
  收益率低 → 负债现值高（未来固定支出折现值大）

资产侧：需要匹配负债
  当收益率长期低（2010-2021年） → 负债/资产缺口扩大
  养老金"资金缺口"（Deficit）普遍化
```

### 1.2 低利率时代的困境（2010-2021年）

| 时间 | 英国10年Gilt收益率 | DB养老金缺口 |
|------|-----------------|------------|
| 2010年 | 约3.5% | 约-1000亿英镑 |
| 2016年（Brexit后）| 约1.0% | 约-4000亿英镑（最大缺口期）|
| 2020年（QE后）| 约0.2-0.3% | 约-2500亿英镑 |
| 2021年底 | 约0.7-1.0% | 约-1500亿英镑 |

**低利率的矛盾效应：**
- 持有的债券价格上涨（资产侧受益）
- 但负债折现率下降，负债现值上涨幅度**更大**（因债券久期通常短于养老金负债久期）
- 净效果：**资金缺口在低利率期反而扩大**（除非专门对冲）

## 二、LDI策略详解

### 2.1 LDI（负债驱动投资）的基本原理

**LDI策略的目标：** 消除养老金资产与负债之间的利率风险错配

**标准LDI操作：**
```
问题：
  养老金负债久期约20-30年（长）
  养老金资产（若持有短期债）久期约5-8年（短）
  利率下降1%：
    负债增加约25%（30年久期）
    资产增加约7%（7年久期）
  净亏损：约18%（严重错配）

LDI解决方案：
  步骤1：购买超长期国债（20-30年期Gilt）→ 将资产久期延长至匹配负债
  步骤2：若无法购买足够实物超长期债 → 使用利率互换（IRS）获取额外久期
  步骤3：IRS需要抵押品（Repo/Gilts） → 使用现有Gilts作为抵押，借入现金
    → 用借入的现金购买更多Gilts/IRS
    → 这就是LDI中的**杠杆**来源
```

### 2.2 杠杆的累积机制

**英国LDI的杠杆规模（2022年9月危机前）：**

```
实际持有资产：约1.5万亿英镑（养老金总资产）
LDI杠杆操作下的久期敞口：约1.0-1.5万亿英镑额外
  →等效总久期敞口约2.5-3万亿英镑

杠杆比率（名义敞口/实际资产）：约2-3倍
```

**为什么接受了如此高的杠杆：**
- 在低利率/低波动时代，LDI杠杆的追缴发生概率极低
- 精算师/受托人关注点在于"消除利率风险"，而非"杠杆风险"
- 监管框架（英国养老金监管机构TPR）未对LDI杠杆设置明确上限
- 资产管理公司（如Legal & General、BlackRock、Insight）的LDI产品在低利率时代大受欢迎

### 2.3 追缴机制与临界点

**正常情况：**
```
收益率小幅上升（如+20bp）→ 债券价值小幅下跌
→ 追缴抵押品→ 养老金卖出少量资产（流动性债券）→ 补充抵押品
→ 整个过程有序，无系统性影响
```

**极端情况（2022年9月发生的）：**
```
收益率急升+100-130bp（数天内）→ 债券价值大幅下跌
→ 追缴规模远超养老金持有的流动性资产
→ 不得不卖出LDI持有的核心资产（即长期Gilt本身）
→ Gilt价格进一步下跌 → 收益率进一步上升 → 更多追缴
→ 正反馈螺旋：自我强化崩溃
```

## 三、"迷你预算"：危机的直接触发

### 3.1 Kwarteng迷你预算（2022年9月23日）

**政治背景：**
- 2022年9月6日：特拉斯（Liz Truss）就任英国首相（约翰逊后继者）
- 承诺：激进减税以刺激增长（"供给侧革命"）
- 财政大臣：夸西·克瓦滕（Kwasi Kwarteng）

**2022年9月23日迷你预算主要内容：**

| 政策 | 成本（年度）|
|------|-----------|
| 取消45%所得税最高税率 | 约20亿英镑 |
| 将基本税率从20%降至19% | 约57亿英镑 |
| 取消国民保险费上调 | 约150亿英镑 |
| 能源价格上限（两年冻结）| 约600亿英镑（最大单项）|
| 企业税率不上调（维持19%）| 约190亿英镑 |
| **总计（未来5年未来融资成本）** | **约450亿英镑** |

**致命问题：没有任何财政来源支撑**
- 未附带任何"如何融资"的说明（违背英国财政框架惯例）
- 英国预算责任办公室（OBR）未被要求做预测（更大的政治信号问题）
- 市场解读：这是"无约束的财政扩张"

### 3.2 市场反应（9月23日-10月14日）

**英国国债（Gilt）收益率的急速跳升：**

| 期限 | 9月22日（前日）| 9月28日（BOE干预前）| 变化 |
|------|-------------|------------------|------|
| 2年期Gilt | 约3.1% | 约4.5% | +140bp |
| 10年期Gilt | 约3.5% | 约4.5% | +100bp |
| **30年期Gilt** | **约3.7%** | **约5.1%** | **+140bp** |

**英镑（GBP/USD）：**
- 9月23日收盘：1.0838
- 9月26日亚洲盘：历史新低**1.0327**（英镑创历史低点）
- 市场一度预期英镑与美元平价（1:1）

**英国主权CDS：**
- 5年期CDS从约20bp→约55bp（飙升175%）

## 四、BOE的紧急干预（9月28日）

### 4.1 危机的临界点

**9月26-27日周末：**
- LDI基金管理人向BOE紧急汇报：追缴规模已达数百亿英镑
- 若BOE不干预，最晚28日（周一）将出现大规模强制清算
- 相当于英国养老金体系实质性崩溃风险

**BOE的两难：**
```
正在加息（对抗通胀：2022年通胀>10%）
    ↓
若购买Gilt（量化宽松式操作）：
  → 与加息逻辑矛盾（宽松与紧缩同时进行）
  → 可能进一步打击英镑/加剧通胀
        ↓
但若不干预：
  → 养老金系统性崩溃 → 金融稳定风险
  → BOE的金融稳定职责要求行动
```

### 4.2 BOE的干预设计

**2022年9月28日上午：BOE宣布**

| 干预要素 | 内容 |
|---------|------|
| 操作类型 | 无限量购买超长期国债（20年+期限Gilt）|
| 每日规模 | 上限50亿英镑/每日（实际购买约10-20亿）|
| 持续时间 | 2022年9月28日-10月14日（13个工作日）|
| 总实际购买 | 约**65亿英镑**（共约19次操作）|
| 配套 | 要求养老金在干预窗口期内修复杠杆/补充流动性缓冲 |
| 到期处置 | 购买的Gilt将在到期后不再续期（非长期QE）|

**干预效果：**
- 30年Gilt收益率从5.1%→4.0%（下降110bp）
- 英镑从1.03→1.12（反弹）
- LDI基金获得喘息时间补充流动性
- 系统性危机被遏制

## 五、政治结局：最短任期首相

### 5.1 政策迅速反转

**10月3日（迷你预算后10天）：**
- Kwarteng在IMF/G20会议期间宣布取消取消45%税率（最受争议的政策）
- 被迫承认政策判断失误

**10月14日：**
- Kwarteng被解职（任期仅38天）
- 新财政大臣杰里米·亨特宣布：将"几乎撤回所有"迷你预算政策

**10月20日：**
- 特拉斯宣布辞职（任期仅45天，英国史上最短任期首相）
- 引用"利率环境改变"→ 无法执行其经济计划

**10月25日：**
- 里希·苏纳克（Rishi Sunak）就任首相
- 11月：亨特发布"真正的秋季声明"：包含200亿英镑财政紧缩措施

## 六、危机后的监管改革

### 6.1 英国养老金监管机构（TPR）的检讨

**暴露的监管漏洞：**

| 问题 | 根源 | 监管空白 |
|------|------|---------|
| LDI杠杆无上限 | 监管框架未规定杠杆限制 | 需要设定久期/杠杆上限 |
| 流动性缓冲不足 | 追缴时无足够现金 | 需要最低流动性要求 |
| 压力测试标准低 | 仅测试正常市场波动 | 需要极端情景（+200bp/+300bp）|
| 追缴时间太短 | 最短24小时追缴 | 需要更长的缓冲时间 |
| 信息不透明 | BOE不知道LDI规模 | 需要实时报告义务 |

### 6.2 2023-2024年改革举措

**TPR/FCA发布的LDI监管指引（2023年）：**

1. **流动性缓冲：** LDI池/基金须持有足够缓冲，应对至少收益率+300bp的追缴需求
2. **杠杆上限：** 对净资产价值的杠杆比例须在监管批准范围内
3. **压力测试：** 须定期进行"极端但可能"的压力测试（收益率+300/+500bp情景）
4. **信息报告：** 向TPR/FCA定期报告LDI敞口、流动性状况
5. **追缴通知期：** 最短追缴期延长（给养老金更多响应时间）

**执行进度（2024-2025年）：**
- 大多数LDI基金已大幅去杠杆（杠杆降低约30-50%）
- 流动性缓冲显著提升
- 但监管框架的完整立法仍在讨论中

## 七、系统性意义与跨市场教训

### 7.1 为什么这场危机是全球性警示

**宏观影响：**
- 揭示了量化宽松10年留下的"对流动性的习惯依赖"——系统中大量隐藏的杠杆策略
- LDI危机与2008年危机的相似：平时看似低风险的"对冲"策略，在极端情况下变成正反馈放大器
- 证明了"杠杆总在意想不到的地方"

**货币政策与财政政策的碰撞：**
```
2022年英国案例是历史上最清晰的"财政主导打断货币政策"案例之一：
  BOE正在加息（货币紧缩）
      ↓
  财政部迷你预算（财政极度扩张）
      ↓
  两者方向完全相反 → 市场失去方向感
      ↓
  信任危机（主权信用溢价急升）→ Gilt暴跌
      ↓
  BOE不得不用QE救市（中断加息逻辑）
      ↓
  教训：货币与财政必须协调，否则两败俱伤
```

### 7.2 类似风险在全球其他地区的分布

| 地区/机构 | 类似LDI风险 | 规模估计 |
|---------|------------|---------|
| 日本寿险公司 | 超长期JGB久期配置+利率风险 | 约100万亿日元 |
| 美国养老金（部分公共养老）| 固定收益承诺+久期错配 | 约数千亿美元 |
| 台湾寿险 | 长期负债+短期投资错配 | 约10万亿台币 |
| 欧洲保险 | Solvency II下的久期管理 | 监管相对严格 |

**全球低利率→快速加息环境（2022年）下，久期错配是全球性脆弱性：**
- 硅谷银行（2023年）：与LDI逻辑相同，只是主体是银行而非养老金

## 八、当前状态（2026年）

| 指标 | 数据 |
|------|------|
| 英国10年Gilt收益率 | 约4.2-4.5% |
| 英国30年Gilt收益率 | 约4.5-5.0% |
| DB养老金整体资金状况 | 约盈余（利率高→负债折现值↓→改善）|
| BOE基准利率 | 约4-5%（加息后，缓慢降息中）|
| LDI基金总规模 | 约1.0万亿英镑（从危机前1.5万亿去杠杆）|
| 英镑（GBP/USD）| 约1.25-1.30（已基本恢复）|

**核心遗留问题（2026）：**
1. 全面LDI监管立法尚未完成——下一次极端利率冲击仍存在脆弱性
2. DB养老金因高利率环境资金状况改善，但若利率再次快速下行，缺口可能重现
3. 英国主权信用受损：市场对英国"财政纪律"的信任需要多年才能完全修复
4. 特拉斯/Kwarteng事件成为"财政轻率"的标志性案例，政治上约束了后续保守党的减税冲动
