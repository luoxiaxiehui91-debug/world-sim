## 一、经典板块轮动模型

### 1.1 美林时钟（Merrill Lynch Investment Clock）

```
经济周期四象限：
                     GDP↑（复苏/扩张）
                    ┌────────────┐
          通胀↓     │  复苏期    │   通胀↑
        ├─────────── │  扩张期    │ ─────────┤
    ↑   │  Reflation │            │ Overheat │  ↑
  通   │  →债券+股  │            │ →原材料  │  通
  胀   │            └────────────┘ +能源     │  胀
       │  滞胀期    │            │   繁荣期  │
        ├─────────── │  衰退期    │ ─────────┤
                     └────────────┘
                     GDP↓（减速/衰退）
```

**四象限配置映射（简化）**：

| 周期阶段 | 经济状态 | 通胀 | 推荐资产 | 推荐板块 |
|----------|----------|------|----------|----------|
| 复苏期（Recovery） | 增速↑ | 低/下行 | 股票 > 债券 | 非必需消费、金融、工业 |
| 扩张期（Overheat） | 增速↑ | 高/上行 | 大宗商品、股票 | 能源、材料、工业 |
| 滞胀期（Stagflation） | 增速↓ | 高/上行 | 现金、大宗 | 能源、必需消费、医疗 |
| 衰退期（Reflation） | 增速↓ | 低/下行 | 债券 | 公用事业、必需消费、医疗 |

## 四、轮动领先指标

### 4.1 领先信号（看哪个方向轮动）

| 信号 | 方向含义 | 领先时间 |
|------|----------|----------|
| PMI制造业 突破50 | 工业/材料开始领涨 | 1-3个月 |
| 收益率曲线陡峭化 | 金融板块相对走强 | 2-4个月 |
| HY利差收窄 | 非必需消费、科技超额 | 1-2个月 |
| HY利差扩大 | 防御板块（公用/必需）超额 | 立即-1个月 |
| 油价月涨>10% | 能源超额，通胀板块轮动 | 即时 |
| 失业率开始上升 | 防御板块开始积累 | 3-6个月 |
| VIX>30持续2周 | 强防御轮动（公用/医疗） | 即时 |

### 4.2 因子轮动（跨行业共性）

| 因子 | 对应体制 | 有效性 |
|------|----------|--------|
| 动量（Momentum） | 趋势扩张期 | 高，但反转时代价大 |
| 价值（Value） | 利率上升/复苏初期 | 中，周期性 |
| 低波动（Low Vol） | 衰退/危机 | 高 |
| 质量（Quality） | 后期周期/滞胀 | 高 |
| 成长（Growth） | 低利率/扩张 | 高，利率敏感 |
| 小盘（Small Cap） | 复苏早期 | 高，流动性改善时 |

## 五、当前体制映射（2026-05）

**当前宏观状态**：
- FFR 3.63%（降息周期中，但通胀3.78%高于目标）
- SPX 约 5700-5800（从2025年低点反弹）
- 穆迪降级 + 贸易战90天暂停
- 体制：**late_cycle / stagflation 边界**（增速放缓+通胀粘性）

**当前板块含义**：

| 推荐关注 | 规避 | 理由 |
|----------|------|------|
| 医疗 XLV | 科技 XLK（部分） | 防御性 + 关税受益小 |
| 必需消费 XLP | 金融 XLF | 信贷周期峰值 |
| 能源 XLE（低配） | 非必需消费 XLY | 通胀粘性，但增速弱化 |
| 黄金/贵金属 | 房地产 XLRE | 货币信任 + 财政压力对冲 |
| 日本（汇率对冲） | 小盘/EM | 日本正常化+日元升值有利 |

> ⚠️ 以上为框架性参考，非投资建议。当前体制高度依赖90天暂停到期（2026-08）走向。

## 六、对本系统的集成建议

本框架可集成到 `run_macro_analysis.py` 的 `generate_summary_report()` 函数：

1. **体制 → 板块映射输出**：在报告中新增"板块含义"段落，根据 `regime_detector` 返回的体制直接映射到推荐/规避板块
2. **Monte Carlo 胁迫测试**：压力情景结果除了GDP/失业率，可附加板块影响
3. **信号触发关联**：弱信号扫描触发时，在 `latest_news.json` 中注明对应板块含义
