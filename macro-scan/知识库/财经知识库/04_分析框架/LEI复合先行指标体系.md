# LEI 复合先行指标体系

> 先行指标（Leading Economic Indicators）是在经济周期转折点**之前**发出信号的统计量，用于预判增长方向、衰退风险和政策空间。本文整合 Conference Board LEI、FRED 可获取系列及本系统内部指标，构建可操作的监控框架。

---

## 一、核心概念

### 1.1 领先性分类

| 类型 | 领先时间（经验值） | 典型指标 |
|:---|:---:|:---|
| **超前先行**（Ultra-leading） | 6–12个月 | 股票价格指数、信用利差、期限溢价 |
| **先行**（Leading） | 3–6个月 | ISM PMI、建筑许可、初请失业金 |
| **短期先行**（Near-leading） | 1–3个月 | 零售销售、工业订单、消费者信心 |
| **同步**（Coincident） | 0 | 工业生产、GDP、就业人数 |
| **滞后**（Lagging） | 3–12个月 | 失业率、CPI、企业贷款利率 |

> **关键误解**：失业率是滞后指标，不是先行指标。用失业率"确认"衰退时，通常已滞后 2–4 个季度。

### 1.2 合成指数的理论基础

Conference Board LEI（美国）构建逻辑：
1. 选取 10 个各代表不同传导机制的子指标
2. 对每个子指标计算月度变化率，标准化消除量纲差异
3. 加权平均后积分还原为水平值
4. 连续3个月下降 → 历史上与衰退的前兆相关性 > 80%

## 三、本系统 LEI 代理指标映射

系统从 FRED 拉取以下序列近似复现 LEI 核心信号：

```
AWHMAN     → 制造业工时（先行约 3–4 个月）
ICSA       → 初请失业金（先行约 1–2 个月）
PERMIT     → 建筑许可（先行约 6–9 个月）
T10Y2Y     → 期限利差（先行约 6–18 个月，倒挂→衰退）
BAA10Y     → 信用利差（先行约 3–9 个月）
VIXCLS     → 市场波动率（反向，高波动→压力）
UMCSENT    → 密歇根消费者信心（先行约 2–3 个月）
```

**快速衰退概率规则（三灯法则）**：

| 条件 | 信号强度 |
|:---|:---:|
| T10Y2Y < 0（倒挂） | 🔴 |
| BAA10Y > 2.5% | 🟠 |
| AWHMAN 月度变化 < -0.3h | 🟡 |
| ICSA > 25万（4周均值） | 🟡 |
| PERMIT 同比 < -15% | 🟡 |

触发 🔴 + 任意2个 🟡/🟠 → 进入"衰退预警期"；  
触发 🔴 + 🟠 + 2×🟡 → 进入"高衰退概率期"（历史命中率 ~78%）。

## 四、全球 LEI 体系对比

### 4.1 OECD CLI（复合先行指标）

| 特点 | 说明 |
|:---|:---|
| 覆盖 | 38 个 OECD 成员国 + 主要新兴市场（中、印、巴、俄） |
| 基准 | 100 = 长期趋势，< 100 表示低于趋势增长 |
| 发布频率 | 每月，约滞后 60 天 |
| 构建方法 | HP 滤波 + BK 滤波剔除周期成分，保留 1.5–8 年周期 |

**OECD CLI 信号解读**：

```
CLI 趋势（3个月移动平均）方向：
  向上穿越 100 → 扩张加速（买入信号）
  向下穿越 100 → 扩张放缓（警戒）
  持续低于 100 + 斜率负 → 收缩风险上升（减仓/对冲）
```

### 4.2 中国先行指标特殊性

中国无官方综合 LEI，替代监控序列：

| 指标 | FRED / 来源 | 领先性 | 备注 |
|:---|:---|:---:|:---|
| 官方 PMI 制造业 | NBS / WIND | 1–2个月 | <50 收缩，临界值敏感 |
| 财新制造业 PMI | Caixin | 1–2个月 | 小企业侧重，波动较大 |
| M1-M2 剪刀差 | PBOC | 2–4个月 | M1>M2 → 企业流动性宽松 |
| 信贷脉冲（信贷增量/GDP） | — | 3–6个月 | 最强先行信号，领先 GDP 约2个季度 |
| 电力消费同比 | NEA | 同步 | 噪声低，造假难度大 |
| 货运量 PMI | CCFA | 1个月 | 真实经济活动代理 |
| 房地产销售面积（30城） | — | 3–6个月 | 地产→钢铁→就业传导链 |

> **克强指数（Li Keqiang Index）**：电力 + 货运 + 银行贷款三指标加权，2007年被李克强提出作为 GDP 替代。近年随服务业比重上升，代表性下降，但仍可作为制造业景气交叉验证。

## 五、利率曲线作为首要先行指标

### 5.1 倒挂→衰退的历史记录（美国）

| 倒挂时间 | 倒挂幅度（最深） | 随后衰退 | 领先时间 |
|:---:|:---:|:---:|:---:|
| 1988–1989 | -50bp | 1990–91 衰退 | ~18 个月 |
| 2000 | -50bp | 2001 科网衰退 | ~12 个月 |
| 2006–2007 | -50bp | 2007–09 GFC | ~18 个月 |
| 2019 | -52bp | 2020 疫情衰退 | ~7 个月（外生冲击） |
| 2022–2024 | -108bp（史上最深） | **待确认** | — |

**2022–2024 倒挂解读**：
- 持续时间 > 2年，深度史无前例
- 但就业市场韧性异常强劲（AI投资、财政刺激对冲）
- 本系统预测框架将 T10Y2Y 倒挂解除时间作为衰退概率关键节点

### 5.2 曲线斗牛模型（Bull/Bear Steepener）

```
倒挂解除方式 A：Bull Steepener（短端跌、长端稳）
  → Fed 降息驱动 → 通常在衰退已开始时发生
  → 衰退信号确认（滞后 0–3 个月）
  
倒挂解除方式 B：Bear Steepener（长端升、短端稳）
  → 通胀预期上升 or 财政恐慌驱动
  → 滞胀风险，非典型衰退信号
  
2024–2025：Bear Steepener 主导 → 与 F8 财政利率螺旋一致
```

## 六、领先指标失效的情形

历史上 LEI 信号失灵的已知原因：

| 原因 | 案例 | 对本系统的影响 |
|:---|:---|:---|
| 外生冲击 | 2020 COVID | 衰退在任何 LEI 触发前到来；本系统弱信号扫描中加入疫情/战争类关键词作为补充 |
| 结构性转变 | 2000s 金融创新（MBS/CDO） | 信用利差低估风险；本系统额外监控 TED 利差和 SOFR 基差 |
| 政策扭曲 | 2010s QE 压低长端收益率 | 曲线人工拉陡，倒挂被推迟；需结合 Fed 资产负债表 QT 进度修正 |
| 服务业占比上升 | 2015 后 | 制造业 ISM 对总体 GDP 代表性下降 20%；本系统增加服务业 PMI（ISM Services）权重 |
| 财政主导 | 2022–2025 | 大规模财政刺激对冲信用收缩；本系统 F8 回路专门跟踪财政-利率-信贷的三角关系 |

## 七、本系统 LEI 得分模块（实现参考）

在 `run_macro_analysis.py` 中，`compute_risk_scores()` 函数已对以下 LEI 相关指标进行评分：

```python
# 利率曲线倒挂风险
curve = indicators.get("T10Y2Y", {}).get("value", 0)
if curve < -0.5:   risk_scores["interest_rate"] = 75
elif curve < 0:    risk_scores["interest_rate"] = 50

# 信用利差扩张风险
baa = indicators.get("BAA10Y", {}).get("value", 1.5)
if baa > 3.0:      risk_scores["credit"] = 80
elif baa > 2.0:    risk_scores["credit"] = 55

# 建筑许可下滑（需计算同比）
# PERMIT 同比 < -20% → 房地产领先信号触发
```

## 八、LEI 与本系统反馈回路的对应关系

| LEI 子指标 | 触发的反馈回路 | 原理 |
|:---|:---|:---|
| 信用利差 BAA10Y ↑ | F3 银行挤兑、F6 美元流动性 | 银行承压，信贷收缩 |
| 期限利差 T10Y2Y ↓ | F8 财政利率螺旋 | 财政融资成本上升 |
| VIX ↑ | F5 保证金螺旋 | 强制平仓去杠杆 |
| 建筑许可 PERMIT ↓↓ | — （直接影响 GDP 分布左尾） | 住宅投资乘数效应 |
| 油价 WTI ↑ + CPI ↑ | F7 油价滞胀循环 | 成本推动通胀→实际收入下降 |
| 日元汇率 DEXJPUS ↓急 | 套利平仓链条（非正式F9） | 日元套利展仓成本急升→全球流动性冲击 |
