> 联动：`political_calendar.yaml`（重要政治节点日历）

## 1. 两类国家的根本差异

### 成熟民主国家

**机制**：不满 → 选票惩罚 → 周期性政权交接 → 政策不确定性

- 选举前12个月：SPX 历史均值 +8%（"选举年牛市"，财政刺激预期驱动）
- 国会分裂（总统/国会不同党）→ 财政僵局风险 → 美债利差走宽 +20~50bp
- 欧洲大国选举前1个月：EUR/USD 历史波动率 +15%
- **底线**：货币体系和产权保护基本不受政权更迭影响

### 新兴市场/威权国家

**机制**：不满积累 → 无选票出口 → 街头抗议/政变 → 制度不确定性暴涨

| 政变类型 | 典型资产冲击 | 恢复时间 | 代表案例 |
|---------|---------|---------|---------|
| 军事政变（成功）| 货币-30%~-50%，FDI-50%+ | 3-5年 | 缅甸2021 |
| 军事政变（失败/平息）| 货币-10%~-20%，股市-5%~-15% | 6-12个月 | 土耳其2016 |
| 平民起义（政权更迭）| 货币-20%~-40%，外储快速消耗 | 1-3年 | 埃及2011 |
| 宪政危机（精英内斗）| 股市-5%~-15%，汇率小幅波动 | 3-6个月 | 韩国2024弹劾 |

## 2. EPU 政策不确定性指数

Baker-Bloom-Davis EPU 指数（`USEPUINDXD`，已在系统 FRED 序列中）衡量政策不确定性。

| EPU 分位数 | 历史背景 | SPX 隐含波动率 |
|---------|---------|---------|
| > 200（> 90分位）| 重大政策转折期：2008金融危机/新冠/选举争议 | VIX 通常 > 25 |
| 150~200（70-90分位）| 高不确定性：贸易战升级/债务上限危机 | VIX 通常 20~30 |
| 100~150（正常偏高）| 政策辩论激烈但方向尚存 | VIX 通常 15~25 |
| < 100（低不确定性）| 政策共识期/蜜月期 | VIX 通常 < 20 |

**当前背景（2026）**：美国 EPU > 2008 年水平，政治极化对政策传导的拖累显著。

## 4. `political_instability_capital` 路径触发条件

与 `propagation_paths.yaml` 中 `political_instability_capital` 路径（cal=0.45）的对接：

**高概率触发完整路径（政变→资本外逃→货币危机）的充分条件**：
- Freedom House < 40 分（威权脆弱区间）
- 外储 < 3 个月进口额（无缓冲空间）
- 美元外债占 GDP > 25%（货币贬值直接冲击资产负债表）

**降低传导概率的因素**：
- 大国担保（中国"一带一路"信用额度 / 沙特援助）
- 资本管制法律（印度/中国可阻断资本外逃）
- 大宗商品出口创汇（尼日尔铀矿 / 赞比亚铜矿支撑外储）

## 5. 发达国家政治极化的宏观影响

以美国为代表的成熟民主，政治极化已从"影响政策效率"升级为"影响经济潜力"：

| 极化指标 | 当前状态 | 宏观影响 |
|---------|---------|---------|
| 总统支持率党派差距 | ~80ppt（历史最高）| 政策摇摆性上升 |
| 债务上限危机频率 | 几乎每次触达 | 美债短期评级压力 |
| 财政政策持续性 | 跨届取消概率上升 | 企业投资计划窗口压缩 |
| 基础设施投资争议 | 分歧加大 | 生产率增长放缓风险 |

## 6. 反面条件

政治动荡**不引发**金融资产冲击的条件：
1. **冲突地理隔离**（克里米亚危机：俄罗斯市场崩，全球市场基本正常）
2. **经济体量太小**（缅甸政变：全球金融市场几乎无反应）
3. **政变结果被快速消化**（土耳其2016未遂政变：市场1个月内恢复）
4. **大国支持提供合法性背书**（某些非洲政变在大国协调下快速稳定）
