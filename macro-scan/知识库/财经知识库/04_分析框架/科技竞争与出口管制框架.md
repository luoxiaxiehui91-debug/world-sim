## 1. 为什么科技竞争与传统地缘冲突不同

科技竞争的冲击是**渐进式、结构性**的，而非突发跳变：

- **时间尺度**：几年甚至十年，不是几天
- **传导机制**：通过供应链重构、监管合规成本、竞争格局分化影响企业盈利，而非直接影响宏观指标
- **反转难度**：出口管制一旦实施，企业供应链重构成本极高，难以快速逆转

**核心规律**：宣布日市场短暂冲击（-3%~-8%），但长期影响才是关键。2019年实体清单事件的真正影响在18个月后供应链重构期才完全显现。

## 2. 半导体出口管制（最成熟的分析领域）

### 传导链

```
出口管制宣布（T=0）
  ↓
被限制方（企业/国家）评估缺口，紧急备货（T+0~3个月）
  → 库存积累→短期需求激增→供应商股价+5%~+20%
  ↓
供应商替代搜寻/内部研发加速（T+3~24个月）
  → 受限方研发投入增加；制裁方供应商失去市场份额
  ↓
供应链分叉/脱钩（T+1~5年）
  → 两套标准体系成本上升：全球IT支出+5%~+15%（长期）
  → 受限方本土化加速，部分领域追赶成功（如中国存储芯片）
```

### 历史参数

| 事件 | 时间 | 直接冲击 | 长期效应 |
|------|------|---------|---------|
| 2019 华为实体清单 | 2019-05 | ARM/高通股价-3%~-8%（1周）| 华为手机市占率-60%，鸿蒙生态出现 |
| 2022 先进芯片出口管制（A100等）| 2022-10 | NVIDIA短暂-5%，后大涨 | 中国AI芯片替代加速，NVIDIA中国收入-25% |
| 2023 荷兰 ASML 光刻机限制 | 2023-01 | ASML股价无显著影响 | 中国EUV断供，先进制程被卡3-5年 |

### 影响不对称性
- **短期**：宣布日供应商股价受损（市场担忧营收损失）
- **中期**：受限方替代需求崛起（竞争对手受益）
- **长期**：整个行业因双轨制效率损失，但两极分化加剧

## 3. AI 监管（EU AI法案为蓝本）

### 三级影响框架

| 级别 | 描述 | 金融影响 |
|------|------|---------|
| **L1 软监管**（EU AI法案2024）| 分类分级，合规成本 | 欧洲AI企业合规支出+5%~+15%；美国AI企业相对受益（规避管辖） |
| **L2 应用禁令**（特定行业/场景）| 医疗/金融/执法禁用部分AI | 垂直领域SaaS公司估值压缩-10%~-30% |
| **L3 紧急叫停**（类似核冬天场景）| 重大AI事故触发全球监管协调 | 类比2008金融危机后的金融监管，系统性重估-20%~-40% |

**当前2026年状态**：处于L1阶段，EU AI法案2024年生效，对全球金融市场影响有限（渐进式合规，无突发冲击）。

### 与半导体管制的协同
当AI监管 + 芯片管制同时收紧时，AI算力需求受抑制 + 供给受限 = 双重压力，但也可能加速"去全球化AI栈"（本地化部署增加）。

## 4. 量子计算突破

### 为什么量子是"异类"风险

量子计算不会像地震一样"突然发生"，但一旦实现**加密相关量子优势**（破解RSA-2048），影响是结构性的：

```
量子计算突破加密门槛
  ↓ 即时
金融体系安全通信体系面临重建压力
  ↓ 短期（1-3年）
全球网络安全支出激增（预计+50%~+100%）
  ↓ 中期（3-7年）
现有公钥加密基础设施替换（巨大成本）
  ↓ 长期
后量子密码学全面迁移完成
```

**当前距离**：主流估计2030-2040年才可能达到破解实用RSA的量子优势，但已有"先收割，后解密"攻击（窃取加密数据留待未来量子解密）。

## 5. 太空军事化

### 主要传导路径

**反卫星武器（ASAT）测试/使用**：
- 直接：轨道碎片增加 → 卫星运营商保险费+20%~+50%
- 间接：GPS/通信中断 → 金融结算延迟 → 短暂流动性压力
- 严重情景：SpaceX星链被攻击 → 乌克兰式通信中断

**GPS干扰**（已有实例，俄罗斯持续干扰波罗的海/中东）：
- 航运导航受影响 → 保险费上升
- 精准农业受影响 → 农业成本上升
- 金融高频交易时间戳错误 → 极端情况下交易暂停

## 6. 反面条件

以下情况科技竞争事件**不产生显著金融冲击**：
1. 监管渐进式推进（如EU AI法案），市场有充分预期消化
2. 受限方有足够替代路径（如特定芯片有多家供应商）
3. 冲击范围窄（单一企业被列入实体清单，非行业性禁令）
4. 技术突破尚在早期阶段（量子"优势"停留于特定算法，非通用破解）
