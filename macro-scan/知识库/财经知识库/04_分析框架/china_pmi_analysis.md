# 中国 PMI 解读框架

## 核心定义

PMI（采购经理人指数）= 制造业/服务业企业采购经理的月度调查综合指数。
**50 为荣枯分水岭**：> 50 = 扩张；< 50 = 收缩。
系统使用**财新综合PMI**（`index_pmi_com_cx`），覆盖制造业+服务业，反映私营企业整体景气度。

## Workflow

### Step 1：判断综合PMI绝对水平

| 综合PMI | 景气状态 | 含义 |
|:--------|:---------|:-----|
| > 54 | 强劲扩张 | 经济活动明显加速，内需旺盛 |
| 52–54 | 温和扩张 | 稳健扩张，正常增长区间 |
| 50–52 | 微弱扩张 | 处于扩张边缘，动能有限 |
| 48–50 | 轻度收缩 | 景气略低于荣枯线，需观察持续性 |
| 46–48 | 明显收缩 | 经济活动收缩，下行压力明显 |
| < 46 | 严重收缩 | 对应经济危机或重大冲击（如2020年2月 COVID = 27.5） |

### Step 2：判断趋势（连续变动方向）

- **连续3个月以上 > 50 且上升**：扩张趋势确立，对全球需求（大宗商品、新兴市场）形成支撑
- **连续3个月以上 < 50**：收缩趋势，全球风险偏好承压
- **从收缩区回升至荣枯线附近**：底部企稳信号，需结合政策面验证
- **单月数据**：季节性波动较大（春节前后尤其不稳定），不宜过度解读

### Step 3：区分财新PMI与官方PMI的差异

| 维度 | 财新综合PMI（系统使用） | 官方制造业PMI（国家统计局） |
|:-----|:-----------------------|:--------------------------|
| 样本 | 中小私营企业为主 | 国有大型企业为主 |
| 覆盖 | 制造业 + 服务业综合 | 仅制造业 |
| 敏感度 | 更敏感，波动较大 | 偏稳定，受政策托底影响更大 |
| 时效 | 次月初发布（约第1–3个工作日） | 次月初发布（约第1–3个工作日） |

若两者方向相反，通常财新PMI更反映市场真实情绪，官方PMI更反映政策执行效果。

### Step 4：联系全球影响判断

- 中国综合PMI > 52 且上升：对铜、铁矿石等大宗商品需求正面，对新兴市场出口正面
- 中国综合PMI < 50 且下降：大宗商品价格承压，全球贸易量预期下修
- 中国PMI与美国 ISM 制造业PMI同向下降：全球制造业周期同步收缩，衰退风险显著上升

### Step 5：生成中国PMI叙事描述

占位符规则：
- `[数值]` — 填入已确认数据，保留1位小数
- `[状态描述]` / `[趋势判断]` / `[影响判断]` — 来自 Step 1–4 判断结果
- **未获取的数据项 → 填 N/A，禁止推测或用近似值替代**
- 若使用上月数据（当期数据未到发布日），须在叙事末尾注明：`（注：本期使用 [上月月份] 数据，当期数据尚未发布）`

> "本期财新中国综合PMI为 [数值]（上期 [数值]），经济景气处于 [状态描述]。[趋势判断]。[对全球需求/商品价格的影响判断]。"

## Important Notes

- 财新综合PMI数据通过标准财经数据接口获取，字段名为综合PMI，数据按月更新
- 春节月份（通常1–2月）数据受节假日影响，单月数据波动失真风险高。处理规则：
  - 优先使用"春节三月均值"：取1月、2月、3月的均值代替单月判断
  - 若只有单月数据可用，叙事中明确标注"本月数据受春节季节性因素影响，趋势判断参考性有限"
  - 不得将春节导致的单月骤降/骤升解读为趋势转折信号
- 历史参考锚点：2020年2月 COVID 冲击 27.5（历史最低）；2020年3月反弹 53.0；正常区间 50–53
- 若当期数据未到发布日（次月初约第1–3个工作日），系统取上月数据，报告中应注明数据期间
