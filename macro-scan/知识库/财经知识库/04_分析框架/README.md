# 04_分析框架

本目录是**面向具体分析场景的应用工具库**，每篇文档对应一个可直接调用的分析框架。

## 内容分类

### 市场与周期框架
`macro_regime_framework.md`、`周期定位框架.md`、`板块轮动与经济周期.md`、`vix_regime_analysis.md`、`yield_curve_analysis.md`、`credit_spread_analysis.md`

### 央行与货币政策
`央行决策框架.md`、`fed_funds_rate_analysis.md`、`LEI复合先行指标体系.md`

### 地缘与政治风险
`地缘政治风险传导机制.md`、`大国博弈分析框架.md`、`政治周期与资产传导.md`、`科技竞争与出口管制框架.md`、`稀土与战略矿产供应链.md`、`GDELT地缘政治维度接入指南.md`

### 新兴市场与社会风险
`新兴市场脆弱性速查表.md`、`社会脆弱性评估框架.md`、`文化摩擦与软实力冲突.md`

### 气候与自然灾害
`气候风险传导框架.md`、`自然灾害系统性风险.md`

### 数据接口
`propagation_paths.yaml`：结构化传导路径配置，供推演引擎直接读取

## 与其他目录的分工

- **本目录**：分析工具库，LLM 推演时直接调用
- **`08_推演元框架/`**：底层认知架构，解释"为什么这么分析"
- **`02_核心变量因果链/`**：量化参数来源
- **`07_方法论/`**：更偏研究方法论，非直接应用工具
