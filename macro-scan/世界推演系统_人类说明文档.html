一、这是什么

世界推演系统是一个跑在家里 NAS 上的世界理解引擎——持续监测全球宏观、地缘、社会、气候等多维度状态，并对任意假设情景进行传导路径推演。每天定时从 FRED、akshare、GPR 地缘风险指数、GDELT 等渠道拉取数据，结合知识库让 AI 写出当日世界形势报告，通过 ntfy 推送到手机。支持随时输入任意情景触发假设推演，并给出有历史依据的推演报告。

🌍5 域推演：经济金融 / 地缘政治 / 社会政治 / 气候自然灾害 / 文化摩擦，48 个快捷别名
📚知识库：558 个 .md 文件，4156 个 RAG 向量块（BAAI/bge-m3），传导路径 20 条（含 2 条跨域复合路径）
🔍情境自动涌现：每日 06:30 自动从 news.db 发现新话题，推送待确认（阈值 1.5x，v3.5.61）
📊历史案例库：32 条（含 1 条反例），覆盖气候 / 社会 / 政治 / 文化 / 地缘域
🔗文档同步保障：pre-commit 联动检查 + 每日 watchdog 巡检，防止代码和文档漂移
🌏GRV 11 维向量：台海 / 中美 / 俄欧 / 中东能源 / 全球合成 + 气候 / 灾害 / 制裁 / 地震 / 能源电网 / 日元货币，每日 06:10 稳定写出
🤖macro-sim 联动：GRV 告警时自动触发 12-Agent Monte Carlo 仿真（v3.5.34+）
📡弱信号共振（R01~R10）：10 条规则，R09/R10（社会压力 / 文化摩擦）v3.5.62 修复启用，Staging 模式运行中
🧪天玑校验闭环（v3.7.0）：预测自动存档 → 月度 Brier/BSS 评分 → 玉衡权重矩阵反哺
📰叙事预处理（v3.7.0）：11维叙事桶，staleness衰减，防务RSS（Al Jazeera/Defense One），注入天璇推演
📐慢变量（v3.7.0）：IRP通胀体制概率 / UCRI中美博弈强度 / GCI地缘格局指数，月频更新

2.2 六步分析流水线（每次生成报告）

1

数据拉取（每日 05:30 起，并行）

美国数据（FRED，经代理）：VIX / 利率曲线 / 信用利差 / CPI / 失业率 + 离岸人民币 / 铜价 / TGA 账户余额

GPR 地缘政治风险指数（台湾 / 中国 / 俄罗斯 / 美国 / 全球）；中国数据（akshare，8 指标）：PMI / CPI / PPI / GDP / 工业增加值 / M2 / LPR；自然灾害（USGS M≥2.5）；气候（NOAA ONI + FIRMS 火点）；双源新闻（crucix 英文 + RSSHub 中文）→ news.db；行业 ETF 动量（yfinance）
2

GRV 地缘风险向量聚合（每日 06:10）

GDELT 信号 + GPR 指数 + 日元数据 → 8 维向量：台海 / 中美战略 / 俄欧 / 中东能源（纯 GDELT）/ 全球综合 / 气候风险 / 灾害风险 / 日本货币压力（japan_monetary）

3

弱信号共振检测（扫描结束自动）

signal_synthesizer.py：10 条规则（R01~R10），Staging 模式（只记录，不推演）

4

情境记忆更新（扫描结束自动）

situation_tracker.py：自动更新 6 个正在演化事件的最新信号

5

情景判断 → 知识库检索 → AI 生成报告

两层知识库检索 + LLM 生成：MiniMax-M3（主力）→ MiMo v2.5 Pro（降级 1）→ SiliconFlow Qwen3.5-27B（兜底）

6

推送到手机 + Web UI 可查

ntfy 推送摘要；Web UI（:8899）可查历史报告与系统状态

9.1 macro-sim 联动（GRV 告警时自动触发）

GRV 单日涨幅 ≥6 或台海 ≥68 时，macro-scan 在推演结束后自动写 sim_trigger.json，macro-sim daemon 检测到后：

  1. 读取当前 GRV / FRED / 新闻数据
  2. 前 50 个月历史校准（LLM 自动调参）
  3. Monte Carlo × 100，预测未来 24 个月演化路径
  4. 生成 Markdown 报告写入 docs/仿真报告/
  5. ntfy 推送摘要（含路径概率 + 传导链 + 情景定性）

报告位置：S:\world-sim\macro-scan\docs\仿真报告\YYYY-MM-DD_HH-MM_演化_L{级别}_校准{分数}.md

手动触发（SSH 进 NAS 后）：

echo '{"level":3,"event":"手动测试"}' > \
  /vol2/1000/software/macro-scan/data/sim_trigger.json
