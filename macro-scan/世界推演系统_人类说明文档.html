一、这是什么

跑在家里 NAS 上的 世界理解引擎——持续监测全球多维度信号，自动推演可能发生的事，主动提醒你需要关注的变化，也能回答你对世界的任何问题。

系统三大能力
📡 自动监测 + 主动提醒
每天自动拉取50+指标，扫描全球新闻，识别异常信号，07:00 主动推送今日摘要
🧠 假设推演
你描述任意情景（"台海冲突""伊朗封锁霍尔木兹"），系统给出历史类比 + 传导路径 + 置信度推演
💬 自由问答
随时发问（ntfy 或浏览器），系统基于实时数据快照 + 知识库回答，区分事实与推断

2.2 八步分析流水线（每次生成报告）

1

数据拉取 · 多源实时快照

从 FRED（美国 36 条经济指标）、akshare（中国7个宏观指标）、crucix（英文地缘新闻 + GDELT）、RSSHub（中文财经新闻）、GPR（地缘风险指数）同步拉取数据。

关键指标：VIX / T10Y2Y（收益率曲线）/ BAA10Y（信用利差）/ DFF（联邦基金利率）/ CPIAUCSL（CPI）/ UNRATE（失业率）/ 台湾GPR指数 / Crucix GSCPI（供应链压力）
2

风险评分 · LEI 框架打分

用6个维度（利率曲线倒挂25分 + 信用利差20分 + 萨姆规则20分 + 初请失业金15分 + 周工时/建筑许可10分 + GDP/消费信心10分）计算衰退风险分（0-100）和通胀风险分。

3

历史情景匹配 · 41 条历史案例

用欧几里得距离在历史案例库（41条，覆盖金融危机/地缘冲突/气候冲击/社会动荡/文化摩擦/航道封锁等）中找到最相似的 2-3 个案例，给出量化参考区间（SPX回撤 P10/P50/P90）。

V3.3 新增案例：印度洋海啸（2004）/ 日本地震+核（2011）/ 巴基斯坦政治+洪灾（2022）/ 土耳其大地震（2023）/ EU AI法案（2024，渐进式无短期冲击反例）+ V3.2新增：沙特阿布盖格/胡塞红海/苏伊士搁浅
4

知识库检索 · RAG 4156 块

用 SiliconFlow BAAI/bge-m3 向量模型在 4156 块知识库文档中检索相关背景知识（558 个 .md 文件），包括分析框架、传导路径库（20条含2条跨域复合路径）、历史案例（32条）、专题报告等。

5

体制检测 + 蒙特卡洛模拟

判断当前宏观体制（normal/stress/crisis），然后用 GARCH+跳跃扩散模型运行 5000 条路径 × 12 个月的蒙特卡洛模拟，输出 GDP/失业率/通胀的概率分布。

体制切换时传导系数差异：危机态 vs 常态，FFR→失业率系数 ×2.5，信用利差→GDP 系数 ×2.4
6

构建 LLM 提示词 · 数据注入

把步骤1-5的所有结构化数据注入 LLM 提示词：实时数据快照 + 风险评分 + 历史类比 + 知识库片段 + GRV 地缘向量 + 最新新闻标题 + Crucix 实时地缘信号。

7

LLM 推理 · 降级链

主力：MiniMax-M3（Anthropic 兼容接口） → 失败降级 → MiMo v2.5 Pro（OpenAI 兼容接口）→ 失败降级 → SiliconFlow Qwen3.5-27B → 纯数据报告（最终兜底）

8

保存 + 推送

报告保存为 .md 文件（docs/ 目录幂等命名），通过 ntfy 以文件附件形式推送到手机；同时预测入库用于月度准确率校验。

2.3 假设推演分支（按需触发）

① 情景解析
别名识别（48个）或关键词分类 → 确定域/子类/烈度
7个域：GEO/FIN/ENERGY/TRADE/MACRO/CLIMATE/CULTURAL/...
→
② 历史类比
在41条案例中按 crisis_category + 关键词匹配，返回最相似2-3个案例及量化区间
→
③ 传导路径
从16条路径库中匹配，注入 [PATHS] 节；复合情景支持跨域路径匹配
→
④ 置信度计算
4维调和平均：历史锚定×40%+路径完整性×25%+信号时效×20%+一致性×15%
🟢≥0.65 / 🟡0.45-0.65 / 🔴<0.45
→
⑤ LLM 推演
标准模式：单次推演
深度模式（deep）：三轮链式——不确定因素→概率估计→综合推演+情景树

2.4 弱信号 → 自动告警链

每6h扫描 → Z-score 异常检测 + 新闻频率比（7d vs 90d） → signal_episodes 写入
共振检测（R01-R12） → 多类别信号在时间窗口内共振 AND GDELT 二次验证 → 触发假设推演（Live模式）
R08 always-on 跨资产相关性突变（4对指标，Δcorr≥0.4）→ 推送告警
B线 GRV台海≥68 OR 单日涨幅≥6 → 自动触发台海推演

八、故障排查

现象处理方法
Web UI 打不开 :8899确认 docker ps 中有 0.0.0.0:8899->8899/tcp
报告只有数据没叙事查 us_daily.log；检查 MiMo key；确认 USE_EXTERNAL_LLM=1
定时任务未执行tail -10 /var/log/macro-scan/scheduler.log；若无新日志则重启容器
假设推演置信度🔴检查 data/grv_latest.json 是否存在；手动跑 fetch_gpr.py
ask/narrative 无响应查 listener.log；确认 ntfy_listener 进程在运行
情景分类错误（走UNKNOWN）检查输入关键词是否在 hypothesis_templates.yaml aliases/keywords 中；V3.3 已支持48个别名
