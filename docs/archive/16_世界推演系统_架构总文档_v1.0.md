## 0. 系统本质

给定关于世界的不完整、有噪声、有延迟的观测信号，对未来状态做出**有置信度的、可被证伪的预测**，并通过验证结果不断校准系统自身。

**核心闭环：**

```
信息源
  ↓
天枢（状态估计）每日常驻
  ↓ 快变量偏离慢变量基准触发
天璇（推演引擎）按需激活
  ↓ 三种并行输出
天玑（校验层）月度验证
  ↓ 生成权重调整建议
玉衡（权重审批）人工确认
  ↓ 写回权重矩阵
回到天枢
```

## 二、天枢（观测层）

### 2.1 每日常驻，做两件事

**① 参数运算 → 状态向量**

状态向量分两层：

| 层级 | 变量类型 | 更新频率 | 说明 |
|------|---------|---------|------|
| **慢变量** | 结构性背景 | 月频 | 决定快变量基准分布 |
| **快变量** | 实时信号 | 日/小时频 | 偏离基准则触发推演 |

**GRV改进**：每个维度从标量改为带不确定度区间的分布（如台海52.7±8，95%置信区间）。

**触发机制——双路径：**
- **路径A（主要）**：快变量经验百分位<10或>90触发天璇；<5或>95同时发ntfy极端预警
- **路径B（辅助）**：天枢每日统计各维度新文章数Z-score，Z>2.0标记为叙事密度突增；路径B**不单独触发天璇**，在下次路径A激活时给该维度1.5倍token权重

偏离度使用经验百分位（scipy.stats.percentileofscore），不用z分数——宏观数据为厚尾分布，z分数低估尾部显著性。

**② 叙事预处理 → 叙事快照**

- 建立11个叙事桶，与GRV 11维一一对应（可扩展至15个以内）
- 每篇文章打主标签（primary_dimension）和次标签（最多2个维度）
- 归类用来源标签+关键词规则（覆盖约80%），不调LLM
- 时间衰减：staleness_score = exp(-hours_age/τ)，普通新闻τ=72h，结构性事件τ=240h
- 去重：sentence-transformers（all-MiniLM-L6-v2）本地embedding，相似度>0.85过滤
- 映射关系写入source_dimension_map.yaml，天枢启动时执行校验，遗漏映射不允许静默失败

**非英语叙事源两步处理（不可合并）：**
- 步骤A（叙事方向信号）：原文统计关键词频率变化趋势，不翻译，不降权，保留信号强度
- 步骤B（内容注入天璇）：Ollama qwen2.5-7b翻译，强制标注`[src:ru, via:qwen2.5-7b, bias:state_media, conf:medium]`；Ollama不可用时保留原文标记`[untranslated]`，不阻塞主流程

### 2.2 慢变量定义与计算

**中美博弈强度指数（UCRI）**，取值[0,1]，月频，五分量等权复合：
1. 美对华有效关税率（Peterson Institute月度数据）
2. BIS实体清单月度净增条目数
3. 外交对抗事件指数（复用天枢现有NLP信号，不新建管道）
4. 中美双边贸易占中国GDP比重趋势（UN Comtrade季度数据月度插值）
5. 科技管制强度月度评分（手工评估0-4分：0=无新措施/2=新限制/4=重大扩大）

**通胀体制概率（IRP）**，取值[0,1]，表示P(高通胀体制)：
- 逻辑回归分类器，四维特征：US_CPI_12m_slope / US_PCE_core_level / Fed_funds_rate_neutral_gap / US_5y5y_breakeven_rate，全来自FRED
- 历史人工标注：1973-75=1，1979-83=1，2021-23=1，其余代表性时段=0
- 每12个月重新训练一次

**地缘格局指数（GCI）**，取值[0,1]，月频，三分量加权复合：
- 大国直接对抗事件计数×0.4（ACLED，P5国家）
- 核威慑态势评分×0.35（手工评估每月-1/0/+1）
- (1-大国多边合作指数)×0.25（UN安理会投票通过率+G20公报情况）

**重要**：科技管制分和核威慑评分为有意保留的月度手工评估节点，确保维护者每月强制阅读关键动态。当月未输入时使用上月值并标注`[手工评估待更新]`。

**存储**：全程使用连续分数，**离散标签仅用于显示层**，不参与任何计算。

**转型期规则**：任意慢变量处于转型区间（IRP∈[0.3,0.7] / UCRI∈[0.35,0.65] / GCI∈[0.35,0.65]）时，天璇自动将所有预测置信区间扩大1.5倍，并标注"慢变量处于转型期，预测不确定度高"。

### 2.3 权重矩阵

不是全局权重，是**信号×预测目标类型的二维矩阵**：

```
              台海冲突  通胀  金融危机  政治动荡  ...
制裁信号        0.8    0.3    0.6      0.4
GDELT事件       0.6    0.2    0.3      0.7
FRED利率        0.2    0.9    0.8      0.2
军事RSS         0.7    0.1    0.2      0.5
...
```

- 冷启动：人工填写prior.yaml，逐预测目标类型手动填入（范围0.05-0.4，禁止超过0.4），附填写理由，经玉衡审批
- 新增信源自动进入3个月冻结期，冻结期内天玑不生成权重建议
- 后续：天玑校准结果通过玉衡审批后更新
- 权重从硬编码常量改为读取`grv_weights.yaml`

### 2.4 继承与改动

大部分fetcher继承，主要新增：
- GRV改为带不确定度分布
- 叙事预处理模块（narrative_chunks表+staleness_score+embedding）
- 权重改读grv_weights.yaml
- 慢变量计算模块（UCRI/IRP/GCI）

## 三、天璇（推演引擎）

> **现有macro-sim基本重写。** agent定义/迭代机制/输出格式全部重新设计。

### 3.1 输入（两类并行）

天璇激活时同时读取：
```
① 数值状态：GRV状态向量 + 慢变量分数 + FRED关键指标（结构化）
② 叙事上下文：触发维度相关文本块（非结构化，按staleness×diversity排序取top-N）
③ 军事背景卡片：/data/static/military_backdrop.md（SIPRI/NTI静态内容，初始化注入一次）
```

叙事context双硬上限：单维度2000 tokens（路径B标记维度3000 tokens），多维度触发时叙事总上限8000 tokens。总prompt目标≤32k tokens（叙事8k+状态向量3k+历史参考路径8k+system prompt 3k+输出预留10k）。

### 3.2 推演引擎：B+A组合

**B（历史相似度匹配）先跑：**
- 在知识库找当前状态最相似的历史时期
- 给出基础参考路径和历史频率概率
- B检索时强制返回最佳匹配相似度分数（0~1）

**A（LLM推理）后跑：**
- 判断当前与历史关键差异，在B的路径基础上做边际调整
- 概率调整公式（有界自适应，替代原±15%固定上限）：
  ```
  max_adj = min(0.20, B_prob, 1 - B_prob)
  actual_adj = clip(LLM_suggested_adj, -max_adj, +max_adj)
  final_prob = B_prob + actual_adj
  ```
  B=50%时允许±20%；B=5%时仅允许±5%；±20%为绝对硬上限

**历史样本不足时四级分档：**

| 等级 | 条件 | B的角色 | 输出标注 |
|------|------|---------|---------|
| HIGH | ≥10条 | 统计先验，标准公式 | 无 |
| LOW | 5-9条 | 弱先验，max_adj翻倍 | LOW_SAMPLE |
| VERY_LOW | 2-4条 | 仅提供方向约束，A主导数值 | LLM_PRIMARY |
| NOVEL | 0-1条或相似度<0.35 | 数值丢弃，作为排除参考传给A | NOVEL |

NOVEL模式：A强制产出区间而非点估计`{low, high, basis, key_uncertainties}`，推理链存入reasoning_trace表。相似度阈值0.35为初始值，积累50条NOVEL预测后重新校准。

**C（参数化转移矩阵）：** 长期演进，积累足够数据后引入。

### 3.3 Agent设计

**定义：agent = 真实行为主体，不是分析视角。**

每个agent读取**全域信息**（数值状态+叙事上下文），基于自身利益+约束条件决策，不锁死在单一视角（央行也要考虑地缘、政治、社会因素）。

| 主体类型 | 示例 |
|---------|------|
| 国家主体 | 美国、中国、俄罗斯、欧盟、日本 |
| 机构主体 | 美联储、OPEC、IMF、WTO |
| 市场主体 | 债券市场、股票市场、外汇市场 |
| 社会主体 | 舆论/媒体、民众情绪 |

- 数量不固定，**按触发情景动态激活相关主体子集**
- Agent之间相互影响，迭代推演（非同时输出）

### 3.4 推演迭代机制

**校准阶段（内部，不输出给用户）：**
- 用历史数据回放，跑到状态向量与历史真实数据误差收敛为止
- 不固定轮数，收敛条件驱动

**推演阶段（满足任一条件停止）：**
- 概率树过于发散（所有路径概率低于阈值）
- 达到时间边界
- 状态收敛（所有路径指向同一稳定状态）

**时间边界动态判断：**

| 情景类型 | 时间边界 |
|---------|---------|
| 金融市场冲击 | 周级 |
| 地缘军事事件 | 月级 |
| 结构性地缘转变 | 年级 |

### 3.5 输出格式（三种并行）

**① 地缘路径（人工验证）**
- 事件序列+各事件概率
- 置信度上限：地缘/军事类≤0.6，经济/金融类≤0.8
- 强制标注epistemic_uncertainty级别，军事类默认high

**② 量化传导（自动验证）**
- 条件概率+具体指标（FRED序列/GRV维度）
- 条件明确：哪个地缘事件发生时，对应什么量化结果

**③ 叙事输出（人类可读）**
- 独立生成，不是①②的翻译
- 基于所有agent行为，将最可能发生的结果串联，写清整个发展过程
- 有温度、有逻辑连贯性的自然语言叙事

## 四、天玑（校验层）

> **全新建设，现有系统完全缺失此闭环。**

### 4.1 核心职责

存档预测 → 到期验证 → 反哺权重矩阵建议

### 4.2 数据库schema

```sql
-- 表一：预测主张
CREATE TABLE predictions (
    id INTEGER PRIMARY KEY,
    created_at DATETIME NOT NULL,
    due_at DATETIME NOT NULL,
    scenario_id TEXT,
    type TEXT NOT NULL,               -- 'quantitative' / 'geopolitical'
    prediction_target_type TEXT NOT NULL,  -- 台海冲突/通胀/金融危机等
    content TEXT NOT NULL,
    outcome_definition TEXT NOT NULL, -- 预测时填写，不可修改
    target_metric TEXT,
    target_direction TEXT,
    target_threshold REAL,
    b_prob REAL,
    b_sample_count INTEGER,
    b_max_similarity REAL,
    llm_adj REAL,
    final_prob REAL,
    prob_low REAL,                    -- NOVEL模式用，其余NULL
    prob_high REAL,
    confidence_tier TEXT,             -- HIGH/LOW/VERY_LOW/NOVEL
    time_horizon TEXT,                -- 周级/月级/年级
    status TEXT DEFAULT '待验证',
    outcome_value REAL,
    brier_score REAL,
    verified_at DATETIME,
    verified_by TEXT
);

-- 表二：推理溯源（与predictions一对一）
CREATE TABLE reasoning_trace (
    id INTEGER PRIMARY KEY,
    prediction_id INTEGER NOT NULL REFERENCES predictions(id),
    agent_id TEXT,
    input_signals TEXT,               -- JSON：信号名+当时值+当时权重
    historical_match TEXT,            -- B阶段匹配的历史时期
    confidence_basis TEXT,            -- 'historical_freq' / 'llm_adjusted'
    llm_adjustment REAL,
    reasoning TEXT                    -- NOVEL模式的推理链
);

-- 表三：权重更新日志
CREATE TABLE weight_update_log (
    id INTEGER PRIMARY KEY,
    updated_at DATETIME NOT NULL,
    prediction_id INTEGER REFERENCES predictions(id),
    signal_name TEXT NOT NULL,
    target_type TEXT NOT NULL,
    weight_before REAL,
    weight_after REAL,
    reason TEXT,                      -- '自动校准' / '人工干预' / '重置'
    notes TEXT                        -- 同方向连续4次时强制填写
);

-- 叙事存储
CREATE TABLE narrative_chunks (
    id INTEGER PRIMARY KEY,
    source_id TEXT NOT NULL,
    source_type TEXT NOT NULL,
    primary_dimension TEXT NOT NULL,
    secondary_dimension TEXT,
    timestamp DATETIME NOT NULL,
    content TEXT NOT NULL,
    token_count INTEGER,
    embedding BLOB,                   -- 阶段二填充
    staleness_tau INTEGER DEFAULT 72,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX idx_dim_time ON narrative_chunks(primary_dimension, timestamp DESC);

-- 叙事密度监测
CREATE TABLE narrative_density_flags (
    dimension TEXT PRIMARY KEY,
    flagged_at DATETIME,
    z_score REAL,
    consumed INTEGER DEFAULT 0
);
```

### 4.3 验证指标体系（三指标并列）

- **Brier Score (BS)**：总体校准质量
- **Brier Skill Score (BSS = 1 - BS/BS_climatology)**：vs朴素基准，BSS≤0表示不如不用，是最关键单一指标
- **锐度**：预测落在(30%,70%)以外的比例，目标>40%，防止退化为基础概率复读机

最低门槛：每类别≥20个已验证预测才计算有效统计数字（地缘类需12-18个月积累）。

### 4.4 验证流程

```
每月1日天玑自动跑
↓
查所有 due_at <= 今天 且 status=待验证 的预测
↓
量化预测 → 自动拉FRED/GRV历史数据 → 计算Brier分 → status=已验证
地缘预测 → ntfy推送提醒人工确认 → 回复发生了/没发生 → status=已验证
↓
触发反哺逻辑
```

### 4.5 反哺逻辑

- 查推理溯源：这条预测用了哪些信号、哪个agent
- 计算该信号在过去N=8条同类预测里的Brier均值
- **触发条件（相对排名）**：连续N=8次中，该信源Brier均值 < 同类预测目标全体信源均值的80%
- 单条错了不触发（样本太少）
- 触发后生成降权建议→写入待审批文件→推送玉衡
- N=8写入配置文件；系统累计预测数>100条后建议手动调为5

### 4.6 慢变量三层验证

- **第一层（面效度，上线前）**：每变量6个历史锚点共18个，修改慢变量逻辑后必须全部通过
- **第二层（构建效度，月度监控）**：自动计算与外部基准相关系数；持续3个月偏离预期方向生成审查警报
- **第三层（预测效度，12个月后启动）**：回测条件化vs不条件化Brier分差异，delta_Brier<0.02进入降权候选

## 五、玉衡（权重审批层）

> **全新建设。天玑发现问题，玉衡修复问题。永远不自动写回。**

### 5.1 标准化判断包（每条建议必须包含5元素）

1. **Brier趋势**：N期均值+标准差+相对排名百分位（自动过滤系统整体变准的运气效应）
2. **历史一致性分布**：该信源在所有预测目标上的Brier分布（区分"全面差"与"只对某类目标差"）
3. **初始设置依据**：当初给此权重的人工批注（判断是否在推翻有依据的初始假设）
4. **受影响预测目标列表**：降权后哪些目标有效信源数会低于安全阈值2
5. **降权安全检查（硬性）**：若接受降权导致任意预测目标有效信源数<2，自动标记"危险建议"，必须二次确认

### 5.2 三个操作选项

| 操作 | 效果 |
|------|------|
| **接受** | 立即写回权重矩阵 |
| **观察** | 再积累N条预测后重新评估 |
| **拒绝** | 记录原因，不修改 |

### 5.3 权重调整硬约束（代码层clip强制执行）

双层约束，同时生效，取更严的：
- **变化速率**：单次调整不超过当前权重值的±25%
- **绝对值范围**：所有权重必须在[0.05, 5.0]之间

同一信源同一方向连续调整≥4次时，强制填写备注（不阻止操作，但强制记录审计轨迹）。

### 5.4 月度权重矩阵健康检查

检测三项指标，2种及以上警告同时出现时触发可视化对比+三选项（局部重置/全部重置/忽略并记录）：
- 预测目标有效信源数<2 → "孤立目标警告"
- 权重Herfindahl集中度超过初始基线3倍 → "过度集中警告"
- 有效信源占总信源比例<30% → "信源萎缩警告"

## 十一、问题清单（N1-N12，原始）+ v1.1 辩论新增问题

### 🔴 阻塞项（实施前必须解决）

**N1 predictions 表缺 prediction_target_type 字段**：需支持按预测类型分组计算 Brier 分；确认三张表支持跨预测目标 JOIN 查询，否则玉衡历史一致性判断无法落地。→ 已在 schema 中加入，实施时注意。

**N9 YAML 映射缺完整性校验**：source_dimension_map.yaml 遗漏映射会静默失败。→ 天枢启动时加配置校验，所有 active 数据源必须有映射条目。

**N13（v1.1）daemon 单线程无 LLM 超时（S1-F3）**：macro-sim `run.py` 的 `run_full_simulation` 是同步调用，无超时保护。一次 LLM hang 即冻结整条触发链路，无告警。→ 必须用 `threading.Thread + join(timeout=600)` 包装，超时后 ntfy 告警。

**N14（v1.1）容器 volume 挂载未验证（S1-F5）**：macro-scan 写 `/workspace/data/sim_trigger.json`，macro-sim 监听路径可能不一致，代码层完全不可见。→ 用 `docker inspect` 验证两容器 data volume 物理路径一致性。

### 🟡 重要（阶段二前解决）

**N2 NOVEL 模式区间下游消费逻辑**：天璇权重矩阵更新与天玑 Brier 计算均按点概率设计，NOVEL 输出区间时取中点/下界/完整区间需独立决策。

**N4 多子系统冷启动集群**：三处独立冷启动：BSS 需 ≥20 条（6-12 个月）；叙事密度 Z-score 需 30 天历史；慢变量分状态历史不足 24 个月。三处均需退化规则。

**N7 月度手工评估节点流程**：UCRI 科技管制分和 GCI 核威慑评分的输入界面、未提交时降级逻辑，以及 Herfindahl 基线快照初始化步骤，三项均未规划。**08-01 前必须填入 manual_scores.json，否则当月慢变量计算缺失输入。**

**N12 三项工程细节**：① sentence-transformers 模型文件 90MB，需明确 Docker volume 挂载策略；② Freightos FBX 访问权限需在第二批实施前验证；③ 初始权重矩阵 prior.yaml 需预留 notes 字段。

**N15（v1.1）T1 历史数据库不存在**：`fx_history/fx_latest.json` 是 427 字节当日快照，不是时序数据库。PCA 需要 T×N 矩阵（最低 T>300 交易日），当前根本无法计算 FCI-lite。→ 立即建立 FX/BDI/商品日频存档 job（T1-A），PCA 本体（T1-B）300 天后才能执行。

**N16（v1.1）T3 字段名事实错误**：优化建议中的 `Mentions.Confidence` 字段在 GKGv2 schema 中不存在，parser 会静默失败返回空值。→ 本期 T3 只升级 V2Tone，其余字段先核实 schema 再写 parser。

**N17（v1.1）prediction schema 必须一次性锁定**：MVT 和完整 Agent 版本若产生不同 schema，天玑历史 Brier 验证需重建基线。→ 在 MVT 动工前一次性定义枚举，含 agent_contribution_breakdown 字段预留。

### 🟢 可推迟（阶段三）

**N3 预测粒度与可验证性**：地缘预测需单独制定操作化定义规范；叙事配额对预测质量的影响未经实证。

**N5 GCI 全球汇总信号抵消**：台海紧张与中东缓和叠加可能使 GCI 中性。是否拆分为区域性慢变量需单独论证。

**N6 历史相似度缺时间加权**：B 模块对 1990 年代与近期历史一视同仁。建议引入可配置滚动时间窗口（初始值 15 年）。

**N8 数据源与慢变量映射未盘点**：现有 22 个源哪些可复用于慢变量计算，哪些需新建拉取任务，需在实施前完成盘点。（注：`18_慢变量数据源盘点_v1.0.md` 已做初版，与 N8 有重叠）

**N10 Ollama 翻译服务降级无告警**：降级触发时无通知，可能长期静默失败。需加天枢运行日志监控。

**N11 叙事方向关键词表维护机制**：俄语/阿语关键词表初始填写、更新触发条件、领域审核流程均未规划。冷启动时为空将导致叙事方向信号提取完全失效。
