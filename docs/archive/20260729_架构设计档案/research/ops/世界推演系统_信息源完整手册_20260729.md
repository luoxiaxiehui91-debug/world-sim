### 11.1 基础数据层

**1. GDACS / EM-DAT / USGS 地震**
- 方式：REST feed（GeoJSON）
- Endpoint：`https://earthquake.usgs.gov/earthquakes/feed/v1.0/summary/2.5_day.geojson`（4次/日），`significant_day.geojson`
- 鉴权：无需
- 出口：走 `PROXY_URL`（mihomo `http://192.168.31.108:7890`）
- 备注：GDACS 仅在 `narrative_processor.py` 引用、无独立 fetcher；EM-DAT 当前无自动拉取。

**2. FRED（29 序列）**
- 方式：REST API
- Endpoint：`https://api.stlouisfed.org/fred/series/observations?series_id=<ID>&api_key=<FRED_API_KEY>&file_type=json`
