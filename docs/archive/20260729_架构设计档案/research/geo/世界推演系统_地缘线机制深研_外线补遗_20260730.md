## 一、ViEWS 实际特征集（公式级，纠正"只写到集成"）

来源：Hegre et al. 2019 *JPR* 56(2):155–174（Table II/III）+ ViEWS 2024 `Fatalities002 Models` 文档。

### 1.1 Country-month（cm）级变量（Table II）

| 主题 | 变量 |
|---|---|
| Baseline | 训练期内有冲突的月份占比 |
| Conflict history | 滞后冲突（sb, nsos）；衰减函数 $2^{-m/12}$（m=无冲突月数，12=半衰期） |
| Demography | 人口规模；15–24 岁且至少低中教育占比；城镇人口占比 |
| Economy | 人均 GDP（含油租 / 剔除油租）；人均 GDP 增速（含油租 / 剔除油租） |
| Institutions | 民主度；半民主；独立前战争距今年数；政权更迭距今年数；被排除权力人口占比；独立距今年数 |
| Protest | 滞后抗议；衰减函数 $2^{-m/12}$ |

### 1.2 PRIO-GRID（pgm，0.5°）级变量（Table III）

| 主题 | 变量 |
|---|---|
| Baseline | 该格内有冲突月份占比 |
| Conflict history | 滞后冲突事件（sb/ns/os）；距上次冲突月数（衰减 $2^{-m/12}$）；滞后冲突的空间滞后 |
| Natural geography | 距最近钻石矿；距最近石油；山地比例；耕地/荒地/森林/灌木/牧场/城区面积占比 |
| Social geography | 距邻国；到最近城市通行时间；距首都；人口；单元 GDP；婴儿死亡率；被排除族群数 |
| cm 级主题 | 民主/半民主/独立·战争·政权更迭距今年数/被排除占比/人均 GDP（含/剔油租）/增速/人口/教育/城镇 |
| Protest | 滞后抗议；距上次抗议月数（衰减）；抗议空间滞后 |

### 1.3 2024 Fatalities002 特征集（13 个 qs_*，4 大主题）

- **特征集**：`qs_baseline` / `qs_conflict` / `qs_conflict_long` / `qs_vdem_short`（民主与制度强度）/ `qs_wdi_short`（世行发展指标：人均 GDP、婴儿死亡率、入学率）/ `qs_topics`（Mueller & Rauh 2018 新闻主题模型）/ `qs_joint_broad` / `qs_joint_narrow` / `qs_all_features` / `qs_aquastat`（水与农业）/ `qs_faostat`（粮食安全）/ `qs_faoprices`（粮价）/ `qs_imfweo`（GDP 预测）。
- **4 大主题分类**：Conflict history（UCDP+ACLED）/ Development（世行 WDI）/ Climate & societal vulnerability（FAO、AQUASTAT、PRIO-GRID、MIRCA、MAPSPAM、SPEI 干旱监测）/ Food security（粮价、营养、清洁水、卫生）。

### 1.4 模型估计与集成（机制要点）

- **估计器**：logistic regression（GLM）+ random forest（CART + bagging + 随机特征）；RF 因计算贵用**下采样**（全事件 + 随机抽非事件）。
- **两步前瞻策略**：① Dynamic simulation（Dynasim，递归推 1–36 月）；② one-step-ahead（osa，逐月重估）。RF-osa 通常比 ds/logit 更 sharp。
- **集成加权**（Appendix A §A-2.2）：按**样本外（OOS）表现**对 sb/os/ns 子模型加权组合，非等权。
- **缺失处理**：预测变量用 Amelia II 多重插补；空间概率插补（Croicu & Hegre 2018）。

### 1.5 局限（补）

- 特征集随版本（2019→2024 Fatalities002）大幅扩张，跨版本**不可直接比对**；我们若借鉴须锁定单一版本口径。
- 衰减函数 $2^{-m/12}$ 是**固定半衰期**，未对冲突类型/地区差异化——对低发区可能过衰减。
- sb/os/ns 三子模型独立估计再加权，加权权重本身来自 OOS，存在**版本内过拟合窗口风险**。

## 二、OECD 综合指标归一化（公式级，纠正"仅 min-max"）

来源：Nardo et al. 2008 *OECD-JRC Handbook* §1.5 + Green Growth Index Methodology（min-max 带边界实例）。

### 2.1 手册 Table 3 五法（原文逐条）

| 方法 | 公式 / 规则 | 适用与陷阱 |
|---|---|---|
| **1. Ranking** | 序数排名 | 不受异常值影响；但丢失绝对水平信息，无法跨年评绝对表现 |
| **2. Standardisation (z-score)** | $Z=(X-\mu)/\sigma$ | 均值 0、标准差 1；**极端值权重被放大**（若想奖励"少数极优"则不利） |
| **3. Min-Max** | $X'=(X-X_{min})/(X_{max}-X_{min}) \in [0,1]$ | 极端值/异常值会扭曲；但能**拓宽小区间指标的影响**，比 z-score 更敏感 |
| **4. Distance to reference** | 相对某参考点（目标值 / 标杆国 / 组均值 / 组 leader）的位置 | 参考点若取极端值（组 leader）则不可靠 |
| **5. Categorical scale** | 按分布百分位打分（top 5%=100，85–95%=80，…逐级至 0） | 丢失方差信息；分布内变异小时会强行分级 |

### 2.2 min-max 带边界推广（Green Growth Index 实例）

通用式：$X'=(X-a)/(b-a)$，其中 a/b 为下/上界（可任意设）。GGI 取 **[1,100]**（避 0 的负面暗示，100=达标），ADB 取 [1,6]。
选 min-max 的三条理由：①简单、最易复现；②可内嵌上下界**部分纠正异常值**；③可注入"目标值"做基准对标。

### 2.3 关键 caveat（直连我们 D1/D3）

> 手册原文："**There are no general rules for selecting appropriate normalization methods**, so they are commonly based on subjective or expert judgement."

即归一化/加权**无客观正解**，本质是专家判断——这正是我们 GRV 合成被诟病「任意权重」(D1/D3) 的方法论根。可借用点不是"抄某法"，而是**把选择显性化 + 敏感性分析**（见 §四）。

## 三、WTM 日频归一（推翻"黑盒"原判）

来源：`worldtensionmeter.com/methodology.html`（v3.0）+ `/analysis/world-tension-score-explained/` + `/world-tension/`。

### 3.1 五信号各自归一规则（原 Batch2 标"未知"，现解明）

| 信号 | 权重 | 归一锚定 | 数据 |
|---|---|---|---|
| Conflict | 25% | 当前冲突数 **vs 10 年基线**：0=低于均值，100=历史极端；**严重度加权**（洲际战争 > 局部内乱） | GDELT + ACLED + news（v2.0 起 ACLED API 替代 60% 媒体估数） |
| Energy | 20% | 油价 **vs 5 年区间**：$60/桶≈30，$120/桶≈95；+ 波动率加权 | Alpha Vantage(Brent)、Yahoo(油期货)、FRED |
| Trade | 20% | 关税升级 + 航运中断（BDI）+ 供应链压力，**对标历史贸易危机**校准 | 新闻情绪 + BDI + 制裁库 |
| Financial | 20% | VIX + 10Y 美债(DGS10) + 黄金(XAU) + DXY，**各指标分别归一 0–100** | FRED + Yahoo |
| Media | 15% | 头条 NLP 正/负情绪，**vs 典型报道基线**；危机报道 ≥90 | NewsAPI(BBC/Reuters/AP/Bloomberg/Al Jazeera) |

→ **总分 = 加权均值（25/20/20/20/15）**，置信区间 **±5 pts**（v2.0+）。

### 3.2 事件半衰期衰减（v1.5，记忆窗口）

Wars 60d / Crisis 21d / Escalation 10d / Incident 4d。极端/高张力文章置顶 24h。

### 3.3 多源共识加权 + 信源可信分层（v2.0）

- 共识：被 **3+ 信源**覆盖的故事 ×1.3，5+ ×1.6。
- 信源分层：AP/通讯社 ×1.5，广播 ×1.0，财经媒体 ×0.8。

### 3.4 Tier-2 子指数公式（v3.0 全披露）

- **Energy Security** = oil×0.45 + gas×0.30 + volatility×0.25（Brent 52 周区间、Henry Hub、30 日波动、金油比）。
- **Sanctions** = oil_score×0.50 + dxy_score×0.50。

### 3.5 结构风险监视器（分离、周更、不进日指数）

5 个慢变量（Brent / Gold / VIX / 10Y 收益率 / Active Conflicts）**单独列示，每周更新，不纳入日指数**。
置信增强逻辑：**高 WTM + 结构指标高** → 信号可信度增强；**高 WTM + 结构指标平静** → 疑似媒体放大。

### 3.6 文档内部不一致（已核对，提示性）

首页/方法页写"Updated **00:00 & 12:00 UTC**"，单页又写"09:00 UTC"——**发布时点文档自相矛盾**，落地时须以方法页 v3.0（双更）为准或实测验证。

### 3.7 局限（补）

- 严重度加权、贸易"历史危机校准"、媒体基线**均为未公开系数的黑盒**，仅知锚定逻辑不知函数。
- v1.0(2026-02)→v3.0(2026-04) 三个月迭代 3 大版本，方法论**仍在剧烈变动**，不宜作为稳定参照。
- 自称"四大 AI 系统独立验证"为自述，无第三方审计，可信度打折。
- 仍依赖 ACLED（需注册 API）——与我们 B5 弃用 ACLED 的本地决策不冲突（WTM 疑似持商业/注册密钥）。
