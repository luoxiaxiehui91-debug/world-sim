## 一、B1 · ICEWS（Integrated Crisis Early Warning System）

### 1.1 它解决什么
DARPA 2008 启动（O'Brien 主导）、Lockheed Martin ATL 集成的**国家级/次国家级不稳定预警系统**：把海量开源新闻实时转成结构化事件，再预测危机/叛乱/暴力。它是事件编码 + 冲突预测的经典范式，也是后续 ViEWS/GDELT 的方法论祖先之一。

### 1.2 方法论（一手来源：Lockheed Martin ICEWS 页 / Wikipedia(ICEWS) / O'Brien 2010 / Ward et al. 比较 GDELT 论文）
**三件套管线（统一语义穿透）：**
```
iDATA  ──►  iTRACE  ──►  iCAST
(事件库)     (趋势识别)    (预测)
```
- **iDATA（事件知识库）**：
  - 45M+ 全球新闻故事（英/西/葡/阿，1991 起），经 Jabari（浅解析）+ BBN Serif（NLP）处理 → **2500万+ 地理事件（>80% 精度）**。
  - 事件 = 加时间戳、加地理坐标的 **「who did-what-to-whom」三元组**；事件类型取自 **CAMEO（Conflict and Mediation Event Observations）** 分类体系，**300+ 种**编码，每种带**观察者中立的 hostile/cooperative 强度分**。
  - 行为体来自 5万+ 具名 + 时间索引实体词典 + 700+ 通用 agent（police/government/protestor…）。
  - 注：CAMEO 后续被 **IDEA（Integrated Data for Events Analysis）** 取代（ICEWS 后期迁移），但强度分/三元组范式不变。
- **iTRACE（Trending, Recognition, Assessment of Current Events）**：把新闻自动转成结构化指数，反映关键行为体间互动的「性质 + 强度」，提供图/时间线/地图视图，**可下钻到原始新闻**——这是「用透明建立对模型的信任」。
- **iCAST（预测）**：**混合方法 = 异构统计模型 + 基于主体模型（ABM）集成**，聚合预测精度 >80%（iCAST 内部称 >90%）。
  - 一等奖团队（Lockheed）集成了 6 类冲突模型：ABM（Silverman 的 Factionalism、Lustick 的 PSI）、logistic 回归（Schrodt）、贝叶斯统计（Shellman）、地理空间网络模型（Ward）。
  - 模型族含 logistic 回归、贝叶斯、随机森林、神经网络、ABM。
  - **透明下钻**：用户可钻入底层模型变量做 what-if 实验。

**关键数字**：100+ 数据源、250+ 国际/地区新闻源、6000+ 新闻源累积；45M+ 故事 → 25M+ 事件。

### 1.3 已知局限（决定我们「怎么用」而非「照搬」）
- **黑箱/不公开**：W-ICEWS 的数据、模型、预测结果**从未公开**（归 Lockheed/SAE/ONR/DoD），无法复现、无法借数据——与 ViEWS 全透明相反。
- **精度声称存疑**：>80%/ >90% 是厂商自报，缺独立第三方回溯验证；且「精度」定义（点预测？事件有无？）未公开。
- **重资产**：Jabari+Serif NLP + 6 模型集成 + 实时门户，个人/小系统不可复刻。
- **CAMEO 编码偏差**：基于英语新闻源，对非英语冲突覆盖不均；强度分为观察者中立但源偏西方媒体。

### 1.4 映射到我们 L 哪层
- **天璇地缘路径（事件序列 + 概率）**：iDATA 的「who-did-what-to-whom 三元组」↔ 我们 GDELT 事件编码与天璇地缘事件序列；iCAST 的「异构模型 + ABM 集成出概率」↔ 我们「B 历史相似度 + A LLM 修正」的集成思想（对标 doc D1）。
- **天玑 Brier 验证**：ICEWS 未公开校准细节，但其「可下钻透明」输出正是天玑/日报缺的**可解释性**层。

### 1.5 后续可借用点（非代码）
- **事件三元组统一语义**：我们 GDELT 事件 → 显式建模 `actor_a — action — actor_b — intensity` 四元组（带 hostile/cooperative 强度分），作为天璇地缘路径的统一事件原语，替代目前松散的 tone/QuadClass 计数。
- **混合集成思想**：天璇地缘预测不必单靠 LLM——可并行「统计基线（历史相似度 B）+ LLM 修正（A）+ 简单 ABM/规则」三路，再集成，呼应 ViEWS 的 ensemble 哲学。
- **可下钻透明输出**：日报/天玑验证结果应支持「钻到原始新闻/事件」而非只给概率，建立对 AI 预测的信任（治对标 doc D1「缺可下钻透明」）。

## 二、B2 · ViEWS（Violence & Impacts Early-Warning System）

### 2.1 它解决什么
Uppsala University + PRIO（Hegre et al.）的**政治暴力早期预警系统**，目前唯一**完全提前公开（数据+算法+结果）**的冲突预测项目。每月发布未来 **36 个月**全球国家层面、非洲/中东 0.5°（PRIO-GRID）次国家层面的致命政治暴力**爆发概率**。

### 2.2 方法论（一手来源：Hegre et al. 2019 JPR 56(2):155–174；Hegre et al. 2021 JPR 58(3):599–611；ViEWS 官网/API；复旦 CCDA 再评估）
- **预测目标 = UCDP 三类有组织的暴力**（与 B4 同源，形成闭环）：
  - **sb**（state-based conflict，国家层面）、**os**（one-sided violence，单边暴力）、**ns**（non-state conflict，非国家冲突）。
  - 输出：每国家/每 PRIO-GRID 单元、每月份、未来 1–36 月的**爆发/强度概率**。
- **集成架构（ensemble of constituent models）**：每个基模型代表一个「主题（冲突文献认为相关）」或一种「特定统计/ML 方法」。即「分而治之」——先拆子任务（sb/os/ns）各自建模，再集成出 forecast。
- **输入数据（covariates）**：UCDP GED（1989–2017）、PRIO-GRID（1946–2008 次国家地理级政经人环数据）、World Bank WDI（天气/经济/矿产）、Excluded Ethnic Groups（Cederman-Wimmer-Min 2010）、人口因子（Lutz）、ACLED（抗议）、V-Dem（民主评级）。
- **缺失值处理（关键工程细节）**：用 **Amelia II 多重插补（multiple imputation）** 补全预测矩阵——避免删样本造成偏差；对**位置不精确的事件**用同冲突、邻近时间的精确事件空间分布做**潜在冲突倾向的空间概率插补**（Croicu & Hegre 2018），显著提升预测。
- **预测推演（projections）**：三种策略——① 动态模拟（Dynasim / Dynamic Multinomial Logit）把 t 期预测当 t+1 期输入；② 外部源（选举日、干旱预测）；③ 简单假设（多数预测变量窗口内不变）。
- **评估指标（一手公式）**：
  - `AUROC`：ROC 曲线下面积（排序能力）。
  - `AUPR`：精确率-召回率曲线下面积（正类稀少时比 AUROC 更诚实）。
  - **Brier score**：`BS = (1/N)·Σ_i (ŷ_i − A_i)²`，范围 0–1，**越低越好**；Brier 奖励「sharp、接近 0/1 的概率预测」，而 AUROC/AUPR 只看排序。
  - `Accuracy`：单阈值正确率（阈值取校准期误分类成本最小处）。
- **迭代闭环（最值钱的方法论）**：模型批评（evaluation）→ 下一代模型改进；对每变量做**主题贡献度/消融（ablation）实验**，量化每个协变量对预测的价值。ViEWS 1.0→2.0 即此循环的产物。

### 2.3 已知局限
- **正类极度稀少**：冲突爆发是稀有事件，AUPR 比 AUROC 更有意义，但绝对水平仍低；高 Brier 易由「全预测 0」刷低（需配合 AUPR 看）。
- **预测≠可干预**：给出概率但因果/机制解释弱，政策端需另配叙事。
- **协变量滞后**：许多 covariate（WDI/PRIO-GRID）更新慢，近实时性不如 ICEWS 新闻驱动。
- **区域偏重**：次国家 0.5° 分辨率仅非洲/中东，全球其他国家只有国家层面。

### 2.4 映射到我们 L 哪层
- **天玑 Brier 验证（直接对标，治 D1 短板）**：本地对标 doc 明确指出天玑 verifier「只 Brier/BSS 缺迭代闭环」。**ViEWS 的「评估→改进→再评估」+ 主题消融贡献度，是天玑缺的那半套**。Brier 我们已有，缺的是「用 Brier/消融驱动下一轮权重/特征迭代」的纪律。
- **天璇地缘路径**：sb/os/ns 三分 + 国家/网格两级，可直接映射我们 GRV 冲突维 + 地缘路径的事件类型细分。

### 2.5 后续可借用点（非代码）
- **Brier + AUPR 双指标验证**：天玑 verifier 在 Brier/BSS 之外**补 AUPR**（稀有事件更诚实）；并明文「Brier 低可能被全零预测刷分」的陷阱。
- **消融/迭代闭环**：天玑每轮验证后，对每个源/特征做「去掉它预测变差多少」的消融，写入 `weight_update_log`（我们已有 tianji_verifier + weight_matrix），形成 ViEWS 式迭代。
- **多重插补 + 空间概率插补**：我们 GED/新闻数据常有缺失/位置不精确，可直接借 Amelia II 式多重插补与「邻近精确事件空间分布」插补思路（轻量 numpy/scipy 实现）。
- **全透明公开纪律**：天玑存档预测 + 推理溯源（我们已有 reasoning_trace）应进一步做到「可被独立复现」，对标 ViEWS 的公开成败记录。

## 三、B4 · UCDP（Uppsala Conflict Data Program · GED v26.1）

### 3.1 它解决什么
UCDP 是**事件级冲突数据**的黄金标准（免费 CC BY 4.0，学术广泛采用）。**GED（Georeferenced Event Dataset）** 把有组织的暴力拆到「单次事件」级别，带日期、经纬、行为体、死亡数、信源——比 UCDP 的「冲突/二元」数据集更细，是冲突强度与地理扩散的真相源。我们已落 `GEDEvent_v26_1.csv`（417,968 事件 × 49 列，1989–2025）与 `ged261.pdf` Codebook 到 NAS。

### 3.2 方法论（一手来源：本地 `ged261.pdf` Codebook 抽取 + UCDP 官方定义）
**三类暴力（type_of_violence，Codebook 附录 1 明确定义）：**
| 码 | 含义 | 定义要点 |
|---|---|---|
| 1 | **state-based** | 两个有组织行为体间使用武力，**至少一方为国家政府**（洲际 + 国内） |
| 2 | **non-state** | 两个有组织行为体间武力，**均非国家政府** |
| 3 | **one-sided** | 有组织行为体**针对平民**的武力 |

- **死亡编码（不确定性区间，Codebook 明确定义）**：每事件给三值
  - `low` = 源材料中最保守估计；`best` = 最可靠估计；`high` = 最高可靠估计（UCDP 刻意剔除不合理 claim，计数高度保守）。
  - 另有 `deaths_a / deaths_b / deaths_civilians / deaths_unknown` 拆分。
  - 年度纳入阈值 = **25  fatalities**（低于仍入 GED，但冲突级数据集另算）。
- **地理精度（where_prec）**：1=精确点；2=已知 25km 半径内；3=仅知二级行政区；… 7=一级行政区质心。
- **时间精度（date_prec / date_start / date_end）**：精确日未知时给时间跨度。
- **信源（number_of_sources）**：计数；`-1` 为「未知/未指定」哨兵值（实测占 23.3%）。
- **地理结构**：`latitude/longitude` + `adm_1/adm_2` + `priogrid_gid`（PRIO-GRID 单元）+ `geom_wkt`；`country/country_id/region` 聚合键。
- **行为体**：`side_a/side_b` + 对应 `*_dset_id / *_new_id`（UCDP 标准行为体字典）；`conflict_dset_id` 跨类型唯一。

### 3.3 已知局限
- **近实时性差**：GED 依赖学术手工编码 + 信源沉淀，事件常滞后数周~数月（远慢于 GDELT 新闻流）。
- **死亡计数保守**：best/high 偏保守，低估隐蔽冲突（尤其 one-sided 对平民）。
- **源覆盖偏西方媒体**：与 ICEWS 同源偏差；`number_of_sources=-1` 占近 1/4，信源质量不均。
- **非预测系统**：UCDP 是**数据**不是**预测**——本身不产出概率，需接 ViEWS 式模型才成预警。

### 3.4 映射到我们 L 哪层
- **冲突信号链路校验（直接对标 narrative_processor + GDELT 三步法）**：GED 是「真实暴力事件」真相源，可反向校验我们 GDELT weak_signal / 11 维叙事桶「说的紧张」是否真转化为「发生的暴力」（见 §四）。
- **doc19 预测目标（难民/人道/粮食）**：GED 的 `country × year × type` + `best` 死亡，正是 doc19 人道/粮食类目标的直接输入（已实现数据资产，待消费）。
- **GRV 区间化（M8）**：GED 的 best/high/low 死亡不确定区间，示范了「单点 vs 区间」——可借到我们 GRV/天玑出区间而非单点。

### 3.5 后续可借用点（非代码）
- **冲突信号校验基准**：用 GED 事件/死亡时间序列做「金标准」，标定我们 GDELT 弱信号 → 实际暴力的滞后与命中率（§四路径）。
- **type_of_violence 三分进 GRV**：我们 GRV 冲突维可显式拆 state-based/non-state/one-sided 三类计数，比笼统「冲突」更可操作。
- **地理精度感知**：消费 GED 时按 `where_prec` 加权（精确点权重 > 行政区质心），避免把低精度事件当高精度用。

### 4.2 与 GDELT 弱信号 / narrative_processor 11 维的对照与验证路径
我们现有冲突信号链：GDELT → GKG → `narrative_processor` 11 维叙事桶 / `weak_signal`（金融 tone：日元87/标普69/USD68）。其本质是**早期紧张度（lead signal）**，但：
- **GDELT 短板**：只有 tone/QuadClass/Goldstein 等粗粒度分数，**无真实伤亡真相**，且 weak_signal→narrative 衰减严重（对标 doc 已指出）。
- **GED 长板**：事件级、带 actor/deaths/地理的**暴力强度真相**——是 GDELT 信号的「事后裁判」。

**可落地校验路径（供实施 session）**：
1. 取 `data/news_export.json`(或 GDELT 落盘) 中某关注国（如 Syria/Ukraine）的月度 tone/紧张度序列；
2. 从 GED 抽同国同期的月度 `type_of_violence` 事件数 + `best` 死亡；
3. 算 **lead-lag 相关**：GDELT 紧张度抬升是否**领先** GED 暴力事件 N 个月？命中率多少？
4. 用结果**标定 narrative_processor 桶的「信号→暴力」转化率**，并反哺 GRV 冲突维权重（呼应 ViEWS 消融思想）。
> 此校验不需新数据源、不碰 prior.yaml，纯消费已落 GED + 已抓 GDELT，属「先不修」定调下即可做的可信度提升。
