## 二、通用成熟方案逐项拆解（5 类）

### 2.1 地缘冲突早期预警系统（整系统对标：ICEWS / ViEWS / World Tension Meter）
- **ICEWS**（DARPA，Lockheed Martin）：混合方法，组合异构统计模型 + ABM，聚合准确率 >80%；100+ 数据源、250+ 新闻 feed；"近实时供给 + 模型可下钻可视化以建立信任"。三件套：iDATA(事件库) → iTRACE(趋势) → iCAST(预测)，层间经"who-did-what-to-whom"事件三元组统一语义穿透。iDATA 本质是事件知识库(2500万+ geolocated events)。
- **ViEWS**（Uppsala/PRIO）：divide and conquer——拆为子任务(sb/os/ns)再用集成出 forecast；评估用 AUROC/AUPR/Brier；模型批评→下代模型的迭代闭环；权重来自**统计/ML 学习**，且有"theme 贡献度"消融实验量化每个变量价值。
- **World Tension Meter**（活例，2026）：每日 GDELT+ACLED+FRED+商品 API 合成"紧张指数" = 冲突25%·能源20%·贸易20%·金融20%·媒体15%；**显式把"慢结构指标"(油价/VIX/收益率/活跃冲突数)作为"结构风险监视器"单列、每周更新、不进每日分**。

> **天枢对应缺口**：天玑 verifier 的 Brier/BSS 方向对，但缺 ViEWS 的"消融/迭代闭环"；GRV 与慢变量的拆分有雏形但无 WTM 那种"慢变量单列不并入"的纪律；整体缺 ICEWS 式"可下钻透明"输出。

### 2.2 OECD/UNECE 综合指标方法学（GRV 11维合成的直接对标）
- GRV 11 维加权合成，**本质就是 OECD 定义的"综合指标(Composite Indicator)"**。
- OECD/JRC 标准步骤（10 步）：理论框架 → 数据选择 → 缺失值插补 → 多元分析(PCA/因子) → 归一化 → 加权 → 聚合 → **敏感性分析(Monte Carlo)** → 与其他指标关联 → 可视化。
- **头号警告原话**：权重的"任意性(arbitrary nature)"是综合指标最大坑；"non-aggregators 学派"根本反对意见正是"加权过程主观"。
- 权重方法：PCA/因子/回归/AHP/公共舆论/**等权**(equal weight ≠ 无权重，是"假设同等重要")；信度检验 Cronbach's α；敏感性分析 Monte Carlo 扰动。

> **天枢对应缺口**：geo_risk_vector.py 里 GRV 权重是**硬编码常量**，prior.yaml 里是**全手写交叉矩阵**——两者都**零理论框架、零归一化说明、零 α 信度、零 Monte Carlo 敏感性**。**正好踩中 OECD 头号反模式"任意权重"**。

### 2.3 特征库与绑定层（Feast + Palantir Ontology）：治 D4 + D2
- **Feast**：Entity/DataSource/FeatureView/FeatureService；`get_historical_features` 用 **point-in-time join** 防未来值泄漏；训练/推理用同一套特征定义(单一真相源)；`feast apply` 把特征注册 Registry 并版本化，schema mismatch 在构建期报错。
- **Palantir Ontology** 三层：语义层(Object Type/Property/Link Type) → 动力层(Action/Function, hydration + 完整血缘) → 动态层(实时血缘/安全)。最值钱：**原始数据→语义对象→可执行操作，靠显式可审计的 Link Type 连接**。

> **天枢对应缺口**："源→GRV→目标"绑定藏在 prior.yaml 一张手写表里，损坏且无 schema 校验，毫无契约先行。

### 2.4 配置防腐与校验闸门（dbt / Pydantic·Pandera / Great Expectations / Data Mesh）：治 D5
- dbt tests：断言写 YAML、随 `dbt test` 失败即阻断下游。Pydantic：记录级 schema 校验自动拒收非法。Pandera：DataFrame 级 `@check_input/@check_output` 双端把关。Great Expectations：expectation suite + checkpoint + Data Docs。共同范式：**Data Contract 先行**。
- Data Mesh：按域模块化 ownership——对应"巨型单一 YAML 应拆成 per-target 小文件"。

> **天枢对应缺口**：prior.yaml 是 ~65 目标×~27 源巨型手写交叉矩阵，无 schema/无校验/无测试，已崩过一次，修好也必继续腐化（**但注意：运行路径已避开它，详见问题清单第二节，非 P0**）。

### 2.5 知识层（Microsoft GraphRAG + GDELT GKG）：治 D6
- GraphRAG(Edge et al. 2024)：LLM 抽取实体/关系→建 KG→Leiden 社区检测→分层摘要→Global/Local/Drift 查询，全局回答比向量 RAG 高 50–70%。
- GDELT GKG 须按本体正确实现为 KG 才能用于 QA。
- **关键警告**：LLM 产 KG 易"star-shaped 退化"(单中心全连)，除非**本体约束抽取**；**实体解析**是质量决定步骤("OpenAI"/"OpenAI Inc."/"the company" 须 canonicalize 合并)；本体驱动 KG + 向量库双轨优于任一方。

> **天枢对应缺口**：narrative_processor/tianji_db(reasoning_trace) 本质是 JSON 堆，无本体约束、未实体解析、无双轨。

## 三、宏观财经成熟架构（6 类）

| 类别 | 代表项目 | 核心架构 | 输出形态 |
|---|---|---|---|
| 实时 Nowcasting | NY Fed Staff Nowcast 2.0、Atlanta GDPNow | 动态因子模型(DFM) + 混频 + 新闻分解 | 周更 GDP 增速 + 概率带 |
| 综合金融条件/压力指数 | OFR FSI、Chicago NFCI、St.Louis FSI、KC FSI、Goldman/Bloomberg FCI | 加权求和 **或** 主成分(PCA) | 日/周/月 单值指数(零=常态) |
| 央行结构模型 | FRB/US、SIGMA、NY Fed DSGE | ~300 方程 + 贝叶斯估计 | 预测+政策反事实+隐变量 |
| 单因子早期预警 | 收益率曲线衰退 probit | 期限利差(10y-3m) → 衰退概率 | 概率值(AUC 0.85-0.89) |
| 数据平台纪律 | FRED/ALFRED、Macrobond、FXMacroData | 数据层与计算层分离 + vintage/point-in-time | 可信时序供给 |
| 另类数据/NLP | GDELT→IP/CPI、FinBERT→FX/利率 | 关键词过滤→NN分类→聚合→PCA/SHAP | 情绪指数/可解释预测 |

### 3.1 实时 Nowcasting（NY Fed）
- 动态因子模型：N 个观测序列由少量（NY Fed 取 5 个）潜在因子驱动；贝叶斯→概率区间。
- 混频+ragged edge：缺失观测在量测更新中跳过；季度目标用月度因子时序聚合约束链接（MIDAS 替代但无法做新闻分解）。
- **新闻分解**：`news_i = 实际_i − 预期_i`；对 nowcast 贡献 = `news_i × weight_i`（权重来自因子载荷）→ 按类别聚合可视化，让"哪条数据把指数推高/压低多少"可追溯。
- **vintage 纪律**：实时历史取自 ALFRED（带修订版本），避免用"已修订数据"回测。

### 3.2 综合金融条件/压力指数（FCI/FSI）
- **加权求和法**：Bloomberg FCI = 货币/债券/股票三子指数等权(10变量)；Goldman 权重≈短端利率35%/股票35%/美元15%/信用利差10%/长端5%。
- **主成分法**：Chicago NFCI 由 105 变量→DFM→z-score(零=历史均值)；St.Louis FSI 由 18 周度序列；OFR FSI 由 33 变量分 5 类(信用/股票估值/融资/安全资产/波动)，统计算法捕捉**协同运动**→权重，按美/其他发达/新兴三区域分解。
- **稳健化(Fed 2013 Composite FCI)**：选若干 FCI→取第一主成分再聚合，降过拟合。语义：**零=常态**，符号比绝对值重要。

### 3.3 央行结构模型（DSGE）
- FRB/US ~300 方程(核心随机约50)，含理性预期；SIGMA 多国开放经济；NY Fed DSGE 含金融摩擦、贝叶斯。用途：预测+政策分析+反事实+隐变量(如自然利率)。概率化+不确定性区间。哲学："所有模型都是错的，但有些有用"——**模型集成**(FRB/US+DSGE+VAR) 而非单依赖。

### 3.4 收益率曲线衰退 probit（极简早期预警）
- `Pr(衰退) = Φ(β0 + β1·期限利差)`，取 10y-3m（Estrella & Mishkin 最强）。样本外 **AUC 0.85–0.89**。可加公司债利差/EBP/CAPE；**修正 QE 扭曲**（ECB 2020 指标准模型被购债压低长端误导，可用 Engstrom-Sharpe 近端远期利差 NTFS 替代）。

### 3.5 数据平台纪律
- FRED 定位"数据分发平台非分析系统"——基石。ALFRED 解决"用已修订数据回测"。Macrobond 覆盖 3亿+序列/320+国/2500+源。
- **FXMacroData 启示**：专为 AI Agent 工作流提供"干净官方宏观数据层"(CPI→EUR/USD、payrolls→USD/JPY)——与 macro-scan(AI 推演系统)**同构**，值得借鉴"面向 agent 的干净数据层"抽象。

### 3.6 另类数据 / 新闻 NLP
- GDELT GKG→宏观标准流水线：关键词过滤→NN(Bi-LSTM)分类→按国家/频率聚合；对成百情绪分 PCA 取前3主成分喂 AR，IP/CPI 预测 10 国中 8-9 国优于基准。
- FinBERT→日度情绪(XGBoost 预测 EUR/USD、USD/JPY、10Y 美债次日收益，样本外 Sharpe 5.87/4.65/4.65；SHAP 确认"情绪离散度+文章冲击"是关键特征)。
- **基线控制变量启示**：GDELT→IP 模型直接用 **BDI+原油**作控制变量——macro-scan 恰好已抓 BDI/商品却闲置。
- 严谨性警示：需严格统计检验；采样不稳定、关键词敏感，非灵丹。

## 四、财经成熟范式「具体机制 + 可借鉴点」深挖

### 4.1 五个范式的具体机制（How they do it）

**① NY Fed 动态因子 Nowcasting**
- 状态空间：量测 `X_t = μ + ΛF_t + ε_t`；状态 `F_t = ΣA_i F_{t−i} + u_t`（VAR(p)）；卡尔曼滤波最优 nowcast；PCA 取因子初值，EM 精炼载荷、处理缺失、产概率带。
- 5 个潜在因子：global/nominal/soft/labor + 疫情临时 COVID 因子；每序列先 load 全局再 load 子组。
- 混频+ragged edge：缺失观测直接跳过；季度目标用3月度因子时序聚合约束链接。
- **新闻分解**（最关键可借鉴）：`news_i = 实际_i − 预期_i`，贡献=`news_i × weight_i`(因子载荷)→按类别聚合可视化。
- 贝叶斯概率带 50/68/80%；开源(MATLAB/Julia)；vintage 取自 ALFRED。

**② Chicago NFCI**（最贴近"市场价格 FCI"）
- 105 指标(46周+33月+26季)覆盖 risk/credit/leverage 三类。
- 单因子 DFM(Brave & Butters)：每个指标先 z-score(相对样本均值/除以样本标准差，样本自1971)；**自适应权重由最大似然估计且随时间变化=序列间瞬时协方差的函数**→信用危机时自动让利差主导、杠杆危机时让中介流量主导，无需分析师先验选信号（这正是 macro-scan 用固定 prior.yaml 权重的反面教材）。
- 三分指数：risk(+权)/credit(−权)/leverage(−权，非金融杠杆+权)；各自 mean0 std1。
- **ANFCI**(周期调整)：剔除经济活动/通胀能解释的变动→回答"给定经济现状，金融条件偏紧/松"。
- 解读：零=历史均值；**+0.5 以上历史上领先每次 NBER 衰退 6-12 月**；+2.0=重大压力(1971来仅6次)。

**③ 收益率曲线衰退 probit**
- `P(衰退_{t+12}=1 | T10Y3M_t) = Φ(α+β·T10Y3M_t)`。
- NY Fed 校准(Estrella-Trubin 2006, 1959至今)：α=−0.5333，β=−0.5984；**100bp 倒挂(利差−1.0)≈53% 概率**(Φ(−0.5333+0.5984)=Φ(0.065))；AUC 0.85-0.89；系数极稳(1996来漂移<10%)。
- 陷阱：QE 压低期限溢价(ACM −50~−100bp)误导→用 NTFS(6季远期−3月)替代；HKMA 拆近段(2y−3m)+远段(10y−2y)提精度。

**④ GDELT→宏观 NLP**
- 三步(arXiv 2009.14281)：关键词过滤(GKG 经济主题)→NN 过滤(Bi-LSTM 1000篇标注)→按国家/月聚 sentiment。
- 降维：对上百 sentiment 分 PCA→前3主成分喂 AR(3)+控制变量（**IP 模型直接用 BDI+原油**；CPI 用贸易条件+原油）。
- 效果：CPI 10国中8-9优于基准；IP 8/10。警示：需严格检验、采样不稳定、关键词敏感。

**⑤ 数据平台纪律**：数据层≠计算层；ALFRED vintage 支撑诚实回测；FXMacroData"面向 agent 干净数据层"同构于 macro-scan。

### 4.3 哪些是「廉价即时借用」（不依赖 P0 修复、不依赖新数据源）
> 用户定调"先不修"，但下面纯属新增分析层、不碰现有损坏文件，可在不修 prior.yaml 前提下独立点亮财经线。

1. **L1 市场价格 FCI（M1）**——**最高性价比**。输入=已在抓却闲置的 FX/加密/商品/BDI + 已在用的 FRED 利差/VIX。GDELT→IP 文献恰好用 BDI+原油作控制变量=idle 数据即最佳原料。成本低(PCA/DFM 几十行)、零新源、绕开 prior.yaml。
2. **L3 收益率曲线 probit（M3）**——**最廉价**。T10Y2Y 已在 regime，几行代码出 12 月衰退概率+阈值，AUC 0.85+。
3. 二者叠加="市场价格强度(FCI)+衰退概率(probit)"双信号，直接补上"宏观满血、市场全暗"暗区。

### 4.4 实施顺序

## 九、方案层建议（非代码改动，待用户决策）

**原则**：转移的是**模式**不是企业平台。个人 NAS 研究系统不宜为学 Palantir 去搭 Neo4j 集群——用 networkx/GraphRAG/Pydantic/numpy 的轻量等价物即可。同时谨记 ViEWS 教训："少而强的几个变量 ≈ 复杂模型"，天枢当前 7 层 + prior.yaml 65×27 **可能已偏重**，回头审视是否过度工程。

**建议优先级：**
1. **🟡 顺手(非紧急)**：prior.yaml 启动自检 + per-target 拆分（治 D5，运行已避开，零架构风险，可维护窗口做）。
2. **🟠 短期(补方法学)**：GRV 合成补 OECD 三件套(理论框架+α+Monte Carlo)；慢变量严格单列不并入（学 WTM）。
3. **🟡 中期(解耦绑定层)**：把"源→GRV→目标"绑定抽成独立、带 schema、可测试模块（学 Feast/Ontology），fetcher 产出加 Pydantic 契约。
4. **🟢 长期(知识层升级)**：narrative_processor/tianji_db 加本体约束 + 实体解析 + KG/向量双轨。
5. **⚪ 贯穿(防腐文化)**：任何 config/架构文档落地前必须"机器加载成功+现实对应物标注"，根除"规划>校验"完备幻觉。
6. **财经最廉价即时借用**（详见第四节）：L1 市场价格 FCI + L3 收益率曲线 probit，均不依赖 prior.yaml、不加新源，可在"先不修"定调下独立点亮财经线。

> 一句话：天枢代码骨架(天玑/玉衡/叙事/慢变量)已高度对齐业界思路，真正缺的是**方法学外壳、绑定层契约化、配置防腐闸门、知识层结构化**这四件"让系统可信、可维护、不会悄悄烂掉"的成熟工程纪律。
