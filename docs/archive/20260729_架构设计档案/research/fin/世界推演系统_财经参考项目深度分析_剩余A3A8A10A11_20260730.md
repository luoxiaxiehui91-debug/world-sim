## 〇、本篇结论速览（先看这个）

- **金融压力指数家族（A3 OFR / A4 KC / 已做 A2 Chicago）**本质都是「单一隐性因子 DFM/PCA + 逐序列 z-score + 动态权重」，差异只在**变量池与频率**。对我们 L1 的启示：**FCI 不必自己选权重**，用 DFM/PCA 自适应权重即可（与 prior.yaml 手写权重形成对照）。
- **A5 FRED/ALFRED 的 point-in-time / vintage** 是「诚实回测」的基石，可直接映射我们 M6（fetcher 改追加快照）。
- **A6 / A7 / A8 是结构模型（DSGE）三档**：FRB/US（约 300 方程、半结构、可切换期望）、NY Fed DSGE（中等规模、贝叶斯、隐变量自然利率）、IMF SIGMA（多国开放、金融加速器）。共同哲学：「所有模型都错，但有些有用」→ **模型集成**而非单依赖。对我们 L4 的启示是「方法论外壳」而非直接搬方程（个人 NAS 跑不了 FRB/US）。
- **A10 FinBERT + GDELT → XGBoost** 是 **L5 叙事 / 情绪层**最直接可借用范式：新闻 → FinBERT 情感（均值 / 离散度 / 事件冲击）→ XGBoost → 方向，SHAP 可解释。我们已有 GDELT，缺的是 FinBERT 打分 + 可解释归因。
- **A11 FXMacroData** 是 **L0 数据层**的活样板：标准化 schema + `announcement_datetime`（point-in-time）+ 原生 MCP server 给 AI agent。其设计模式（干净 agent 数据层）正是我们 M7 方向，但它是 2026 商用 SaaS、非 USD 需 key，**只能借设计、不能借数据**。

## 一、A3 · OFR Financial Stress Index（OFR 金融压力指数）

### 机制原理
- **定义**：金融压力 = 市场正常运转的断裂。OFR FSI 是**日频、全球、市场基**的压力快照，由 33 个金融市场变量构成，分 5 类：credit / equity valuation / funding / safe assets / volatility。
- **两步构造**（OFR wp-17-04 原文）：
  1. **变量筛选**：文献调研候选 → 至少日频、及时反映压力、历史够长（回至 2001）、跨资产 / 市场 / 区域平衡、定量冗余检验剔除。
  2. **聚合（核心）**：先对每个变量做**滚动标准化**——减「截至当日」的均值、除其标准差，符号取「该变量上升 = 压力上升」的方向（如信用利差走阔 = 正贡献，股价上涨 = 负贡献）。然后用**带单一隐性因子的动态因子模型（本质 = 约束 PCA / 第一主成分）**产出权重：
     - 用**前 500 个交易日**估计第一载荷向量（动态 PCA）；
     - 当日指数 = 当日标准化数据在该载荷向量上的**标量投影**；
     - 权重与符号由 DFM 决定，**随瞬时协方差自适应**（与 A2 Chicago NFCI 同一思想）。
- **尊重时间箭头**：OFR FSI 的值只依赖「当日及之前可得信息」，一旦估计**不再修订**（区别于每周 / 月频 FSI 每次全量重估）。这点与 ALFRED vintage 纪律一致。
- **可分解**：指数可拆成 5 类贡献 + 3 区域（美国 / 其他发达 / 新兴）贡献。例：2013 Taper Tantrum 时 equity / funding / volatility 贡献结构可下钻。
- **解读**：> 0 压力高于历史均值，< 0 低于；量级 = 偏离零的程度。实证：FSI 高位预示未来经济活动下降、衰退概率上升。
- **发布滞后**：数据截止「两个交易日之前」。

### 已知局限
- 仅测「已实现的冲击及其对压力的影响」，**不测脆弱性（vulnerabilities）**——OFR 另用 FSVM（Financial System Vulnerabilities Monitor，58 指标热力图）单列脆弱性。启示：**压力与脆弱性要分开测**（同 WTM 慢变量单列纪律）。
- 33 变量部分依赖市场流动性报价，极端行情下报价冻结会失真。
- 2026-05-15/18/21/22 曾因 CEMBI Strip Spread 数据馈送错误需修正——提醒「指数可靠性依赖单源数据质量」。

### 映射到我们 L 哪层
- 直接对标 **L1 市场价格 FCI**（与 A2 同类，但 OFR 是全球日频 + 5 类分解 + 3 区域分解，比 Chicago 的 US / risk-credit-leverage 更「国际」）。

### 后续可借用点（非代码）
- **FCI 构造「动态 PCA + 500 日窗 + 滚动标准化 + 不回修订」四件套**可直接抄作业做我们的 L1 FCI-lite（用闲置 FX / 加密 / 商品 / BDI + FRED VIX / BAA）。
- **类别 / 区域分解**思路：我们的 FCI 也可拆 risk / credit / leverage + 区域（美 / 欧 / 日 / 新兴），让日报能说「是哪类资产在推高压力」。
- **压力 vs 脆弱性分离**：提醒我们在 L1 FCI（压力 / 已实现）之外，慢变量（UCRI / GCI）应单列作「脆弱性监视器」，不并入日更快变量。

## 二、A4 · KC Fed Financial Stress Index（堪萨斯联储金融压力指数）

### 关于 KC FSI 性质的一点澄清（注：非本地 doc 误标）
经复核，本地对标 doc 仅在 §3 表格与参考文献中以「KC FSI」列名，**从未把它描述为「州级金融压力」**——我此前报告称"本地 doc 误标 KC 为州级"是**我自己说错了**，在此更正。正确的机制性质（来自一手来源 KCFSI 官网 + Hakkio & Keeton 2009）是：KCFSI 是**美国金融体系**的月度压力测度（基于 11 个金融市场变量），**并非州级（state-level）**；其不含任何汇率变量，原因正是「美元作为全球储备 / 结算货币不存在汇率危机」——这反过来证明它是国家层面。此澄清供机制库参考，本地 doc 无需改动。

### 机制原理
- **11 个变量**（Hakkio & Keeton 2009 原文列举）：
  1. TED 利差（3 月期美元 Libor − T-bill）
  2. 掉期利差（swap spread）
  3. 10 年期国债 on-the-run vs off-the-run 利差
  4. AAA 公司债 vs 10 年国债利差
  5. Baa 公司债 vs Aaa 公司债利差
  6. 高收益债（垃圾债）vs Baa 利差
  7. CMO（资产抵押证券）vs 5 年国债利差
  8. 股票收益率与国债收益率相关系数
  9. 股票价格隐含波动率（VIX）
  10. 银行股特质波动率（idiosyncratic volatility）
  11. 典型银行股收益横截面离散度（return dispersion）
- **构造**：11 变量 → **PCA 第一主成分**（KCFSI 与 CNFCI 高度相关的根因：都用同类广谱变量 + PCA）。每月 5 日更新。
- **符号约定**：变量上升 = 压力上升的方向取正（如利差走阔、VIX 升 = 正贡献）。
- **解读**：> 0 压力高于长期均值，< 0 低于。用法：与历史公认压力期（GFC、欧债、COVID）比对当前值。
- **2018 修订**（Cook & Doh 2018）：用 Treasury repo rate 重做，因危机后回购市场成为压力前沿。

### 已知局限
- **月频**（比 OFR 日频、Chicago 周频都慢）——对实时预警不够快，但胜在历史长、稳健。
- 11 变量偏「利率 + 信用 + 股票尾部」，对汇率 / 商品覆盖弱（设计使然，因测美国）。
- PCA 权重固定（不似 OFR / Chicago 的动态权重）——结构变化期自适应差。

### 映射到我们 L 哪层
- **L1 市场价格 FCI** 的「最小可行版本」参照：11 变量 PCA 即一个可立刻复刻的 FCI 原型（若只想快速点亮 L1，KCFSI 变量集比 OFR 33 / Chicago 105 更轻）。

### 后续可借用点
- **轻量 FCI 原型变量集**：TED / 掉期利差 / Baa−Aaa / VIX / 银行股离散度 这 5–6 个，恰好大多可由 FRED + 我们已抓数据组装，是 L1 的「最小可用起步集」。
- 提醒：若用 PCA，**固定权重**在结构突变（如 2020 回购冻结）会滞后——优先学 OFR / Chicago 的**动态权重**。

## 三、A5 · FRED / ALFRED（数据供给与 vintage 纪律）

### 机制原理（重点在 ALFRED，不是 FRED 本身）
- **FRED** 定位「数据分发平台非分析系统」——基石。ALFRED = ArchivaL FRED，**vintage 版本的合集**。
- **核心概念**：经济数据发布后**会被修订**（初值 → 修正值 → 终值）。ALFRED 存「数据在历史上某天长什么样」。
- **三日期模型**（fredapi 文档）：每个观测有三个日期——`date`（数值对应的时期）、`realtime_start`（该值首次有效的日期）、`realtime_end`（该值最后一次有效的日期）。例：2014Q1 GDP 发布了 3 次（4/30、5/29、6/25），各有不同 realtime 区间。
- **API 方法**（fredapi 暴露，直接可映射我们 fetcher 设计）：
  - `get_series_first_release`：只取初值（忽略修订）
  - `get_series_latest_release`：取最新（= 普通 FRED）
  - `get_series_as_of_date('GDP','2014-06-01')`：**取某历史时点已知的值** ← point-in-time 回测关键
  - `get_series_all_releases`：全修订史 DataFrame
  - `get_series_vintage_dates`：所有 vintage 日期
- **入库纪律**：新 / 修订观测在发布后**通常 1 个工作日内**入 ALFRED；release date 由源实际发布日决定；增长 / 变化率用 ALFRED 既定公式（含 260 日 / 年等频率参数）。
- **修订验证**：可能时与原始源核对；许多源不保留历史已发布估计，则用第三方服务校验。

### 已知局限
- 很多源**不保留历史已发布估计**——ALFRED 用第三方服务校验，部分 vintage 不可得。
- vintage 数据量大（每个序列多版本），存储需设计（不能覆盖写）。

### 映射到我们 L 哪层
- 直接对标 **L0 数据层（M6 vintage / point-in-time）**。

### 后续可借用点
- **fetcher 改造蓝图**：我们 fetcher 现覆盖写、无修订追踪（对标 doc 判 P2）。改法 = 每次拉取**追加快照**（date + realtime_start + realtime_end 三元组），不覆盖；留 ALFRED 式修订史。这样未来任何回测都用「当时已知数据」，根除「用已修订数据回测」的虚假精度。
- **point-in-time join**（Feast 同源思想）：特征拼接时用 `as_of_date` 而非「最新值」，防未来值泄漏——我们天璇训练 / 推演若消费历史数据，必须此纪律。

## 四、A6 · FRB/US（美联储理事会大规模结构宏观模型）

### 机制原理
- **定位**：美联储理事会自 1996 年用于预测、政策选项分析、研究的**大规模估计一般均衡模型**（large-scale estimated GE model of U.S. economy）。
- **规模**：约 300 方程（核心随机约 50），含美国国民账户产品 / 收入双侧全部主要成分。
- **与 DSGE 的共性**：许多家庭 / 企业行为基于**优化**且**预期重要**；但比 DSGE 更灵活地应用优化理论，使方程更贴合历史数据、可更细建模。
- **期望形成（关键设计）**：可切换两种假设——
  - **VAR-based**：预期来自估计 VAR 的历史平均动态；
  - **Model-consistent (MC) / 理性预期 (RE)**：agent 用 FRB/US 自身模拟生成准确预期。解 RE 用 `mce_solve` 库（E-Newton / E-QNewton 迭代）。
- **示例方程（10 年期国债利率，表 1）**：
  `r10 = 0.46 + 1.0·leads_40(r^e) − 0.79·leads_40(x̃^e) + 0.85·lags_1(μ̃_10)`
  R² = 0.98，SEE = 0.32；权重 w_i 对 40 季度预期联邦基金率求和 = 1；−0.79 = 期限溢价逆周期。
- **摩擦**：除金融市场即时均衡外，多数部门受**调整成本**约束（价格方程即「摩擦下的理性行为」范例）。
- **开源**：2022 起可 Python + EViews 双跑；线性版 LINVER 用于大规模 MC 实验降本。

### 已知局限
- 半结构、方程多，**维护重**；个人 / 小系统不可能养。
- RE 假设在「战争 / 市场崩盘」等异常事件短期失效（原文档自承）。
- 非概率化单点预测为主（虽可加不确定性），不如 DSGE 天然出区间。

### 映射到我们 L 哪层
- 对标 **L4 结构 / Agent 层**的「方法论外壳」：我们天璇是 Agent 仿真，可借 FRB/US 的「**期望可切换（VAR vs MC）**」与「**摩擦导致调整滞后**」思想，而非搬 300 方程。

### 后续可借用点
- **期望形成双轨**：我们的推演 agent 也可支持「基于历史 VAR 的朴素预期」与「模型一致理性预期」两种模式切换，做情景对照。
- **摩擦 / 调整成本**：真实传导有滞后，我们仿真不应假设冲击即时到位——在 regime / 冲击传播里加调整成本项。
- **LINVER 思路**：对大规模情景实验用线性近似版提速（我们天璇若跑多情景 MC，可借「线性版降本」）。

## 五、A7 · NY Fed DSGE（纽约联储 DSGE 模型）

### 机制原理
- **定位**：自 2011 预测、2014 起实时公开的中等规模 DSGE；央行中少数**实时公开模型预测**的案例（为留「成败公开记录」）。
- **结构**：封闭经济、代表 agent、理性预期（对平均通胀目标等政策变动作 RE 偏离），medium-scale，加**金融摩擦**（大衰退后预测关键）。
- **谱系**：基于 Smets & Wouters (2007) + Christiano-Eichenbaum-Evans，加 Bernanke et al. (1999) 金融加速器（企业投资受杠杆 / 金融条件约束），Del Negro et al. (2015) SWFF 版；含确定性 + 随机趋势、前瞻指引（anticipated policy shocks, Laseen-Svensson 2011）。
- **贝叶斯估计**：参数用先验 + 数据后验（Schorfheide / Smets-Wouters 路线）。数据含 GDP / GDI、实际消费 / 投资、实际工资、工时、PCE / GDP 平减通胀、FFR、10 年国债收益率、10 年调查通胀预期、Baa−10 年国债利差、TFP、市场对未来 FFR 预期（2008Q4–2015Q2）。
- **隐变量提取**：可抽**自然利率 r\***（「无名义刚性 + Markup 冲击 + 金融摩擦」的反事实利率）——比单看利率水平更准评估政策立场。
- **代码开源**：Julia，GitHub 公开。
- **预测表现**：约等同 Blue Chip / SPF，部分维度优于 FOMC SEP；大衰退后因金融摩擦项表现改善。

### 已知局限
- 强假设（RBC 根源 + 新凯恩斯摩擦），「所有模型都错」——NY Fed 自己强调「非终点，是过程」。
- 封闭经济（虽在开发开放 / 异质 / 非线性版），对全球溢出刻画弱。
- 概率带常很大（模型自认局限）。

### 映射到我们 L 哪层
- 对标 **L4 结构层 + L3 隐变量**：我们可借「**贝叶斯 + 隐变量（自然利率 / 金融条件）**」思想做天璇内部的「反事实利率 / 潜在产出」估计，而非直接套模型。

### 后续可借用点
- **隐变量思想**：我们系统可估计「自然利率 / 潜在产出」类反事实量，作为评估实际政策 / 市场状态的基准（类似天玑抽 latent）。
- **贝叶斯 + 公开成败记录**：我们天玑 verifier 已有 Brier / BSS，可加「模型预测实时公开 + 回溯」纪律（ViEWS 迭代闭环同类）。
- **金融加速器**：在我们冲击传播里，企业部门投资 / 杠杆受金融条件约束的放大机制，可直接增强天璇传导 realism。

## 六、A8 · IMF SIGMA（多国开放经济 DSGE）

### 机制原理
- **定位**：美联储理事会开发的多国（multicountry）开放经济 DSGE；与 GEM（Laxton-Pesenti, IMF 2003）同源，用于全球政策分析。
- **结构（Bundesbank 讲座披露）**：**3 国家块**——US / Europe / ROW（"Asia"，实约 61% 东亚）；参数校准至全球经济。
- **关键特征（区别于封闭 DSGE）**：
  - **信息摩擦**：agent 用简单 **Kalman filter 式学习机制**估计冲击（非完全理性）→ 更贴合实战。
  - **非李嘉图**：部分家庭花光可支配收入（hand-to-mouth）→ 财政乘数更持久（如观测数据）。
  - **金融加速器**：企业家购资本，自有财富或向银行借；银行收存款放贷、监控有成本；企业家付风险溢价（随杠杆升）→ **内生商业周期放大**。
  - **零利率下限（ZLB）显式允许**：少数 DSGE 支持；正油价冲击在 ZLB 下对进口国产出可为正（Bodenstein 2010）。
  - 名义刚性（Calvo 定价、local currency pricing）+ 实际刚性（投资 / 进口调整成本）+ 习惯形成。
- **政策**：货币随利率规则（偏离目标 + 产出缺口），受 ZLB 约束；财政靠扭曲性资本 / 劳动税，可外债融资。
- **用途**：欧元危机「sudden stop」等全球溢出模拟——欧洲 periphery 借贷骤停 → austerity → 欧元暴跌 → 蔓延美亚。

### 已知局限
- 多国块少（仅 3），对真正多极化全球溢出简化。
- 校准依赖，部分参数非纯估计。
- 计算重，个人 NAS 不可行。

### 映射到我们 L 哪层
- 对标 **L4 结构层 + 地缘 / 全球溢出**：我们世界推演系统本质「全球」，SIGMA 的「多国块 + 金融加速器 + ZLB + 全球传染」正是我们**缺的全球传导骨架**。

### 后续可借用点
- **多国块 + 传导矩阵**：我们推演可建模「美 / 欧 / 中 / 新兴」等块，靠贸易 / 金融链路传导冲击——SIGMA 给范式。
- **金融加速器（杠杆 → 风险溢价 → 投资削减）**：作为天璇里「金融冲击放大」的标准模块。
- **ZLB / sudden stop**：极端金融事件（流动性骤停、利率触零）的建模提醒——我们情景库应包含此类尾部。

## 七、A10 · FinBERT + GDELT → 宏观 alpha（金融 NLP 范式）

### 机制原理（一手：Araci 2019 + arXiv 2505.16136）
- **FinBERT 模型本身**（Araci 2019, ProsusAI）：
  - 基底 = **BERT-base（~110M 参数）**，在金融语料（Reuters TRC2）上**继续预训练（domain adaptation / further pre-training）**，再用 **Financial PhraseBank**（Malo et al. 2014，约 2260 句 100% 一致 + 3450 句多数一致标注）**有监督微调**三分类（positive / negative / neutral）。
  - 输出 softmax 三标签概率。HuggingFace `ProsusAI/finbert`，1.7M+ 下载。
  - 优于通用 BERT / GPT-2 LoRA 的原因：encoder-only 双向读全句，分类任务本质更适合。
- **端到端预测流水线**（arXiv 2505.16136, "Interpretable ML for Macro Alpha"）：
  1. **新闻采集**：GDELT 全球 feed，按经济 / 政策关键词过滤。
  2. **FinBERT 打分**：每篇 → 连续极性分（net bullishness）。
  3. **日度情感指数构造（核心特征）**：不止均值，还含 **mean tone（均值语调）/ dispersion（离散度）/ event impact（事件冲击）/ Goldstein score / 文章数 spike / 平滑情感**，及其**滞后与滚动统计**。
  4. **预测模型**：XGBoost（捕非线性）vs Logistic Regression（透明基线），预测 **EUR/USD、USD/JPY、10Y 美债期货 (ZN) 次日收益方向**。
  5. **可解释**：SHAP 分解每预测的特征贡献。
  6. **回测**：5-fold **expanding-window** 交叉验证，OOS 期 ≈ 2017–2025-04，含交易成本。
- **结果**：XGBoost 成本调整后 Sharpe **5.87 (EUR/USD) / 4.65 (USD/JPY) / 4.65 (ZN)**，CAGR FX > 50%、债券 > 22%；胜率 0.72 / 0.72 / 0.66。**SHAP 确认「情感离散度 + 文章冲击」是关键预测特征**（非简单均值）。

### 已知局限（严谨性警示）
- 单一论文结果，**未独立复现广泛验证**；Sharpe 极高需警惕过拟合 / 幸存偏差（作者自承个人研究）。
- 依赖 GDELT 覆盖与关键词质量；采样不稳定、关键词敏感（对标 doc 已警示）。
- 日频方向预测，非结构性因果；监管环境需可解释（故用 SHAP）。
- 仅宏观资产（FX / 利率），未覆盖权益 / 信用 / 商品全谱。

### 映射到我们 L 哪层
- 直接对标 **L5 叙事 / 情绪层 + L2 weak_signal 升级**：我们已用 GDELT weak_signal（日元 87 / 标普 69 / USD 68 密集）但**止于文本计数、衰减严重、无统计检验**。FinBERT 范式正好补「文本 → 可量化情感 → 可解释预测」闭环。

### 后续可借用点
- **GDELT → FinBERT 打分**：我们已抓 GDELT，加 FinBERT（开源、CPU 可跑）打情感分，产「均值 / 离散度 / 事件冲击」三指数——直接升级 weak_signal。
- **SHAP 式归因**：替代我们「笼统金融压力」叙述，做到「哪些新闻 / 情感维度推高 / 压低了 FCI / 汇率预期」，根治 narrative 衰减。
- **特征集借鉴**：mean tone + dispersion + event impact + Goldstein + 滞后 / 滚动——可作为我们 L5 情感因子的标准特征工程模板。
- **expanding-window + 成本调整回测**：我们任何 NLP → 预测信号都应此纪律，防虚假 alpha。

## 八、A11 · FXMacroData（面向 AI Agent 的干净宏观数据层，2026 SaaS）

### 机制原理（一手：官网 + GitHub SDK）
- **定位**：为 systematic FX / quant / AI agent workflow 提供的**实时央行数据层**。创始人前 Macquarie 数据平台负责人。2026 launch，澳洲注册，Google for Startups。
- **核心抽象（正是我们 M7 想要的同构）**：
  - **数据层 ≠ 计算层**：只供「干净官方宏观数据」，不替你算信号。
  - **标准化 schema**：跨币种同一字段名（USD / EUR / GBP / JPY / AUD / CAD / NZD / CHF…），直接转 `pd.DataFrame`、ISO 8601 时间戳，免每源解析。
  - **point-in-time / 无前视偏差**：每条发布带 **`announcement_datetime`**（官方发布时刻），回测时只看得见当时公开数据——兼容 `pandas merge_asof`、event-study。
  - **修订存为独立条目**（非覆盖）。
  - **原生 MCP server**：Claude / Cursor / 任意 MCP host 直连，自然语言问宏观、回官方源数据 + provenance 字段（source_type / source_name / freshness / announcement_datetime）。
- **覆盖**：14 币种、400+ 指标端点、GDP / 通胀 / 就业 / 贸易 / 政策利率 / 国债收益率 / COT / 商品 / FX spot；实时发布 < 50ms（USD 免费、非 USD 需 Pro key；COT / 商品需 key）。
- **集成**：Python SDK（sync / async）、REST、Postman、OpenBB（provider / router / MCP / CLI / Workspace）、HuggingFace Space、Kaggle。

### 已知局限
- **商用 SaaS、非免费**：非 USD 数据 + COT / 商品需付费 key；个人 NAS 研究**不能依赖其作数据源**（我们已有 FRED / 官方源）。
- 覆盖以宏观发布为主，不含我们关心的「市场价格微观结构 / 另类」。
- 2026 新项目，长期可靠性未验证。

### 映射到我们 L 哪层
- 直接对标 **L0 数据层（M7：面向 agent 的干净数据层）**——它是「该抽象长什么样」的**活样板**。

### 后续可借用点（只借设计，不借数据）
- **MCP server 暴露数据层**：我们 macro-scan 也可给天璇 / 外部 agent 暴露一个「整理后数据层」MCP 工具（而非裸 `raw data/` 倾倒），字段带 provenance + point-in-time。
- **announcement_datetime + 修订独立条目**：我们的 L0 落盘格式应内建这两个字段（与 A5 ALFRED 纪律一致）。
- **一致 schema 跨源**：我们 22 源（FRED / SotW / World Bank / BDI…）应归一化到统一字段名，消费方零解析——学 FXMacroData 的「跨源同构」。
