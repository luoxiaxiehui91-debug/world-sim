## 〇、结论先行（给实施 session 的 TL;DR）

1. **A1 NY Fed Nowcasting（DFM）** —— 完整 DFM 对我们过重，**只借其"新闻分解归因"原则**（`news = 实际 − 预期`，`贡献 = news × 载荷`）做日报贡献柱状图（L5 叙事归因）。这是**零新模型、几行代码**的高价值借用，且不依赖 prior.yaml。
2. **A2 Chicago NFCI** —— 最强、最对口"市场价格层"。我们用**已闲置的 FX/加密/商品/BDI + 已在用的 FRED VIX/BAA/T10Y2Y** 造一个 *lite FCI*：先 z-score、再取第一主成分（PCA 是 DFM 的静态特例）或等权，零=常态。NFCI 的"自适应权重随瞬时协方差变化"是**对 macro-scan 固定权重的直接反面教材**——但 lite 版先用数据驱动权重（PCA）即可，不必一步到位 MLE 自适应。
3. **A9 收益率曲线 probit** —— **最廉价**（几行代码）。关键决策：**拉 T10Y3M（DGS10 − DGS3MO）而非用现有 T10Y2Y**，系数统一用 NY Fed 发布版（Estrella-Trubin 2006：α=−0.5333, β=−0.5984）。它是**美国衰退信号**，对全球系统只能当"美国金融 regime 驱动因子"用；非美国家**绝不套同一系数**。须加 **NTFS 近端远期利差**修正 QE 扭曲。

**三者组合 = 阶段 A 财经线点亮**：`L1 FCI（市场紧松强度） + L3 probit（衰退概率）` 双信号，直接补"宏观满血、市场全暗"暗区，且全部不依赖 prior.yaml / 天璇重写。

## 一、A1 · NY Fed Staff Nowcast（动态因子模型 DFM）

### 1.1 它解决什么
实时（周更）跟踪本季 GDP 增速，把杂乱发布的宏观指标消化成"现在经济在哪个位置"。核心是**用 Kalman 滤波把新数据当成"新闻"递归更新预测**。

### 1.2 方法论（一手来源：NY Fed Staff Report 830 / Nowcast 2.0 技术论文，2023）
状态空间模型：

```
量测方程:  y_t = μ + ι·g_t + Λ·f_t + e_t
转移方程:  f_{j,t} = a_j·f_{j,t-1} + u_{j,t}      (潜在因子 AR(1))
           e_{i,t} = ρ_i·e_{i,t-1} + ε_{i,t}      (特异误差 AR(1))
```

- `f_t` = **5 个潜在因子**（Nowcast 2.0 明确用 5 个：global / nominal / soft / labor + 疫情临时因子）；`g_t` = 长期增长趋势（随机游走，吸收 2000s 后增速下移）。
- 贝叶斯估计 → 每个点估计带 **50/68/80% 概率区间**；参数每季度重估，每周五更新。
- **混频 + ragged edge**：缺失观测在量测更新中直接跳过；季度目标用月度因子时序约束链接（MIDAS 替代方案无法做新闻分解）。

**最关键可借鉴点 —— 新闻分解（News Decomposition）**：
```
news_i      = actual_i − model_forecast_i        # 经济意外
contribution_i = news_i × weight_i              # weight = 该指标的信息含量×时效性（因子载荷）
nowcast 变动 = Σ contribution_i                  # 每周新闻的加权平均
```
即"哪条数据把指数推高/压低多少"**可追溯、可下钻**。Liberty Street Economics 明确："the contribution of new data... News is defined as the difference between released data and model predictions. The weights account for the information content as well as the timeliness."

> 重要数学事实（SR 830）：当 `a_j=0, ρ_i=0, 各序列同方差` 时，DFM 退化为**静态因子模型 = 主成分分析（PCA）**。所以 PCA 是 DFM 的特例——我们 lite 版用 PCA 在理论上站得住。

### 1.3 数据需求
数十个宏观序列（就业/工业产出/销售/收入/调查/利率…），混频周/月/季。我们**当前不备 GDP 目标**，直接照搬 DFM 成本过高。

### 1.4 强项 / 局限
- ✅ 概率区间 + 可下钻归因，信任度高。
- ❌ 工程重（状态空间 + Kalman + 混频）；无 GDP 目标则"nowcast 什么"要重新定义。
- ❌ 对我们性价比低——但**新闻分解原则可独立提取**。

### 1.5 映射到我们 L0–L5
- **L2（宏观 nowcasting/regime）**：完整 DFM → 阶段 C 深化（见 §4.4 蓝图），非阶段 A。
- **L5（叙事归因）**：**直接借用新闻分解**。当 L1 FCI 或某宏观指标跳变时，用 `贡献 = 意外 × 载荷` 拆解"是谁驱动"，进日报，根治 weak_signal→narrative 衰减（local doc 第六节④、问题清单七.6）。

### 1.6 借用实现草图（L5 新闻分解，零新模型）
```python
# 输入: 一组已 z-score 的市场/宏观序列 daily_z[(date, series, z)]
# 思路: 用 EWMA 预测下期 z_hat, 实际 z 到达即算 news, 用该序列对 FCI 的载荷(β) 计贡献
def news_decomposition(series_z, fci_loadings):
    contrib = {}
    for s in series_z:
        z_hat = ewma_forecast(series_z[s])          # 模型预期
        news  = series_z[s].latest - z_hat           # 经济意外
        contrib[s] = news * fci_loadings[s]          # 贡献 = 意外 × 载荷
    return sorted(contrib.items(), key=lambda x: -abs(x[1]))
# 输出: 贡献柱状图 → 日报 "本周 FCI 上行 +0.3，其中 VIX +0.18 / BDI +0.09 ..."
```
载荷 `fci_loadings[s]` 直接取 §二 NFCI-lite 的 PCA 第一主成分载荷，天然复用，零额外估计。

## 二、A2 · Chicago Fed NFCI（国家金融条件指数）

### 2.1 它解决什么
周更、覆盖全美金融条件（货币/债/股/传统+影子银行）的**单一综合指数**，零=历史均值，符号比绝对值重要：正=偏紧、负=偏松。

### 2.2 方法论（一手来源：Brave & Butters；Chicago Fed NFCI 当前数据页 + 技术报告）
- **单因子 DFM + AR(1) 潜因子 + 逐序列特异误差**；每月重估参数，权重**每周**应用到指数更新。
- **自适应权重 = MLE 估计、且随序列间瞬时协方差变化**（这是灵魂）：信用危机时利差自动主导、杠杆危机时中介流量主导，**无需分析师先验选信号**。这正是 macro-scan 用固定 prior.yaml/硬编码权重权重的反面教材。
- **归一化**：全样本（自 1971）零均值、单位标准差；新观测加入时历史**向后一致修订**（旧值最多微调 <0.02σ）——保证 55 年跨期可比。
- **105 指标**：46 周 + 33 月 + 26 季，分三类：
  - **risk（+权）**：波动/融资风险，**同步指标**，拐点最先动（波动率重定价最快）。
  - **credit（−权）**：借贷条件/贷款标准，**滞后指标**。
  - **leverage（−权）**：债务/权益（含影子银行），**领先指标**。
  - 三分指数各自 mean0 std1，**贡献相加 = 总指数**（可下钻"谁在推"）。
- **ANFCI（周期调整）**：剔除 GDP/就业/通胀能解释的部分 → "给定经济现状，金融条件偏紧/松"，用于货币政策规则与压力测试。

### 2.3 数据需求
105 个机构级金融序列（我们无）。但**我们可以用自己已闲置的市场序列造 lite 版**——ViEWS 教训"少而强的几个变量 ≈ 复杂模型"支持精简。

### 2.4 强项 / 局限
- ✅ 数据驱动权重（不自欺）、向后一致修订、可下钻、周频高响。
- ❌ 105 序列门槛高；我们复刻不了全部 → lite 版用 ~10–15 序列替代。
- ⚠️ 读值陷阱：当**水平+趋势**双看，非二元；周自相关 >0.95，按 **4–8 周滚动窗口**读，单周跳动多为测量边角。

### 2.5 映射到我们 L0–L5
- **L1 市场价格 FCI（M1）**：最直接对口。我们已有"死数据"= 最佳原料。

### 2.6 借用实现草图（L1 FCI-lite，用现有闲置数据）
**输入（全部已在 /workspace/data/，当日新鲜、零新源）：**
| 类别 | 我们的序列 | 文件 |
|---|---|---|
| 波动 risk | VIX（FRED 已在用）、BTC/ETH 最大回撤（CoinGecko） | `crypto_history.jsonl` |
| 波动 risk | 主要货币对实现波动（USD/JPY, EUR/USD…） | `fx_history.jsonl` |
| 信用 credit | BAA−国债利差（FRED 已在用） | FRED fetcher |
| 贸易/杠杆 | BDI 航运压力 | `bdi.json` |
| 商品 | 原油/黄金/铜异动 | `commodity_yahoo.json` |
| 叙事 | GDELT weak_signal 金融强度（日元87/标普69） | weak_signal |

```python
# 1) 每个序列做 z-score (相对各自 1y 滚动均值/标准差), 统一符号: 压力=正
z = {s: (x[s] - roll_mean(s, 252)) / roll_std(s, 252) for s in series}
z_signed = {s: -z[s] if s in NEG_MEANING else z[s] for s}   # 如"股指上涨"在 NFCI 语义为负(宽松)
# 2) 静态因子 = 第一主成分 (PCA, DFM 静态特例) → FCI, 零=样本均值
from sklearn.decomposition import PCA
X = pd.DataFrame(z_signed).dropna()
FCI = PCA(n_components=1).fit_transform(X)   # 第一主成分即综合金融条件
# 3) 载荷 → 三分(风险/信用/杠杆)可类比: 按序列归类后分别取子 PCA 或等权
# 4) 输出: FCI 日/周更, 零=常态; 同时用 §一 新闻分解下钻贡献
```
- **进阶（M1 完整化）**：把静态 PCA 升级为 Brave-Butters 式**自适应权重**（权重 = 瞬时协方差的函数），信用危机自动让利差主导。阶段 A 先用 PCA，阶段 C 再上 MLE 自适应。
- **校验**：FCI 应与已知压力期（2020-03、2022 英国养老金、2023 SVB）同向；不一致即数据/z-sign 错。

## 三、A9 · 收益率曲线衰退 probit（极简早期预警）

### 3.1 它解决什么
用**一个输入**（期限利差）预测未来 12 个月美国衰退概率。样本外 AUC 0.85–0.89，是宏观里最稳的单指标。

### 3.2 方法论（一手来源：Estrella & Mishkin 1996/1998；Estrella-Trubin 2006）
```
P(衰退_{t+12} = 1 | spread_t) = Φ(α + β · spread_t)
```
- `spread_t` = **T10Y3M**（10 年国债 − 3 月国库券，月度均值，单位 %）。3 月端贴政策利率，捕捉"当下政策 vs 长期预期"落差，预测记录最干净。
- `Φ` = 标准正态 CDF；`β < 0`（利差越倒挂，概率越高）。

**校准系数（多版，须标准化）：**
| 来源 | α | β | 样本 | 备注 |
|---|---|---|---|---|
| Estrella-Mishkin (1998) | −0.5333 | −0.6629 | 1959–1995 | 经典原版，pseudo-R²≈0.30，样本内 AUC≈0.92 |
| **Estrella-Trubin (2006, NY Fed 发布版)** | **−0.5333** | **−0.5984** | 1959–2009 | **建议采用**（与 NY Fed 公布序列一致） |
| 某 1990–2024 复现 | −0.8493 | −0.4954 | 1990–2024 | 样本不同，系数漂移大，仅供参照 |

> ⚠️ **修正本地对标文档**：local doc 写 α≈−0.55, β≈−0.72，与官方发布版不一致。实施时**统一用 NY Fed 发布版 (−0.5333, −0.5984)**，避免"纸面系数"与 NY Fed 公布序列对不上。

- **阈值经验**：30% 阈值自 1969 来每次衰退前都突破（1985 后除 1998 近失无假阳性）。100bp 倒挂 ≈ 52–57% 概率（视校准）。

### 3.3 数据需求（关键决策）
- **首选 T10Y3M**：FRED 有 `DGS10`（10 年）+ `DGS3MO`（3 月），相减即得。我们 FRED fetcher 已就绪，**加两个 series 即可**，零新源。
- 我们现有 `T10Y2Y`（10 年−2 年）已进 regime_detector，但**非模型首选利差**——2 年端不如 3 月端贴政策利率干净。建议：probit 用 T10Y3M；T10Y2Y 保留给现有 regime。
- 频率：月度即可（原模型月频），但我们可以用周度 T10Y3M 近似周更信号。

### 3.4 强项 / 致命局限（决定我们怎么用）
- ✅ 极简、稳、可解释、AUC 高。
- ❌ **QE 扭曲**：2008 后期限溢价被压（Adrian-Crump-Moench），长端机械走低→Bauer-Rudebusch(2020) 证明控制期限溢价后，原始 3m10y 边际预测力**减半**。修正：**NTFS（近端远期利差）= 6 季度远期 − 3 月**（Engstrom-Sharpe），避开长端失真。HKMA 拆近段(2y−3m)+远段(10y−2y)提精度。
- ❌ **仅美国**：NBER 衰退定义美国特有。非美（日/中/印）套同系数**系统性高估**；本地重估（Moneta 2005 欧元 / Chinn-Kucko 2015 OECD / Hasse-Lajaunie 2022 新兴）斜率更平、AUC 更低。最佳实践：**美国校准只作跨国排序（rank），不作独立概率**。
- ❌ **解倒挂陷阱**：历史规律是衰退发生在**曲线"解倒挂"之后**（中位滞后 ~5 月），不是倒挂时。正利差≠安全，滞后效应已埋雷。

### 3.5 映射到我们 L0–L5
- **L3 早期预警（M3）**：直接产出"美国 12 月衰退概率"。
- 对全球系统定位：**美国衰退 = 全球金融 regime 驱动因子**（我们 GRV 的金融维/慢变量的上游），而非"某国衰退概率"。

### 3.6 借用实现草图（L3 probit）
```python
import numpy as np
from scipy.stats import norm

ALPHA, BETA = -0.5333, -0.5984          # NY Fed 发布版 (Estrella-Trubin 2006)
def recession_prob_12m(t10y3m_pct: float) -> float:
    return norm.cdf(ALPHA + BETA * t10y3m_pct)   # t10y3m 单位: %

# 数据: 拉 FRED DGS10, DGS3MO → spread = DGS10 - DGS3MO (周/月频)
# 阈值: prob >= 0.30 → 触发 L3 早期预警, 进日报 + 喂 GRV 金融维/慢变量
# 非美: 不套同系数, 仅用美国 prob 作为全球金融压力排序锚
# QE 修正(可选进阶): 同时算 NTFS = FRED 6q fwd spread - DGS3MO, 双信号交叉验证
```

## 四、三者组合 = 阶段 A 财经线点亮方案

### 4.1 数据流（全用现有文件，零新源、不依赖 prior.yaml）
```
[闲置死数据]                [已在用 FRED]               [产出]
fx_history.jsonl     ┐
crypto_history.jsonl ├─► L1 FCI-lite (PCA) ──► 市场紧松强度(FCI, 零=常态)
commodity_yahoo.json┤                          └─► 新闻分解下钻(§一) ─► L5 叙事归因
bdi.json            ┘
                      VIX / BAA / T10Y2Y ──────┘
DGS10 + DGS3MO ─────► L3 probit ─────────────► 美国12月衰退概率(阈值30%)

        L1 FCI + L3 probit  =  "市场强度 + 衰退概率" 双信号
                  │
                  └─► 接 GRV 金融维(补 11 维缺的市场维度, P1) / 慢变量 / 日报
```
- **与现有 regime_detector 衔接**：regime_detector 已用 VIX/BAA/T10Y2Y 出三态；L1 FCI 复用同样输入但升级为**连续 z-score 综合**而非三态硬切，信息更密。不冲突、可并存验证。
- **与 GRV 衔接**：GRV 11 维无市场维度（P1），L1 FCI 可作为第 12 维候选喂入——但属"先不修"范围外的增强，实施 session 评估。

### 4.2 校验纪律（呼应铁律）
- **vintage / point-in-time（M6）**：FCI/probit 历史回测必须用**当时可得数据**，不能拿修订后 FRED 回测（ALFRED 纪律）。我们 fetcher 当前覆盖写，阶段 A 先出实时值，M6 留阶段 B。
- **概率区间（M8）**：FCI 出 z-score 即含"偏离几 sigma"区间语义；probit 是点概率，可补充"倒挂加深速率"作不确定度代理。
- **防衰减（M4）**：weak_signal→narrative 衰减，用新闻分解贡献柱状图替代笼统"金融压力"描述。

### 4.3 风险与不做的事
- 不照搬 105 序列 NFCI（我们无）；lite 版用 ~10–15 序列，接受精度折让。
- 不把 probit 当"全球衰退概率"；明确它是美国 signal、全球 regime 驱动。
- 不加新数据源（用户定调"不加新源、不修 prior"）；T10Y3M 用已有 FRED 通道拉。

### 4.4 实施顺序（与本地对标 §4.4 一致）
```
阶段 A（独立、不依赖 P0）: L1 FCI-lite(§二) → L3 probit(§三) → L5 新闻分解(§一)
阶段 B（依赖 prior 修复）: vintage(M6) → 天璇消费 L1-L3 → 全局概率区间(M8)
阶段 C（深化）          : L2 完整 DFM(§一) → NFCI 自适应权重(MLE) → NTFS 修正 → GDELT 三步+PCA(M4)
```
