## 二、版权分析

### 2.1 AGPL-3.0 约束

| 场景 | 是否触发开源义务 | 说明 |
|---|---|---|
| 不修改 + 仅个人使用 | ❌ 不触发 | NAS 自用不构成"对外提供网络服务" |
| 修改 + 仅个人使用 | ❌ 不触发 | AGPL 只在网络服务对外时触发 |
| 修改 + 对外提供服务 | ✅ 触发 | 必须开源修改后的完整源码 |
| 完全重写（clean room） | ❌ 不受约束 | 不使用原代码，从零实现 |

### 2.2 什么受版权保护，什么不受保护

| 元素 | 是否受版权保护 | 说明 |
|---|---|---|
| jarvis.html 的 JS/CSS 源码 | ✅ 受保护 | 不能直接复制 |
| globe.gl / d3 / gsap 库 | ❌ 不受保护 | MIT/ISC 开源许可，自由使用 |
| API 端点和数据格式 | ❌ 不受保护 | 事实，非创作 |
| CSS 视觉风格（玻璃拟态、扫描线、配色） | ❌ 不受保护 | 设计语言/风格不受版权保护 |
| 函数名、变量名 | ⚠️ 灰色 | 建议改命名 |
| 架构模式（3D地球+扁平地图双模式+boot动画） | ❌ 不受保护 | 思想/方法不受版权保护 |
| 数据结构（JSON 格式定义） | ❌ 不受保护 | 事实格式 |

### 2.3 复现策略

**不复制 jarvis.html 的任何一行代码，但使用相同的开源库 + 相似的视觉风格。**

- CSS：自己写，参考相同的视觉设计语言（玻璃拟态 + 青绿色调 + 扫描线 + boot 动画）
- JS：全部从零实现，用 globe.gl / d3 / gsap 的公开 API 实现相同功能
- 数据绑定：绑定天枢 + 天璇 + 天玑的输出 JSON，不绑定 Crucix 的数据
- HTML 骨架：几行 div 容器，无版权风险

## 三、技术方案

### 3.1 架构

```
开阳 WebUI（前端纯静态）
  │
  ├── 数据来源（三选一）
  │   ├── 模式 A：SSE 实时推送（从开阳后端）
  │   ├── 模式 B：fetch /api/data 轮询（从开阳后端）
  │   └── 模式 C：内嵌 JSON 快照（静态文件，离线可看）
  │
  ├── 渲染层
  │   ├── CSS：玻璃拟态 + 青绿色调 + 扫描线 + boot 动画
  │   ├── 3D 地球：globe.gl（MIT）
  │   ├── 扁平地图：d3.js + topojson（ISC/BSD）
  │   └── 过渡动画：gsap（免费许可）
  │
  └── 数据绑定（替换为世界推演系统数据）
      ├── 天枢观测数据（GRV、FRED、空气、热源、辐射、SDR、太空）
      ├── 天璇推演数据（假设推演报告、置信度、传导路径）
      ├── 天玑验证数据（预测校验结果、实际结果对比）
      └── macro-sim 仿真数据（Monte Carlo 路径、聚类结果）
```

### 6.3 Monte Carlo 路径叠加

macro-sim 输出最多 3 条主路径（占比 ≥5%），每条路径包含 12 个 agent 的因果链。

在 3D 地球上用弧线连接路径上的关键地理点：

```javascript
// 3 条主路径，颜色从绿到红
const simPaths = data.sim.paths.map((path, i) => {
  const colors = [
    ['rgba(100,255,150,0.6)', 'rgba(100,255,150,0.1)'],  // 乐观路径
    ['rgba(255,215,0,0.6)', 'rgba(255,215,0,0.1)'],       // 中性路径
    ['rgba(255,100,100,0.6)', 'rgba(255,100,100,0.1)'],   // 悲观路径
  ][i];
  
  return path.agentChain.map((agent, j) => ({
    startLat: agent.lat, startLng: agent.lon,
    endLat: path.agentChain[j+1]?.lat || agent.lat,
    endLng: path.agentChain[j+1]?.lon || agent.lon,
    color: colors,
    stroke: 0.5 + path.probability * 2,
    label: `${path.name}: ${agent.name} → ${path.agentChain[j+1]?.name || '终端'}`,
  }));
}).flat();

globe.arcsData([...flightArcs, ...simPaths]);
```

## 十、性能优化

### 10.1 低性能模式

- 3D 地球优先级标记点（zoom 远时只显示 priority=1）

- 移动端 / 弱设备默认启动扁平模式
- globe.gl `pauseAnimation()` / `resumeAnimation()` 切换时管理

### 10.3 数据加载

- 首次加载：内嵌 JSON 快照（即时显示）
- 后续：SSE 实时推送（无轮询）
- 容器内数据目录热挂载，无需重建
