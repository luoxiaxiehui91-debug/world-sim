> 对应原文档：`13_世界推演系统_新架构设计_20260729.md`

## 一、对原方案的修改清单

**[天璇 B+A 概率生成] 调整上限公式改为有界自适应**
- 原设计：平坦 ±15% 固定调整上限，对所有基础概率一视同仁
- 修改后：max_adj = min(0.20, B_prob, 1 - B_prob)；actual_adj = clip(LLM_suggested_adj, -max_adj, +max_adj)；final_prob = B_prob + actual_adj。B=50% 时允许 ±20%，B=5% 时只允许 ±5%，±20% 为绝对硬上限
- 修改原因：平坦 ±15% 对不同基础概率行为不一致——B=5% 时允许 A 推到 20% 相当于 4 倍变化，严重违背边际调整语义。自适应公式保证小概率事件受到更严格约束，中等概率给更宽空间

**[天璇 B+A] 历史样本不足时的分级处理**
- 原设计：样本不足时简单截断或直接使用 LLM 估计，无分级降级机制
- 修改后：四级置信度分档：HIGH（≥10 条）标准公式；LOW（5-9 条）max_adj 翻倍，标注 LOW_SAMPLE；VERY_LOW（2-4 条）B 只提供方向约束不参与数值公式，A 主导，标注 LLM_PRIMARY；NOVEL（0-1 条或相似度 <0.35）B 数值丢弃，A 强制产出区间，标注 NOVEL
- 修改原因：样本不足时 B 的统计意义很弱，但直接丢弃 B 会使 LLM 失去任何基准约束。分级处理允许系统在不同数据质量下优雅降级，而非在某个阈值处硬切换

**[天璇 B+A] 全无先例情景的 NOVEL 模式**
- 原设计：未定义全无先例场景的处理方式，历史先例无论相似度高低均作为数值锚点使用
- 修改后：B 检索时强制返回最佳匹配相似度分数；相似度 <0.35 触发 NOVEL 模式；B 数值输出丢弃，但作为排除参考传给 A；A 强制产出区间而非点估计（low/high/basis/key_uncertainties）；推理链存入 reasoning_trace 表。相似度阈值 0.35 为初始值，积累 50 条 NOVEL 预测后重新校准
- 修改原因：弱相似历史先例作为数值锚点会引入锚定偏误，比不提供先验更糟。NOVEL 模式显式承认 LLM 在做纯判断，要求区间输出以体现不确定性

**[天玑] 校准验证指标体系**
- 原设计：单一 Brier Score 验证，无最低数据量门槛，outcome_definition 可事后填写
- 修改后：并列追踪三指标：Brier Score + Brier Skill Score（BSS = 1 - BS/BS_climatology）+ 锐度（预测落在 (30%, 70%) 以外的比例，目标 >40%）；最低门槛每类别 ≥20 个已验证预测才计算有效统计数字；predictions 表强制要求 outcome_definition 字段在预测时填写，不允许后续修改
- 修改原因：单一 Brier Score 存在被保守预测游戏的风险。BSS 衡量是否超越朴素基准，锐度防止系统退化为无判断力的基础概率复读机

**[天枢 观测层] 叙事预处理设计改为锚定 GRV 维度**
- 原设计：叙事预处理基于独立"主题"分类，与 GRV 11 个维度是两套独立体系
- 修改后：建立 11 个叙事桶与 GRV 维度一一对应；每篇文章打主/次标签，最多 2 个维度；22 个数据源到维度的映射写入 source_dimension_map.yaml；文章归类用来源标签+关键词规则（覆盖约 80%），不调 LLM；被引用时只计入主维度 token 预算
- 修改原因：原设计的"主题"与 GRV 维度是两套独立体系，触发天璇后无法直接对应取回叙事，导致需要全文检索或引入向量数据库。直接锚定 GRV 维度后，检索退化为 SQLite 索引查询，无需额外基础设施

**[天枢 观测层] 触发机制新增叙事密度路径**
- 原设计：仅有数值偏离触发（路径 A）
- 修改后：双路径机制——路径 A 保持原有数值触发；新增路径 B 叙事密度监测：天枢每日对各维度新文章数做滑动窗口 Z-score 检测（Z >2.0 标记为叙事密度突增），在下次路径 A 激活时给该维度 1.5 倍 token 权重（3000 tokens 而非 2000 tokens）。路径 B 不单独触发天璇。冷启动前 30 天退化为简单阈值（当日数量 > 过去 7 天均值×1.5）
- 修改原因：数值数据有 12-24 小时延迟，突发地缘事件可能在叙事层已有大量信号但 GRV 数值尚未偏离，导致系统性忽略。路径 B 通过加权而非直接触发，在解决盲区的同时避免叙事幻觉驾驶推演

**[天璇 推演引擎] 叙事 context 双硬上限**
- 原设计：无明确 token 上限，多维度同时触发时 context 长度无控制
- 修改后：单维度叙事配额 2000 tokens（路径 B 标记维度 3000 tokens）；多维度触发时叙事总上限 8000 tokens，超出时各维度按比例压缩；总 prompt 构成目标 ≤32k tokens（叙事 8k + 状态向量 3k + 历史参考路径 8k + system prompt 3k + 输出预留 10k）；截断规则按 staleness_score × source_diversity_bonus 排序取 top-N，排序在 SQLite 层预计算完成
- 修改原因：无上限设计在多维度同时触发时必然导致 context 爆炸

**[天枢 观测层] 叙事陈旧性时间衰减与去重**
- 原设计：无时间权重机制，叙事内容无去重处理，旧新信息并列输入
- 修改后：staleness_score = exp(-hours_age / τ)，普通新闻 τ=72 小时，结构性事件（官方声明/央行声明）τ=240 小时；摄取阶段用 sentence-transformers（all-MiniLM-L6-v2）做本地 embedding，相似度 >0.85 过滤同维度内重复；同 source_type 在同维度内配额限制最多保留 3 条最新文章
- 修改原因：无时间权重会将矛盾的新旧信息并列喂给 LLM。连续时间衰减比二元截断更鲁棒；embedding 去重解决标题 hash 方案的双向错误

**[天璇 推演引擎] 军事结构性数据重新定位为背景卡片**
- 原设计：SIPRI/NTI 等军事结构性数据计划作为 GRV 维度参与日频处理
- 修改后：军事结构性数据明确定位为情景前提背景卡片，不参与 GRV 量化状态向量，不日频处理。天璇推演被激活时读取 /data/static/military_backdrop.md 注入推演初始化 system prompt 一次，后续迭代轮次不重复注入。由开发者在年度数据更新后手动刷新该文件
- 修改原因：SIPRI/NTI 是年度/季度更新的结构性数据，与天璇事件触发的月级推演时间粒度不匹配。强行作为日频 GRV 维度增加摄取复杂度却没有推演质量增益

**[天枢 观测层] 非英语叙事源处理拆分为两个独立步骤**
- 原设计：非英语叙事源翻译后统一处理，叙事方向信号与内容注入混合，无差别降权
- 修改后：步骤 A（叙事方向信号提取）在原文中统计关键词词频/强度变化趋势，不经翻译，不降权，保留原始信号强度；步骤 B（叙事内容注入天璇 prompt）经 Ollama qwen2.5-7b 翻译后强制标注 [src:ru, via:qwen2.5-7b, bias:state_media, conf:medium]，天璇 system prompt 加入降权指令（字面事实陈述证据权重降低 30%，epistemic_uncertainty=high）。Ollama 不可用时降级：保留原文标记 [untranslated]，不阻塞主流程
- 修改原因：对非英语国家官方媒体，叙事方向信号本身是有价值的信号，无差别降权会丢失这个信号

**[权重矩阵] 冷启动机制引入强制 prior 填写与冻结期**
- 原设计：新增信息源使用统一比例初始权重，无冻结期，天玑可立即生成权重更新建议
- 修改后：新增信息源强制填写 prior.yaml，逐预测目标类型手动填写初始权重（范围 0.05-0.4，禁止超过 0.4），附填写理由，经玉衡审批。添加后自动进入 3 个月冻结期，冻结期内天玑不生成权重更新建议。解冻条件：冻结期满且积累至少 10 条该信源相关可验证预测
- 修改原因：统一比例无法反映新信息源在不同预测目标类型上的差异化贡献。冻结期保证玉衡的实质审批基于初步客观数据而非空白主观判断

**[天璇 推演引擎] 量化传导输出置信度差异化上限**
- 原设计：所有预测目标类型使用统一置信度上限，无 epistemic uncertainty 标注
- 修改后：经济/金融类预测置信度上限 =0.8，地缘/军事类预测置信度上限 =0.6。输出层强制标注 epistemic uncertainty 级别（low/medium/high），军事类默认 high
- 修改原因：军事预测的信号链天然更长，系统不能假装二手 RSS 数据能提供与经济指标同等精度的预测

**[天璇 推演引擎] 慢变量存储格式改为连续分数**
- 原设计：三个慢变量使用离散状态存储和计算
- 修改后：三个慢变量全部存储为连续分数——UCRI（中美博弈强度）[0,1] 五分量等权复合；IRP（通胀体制概率）P(高通胀) [0,1] 基于 FRED 四指标逻辑回归；GCI（地缘格局指数）[0,1] 三分量加权复合。离散标签仅用于显示层，不参与任何计算逻辑
- 修改原因：离散三状态设计存在悬崖效应——阈值附近微小变化触发级联切换，在天璇输出中制造虚假的不连续信号

**[天璇 推演引擎] 偏离量化方法改为经验百分位**
- 原设计：使用 z 分数衡量快变量偏离程度
- 修改后：偏离度定义为经验百分位排名，用 scipy.stats.percentileofscore(historical_values, today_value, kind='rank') 计算。触发阈值：百分位 <10 或 >90 触发天璇推演；百分位 <5 或 >95 同时发送 ntfy 极端预警。每个慢变量状态历史样本 <24 个月时退化到全量历史分布并附加警告标志
- 修改原因：经济和地缘政治数据为厚尾分布，z 分数会系统性低估尾部偏离的显著性，导致漏报重要触发信号

**[天玑 校验层] 新增慢变量三层验证模块**
- 原设计：只验证输出层预测，慢变量本身无质量控制机制
- 修改后：第一层面效度回归测试——每变量预定义 6 个历史锚点（共 18 个），修改慢变量逻辑后必须全部通过；第二层构建效度月度监控——自动计算与外部基准指标的相关系数，持续 3 个月偏离预期方向则生成审查警报；第三层预测效度（12 个月积累后启动）——回测条件化 vs 不条件化 Brier 分差异，delta_Brier <0.02 进入降权候选队列
- 修改原因：慢变量是整个推演链路的最上游，其错误会向下游无声传播

**[天璇 推演引擎] 转型期自动扩宽置信区间**
- 原设计：未定义慢变量处于临界区间时的特殊处理，转型期与稳态期使用相同推演参数
- 修改后：当任意慢变量连续分数处于转型区间（IRP ∈ [0.3, 0.7]；UCRI ∈ [0.35, 0.65]；GCI ∈ [0.35, 0.65]）时，天璇自动将该次推演所有预测的置信区间扩大 1.5 倍，并在输出中标注"慢变量处于转型期，预测不确定度高"
- 修改原因：转型期是预测最不可靠的阶段，明确的扩宽规则将不确定度显式化

**[玉衡 审批层] 建议展示信息框架标准化**
- 原设计：未定义标准化判断包，建议展示信息不完整
- 修改后：每条建议展示五元素标准化判断包：① N 期 Brier 均值+标准差+相对排名；② 该信源在所有预测目标上的历史一致性分布表；③ 初始权重设置的人工批注；④ 受影响预测目标列表；⑤ 降权安全检查（硬性）——若降权导致任何预测目标有效信源数 <2，默认标记为"危险建议"，必须用户主动二次确认才能接受
- 修改原因：Brier 分单独不足以支撑判断，用户需要知道降权的后果和历史依据

**[天玑 校验层] 触发条件 N 值与阈值改为相对排名**
- 原设计：N 值未明确定义，触发条件使用绝对 Brier 阈值
- 修改后：N=8（写入配置文件，系统累计预测数 >100 条后建议手动调为 5）；触发条件改为相对排名：连续 N=8 次预测中，该信源 Brier 均值 < 同类预测目标全体信源 Brier 均值的 80%，才触发建议
- 修改原因：绝对阈值在宏观事件密度不均匀的情况下会产生系统性误触发或漏触发；相对排名自动适应宏观环境变化

**[玉衡 审批层] 权重调整增加代码级双层硬约束**
- 原设计：仅有人工审批，无代码级硬性边界约束
- 修改后：代码层 clip 强制执行双层约束：① 变化速率约束：单次调整不超过当前权重值的 ±25%；② 绝对值范围约束：所有信源权重必须在 [0.05, 5.0] 之间。两者同时生效，取更严的那个。同一信源同一方向连续调整 ≥4 次时，强制填写一行备注
- 修改原因：无硬性约束时连续接受建议可能导致权重无界漂移

**[天玑 校验层] 新增月度权重矩阵健康度检测机制**
- 原设计：无主动长期漂移检测，权重矩阵退化只能被动发现
- 修改后：新增月度自动健康度检查，检测三项指标：① 预测目标覆盖健康度（有效信源数 <2 触发警告）；② 权重 Herfindahl 集中度（超过初始值 3 倍触发警告）；③ 全局信源参与度（有效信源占比 <30% 触发警告）。2 种及以上警告同时出现时，玉衡展示初始矩阵 vs 当前矩阵可视化对比，提供局部重置/全部重置/忽略三个选项
- 修改原因：原设计没有主动检测机制，长期运行后权重矩阵可能在无人察觉的情况下退化为孤立结构

## 二、P1 概率生成逻辑 — 最终方案

### 调整幅度上限

弃用平坦 ±15%，改为有界自适应公式：

```
max_adj = min(0.20, B_prob, 1 - B_prob)
actual_adj = clip(LLM_suggested_adj, -max_adj, +max_adj)
final_prob = B_prob + actual_adj
```

B=50% 时允许 ±20%；B=5% 或 B=95% 时仅允许 ±5%。平坦上限在 B=5% 时允许 A 将概率推至 20%，相当于 4 倍变化，违反边际调整语义。依据 Kahneman 概率权重函数，人类判断在极端概率区间误差最大，自适应公式确保此处约束最严，中等概率区间给更宽空间。

### 历史样本不足处理

四级置信度分档，B 的参与方式随样本量递减：

| 等级 | 条件 | B 的角色 | 输出标注 |
|------|------|----------|----------|
| HIGH | ≥10 条 | 统计先验，标准公式 | 无 |
| LOW | 5–9 条 | 弱先验，max_adj 翻倍 | LOW_SAMPLE |
| VERY_LOW | 2–4 条 | 仅提供方向约束，A 主导数值，须与 B 方向一致 | LLM_PRIMARY |
| NOVEL | 0–1 条或相似度 <0.35 | 数值丢弃，作为排除参考传给 A | NOVEL |

### 全无先例情景

B 检索时强制返回最佳匹配相似度分数（0~1）。当 max_similarity < 0.35 时触发 NOVEL 模式：B 数值结果丢弃，匹配结果以"排除参考"形式传给 A（说明当前情景与历史最近似案例的关键差异），避免锚定偏误的同时不浪费 B 的检索信息。A 必须产出区间而非点估计：`{ low, high, basis, key_uncertainties }`，prompt 中明确禁止单一数字。推理链存入 reasoning_trace 表。相似度阈值 0.35 为初始值，积累 50 条 NOVEL 预测完成首轮验证后重新校准。

### 校准验证指标

必须同时追踪三项，缺一不可：

- **Brier Score（BS）**：总体校准质量，单独看可被保守预测游戏。
- **Brier Skill Score（BSS = 1 - BS/BS_climatology）**：与朴素基准（直接用历史频率）对比。BSS > 0 表示系统有增量价值；BSS ≤ 0 表示不如不用，是最关键的单一指标。
- **锐度**：预测落在 (30%, 70%) 以外的比例，目标保持 >40%。锐度持续下降说明系统退化为基础概率复读机，即使 BS 好看也是退化。

最低门槛：每个分析类别至少 20 个已验证预测才能计算有统计效力的 BSS。地缘预测（月级验证周期）需 12–18 个月积累；系统运行前 6 个月只记录不评判。predictions 表强制要求 `outcome_definition` 字段在预测时填写，不允许事后修改。

### 核心数据结构

```sql
predictions(
  id, created_at, scenario_id,
  target_description TEXT NOT NULL,
  outcome_definition TEXT NOT NULL,   -- 预测时填写，不可修改
  time_horizon TEXT,
  b_prob REAL, b_sample_count INT, b_max_similarity REAL,
  llm_adj REAL, final_prob REAL,
  prob_low REAL, prob_high REAL,      -- NOVEL 模式用，其余 NULL
  confidence_tier TEXT,               -- HIGH/LOW/VERY_LOW/NOVEL
  outcome_value REAL, verified_at TIMESTAMP, verified_by TEXT
)
```

reasoning_trace 表与 predictions 一对一关联，存储 A 的推理链。

### 新发现问题（P1）

1. **历史分布非平稳性**：B 须对历史事件加指数衰减时间权重，或设置可配置滚动时间窗口（初始值建议 15 年）。
2. **预测粒度与可验证性**：地缘预测须单独设计操作化定义规范，结果定义必须基于可观测事件标志。
3. **冷启动参数策略**：前 3 个月纯记录不调参，3–12 个月使用文献默认参数，12 个月后才允许天玑提出参数调整建议。
4. **区间传播到下游**：NOVEL 模式输出区间时，下游（叙事输出、权重矩阵更新、天玑 Brier 计算）需明确策略——取中点、取下界还是传播完整区间，须独立设计。

## 三、P2 叙事预处理设计 — 最终方案

### 聚合维度

叙事桶直接锚定 GRV 11 个维度，与数值层共享同一套语义锚点，避免两套体系独立演化导致触发时无法对应取回。

具体方案：建立 11 个叙事桶，与 GRV 维度一一对应（可扩展至 15 个以内，不允许无限增殖）。地理区域（台海、欧洲、中东等）作为二级索引字段，不独立分桶。22 个数据源到 GRV 维度的映射写入 `source_dimension_map.yaml`，不硬编码，独立维护；天枢启动时执行配置校验，确保所有 active 数据源均有映射条目，遗漏映射不允许静默失败。

每篇文章打主标签（`primary_dimension`）和次标签（`secondary_dimension`，可为 NULL），最多 2 个维度。被引用时只计入主维度的 token 预算，次标签仅作相关性补充标记，不占用 context。

文章归类采用来源标签 + 关键词规则做第一层分配（覆盖约 80% 的明确文章），常规摄取阶段不调用 LLM。

### 相关性判断

采用双路径机制：

**路径 A（主要路径，数值触发）：** GRV 维度偏离触发天璇 → 按 `(primary_dimension = 触发维度, timestamp DESC)` 做 SQLite 索引查询 → 按 `staleness_score × source_diversity_bonus` 排序 → 取 top-N 至填满 token 配额。无需向量数据库，无需全文检索，`idx_dim_time` 复合索引即可满足。

**路径 B（辅助路径，叙事密度监测）：** 天枢每日统计各维度新文章数量，用滑动窗口 Z-score 检测突增（Z > 2.0 则标记该维度）。路径 B **不单独触发天璇**，防止叙事幻觉驱动推演；在下次路径 A 激活时，被标记维度获得 1.5 倍 token 权重（3000 tokens 而非 2000 tokens）。

冷启动处理：前 30 天历史数据不足时，Z-score 退化为简单阈值（当日数量 > 过去 7 天均值 × 1.5）。

### Context 长度控制

双硬上限 + 排序截断，总 prompt 目标 ≤ 32k tokens：

| 配额项 | 值 |
|---|---|
| 单维度叙事配额（普通） | 2000 tokens |
| 单维度叙事配额（路径 B 标记维度） | 3000 tokens |
| 多维度触发时叙事总上限 | 8000 tokens |

总 prompt 构成目标：叙事层 8k + 状态向量 3k + 历史参考路径 8k + system prompt 3k + 输出预留 10k = 32k tokens。

截断规则：按 `score = exp(-hours_age/τ) × source_diversity_bonus` 排序取 top-N 至填满配额；排序在 SQLite 层完成（`staleness_score` 预计算存储），不在 Python 层做全表加载。

### 叙事信号陈旧性处理

**时间衰减：** `staleness_score = exp(-hours_age / τ)`

- 普通新闻：τ = 72 小时（3 天半衰，一周后 score < 0.06，实际不会被选中）
- 结构性事件（央行声明、国家级政策、战略协议）：τ = 240 小时（10 天半衰）
- 结构性事件识别：`source_type` 为 `official_statement` 或 `central_bank` 加关键词启发式规则，不调 LLM

**去重机制：** 摄取阶段使用 sentence-transformers（all-MiniLM-L6-v2，384 维）做本地 embedding，相似度 > 0.85 则过滤同维度内重复文章。CPU 批处理约 100–300 条/日，耗时 3–10 秒，无 API 成本。同来源类别在同维度内配额限制为最多 3 条最新文章，防止单一渠道淹没其他来源。模型文件挂载至固定 Docker volume（如 `/data/models/`），避免容器重建重新下载。

**矛盾信息处理：** 对于真正并存的矛盾信号，让 LLM 看到矛盾本身具有信息价值——矛盾信号是市场不确定性的真实反映，不应在预处理阶段人为消除。

### 核心数据结构

```sql
CREATE TABLE narrative_chunks (
    id INTEGER PRIMARY KEY,
    source_id TEXT NOT NULL,
    source_type TEXT NOT NULL,
    primary_dimension TEXT NOT NULL,
    secondary_dimension TEXT,
    timestamp DATETIME NOT NULL,
    content TEXT NOT NULL,
    token_count INTEGER,
    embedding BLOB,
    staleness_tau INTEGER DEFAULT 72,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX idx_dim_time ON narrative_chunks(primary_dimension, timestamp DESC);

CREATE TABLE narrative_density_flags (
    dimension TEXT PRIMARY KEY,
    flagged_at DATETIME,
    z_score REAL,
    consumed INTEGER DEFAULT 0
);
```

**结构性慢数据（SIPRI/NTI）：** 定位为"情景前提背景卡片"——不参与 GRV 量化状态向量，不触发日频处理。天璇推演被激活时读取 `/data/static/military_backdrop.md` 注入推演初始化 system prompt 一次，后续迭代轮次不重复注入（避免 token 累积）。

**实时叙事军事 RSS：** 按信源质量分级：第一手官方声明（五角大楼/国防部官网 RSS）> 专业防务分析（War on the Rocks）> 综合新闻媒体。叙事快照标注信源级别，天璇对不同级别赋予不同叙事证据权重。

新增信息源禁止使用统一比例，强制在 prior.yaml 中逐预测目标类型手动填写初始权重（范围 0.05–0.4，禁止超过 0.4），附填写理由，经玉衡审批后生效。

- 供应链指标（GSCPI/FBX）对台海冲突 0.1、对通胀 0.4、对金融危机 0.35、对供应链压力 0.5
- 多语种叙事媒体各列比同类英语媒体降低 0.1 作为起点

添加后自动进入 3 个月冻结期，冻结期内天玑不生成权重更新建议。解冻条件：冻结期满且积累至少 10 条该信源相关的可验证预测。解冻后由天玑基于 Brier 分提出调整建议，均须经玉衡审批方可生效。

## 五、P4 慢变量测量 — 最终方案

### 操作性定义与计算方法

**中美博弈强度指数（UCRI）**，取值 [0,1]，月频，五分量等权复合：

1. 美对华有效关税率（Peterson Institute PIIE 月度关税追踪）
2. BIS 实体清单月度净增条目数（取增量而非全量）
3. 外交事件对抗指数（复用天枢现有新闻 NLP 信号，按极性加权，不新建数据管道）
4. 中美双边贸易占中国 GDP 比重趋势（UN Comtrade + World Bank，季度数据月度线性插值）
5. 科技管制强度月度评分（手工评估 0–4 分：0 = 无新措施 / 2 = 新限制公告 / 4 = 重大管制扩大）

`UCRI = 0.2 × 各分量归一化值`，冷启动等权，权重经玉衡审批后可调整。

**通胀体制概率（IRP）**，取值 [0.0, 1.0]，表示 P(高通胀体制)。计算方法为逻辑回归分类器，特征向量四维：`US_CPI_12m_slope`、`US_PCE_core_level`、`Fed_funds_rate_neutral_gap`、`US_5y5y_breakeven_rate`，全部来自 FRED API（fredapi 库，免费）。历史人工标注标签：1973–1975 = 1，1979–1983 = 1，2021–2023 = 1，其余代表性时段 = 0。模型仅 4 个参数，每 12 个月重新训练一次。

**地缘格局指数（GCI）**，取值 [0,1]，月频，三分量加权复合：

1. 大国直接对抗事件计数（ACLED API，P5 国家，月度汇总）
2. 核威慑态势评分（手工评估每月 -1/0/+1：-1 = 缓和 / 0 = 稳定 / +1 = 升温）
3. 大国多边合作指数（UN 安理会投票通过率 + G20 公报通过情况，与 GCI 负相关）

`GCI = 0.4 × 对抗事件分数 + 0.35 × 核态势分数 + 0.25 × (1 - 多边合作分数)`

UCRI 的科技管制分数和 GCI 的核威慑态势评分均为月度手工评估节点，这是有意设计，确保维护者每月强制阅读关键动态；若当月未输入，系统使用上月值并在日报中标注 `[手工评估待更新]`。

### 连续值与离散状态的选择

**存储层和计算层全程使用连续分数，离散标签仅出现在显示层。**

离散三状态设计存在悬崖效应：P = 0.29 与 P = 0.31 之间的微小差异会触发参考样本集的完整切换，在天璇输出中制造虚假的不连续信号。

显示层阈值（仅用于日志和人类可读报告）：IRP > 0.7 标注"高通胀期"；IRP < 0.3 标注"低通胀期"；[0.3, 0.7] 标注"转型期"。

**转型期处理规则：** 当任意慢变量连续分数处于转型区间（IRP ∈ [0.3, 0.7]；UCRI ∈ [0.35, 0.65]；GCI ∈ [0.35, 0.65]）时，天璇自动将该次推演所有预测的置信区间扩大 1.5 倍，并在输出中标注慢变量处于转型期、预测不确定度高，不强行给出窄置信区间。

### 慢变量验证机制

三层验证策略，按工程成本递增排列，冷启动仅需完成第一层：

**第一层：面效度回归测试**（上线前，约半天工作量）。为每个慢变量预定义 6 个历史锚点事件作为自动测试用例，格式为 `(date, variable, expected_direction, event_description)`，共 18 个锚点。每次修改慢变量计算逻辑后自动运行，不全部通过则阻断更新。

**第二层：构建效度月度监控**（系统运行后持续）。每月自动计算慢变量与外部基准指标的相关系数：UCRI 应与外资在华直接投资月环比变化负相关（期望 |r| > 0.3）；IRP 应与 TIPS 实际利率呈强负相关（期望 |r| > 0.5）；GCI 应与全球能源价格波动率正相关。持续 3 个月偏离预期方向时，天玑生成审查警报。

**第三层：预测效度**（12 个月积累后启动）。通过天玑回测条件化 vs. 不条件化对快变量预测的 Brier 分改善量。若 delta_Brier < 0.02，进入降权候选队列，经玉衡审批决定是否调整权重。

### 偏离量化方法

**使用经验百分位排名，不使用 z 分数，不假设任何分布形态。**

```python
scipy.stats.percentileofscore(historical_values, today_value, kind='rank')
```

返回值 0–100，表示今日快变量值在给定慢变量状态下的历史条件分布中所处的百分位位置。

**触发阈值：** 百分位 < 10 或 > 90 触发天璇推演；百分位 < 5 或 > 95 同时发送 ntfy 极端预警；百分位 [10, 90] 正常，不触发。若触发过于频繁，经玉衡审批可收紧至 5th/95th。

每个状态的历史样本要求 >= 24 个月；不足时退化到全量历史分布并附加警告标志，不阻断触发逻辑。

## 六、P5 玉衡判断标准 — 最终方案

### 辅助判断信息（玉衡标准化判断包）

每条降权/升权建议必须附带以下 5 个元素，缺一不可：

**① Brier 趋势（统计层）：** 展示该信源连续 N 期的 Brier 均值与标准差。标准差大意味着预测质量不稳定，均值不可信。同时展示该信源均值相对同类预测目标全体信源均值的排名百分位，自动过滤系统整体在特殊时期集体变准的运气效应。

**② 历史一致性分布：** 该信源在所有预测目标上的 Brier 分布列表，使用户能区分"全面差"与"只在某类目标上差"两种性质截然不同的情况。

**③ 初始设置依据：** 系统初始化时必须填写的人工批注，说明当初给此权重的理由。降权时展示，让用户判断当前操作是否在推翻有依据的初始假设。

**④ 受影响预测目标列表：** 降权后，哪些预测目标的有效信源数（权重 > 0.1 的信源数）会低于安全阈值 2。

**⑤ 降权安全检查（硬性）：** 若接受降权会导致任意预测目标有效信源数跌破 2，系统自动将该建议标记为"危险建议"，必须用户主动二次确认方可执行，不可直接点接受。

### N 值设定

**推荐值：N = 8，写入配置文件，不自适应。**

理由：宏观预测验证周期为月度，8 个月覆盖跨季度多样性，包含足够的宏观环境变化。N < 5 时统计功效极低，易误触发；N > 12 时结构性问题需积累近一年才能被发现，学习过慢。

**触发条件使用相对排名，而非绝对阈值：** 连续 N = 8 次预测中，该信源 Brier 均值 < 同期全体信源 Brier 均值的 80%，触发降权建议。

当系统累计预测数超过 100 条时，建议人工将 N 调至 5，在配置文件修改一个数字即可。

### 权重调整幅度限制

**双层约束，两者同时生效，取更严的那个，在代码层 clip 强制执行：**

- **层 1 — 变化速率约束：** 单次调整不超过当前权重值的 ±25%
- **层 2 — 绝对值范围约束：** 所有信源权重必须在 [0.05, 5.0] 之间（0.05 保证信源永远保留最小贡献；5.0 防止单一信源过度主导）

**连续方向审计：** 同一信源同一方向连续调整达到 4 次时，玉衡强制要求用户填写一行备注（不阻止操作，但强制记录），形成可供复盘的审计轨迹。

不设累计总量上限：[0.05, 5.0] 硬约束已足够防止极端值，全局累计上限会阻碍合理的结构性重新校准。

### 长期漂移检测

检测目标为**权重矩阵的内部结构健康度**，而非偏离初始值的程度（初始值是人工先验，偏离它可能是系统学习到了真实规律）。

**月度自动检测三项指标（Python 脚本，运行成本近零）：**

- **指标 A — 预测目标覆盖健康度：** 任意目标有效信源数（权重 > 0.1 的信源数）< 2，触发"孤立目标警告"
- **指标 B — 权重集中度（Herfindahl 指数）：** 若某目标集中度超过初始基线值的 3 倍，触发"过度集中警告"。初始基线须在系统启动时一次性计算并存储
- **指标 C — 全局信源参与度：** 有效信源数占总信源数的比例低于 30% 时触发"信源萎缩警告"

**纠正机制：**
- 1 种警告：ntfy 推送，用户自行判断
- 2 种及以上警告同时出现：ntfy 推送"结构健康度异常"，玉衡展示当前权重矩阵与初始矩阵的可视化对比，提供三个选项：局部重置、全部重置、忽略并记录原因。任何重置操作均须经玉衡审批，重置原因和日期存入权重更新日志

## 七、新发现的待解决问题

N1: **天玑表结构缺失关键字段**（P3、P5）：需新增 `prediction_target_type` 字段，以支持按预测类型分组计算 Brier 分；同时需确认三张表是否支持跨预测目标 JOIN 查询，否则玉衡历史一致性判断和降权影响计算均无法落地。

N2: **概率区间下游消费逻辑未定义**（P1）：NOVEL 模式输出区间 [8%, 35%]，但天璇权重矩阵更新与天玑 Brier 计算均按点概率设计。区间传播时取中点、取下界还是传播完整区间，直接影响两个模块的计算结果，需独立设计决策规则。

N3: **预测粒度与可验证性不匹配**（P1、P2）：地缘预测与量化预测共用同一验证流程，但验证周期和结果定义差异极大，需为地缘预测单独制定操作化定义规范；叙事配额（2000 tokens/维度）对预测质量的实际影响亦未经实证，建议一并纳入天玑校验框架进行对照评估。

N4: **多子系统冷启动集群**（P1、P2、P4）：三处独立冷启动问题：① BSS 校准需 20 个已验证预测（约 6–12 个月）；② 叙事密度 Z-score 需至少 30 天历史；③ 慢变量状态细分后部分（状态、快变量）组合历史样本不足 24 个月。三处均需定义退化规则，当前设计均未覆盖。

N5: **GCI 全球汇总导致信号相互抵消**（P4）：台海紧张与中东缓和叠加可能使 GCI 中性而不触发任何条件分布切换，但两地事件对不同快变量的传导路径完全独立。是否需将 GCI 拆分为区域性慢变量，需单独论证，影响整体维护成本。

N6: **历史相似度检索缺乏时间加权**（P1）：B 模块对 1990 年代与近期历史一视同仁，而当前制度环境已根本改变，远期数据对现时预测参考价值极低。需引入指数衰减权重或 15 年滚动窗口（建议设为可配置参数）。

N7: **月度手工评估节点流程设计缺失**（P4、P5）：UCRI 科技管制分和 GCI 核威慑评分的输入界面、维护者未按时提交时的降级处理，以及 Herfindahl 基线快照的系统初始化步骤，三项均未规划。缺失将导致慢变量模块和长期漂移检测无法正常运行。

N8: **数据源与慢变量映射关系未盘点**（P4）：现有 22 个数据源中哪些可直接复用于慢变量计算、哪些需新建独立拉取任务，尚未明确。这一映射决定慢变量模块的实际工程成本，应在实施前优先完成盘点。

N9: **YAML 配置映射缺乏完整性校验**（P2）：22 个数据源到 11 个 GRV 维度的映射需人工维护，数据源变动时遗漏映射将静默失败。需在天枢启动时加配置校验步骤，确保所有 active 数据源均有对应映射条目。

N10: **Ollama 翻译服务单点依赖缺乏监控告警**（P3）：降级逻辑已设计，但降级触发时无告警通知，日频运行中可能长期静默失败而不被发现。需在天枢运行日志中加 Ollama 可用性监控。

N11: **叙事方向信号关键词表维护机制未定义**（P3）：俄语/阿语关键词表的初始填写者、更新触发条件和领域审核流程均未规划。冷启动时关键词表为空将导致叙事方向信号提取完全失效，且无任何告警。

N12: **工程细节未决三项**（P2、P3、P5）：① sentence-transformers 模型文件约 90MB，NAS 挂载场景需明确 Docker volume 挂载策略，避免每次重启重新下载；② Freightos FBX 访问权限未确认，应在第二批实施前先行验证，不可行则彻底放弃；③ 初始权重矩阵需人工填写批注，应在格式设计时预留 notes 字段并排期完成。
