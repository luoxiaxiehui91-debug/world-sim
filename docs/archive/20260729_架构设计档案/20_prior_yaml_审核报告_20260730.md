### 🔴 P1 — YAML 语法错误（影响 16 个信源）

**位置**：USGS 及之后所有信源（第 315 行起）  
**现象**：多个 `key: value` 写在同一行，以空格分隔：

```yaml
# 当前（错误）
"1.1": 0.05  "1.2": 0.05  "1.3": 0.05
```

**原因**：YAML block mapping 不支持同行多键值对；这是 flow mapping `{...}` 专属语法。PyYAML / ruamel.yaml 均会在 parse 阶段报错，或将后续内容错误解析为字符串值。

**影响范围**：USGS、EIA、Yahoo_FX、Yahoo_Commodities、Crypto、News_Feeds、GDACS、AkShare_China、OpenSky、HDX、Crucix、Defense_RSS、SIPRI_Static、GSCPI、AkShare_World、BDI_Stooq（共 16 个信源，约 360 行）

**修复方案（任选其一）**：

```yaml
# 方案A：block 格式，每行一条（推荐，与 FRED/GPR 格式一致）
"1.1": 0.05
"1.2": 0.05
"1.3": 0.05

# 方案B：flow mapping（紧凑合法）
{"1.1": 0.05, "1.2": 0.05, "1.3": 0.05}
```

## 三、语义质量问题（建议修复，不阻断运行）

### 🟡 Q1 — USGS `"5.5"` 权重 0.20：因果路径有歧义

**问题**：USGS 能检测地震造成的物理破坏，但无法识别蓄意攻击；若系统将 USGS 用于预测 5.5，实际覆盖的只是"自然灾害导致能源设施损毁"这一子集，而非"攻击"本义。  
**建议**：权重降至 0.10，或在 notes 中明确限定为"地震触发的能源设施损毁，非蓄意攻击"。

**当前注释**："制裁→加密规避"  
**问题**：制裁压力通常推动资金流入加密（用于规避），而非触发崩溃；制裁数据库新增条目与加密市场崩溃没有直接正向预测关系。  
**建议**：权重降至 0.05，与其他无直接关联子类型保持一致。

### 🟡 Q3 — GSCPI `"9.1"` / `"9.2"` 权重 0.30：领先性存疑

**子类型 9.1/9.2**：美国通胀反弹 / 全球滞胀  
**问题**：GSCPI 是月频综合指数，发布时已滞后 4–6 周，更接近 coincident indicator 而非 leading indicator。对通胀预测的领先性低于 FRED（CPI/PCE 直接数据）和 Yahoo_Commodities（能源价格实时）。  
**建议**：权重降至 0.20–0.25，或在系统内将 GSCPI 标注为 `lag_type: coincident`，由推理层相应折扣其时间权重。
