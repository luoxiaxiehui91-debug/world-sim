## 一、调研对象与架构范式

| 类别 | 代表项目 | 核心架构 | 输出形态 |
|---|---|---|---|
| 实时 Nowcasting | NY Fed Staff Nowcast 2.0、Atlanta GDPNow | 动态因子模型(DFM) + 混频 + 新闻分解 | 周更 GDP 增速 + 概率带 |
| 综合金融条件/压力指数 | OFR FSI、Chicago NFCI、St.Louis FSI、KC FSI、Goldman/Bloomberg FCI | 加权求和 **或** 主成分(PCA) | 日/周/月 单值指数(零=常态) |
| 央行结构模型 | FRB/US、SIGMA、NY Fed DSGE | ~300 方程 + 贝叶斯估计 | 预测+政策反事实+隐变量提取 |
| 单因子早期预警 | 收益率曲线衰退 probit | 期限利差(10y-3m) → 衰退概率 | 概率值(AUC 0.85-0.89) |
| 数据平台纪律 | FRED/ALFRED、Macrobond、FactSet、Bloomberg、FXMacroData | 数据层与计算层分离 + vintage/point-in-time | 可信时序供给 |
| 另类数据/NLP | GDELT→IP/CPI、FinBERT→FX/利率 | 关键词过滤→NN分类→聚合→PCA/SHAP | 情绪指数/可解释预测 |

### 1.1 实时 Nowcasting（NY Fed Nowcast / GDPNow）
- **动态因子模型**：`y_t = μ + ι·g_t + Λ·f_t + e_t`，假设 N 个观测序列由少量（NY Fed 取 **5 个**）潜在公共因子驱动，其余为特异误差。贝叶斯估计 → 报告**概率区间**。
- **混频 + 非平衡到达**：允许不同频率、不同到达时间的数据流入，模拟专业分析师的实时监测。
- **新闻分解（News Decomposition）**：每条新发布相对模型预期的"意外"×该指标权重 = 对 nowcast 的贡献，**逐条归因**并可视化（哪个发布把指数推高/压低了多少）。
- **开源透明**：NY Fed 已公开 MATLAB/Julia 代码（GitHub），强调"输出只取决于进模型的序列与设定，无人为判断"。
- **vintage 意识**：实时历史数据取自 St.Louis **ALFRED**（带修订版本），避免用"已修订数据"回测"当时决策"。

### 1.2 综合金融条件/压力指数（FCI/FSI）
两种通用构造法：
- **加权求和法**：Bloomberg FCI = 货币/债券/股票 三子指数等权（共 10 变量）；Goldman FCI 权重≈短端利率35%/股票35%/美元15%/信用利差10%/长端5%；Citi 权重来自对" coincident index "的简化式预测方程。
- **主成分法**：Chicago **NFCI** 由 **105 个**金融市场变量 → 动态因子模型 → z-score（零=历史均值，正=收紧/负=宽松）；St.Louis FSI 由 **18 个**周度序列（7 利率+6 利差+5 其他）构造。
- **OFR FSI**（最贴近"全球系统性压力"）：**33 个**市场变量，分 5 类——信用(credit)/股票估值(equity valuation)/融资(funding)/安全资产(safe assets)/波动(volatility)；统计算法捕捉变量**协同运动**→权重；按**美国/其他发达/新兴**三区域分解贡献；日度。
- **稳健化（Fed 2013 Composite FCI）**：选表现最好的若干 FCI → 取**第一主成分**再聚合，降低单指数过拟合风险。
- 关键语义：**零=常态**，符号比绝对值重要；不同指数可叠加互补（如 NFCI 看市场定价、SLOOS 看银行授信）。

### 1.3 央行结构模型（DSGE：FRB/US、SIGMA、NY Fed DSGE）
- FRB/US 约 **300 方程**（核心随机方程约 50），含显式理性预期；SIGMA 为多国开放经济 DSGE；NY Fed DSGE 为中等规模、含金融摩擦、贝叶斯估计。
- 用途：**预测 + 政策分析 + 反事实 + 隐变量提取**（如自然利率）。
- 概率化输出且**自带不确定性区间**（"模型至少知道自己的部分局限"）。
- 哲学："**所有模型都是错的，但有些有用**"——实践中**模型集成**（FRB/US + DSGE + VAR 并用），而非单模型依赖。

### 1.4 单因子早期预警（收益率曲线衰退 probit）
- 经典式：`Pr(衰退) = Φ(β0 + β1·期限利差)`，解释变量取 **10y-3m** 期限利差（Estrella & Mishkin 验证最强）。
- 样本外判别力 **AUC 0.85–0.89**（远超随机 0.5）。
- 可扩展：加入公司债利差、超额债券溢价(EBP)、CAPE；并**修正 QE 对期限溢价的扭曲**（ECB 2020 指出标准模型会被央行购债压低的长端利率误导）。
- 优点：**极简、可解释、样本外稳健**——是"廉价早期预警"的标杆。

### 1.5 数据平台纪律（FRED/ALFRED、Macrobond、FactSet、Bloomberg）
- **数据与计算分离**：FRED 明确定位"数据分发平台，非分析/预测系统"——这一定位是宏观系统的基石。
- **vintage / point-in-time / 修订追踪**：ALFRED 解决"用已修订数据回测"的方法论错误；Macrobond 内置历史 vintage 与修订追踪，支持合规回测。
- **结构化元数据**：Macrobond 覆盖 **3亿+ 序列 / 320+ 国家 / 2500+ 源**，SA/NSA 区分、频率/单位标注。
- **可编程供给**：Web API + SQL 连接器 + AI Data Feed（许可内环境内用生成式 AI）。
- **FXMacroData 启示**：专为 **AI Agent 工作流**提供"干净官方宏观数据层"（CPI→EUR/USD、 payrolls→USD/JPY）——这与 macro-scan 本质（AI 推演系统）高度同构，值得借鉴"面向 agent 的干净数据层"思路。

### 1.6 另类数据 / 新闻 NLP（GDELT→宏观、FinBERT→FX/利率）
- **GDELT GKG**（全球新闻，15 分钟更新，含主题/情绪/位置）→ 宏观预测标准流水线：**关键词过滤 → NN(如 Bi-LSTM)分类 → 按国家/频率聚合**；对成百情绪分做 **PCA** 降维取前三主成分喂入自回归模型，显著提升 IP/CPI 预测（10 国中 8–9 国优于基准）。
- **FinBERT**（金融域 BERT）→ 日度情绪指数（均值语气/离散度/事件冲击）→ XGBoost 预测 EUR/USD、USD/JPY、10Y 美债次日收益，**样本外 Sharpe 达 5.87/4.65/4.65**；**SHAP** 确认"情绪离散度+文章冲击"是关键特征（可解释）。
- **基线控制变量启示**：GDELT→IP 模型直接用 **BDI + 原油**作控制变量——**macro-scan 恰好已抓 BDI/商品却闲置**，正好可复用。
- **严谨性警示**（文献共识）：情绪数据需严格统计检验；存在**采样不稳定、关键词选择敏感**等陷阱，非灵丹。

## 二、跨项目共性架构（可复用范式提炼）

1. **数据层 ≠ 计算层**：先有可信、带修订追踪的时序供给，再有模型。macro-scan 的 fetcher 目前**覆盖写、无 vintage**，违背此纪律。
2. **综合指数两法通用**：加权求和（可解释、需先验权重）vs 主成分（数据驱动、降维）。OFR/NFCI 实证——**变量协同运动是核心信号**。
3. **"新闻分解"归因**：每条发布对指数的贡献可量化、可展示。这是叙事层该有的形态（macro-scan 目前只有"笼统金融压力"）。
4. **概率化 + 不确定性区间**：NY Fed / DSGE 均给区间，拒绝单点"算命"。
5. **模型集成而非单依赖**：FRB 同时跑 FRB/US + DSGE + VAR。"天枢(统计MC) + 天璇(Agent仿真)"本就是这一思想，但**两层间契约断在 prior.yaml**。
6. **可解释性闭环**：SHAP / 归因让"为什么"可追溯——直接对应监管/审计需求，也对应 macro-scan 的"用户质疑推演依据"。

## 三、macro-scan 财经线现状（2026-07-30 容器实况核验）

**活着的（满血）：**
- **FRED**：VIX/BAA/T10Y2Y → `regime_detector`(normal/stress/crisis) + `scorer` + `slow_variables` + 报告 live。**这正是 FCI/早期预警的原材料**。
- **GPR**：GRV + backfill + 慢变量。
- **GDELT 金融 NLP**：weak_signal 中"日元87/标普69/USD68"密集——但来源是新闻文本，**非价格文件**。

**休眠/死数据（已抓零消费）：**
| 源 | 落盘状态 | 是否进 GRV/报告/天璇契约 |
|---|---|---|
| Yahoo FX | 当日新鲜(`fx_history`) | ❌ 零消费 |
| CoinGecko/Binance/Kraken 加密 | 当日新鲜 | ❌ 零消费 |
| Yahoo 商品 | 当日新鲜 | 仅被 EIA fetcher 间接读 1 跳 |
| Stooq BDI 航运 | 当日新鲜 | 仅 commodity fetcher 交叉读 |
| AkShare 全球宏观 | 当日新鲜 | ❌ 零消费 |

**结构性缺口：**
- **GRV 11 维无市场价格维度**：仅 `japan_monetary`(48.5)/`energy_grid`(59.7)/`sanctions`(82.7) 沾金融边，无 FX/加密/商品/BDI 维度。
- **prior.yaml 语法损坏（P0）**：规划中的 `Yahoo_FX→6.5 汇率危机 / Crypto→8.4 加密崩溃` 映射因 `yaml.safe_load` 崩溃而无法触发 → **08-01 月度管道必炸**，市场价格层那条规划接线彻底堵死。
- **报告 `run_macro_analysis.py` 既不读价格文件也不 live 重拉** FX/加密/商品（grep 实证为空）。
- **news_export / daily_digest（→天璇契约）**：grep 全部财经价格词 → **全空**。
- **weak_signal → narrative 严重衰减**：金融词密密麻麻（日元87），到终稿叙事只剩"日元套利+FOMC"三两句。
- **无 vintage/修订纪律**：fetcher 覆盖写，无法做诚实回测。

> 一句话：**宏观财经满血（FRED/GPR/新闻话语），市场价格全暗（FX/加密/商品/BDI 死数据），GRV 无市场维度，prior.yaml 损坏致规划接线失效，新闻财经信号到终稿衰减严重。**

## 五、建议的财经架构蓝图（结合 macro-scan 实际，待决策未实施）

```
L0 数据层（纪律）         L1 市场价格 FCI        L2 宏观 nowcasting/regime   L3 早期预警          L4 结构/Agent(天璇)      L5 叙事归因
─────────────────        ────────────────       ───────────────────────     ──────────────       ───────────────────       ──────────────
· FX/加密/商品/BDI        · 由 L0 死数据构造      · 扩展 regime_detector      · 期限利差 probit     · 经修复 prior.yaml      · "新闻分解"式：
  分源存储+修订追踪         FCI(PCA或加权)          为 DFM，含市场因子            (10y-3m→衰退概率)     消费 L1-L3 输出          "日元套利平仓 +X 至 FCI"
· ALFRED 式 vintage       · 零=常态，日/周更       · 概率带 + 新闻分解          · FCI 阈值触发         · Agent 传播价格冲击      · SHAP 式特征归因
· 面向 agent 的干净       · 区域/类型分解           · 接 slow_variables         · + GRV 金融维         · 输出回天枢契约          · 杜绝"笼统金融压力"
  数据层(FXMacroData 思路)                                                                                 
```

**逐层说明：**
- **L0 数据层纪律**：把 FX/加密/商品/BDI 改为分源、带修订时间戳的存储（不覆盖写）；建立 point-in-time 快照，支撑诚实回测。参考 FRED/ALFRED、Macrobond。
- **L1 市场价格 FCI（点亮死数据）**：用已抓的 FX 波动率、加密回撤、商品异动、BDI、叠加上 FRED 信用利差/VIX，构造综合 FCI（PCA 或加权求和，零=常态，日/周更），按 OFR 思路做区域/类型分解。**这一步直接把"死数据"转为"活信号"**。
- **L2 宏观 nowcasting/regime 增强**：将 regime_detector 升级为含市场因子的动态因子模型，输出概率带 + 新闻分解归因（哪条发布推动指数）。
- **L3 早期预警**：把已进 regime 的 T10Y2Y 做成**收益率曲线衰退 probit**（10y-3m，AUC 0.85-0.89），叠加 FCI 阈值与 GRV 金融维度，输出衰退/通胀概率。
- **L4 结构/Agent 层（天璇）**：修复 prior.yaml（P0）后，天璇 Agent 仿真消费 L1-L3 输出，传播价格冲击；契约文件回写天枢。
- **L5 叙事归因**：采用"新闻分解"+"SHAP 式归因"，让日报写清"日元套利平仓对 FCI 贡献 +X"，而非笼统的"系统性金融压力"，根治当前衰减。
