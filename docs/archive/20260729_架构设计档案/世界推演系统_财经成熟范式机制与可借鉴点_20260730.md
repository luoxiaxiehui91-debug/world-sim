## 一、五个成熟范式的具体机制（How they do it）

### 1.1 NY Fed 动态因子 Nowcasting（GDP 实时追踪）
- **状态空间形式**：
  - 量测方程：`X_t = μ + Λ F_t + ε_t`（N 个观测序列 = 少量潜在因子 F_t 的线性组合 + 特异误差）
  - 状态方程：`F_t = Σ A_i F_{t−i} + u_t`（因子服从 VAR(p) 动态）
  - **卡尔曼滤波**给出最优 nowcast；PCA 先取因子初值，再用 EM 精炼载荷、处理缺失、产出概率带。
- **5 个潜在因子**：global / nominal（价格口径）/ soft（调查）/ labor / 及疫情期间临时激活的 COVID 因子。每序列先 load 全局因子，再 load 所属子组因子。
- **混频 + ragged edge（数据非平衡到达）**：缺失观测在量测更新中直接跳过；季度目标用"3 个月度因子值的时序聚合约束"链接到月度面板。**MIDAS** 是替代方案，但缺点是无法做新闻分解。
- **新闻分解（News Decomposition，最关键的可借鉴点）**：
  `news_i = 实际发布_i − 模型预期_i`（"意外"）
  对 nowcast 的贡献 = `news_i × weight_i`（权重来自因子载荷）
  → 按类别（劳动/贸易/调查…）聚合，可视化成每周贡献柱状图。**让"哪条数据把指数推高/压低了多少"可追溯**。
- **贝叶斯 → 概率带**：50/68/80% 概率带；开源（MATLAB/Julia on GitHub）；原则"输出只取决于进模型的序列与设定，无人为判断"。
- **vintage 纪律**：实时历史取自 **ALFRED**（带修订版本），避免用"已修订数据"回测"当时决策"。

### 1.2 Chicago NFCI（综合金融条件指数，最贴近"市场价格 FCI"）
- **105 个指标**（46 周 + 33 月 + 26 季）覆盖 risk / credit / leverage 三类金融市场变量。
- **单因子 DFM（Brave & Butters）**：从 105 序列提取一个共同因子。每个指标先"相对样本均值、除以样本标准差"→ **z-score（均值 0、标准差 1，样本自 1971）**。
- **自适应权重**：权重由**最大似然估计**，且**随时间变化 = 序列间瞬时协方差的函数**。→ 信用危机时自动让利差主导、杠杆危机时让中介流量主导，**无需分析师先验选信号**。这正是 macro-scan 用"固定 prior.yaml 权重"的反面教材。
- **三分指数**：risk（波动/融资风险，+权）、credit（借贷条件，−权）、leverage（债/股，−权，但非金融杠杆 +权，对应"金融加速器"）。各自标准化 mean0 std1。
- **ANFCI（周期调整版）**：剔除经济活动和通胀能解释的变动（CFNAI 三月均、失业缺口、PCE、KR-CRB 商品）→ 回答"给定经济现状，金融条件偏紧还是偏松"。
- **解读阈值**：零=历史均值；**+0.5 以上历史上领先每次 NBER 衰退 6–12 个月**；+2.0=重大压力（1971 来仅 6 次）。负=宽松。

### 1.3 收益率曲线衰退 probit（极简早期预警）
- **模型**：`P(衰退_{t+12}=1 | T10Y3M_t) = Φ(α + β·T10Y3M_t)`，probit（标准正态 CDF）。
- **NY Fed 校准**（1959–2024）：α≈−0.55，β≈−0.72；**100bp 倒挂 ≈ 57% 概率**。MLE 估计，年度重估，系数极稳（1996 来漂移 <10%）。
- **判别力 AUC 0.85–0.89**；1968 来 8 次衰退标中 7 次，TPR >87%。
- **陷阱与修正**：QE 压低期限溢价（ACM 估计 −50~−100bp）会误导 → 可用 Engstrom-Sharpe **近端远期利差**（6 季远期 − 3 月）替代；HKMA 把利差拆成近段(2y−3m)+远段(10y−2y)提升精度；可加公司债情绪 + 领先指标。

### 1.4 GDELT → 宏观 NLP（新闻情绪做预测）
- **三步流水线**（Quoniam / arXiv 2009.14281）：
  1. **关键词过滤**：GKG themes 中按经济成长/通胀主题筛；
  2. **NN 过滤**：Bi-LSTM 在 1000 篇人工标注文章上训练，进一步判相关；
  3. **聚合**：按 国家/月 聚 sentiment 分数。
- **降维**：对 GDELT 上百 sentiment 分数做 **PCA → 取前 3 主成分**，喂入 AR(3) 基线 + 控制变量（**IP 模型直接用 BDI + 原油**；CPI 用贸易条件 + 原油）。
- **效果**：CPI 模型 10 国中 8–9 国优于基准；IP 8/10；每国至少一个显著 GDELT 因子。
- **严谨性警示**（文献共识）：需严格统计检验、谨慎误差指标；**采样不稳定、关键词敏感**；GDELT 非天然金融数据，须手工选经济主题。

### 1.5 数据平台纪律（FRED/ALFRED/Macrobond/FXMacroData）
- **数据层 ≠ 计算层**；ALFRED 带修订 vintage，支撑诚实回测。
- **FXMacroData 启示**：专为 **AI Agent 工作流**提供"干净官方宏观数据层"（CPI→EUR/USD、payrolls→USD/JPY）——与 macro-scan（AI 推演系统）**同构**，值得借鉴"面向 agent 的干净数据层"抽象。

## 三、哪些是「廉价即时借用」（不依赖 P0 修复、不依赖新数据源）

> 用户定调"先不修"，但下面的借用**纯属新增分析层、不碰现有损坏文件**，可在不修 prior.yaml 的前提下独立点亮财经线——供你判断"即便暂不修 P0，也能先拿到财经价值"。

1. **L1 市场价格 FCI（M1）**——**最高性价比**。输入 = 你**已经在抓却闲置**的 FX/加密/商品/BDI + 已在用的 FRED 利差/VIX。GDELT→IP 文献**恰好用 BDI+原油作控制变量**，等于 idle 数据就是最佳原料。成本低（PCA/DFM 几十行）、零新源、绕开 prior.yaml。
2. **L3 收益率曲线 probit（M3）**——**最廉价**。T10Y2Y 已在 regime，几行代码出 12 月衰退概率 + 阈值，AUC 0.85+。即便只做这一条，财经早期预警即具雏形。
3. 二者叠加 = "市场价格强度（FCI）+ 衰退概率（probit）"双信号，直接补上"宏观满血、市场全暗"的暗区。

## 四、实施顺序建议（待决策，未实施）

```
阶段 A（独立、不依赖 P0）：L1 FCI（M1+M5） → L3 probit（M3） → L0 vintage（M6+M7）
阶段 B（依赖 P0 修复）：修 prior.yaml → 天璇消费 L1-L3 → 全局概率区间（M8）
阶段 C（深化）：L2 DFM+新闻分解（M2） → L5 GDELT 三步+PCA（M4）
```

- 阶段 A 是"先不修也能拿到的财经价值"，与用户"先不修"定调兼容；阶段 B/C 是规划闭环。
- 全部依定调暂不实施；唯一零架构风险、可立即修的仍是 **P0 prior.yaml**（见问题清单第二节）。
