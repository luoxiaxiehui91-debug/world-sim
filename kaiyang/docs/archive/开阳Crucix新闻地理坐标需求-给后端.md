## 一、需求背景

开阳目前有两类数据可以上 3D 地球画告警柱：

| 类型 | 数据来源 | 有坐标？ | 上地球？ |
|------|----------|:---:|:---:|
| 气候/灾害事件 | `grv_latest.json` → `events[]`（含 lat/lng） | ✅ | ✅ |
| Crucix 新闻事件 | `news_export.json` → Crucix 条目 | ❌ | ❌ |

Crucix 新闻（"地缘升级""衰退信号""能源政治"等）目前只在新闻面板以文字卡片展示，**不出现在地球上**。开阳希望让 Crucix 的关键新闻事件也能像气候灾害一样，在对应地理位置画出告警柱。

---

## 二、需要后端做什么

在 `news_export.json` 的 **Crucix 新闻条目**中新增两个**可选**字段：`lat` / `lng`。

### 当前格式（示例）

```json
{
  "date": "2026-06-28",
  "source": "Crucix新闻",
  "indicator": "关键词：地缘升级",
  "level": "[警报]",
  "current": 1.29,
  "baseline": 0.1,
  "ratio": 12.9,
  "title": "关键词：地缘升级",
  "category": "[警报]",
  "alert_type": "WARNING",
  "trigger_titles": ["伊朗和伊拉克外长...", "乌军袭击俄境内..."]
}
```

### 期望格式（加 lat/lng）

```json
{
  "date": "2026-06-28",
  "source": "Crucix新闻",
  "indicator": "关键词：地缘升级",
  "level": "[警报]",
  "lat": 33.2,         // ← 新增（可选，有则上地球）
  "lng": 44.4,         // ← 新增（可选，有则上地球）
  "current": 1.29,
  "baseline": 0.1,
  "ratio": 12.9,
  "title": "关键词：地缘升级",
  "category": "[警报]",
  "alert_type": "WARNING",
  "trigger_titles": [...]
}
```

## 三、坐标怎么定？（由后端决定，以下是建议选项）

### 方案 A：关键词 → 地区映射表（推荐）

后端维护一个映射表，由关键词自动分配坐标。有坐标的条目上地球，没有的继续走纯文字卡片。

| 关键词 | 对应地区 | lat | lng |
|--------|----------|-----|-----|
| 地缘升级 | 中东（巴格达） | 33.2 | 44.4 |
| 能源政治 | 波斯湾 | 26.5 | 50.5 |
| 衰退信号 | 全球/无坐标 | — | — |
| 文化贸易摩擦 | 无坐标 | — | — |

### 方案 B：由 Crucix 引擎在生成条目时直接注入坐标

如果 Crucix 引擎在生成新闻时已经能定位到具体事件发生地（如从 GDELT 文章中提取 Actor1Geo_Lat/Actor1Geo_Long），直接写入 lat/lng 最准。

### 方案 C：不区分，全部不给坐标

如果认为 Crucix 新闻不适合画在地球上（因为是关键词聚合而非单一地点事件），完全不加 lat/lng 也可以——开阳会继续只在新闻面板展示。

---

## 四、开阳侧的对应改动（仅描述，不阻塞后端）

如果条目带了 lat/lng，开阳会将其映射为事件告警柱：

- `type: 'crucix_alert'`（区别于 `climate` / `disaster`）
- 用另一种颜色（如橙/金色），区别于气候（蓝）和灾害（红）
- tooltip 显示关键词 + level + ratio
- 无坐标的条目保持现状，走 NewsPanel 文字卡片
- **不需要新 feed**，不需要新端点，不改变现有文件结构

工作量约 25 行代码。

## 五、需要确认的问题

| # | 问题 | 建议 |
|---|---|---|
| 1 | Crucix 新闻适不适合画在地球上？（关键词聚合 ≠ 单点事件） | 你们判断——如果适合就加 lat/lng，不适合就保持纯文字 |
| 2 | 如果适合，按方案 A（映射表）还是方案 B（引擎直出）？ | 方案 A 最简单，方案 B 最准 |
| 3 | 是否有 Crucix 条目的 `current`/`ratio` 值可用来决定柱的高度？ | 目前 climate/disaster 用 `value`(0-100)，crucix 建议用 `ratio` 或 `current` 归一化 |
| 4 | 是否所有 Crucix 条目都需要坐标，还是只挑"警报"级别？ | 建议只给 [警报] 级别加坐标，[注意]/[提示] 走文字即可 |
